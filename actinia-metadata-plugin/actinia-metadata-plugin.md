# actinia-metadata-plugin

> 标签: Python

## 简介

A (RESTFUL) Flask application which to communicate with a metadata catalog via OGC-CSW, in usage with GeoNetwork opensource.

- 官网：https://github.com/mundialis/actinia-metadata-plugin
