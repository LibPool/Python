# Adafruit-WS2801

> 标签: Python

## 简介

Python code to control WS2801 and similar SPI interface addressable RGB LED strips on a Raspberry Pi & BeagleBone Black.

## 官网

- 官网：https://github.com/adafruit/Adafruit_Python_WS2801/
- PyPI 项目页：https://pypi.org/project/Adafruit-WS2801/
