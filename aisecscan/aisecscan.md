# aisecscan

> 标签: Python

## 简介

Static security scanner for Claude Code configs (.claude/, .mcp.json, CLAUDE.md), MCP servers, subagents, and skills. Cursor, Copilot, Windsurf, Cline, LLM app-code, and AI supply-chain checks are on the roadmap.
