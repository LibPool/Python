# ark-oauth-client

> 标签: Python

## 简介

The OAuth 2.1 / OpenID Connect client for Python applications, built for Ark.oAuth.Oidc. Authorization code + PKCE with state, nonce, iss and at_hash checks, JWKS rotation, silent refresh, client credentials, the device grant, PAR, introspection, revocation, dynamic client registration and RP-initiated logout - plus a Flask integration for interactive sign-in, for protecting an API, and for account switching on a shared browser.
