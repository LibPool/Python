# actuisense

> 标签: Python

## 简介

Cross-platform terminal UI to configure Actisense NMEA 2000 gateways (NGT-1/NGW-1/NGX-1) over serial or TCP

- 官网：https://github.com/phobicdotno/actuisense
- PyPI 项目页：https://pypi.org/project/actuisense/
