# ammonkey

> 标签: Python

## 简介

A package for organizing, processing and performing markerless 3D tracking on primate behavior videos using DeepLabCut, Anipose, with a user-friendly GUI.

## 官网

- 官网：https://github.com/melokeo/AmbiguousMonkey
