# arxiv-translate

> 标签: Python

## 简介

arXiv 论文翻译工具 - 将英文 LaTeX 论文翻译成中文，保留数学公式和文档结构

## 官网

- 官网：https://github.com/zcyisiee/arxiv-translate
- PyPI 项目页：https://pypi.org/project/arxiv-translate/

## 历史版本号

- 当前版本：1.3.0.post4

- 1.3.0.post4

## 获取地址

- pip 安装：`pip install arxiv-translate`
- 下载页面：https://pypi.org/project/arxiv-translate/#files
- 运行要求：Python >=3.10
