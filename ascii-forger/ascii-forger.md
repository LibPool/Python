# ascii-forger

> 标签: Python

## 简介

Convert images into ASCII art — terminal, color, braille, HTML export, image export (PNG/JPEG/SVG), custom char ramp, and invert mode.

- 官网：https://github.com/ArshSharan/Ascii-Forge
