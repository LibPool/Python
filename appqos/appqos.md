# appqos

> 标签: Python

## 简介

App QoS is a software created to demonstrate the use of Intel(R) RDT technologies (CAT, MBA) to improve QoS for applications via partitioning system resources.

## 官网

- 官网：https://github.com/intel/intel-cmt-cat
- PyPI 项目页：https://pypi.org/project/appqos/
