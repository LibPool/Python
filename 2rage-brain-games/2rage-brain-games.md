# 2rage-brain-games

> 标签: Python

## 简介

2rage-brain-games is a set of console-based brain games built in Python. Each game provides a different mental challenge, ranging from calculations and number theory to recognition of even numbers. The project includes games like 'brain-even', 'brain-calc', 'brain-gcd', 'brain-progression', and 'brain-prime'. Test your mental agility and have fun with this collection of games!
