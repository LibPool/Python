# attenu-guard

> 标签: Python

## 简介

Attenu Guard: enforces per-agent permissions on every tool call and sub-agent handoff — a sub-agent never holds more than its parent — and writes a hash-chained audit log you verify offline. 19 agent frameworks and the A2A protocol, unmodified.
