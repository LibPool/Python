# alphaessopenapi

> 标签: Python

## 简介

A python library to retrieve energy statistics from your Alpha ESS inverter by polling the Official Alpha ESS Open API.

## 官网

- 官网：https://github.com/CharlesGillanders/alphaess-openAPI
- PyPI 项目页：https://pypi.org/project/alphaessopenapi/
