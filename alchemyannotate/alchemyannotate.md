# alchemyannotate

> 标签: Python

## 简介

Lightweight desktop image annotation tool for bounding box and polygon labeling with YOLO, Pascal VOC, and COCO export

## 官网

- 官网：https://github.com/kouya-marino/AlchemyAnnotate
- PyPI 项目页：https://pypi.org/project/alchemyannotate/

- 下载页面：https://pypi.org/project/alchemyannotate/#files
