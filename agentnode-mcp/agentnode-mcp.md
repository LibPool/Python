# agentnode-mcp

> 标签: Python

## 简介

MCP server adapter for AgentNode — expose AgentNode packs as MCP tools for OpenClaw, Claude Code, Cursor, and other MCP clients.

## 官网

- 官网：https://pypi.org/project/agentnode-mcp/
- PyPI 项目页：https://pypi.org/project/agentnode-mcp/

- 下载页面：https://pypi.org/project/agentnode-mcp/#files
