# amazon-trends-agent

> 标签: Python

## 简介

Amazon product search volume as a ready-made tool for LangChain, CrewAI, AutoGen, and any tool-calling AI agent. Search volume, growth signals, and live best sellers. No Amazon API key. Powered by trendsmcp.ai
