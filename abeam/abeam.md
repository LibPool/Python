# abeam

> 标签: Python

## 简介

One window for an AI coding session on Windows or Linux: your agent hosted in a pty pane, with git, a file viewer and a shell beside it. Built on Claude Code; OpenAI Codex CLI has had a signed-out smoke test, and GitHub Copilot CLI and the hailer data agent are supported but not yet exercised.
