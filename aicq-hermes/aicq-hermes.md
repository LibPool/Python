# aicq-hermes

> 标签: Python

## 简介

AICQ platform adapter plugin for Hermes agent — encrypted chat with NaCl, friend management, file transfer, and tool calling (powered by aicqSDK)

## 官网

- 官网：https://aicq.me
- 源码仓库：https://github.com/samaidev/pluginAICQ
