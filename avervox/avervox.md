# avervox

> 标签: Python

## 简介

Alias package for AverVOX. The real package is avrvx; installing this pulls it in so `pip install avervox` works.

## 官网

- 官网：https://github.com/avrvx/AverVOX-OSS
- PyPI 项目页：https://pypi.org/project/avervox/

## 历史版本号

- 0.5.5

## 获取地址

- pip 安装：`pip install avervox`
- 下载页面：https://pypi.org/project/avervox/#files
- 运行要求：Python >=3.12
