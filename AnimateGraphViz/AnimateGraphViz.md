# AnimateGraphViz

> 标签: Python

## 简介

A tool to create animated graph visualizations, based on graphviz, based on legacy source code of gvanim - Massimo Santini

## 官网

- 官网：https://github.com/tranduythanh/GraphvizAnim
- PyPI 项目页：https://pypi.org/project/AnimateGraphViz/
