# any2heliosdb

> 标签: Python

## 简介

Migrate Oracle / MySQL / PostgreSQL / SQL Server into HeliosDB or stock PostgreSQL — a modern, Python successor to Ora2Pg.

- 官网：https://github.com/HeliosDatabase/Any2HeliosDB
