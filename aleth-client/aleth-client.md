# aleth-client

> 标签: Python

## 简介

Thin, standalone Python client for the Aleth memory engine over the frozen local wire (MEM-SDK, ROADMAP ch.161). Depends only on pydantic.

## 官网

- 官网：https://aleth.ai
- PyPI 项目页：https://pypi.org/project/aleth-client/
