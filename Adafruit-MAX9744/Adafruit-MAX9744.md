# Adafruit-MAX9744

> 标签: Python

## 简介

Library for controlling the MAX9744 class D amplifier with I2C volume control on a Raspberry Pi or Beaglebone Black.

## 官网

- 官网：https://github.com/adafruit/Adafruit_Python_MAX9744/
- PyPI 项目页：https://pypi.org/project/Adafruit-MAX9744/
