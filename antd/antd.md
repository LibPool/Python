# antd

> 标签: Python

## 简介

Python client for the antd daemon: store and fetch data on the Autonomi network over REST or gRPC (not the Ant Design UI library)

## 官网

- 官网：https://autonomi.com
- 源码仓库：https://github.com/WithAutonomi/ant-sdk
- PyPI 项目页：https://pypi.org/project/antd/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install antd`
- 下载页面：https://pypi.org/project/antd/#files
- 运行要求：Python >=3.10
