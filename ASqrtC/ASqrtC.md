# ASqrtC

> 标签: Python

## 简介

ASqrtC is a fast square root calculator with 100% accuracy. It delivers exact results to any specified number of decimal places. ASqrtC outperforms Python’s built-in math and decimal modules in speed when calculating less then ~5000 decimal places.
