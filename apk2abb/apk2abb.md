# apk2abb

> 标签: Python

## 简介

Convert Android APK files to AAB (Android App Bundle) for Google Play Store

## 官网

- 官网：https://github.com/nithin434/apk2abb
- PyPI 项目页：https://pypi.org/project/apk2abb/

- pip 安装：`pip install apk2abb`
- 下载页面：https://pypi.org/project/apk2abb/#files
- 运行要求：Python >=3.7
