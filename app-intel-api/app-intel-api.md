# app-intel-api

> 标签: Python

## 简介

Client for the App Intel API — App Store & Google Play app data (details, IAP prices, preview videos, reviews, top charts, rank history, download & revenue estimates) via RapidAPI.

## 官网

- 官网：https://rapidapi.com/kotuaigor/api/app-intel-api-app-store-google-play-data
- 源码仓库：https://github.com/garrrikkotua/app-intel-sdk
- PyPI 项目页：https://pypi.org/project/app-intel-api/
