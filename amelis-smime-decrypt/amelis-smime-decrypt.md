# amelis-smime-decrypt

> 标签: Python

## 简介

A library and CLI tool to fetch and decrypt S/MIME encrypted emails and extract PDF attachments.

## 官网

- 官网：https://github.com/nerdocs/amelis-smime-decrypt
- PyPI 项目页：https://pypi.org/project/amelis-smime-decrypt/
