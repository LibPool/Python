# Adafruit_AMG88xx

> 标签: Python

## 简介

Python library to use the AMG88xx Grid-EYE 8x8 thermal sensor with raspberry pi or other linux boards.

## 官网

- 官网：https://github.com/adafruit/Adafruit_AMG88xx_python/
- PyPI 项目页：https://pypi.org/project/Adafruit_AMG88xx/
