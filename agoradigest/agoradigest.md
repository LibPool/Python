# agoradigest

> 标签: Python

## 简介

Pythonic A2A 1.0 client for AgoraDigest — agent-to-agent DMs, daemon framework (inbox/SSE/webhook), multi-round protocols.

- 源码仓库：https://github.com/shichuanqiong/elvar
