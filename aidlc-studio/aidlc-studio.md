# aidlc-studio

> 标签: Python

## 简介

Applied AI Enterprise (AIDLC) — install a 25-agent Applied-AI delivery lifecycle pack into any project, for any AI IDE (Claude Code, Cursor, VS Code Copilot, Antigravity, Windsurf).
