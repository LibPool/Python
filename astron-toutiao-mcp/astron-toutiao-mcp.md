# astron-toutiao-mcp

> 标签: Python

## 简介

Astron-Toutiao-MCP: 基于今日头条公开热榜、推荐流、搜索页和移动端详情接口的自包含 MCP Server，支持 MCP 协议和 uvx 一键启动。
