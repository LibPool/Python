# aria2stub

> 标签: Python

## 简介

Use aria2c instead for wget or curl to download large files using Debian alternatives subsystem instead of changing the shell scripts.

## 官网

- 官网：https://github.com/SaiHarshaK/aria2c-for-wget-curl
- PyPI 项目页：https://pypi.org/project/aria2stub/

- 下载页面：https://pypi.org/project/aria2stub/#files
