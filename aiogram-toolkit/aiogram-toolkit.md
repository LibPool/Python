# aiogram-toolkit

> 标签: Python

## 简介

A compact utility library extending Aiogram with ready-to-use helpers for everyday bot development. It includes safe callback data unpacking, deep link generation, long message handling, markdown formatting, pagination, and optional async SQLAlchemy session helpers. Designed for clean, modular, and production-grade Telegram bot architecture.
