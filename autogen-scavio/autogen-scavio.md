# autogen-scavio

> 标签: Python

## 简介

AutoGen integration for the Scavio API -- 188 real-time data tools across 31 platforms (Google, Amazon, Walmart, eBay, Target, Home Depot, Zillow, Redfin, Booking, Airbnb, Tripadvisor, Yelp, Indeed, Glassdoor, G2, Capterra, App Store, Google Play, SEC EDGAR, Companies House, Google Ads, Meta Ad Library, YouTube, TikTok, TikTok Shop, Instagram, Threads, Kuaishou, X, LinkedIn, Reddit) plus extract, which reads any URL as clean Markdown
