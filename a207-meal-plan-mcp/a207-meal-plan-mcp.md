# a207-meal-plan-mcp

> 标签: Python

## 简介

儿童 CKD 食谱生成 MCP（M7）：按 PRNT 目标生成多日食谱（3 餐 + 加餐）并算达成率。营养师可调；自带 CKD 适宜食物子集，生产环境应改调 M5 食物库。
