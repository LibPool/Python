# arcis

> 标签: Python

## 简介

Inside-the-app security middleware for Python. FastAPI, Django, and Litestar run the full sanitizer pipeline (XSS, SQL, NoSQL, path, command, SSTI, XXE, LDAP, XPath, header, prototype); Flask is sanitize-only. Bot detection, scanner and per-IP correlation, SSRF body checks, mass-assignment detection, GraphQL limits, and prompt-injection screening run by default. Same API as the Node and Go SDKs. CLI: npm install -g @arcis/cli.
