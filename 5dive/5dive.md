# 5dive

> 标签: Python

## 简介

Python client for the 5dive CLI — read the task queue, agents and org chart of a 5dive box.

## 官网

- 官网：https://5dive.ai
- 源码仓库：https://github.com/5dive-ai/5dive
- PyPI 项目页：https://pypi.org/project/5dive/
