# andreax-sdk

> 标签: Python

## 简介

Pure Python client (no LangChain) for Andreax's pay-per-call x402 AI tools (USDC on Base, EIP-3009 autopay).

- 官网：https://andreax.dev
- PyPI 项目页：https://pypi.org/project/andreax-sdk/

- 下载页面：https://pypi.org/project/andreax-sdk/#files
