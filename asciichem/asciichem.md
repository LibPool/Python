# asciichem

> 标签: Python

## 简介

Python implementation of AsciiChem - parse ASCII chemistry into a semantic model; canonical text and wire JSON. Conformant with asciichem-model v1 and the asciichem-tests corpus.

## 官网

- 官网：https://asciichem.org
- 源码仓库：https://github.com/asciichem/asciichem-py
- PyPI 项目页：https://pypi.org/project/asciichem/
