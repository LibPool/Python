# AcaHtml2Md

> 标签: Python

## 简介

将HTML格式的学术论文转化Markdown文档，方便与AI交互和编辑。转换内容包括：标题、段落、公式（MathML转为LaTex）、图片、表格（支持合并单元格的处理）、列表等。
