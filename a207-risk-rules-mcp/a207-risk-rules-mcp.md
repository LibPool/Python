# a207-risk-rules-mcp

> 标签: Python

## 简介

儿童 CKD 风险规则引擎 MCP（M8）：基于本轮新化验/人体测量/分期重评风险，命中规则库并分级 L1/L2/L3。系统重评、医生/风险预警可读。核心范式 level_correction：新数据驱动重评，历史等级仅作对比不兜底。
