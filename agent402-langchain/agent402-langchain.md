# agent402-langchain

> 标签: Python

## 简介

Agentic Finance (AIFI): turn Agent402's catalog - 500+ strong: 400+ pay-per-call tools (x402 or MPP) + 100+ skill packs - into LangChain and CrewAI tools for Python agents. Free tier via proof-of-work - no wallet, no API keys.
