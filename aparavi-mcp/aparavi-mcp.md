# aparavi-mcp

> 标签: Python

## 简介

Aparavi MCP stdio server that streams local files to Aparavi EaaS

## 官网

- 官网：https://aparavi.com
- 源码仓库：https://github.com/aparavi/aparavi-clients
- PyPI 项目页：https://pypi.org/project/aparavi-mcp/

- 下载页面：https://pypi.org/project/aparavi-mcp/#files
- 运行要求：Python >=3.10
