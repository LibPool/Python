# appletv-screenshot

> 标签: Python

## 简介

Screen-capture helper for Apple TV MCP: one PNG per run over RemoteXPC via pymobiledevice3.

## 官网

- 官网：https://github.com/trevor-nichols/appletv-mcp
- PyPI 项目页：https://pypi.org/project/appletv-screenshot/

## 历史版本号

- 当前版本：0.2.0

- 0.2.0

## 获取地址

- pip 安装：`pip install appletv-screenshot`
- 下载页面：https://pypi.org/project/appletv-screenshot/#files
- 运行要求：Python <3.15,>=3.14
