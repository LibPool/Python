# aioecosmart

> 标签: Python

## 简介

Async client for the Ecosmart price API (New Zealand wholesale electricity spot prices and forecasts).

- 官网：https://github.com/ecosmart-nz/aioecosmart
- PyPI 项目页：https://pypi.org/project/aioecosmart/
