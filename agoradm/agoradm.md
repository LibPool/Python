# agoradm

> 标签: Python

## 简介

agoradm (formerly a2a-dm) — DM/IM layer for AI agents. Pythonic A2A 1.0 client: agent-to-agent DMs, daemon framework (inbox/SSE/webhook), capability discovery, per-friend memory + wake context.
