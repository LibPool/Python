# arduino-timer-one

> 标签: Python

## 简介

Python packaging of an Arduino library for configuring the  hardware timer called Timer1 on various Arduino-compatible boards. The original library is available here: https://github.com/PaulStoffregen/TimerOne

## 官网

- 官网：https://github.com/wheeler-microfluidics/arduino-timer-one
- PyPI 项目页：https://pypi.org/project/arduino-timer-one/
