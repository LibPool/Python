# apk2aab

> 标签: Python

## 简介

Convert Android APK files to AAB (Android App Bundle) for Google Play Store

## 官网

- 官网：https://github.com/nithinjambula/apk2aab
- PyPI 项目页：https://pypi.org/project/apk2aab/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install apk2aab`
- 下载页面：https://pypi.org/project/apk2aab/#files
- 运行要求：Python >=3.7
