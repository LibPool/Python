# any2pdf

> 标签: Python

## 简介

Convert PPTS, IMAGES [JPG, PNG, WEBP, TIFF], HTML, TXT, MD type to PDF

## 官网

- 官网：https://github.com/intelkid7/any2pdf
- PyPI 项目页：https://pypi.org/project/any2pdf/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install any2pdf`
- 下载页面：https://pypi.org/project/any2pdf/#files
- 运行要求：Python >=3.8
