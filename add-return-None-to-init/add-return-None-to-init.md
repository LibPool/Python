# add-return-None-to-init

> 标签: Python

## 简介

Script to add None as return type to every __init__ in the codebase.

## 官网

- 官网：https://github.com/soraxas/py-return-None-for-__init__
- PyPI 项目页：https://pypi.org/project/add-return-None-to-init/

- 下载页面：https://pypi.org/project/add-return-None-to-init/#files
