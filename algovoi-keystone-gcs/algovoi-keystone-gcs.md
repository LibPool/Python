# algovoi-keystone-gcs

> 标签: Python

## 简介

Bind Google Cloud Storage object writes to the AlgoVoi keystone -- wrap any GCS blob and every upload / delete gets a content-addressed execution_ref (keystone-only edition, Apache-2.0)
