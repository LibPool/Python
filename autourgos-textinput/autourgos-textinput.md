# autourgos-textinput

> 标签: Python

## 简介

Global-hotkey-triggered Tkinter popup text input for the Autourgos framework -- press a shortcut, type, and hand the text to an agent.

## 官网

- 官网：https://github.com/devxjitin/autourgos-textinput
- PyPI 项目页：https://pypi.org/project/autourgos-textinput/
