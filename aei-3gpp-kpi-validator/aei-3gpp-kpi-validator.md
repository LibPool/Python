# aei-3gpp-kpi-validator

> 标签: Python

## 简介

A dependency-light Python validator for real 3GPP-standard telecom KPIs (RSRP, RSRQ, SINR, handover quality, NB-IoT power) - cites the actual TS specs, and states plainly what it does not implement.
