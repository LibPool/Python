# autolecture

> 标签: Python

## 简介

Official Python SDK for AutoLecture (https://autolecture.ai). Generate explainer videos from script or audio via a clean HTTP client.

## 官网

- 官网：https://autolecture.ai
- 源码仓库：https://github.com/scao7/autolecture-python
- PyPI 项目页：https://pypi.org/project/autolecture/
