# audio-to-text-cli

> 标签: Python

## 简介

音频下载 + 语音转文字 CLI 工具，支持 B站/YouTube 等视频平台及直链音频，中文简繁体可选

## 官网

- 官网：https://github.com/afuaide/audio-to-text-cli
- PyPI 项目页：https://pypi.org/project/audio-to-text-cli/

## 历史版本号

- 当前版本：1.0.1

- 1.0.1

## 获取地址

- pip 安装：`pip install audio-to-text-cli`
- 下载页面：https://pypi.org/project/audio-to-text-cli/#files
- 运行要求：Python <3.14,>=3.10
