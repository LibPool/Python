# aethyn-proxy

> 标签: Python

## 简介

Alias for `proxy-builder-sdk` — the Aethyn-first, multi-provider proxy SDK. Installs proxy-builder-sdk and re-exports it, so `import aethyn_proxy` keeps working.

## 官网

- 官网：https://www.aethyn.io
- 源码仓库：https://github.com/aethynio/proxy-builder-sdk-python
- PyPI 项目页：https://pypi.org/project/aethyn-proxy/
