# actor-debugger

> 标签: Python

## 简介

Drop-in remote debugging for Apify Python Actors: debugpy plus a browser debugger UI served over the run's container URL.

## 官网

- 官网：https://github.com/apify/actor-debugger/tree/master/python#readme
- 源码仓库：https://github.com/apify/actor-debugger
