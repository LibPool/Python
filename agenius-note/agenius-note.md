# agenius-note

> 标签: Python

## 简介

AgeniusNote: voice-first scratchpad with local speech-to-text, optional AI parsing, quick todos, custom wake words. Cross-platform desktop app.

- 官网：https://github.com/Agenius-AI-Labs/agenius-note
