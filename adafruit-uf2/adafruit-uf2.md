# adafruit-uf2

> 标签: Python

## 简介

Utilities for converting between USB Flashing Format (UF2) files and other firmware formats

- 官网：https://github.com/adafruit/uf2
- PyPI 项目页：https://pypi.org/project/adafruit-uf2/

- 下载页面：https://pypi.org/project/adafruit-uf2/#files
- 运行要求：Python >=3.7
