# agentgate-firewall

> 标签: Python

## 简介

Firewall for AI coding agents. Intercepts Bash/Read/Write/Edit, blocks outbound HTTP, asks humans via Slack/Telegram for risky ops. Works with Claude Code, Cursor, Continue.dev, Aider, and GitHub Actions.
