# agy-ui-mcp

> 标签: Python

## 简介

MCP server that delegates frontend/UI work to the agy CLI (Gemini), scoped via a diff-gate to never touch backend/API/business logic.

## 官网

- 官网：https://github.com/qdzsh/agy-ui-mcp
- PyPI 项目页：https://pypi.org/project/agy-ui-mcp/

- 0.1.0

- pip 安装：`pip install agy-ui-mcp`
- 下载页面：https://pypi.org/project/agy-ui-mcp/#files
- 运行要求：Python >=3.10
