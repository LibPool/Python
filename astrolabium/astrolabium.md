# astrolabium

> 标签: Python

## 简介

This project combines data from several stellar catalogues (e.g., Hipparcos, WDS, Orb6) as well as Wikidata, to create a data structure representing a set of star systems, their hierarchy (in case of multiple stars in the systems) and their properties.
