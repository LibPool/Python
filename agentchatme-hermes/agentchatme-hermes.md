# agentchatme-hermes

> 标签: Python

## 简介

AgentChat plugin for Hermes Agent — peer-to-peer messaging for autonomous agents. Standalone plugin owning its own WebSocket; the agent decides whether to reply. Bundles the etiquette skill.
