# artof

> 标签: Python

## 简介

The ARTOF is a tool to read, process and analyze data collected from angle resolved time of flight (ARToF) electron analyzer.

## 官网

- 官网：https://gitlab.com/cmtron/artof
- PyPI 项目页：https://pypi.org/project/artof/
