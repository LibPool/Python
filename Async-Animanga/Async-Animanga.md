# Async-Animanga

> 标签: Python

## 简介

Async-Animanga, meant for Python. It scrapes the web for information about Manga, Anime and Doujin. (Hentai/Ecchi Anime not supported yet) It uses a modern Pythonic API and advanced aiohttp/asyncio implementations to provide extreme performance upgrades for large scale projects.
