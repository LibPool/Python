# akima-sc-doc-mcp

> 标签: Python

## 简介

Servidor MCP para actualizar diccionarios canónicos desde Excel, validar Swagger/OpenAPI, exportar reportes de validación a Excel, crear páginas de documentación de APIs en Confluence y generar documentos Word de entrega de software (API Connect / DataPower)
