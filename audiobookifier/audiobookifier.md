# audiobookifier

> 标签: Python

## 简介

Convert EPUB and MOBI/AZW files to M4B audiobooks using Microsoft Edge TTS

- 官网：https://github.com/loganrooks/audiobookify
- 源码仓库：https://github.com/loganrooks/audiobookify.git
- PyPI 项目页：https://pypi.org/project/audiobookifier/
