# arrey

> 标签: Python

## 简介

It adds a class named `Arrey` to your Python code. This class acts like a 2D data map (or 2D dictionary):You can write data to—or retrieve existing data from—any desired x,y location using just a single function! It is perfect for those who find NumPy too complicated.
