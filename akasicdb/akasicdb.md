# akasicdb

> 标签: Python

## 简介

Python client library for AkasicDB, a Vector-Graph-Relational DBMS based on PostgreSQL

## 官网

- 官网：https://pypi.org/project/akasicdb/
- PyPI 项目页：https://pypi.org/project/akasicdb/

- 1.0.0

- pip 安装：`pip install akasicdb`
- 下载页面：https://pypi.org/project/akasicdb/#files
- 运行要求：Python >=3.11
