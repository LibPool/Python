# lxml

> 标签: HTML, XML, 解析

## 简介

Powerful and Pythonic XML processing library combining libxml2/libxslt with the ElementTree API.

## 官网

- 官网：https://lxml.de/
- 源码仓库：https://github.com/lxml/lxml
- PyPI 项目页：https://pypi.org/project/lxml/
