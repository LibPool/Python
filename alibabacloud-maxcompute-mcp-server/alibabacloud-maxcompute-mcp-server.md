# alibabacloud-maxcompute-mcp-server

> 标签: Python

## 简介

MCP (Model Context Protocol) server for Alibaba Cloud MaxCompute — list projects/schemas/tables, search metadata, execute SQL, and manage instances via Catalog API and PyODPS.
