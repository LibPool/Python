# antdb

> 标签: Python

## 简介

Python library for managing fake databases, in memory, so you no longer need to create lists to store data.

## 官网

- 官网：https://pypi.org/project/antdb/
- PyPI 项目页：https://pypi.org/project/antdb/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install antdb`
- 下载页面：https://pypi.org/project/antdb/#files
- 运行要求：Python >=3.13
