# argus-diff

> 标签: Python

## 简介

Geometric diff for mechanical CAD: structured, rendered, CI-gateable diffs of STEP files. git diff for atoms.

## 官网

- 官网：https://argusdiff.com
- PyPI 项目页：https://pypi.org/project/argus-diff/
