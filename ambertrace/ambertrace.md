# ambertrace

> 标签: Python

## 简介

Python SDK for tracing LLM calls (OpenAI, Anthropic, Google Gemini) to AmberTrace observability platform

## 官网

- 官网：https://ambertrace.dev
- 源码仓库：https://github.com/ambertrace/ambertrace-sdk
- PyPI 项目页：https://pypi.org/project/ambertrace/

- 下载页面：https://pypi.org/project/ambertrace/#files
