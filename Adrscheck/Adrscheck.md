# Adrscheck

> 标签: Python

## 简介

This Library is a Python package designed to provide a comprehensive dataset of all addresses within the city of Mysore. It allows users to efficiently store, search, and validate addresses using a structured database. The package supports querying addresses by locality, street, pincode, and landmarks, and is designed to be easily extendable for additional features like geospatial queries or classification.
