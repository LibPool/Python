# Adafruit-ADS1x15

> 标签: Python

## 简介

Python code to use the ADS1015 and ADS1115 analog to digital converters with a Raspberry Pi or BeagleBone black.

## 官网

- 官网：https://github.com/adafruit/Adafruit_Python_ADS1x15/
- PyPI 项目页：https://pypi.org/project/Adafruit-ADS1x15/
