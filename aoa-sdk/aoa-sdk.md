# aoa-sdk

> 标签: Python

## 简介

Official Python SDK for the AOA public API: venues, table bookings, events, tickets, checkout and webhooks in Ukraine.

## 官网

- 官网：https://aoa.com.ua/docs
- 源码仓库：https://github.com/aoa-ua/aoa-agent-kit
- PyPI 项目页：https://pypi.org/project/aoa-sdk/

- 下载页面：https://pypi.org/project/aoa-sdk/#files
