# auto-faulthandler

> 标签: Python

## 简介

Automatically enable Python's faulthandler for extension development.

- 官网：https://github.com/mrexodia/auto-faulthandler
- PyPI 项目页：https://pypi.org/project/auto-faulthandler/

- 下载页面：https://pypi.org/project/auto-faulthandler/#files
- 运行要求：Python >=3.7
