# aliyun-ecs-vnc

> 标签: Python

## 简介

A local relay that bridges Alibaba Cloud ECS VNC (RFB over WebSocket) to any VNC client over plain TCP

## 官网

- 官网：https://github.com/Moha-Master/Aliyun-ECS-VNC
- PyPI 项目页：https://pypi.org/project/aliyun-ecs-vnc/
