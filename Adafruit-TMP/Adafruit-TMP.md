# Adafruit-TMP

> 标签: Python

## 简介

Library for accessing the TMP006 & TMP007  non-contact temperature sensor on a Raspberry Pi or Beaglebone Black.

## 官网

- 官网：https://github.com/adafruit/Adafruit_Python_TMP/
- PyPI 项目页：https://pypi.org/project/Adafruit-TMP/
