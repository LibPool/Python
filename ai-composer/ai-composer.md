# ai-composer

> 标签: Python

## 简介

AIComposer: a lightweight AI application development framework. Write AI apps in plain Python plus two concepts -- ctx (capability container) and mount (plugin assembly). Opt-in capability layer, not a constraint; toolchain: init/graph/template/skills
