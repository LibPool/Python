# ansible-static-lint

> 标签: Python

## 简介

A fast, offline static companion to ansible-lint, for editor-on-save, pre-commit, or a CI pre-check.

## 官网

- 官网：https://github.com/arhuman/ansible-static-lint
- PyPI 项目页：https://pypi.org/project/ansible-static-lint/

- 下载页面：https://pypi.org/project/ansible-static-lint/#files
- 运行要求：Python >=3.8
