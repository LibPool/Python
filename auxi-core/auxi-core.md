# auxi-core

> 标签: Python

## 简介

`auxi` provides tools to help users do calculations for metallurgical process engineering. `auxi-core` provides base infrastructure used by other `auxi` packages.

## 官网

- 官网：https://pypi.org/project/auxi-core/
- PyPI 项目页：https://pypi.org/project/auxi-core/
