# atlasdocs-metadata

> 标签: Python

## 简介

Syncs the atlasdocs/metadata registry (data_<CODE>.yml / stare_<CODE>.json.br, every group) and renders it via GroupMacros/GlanceMacros and table macros for atlasdocs-theme sites
