# agbcia

> 标签: Python

## 简介

Pure-Python library and CLI for injecting GBA ROMs into 3DS CIA files, with custom Home Menu icons, banners, and sound.

## 官网

- 官网：https://github.com/marco-zanella/agbcia
- PyPI 项目页：https://pypi.org/project/agbcia/
