# advisorfinder-cli

> 标签: Python

## 简介

CLI for querying SEC-registered financial advisor data from IAPD and FINRA BrokerCheck

- 官网：https://advisorfinder.com
- 源码仓库：https://github.com/drew-keever/sec-advisor-project
- PyPI 项目页：https://pypi.org/project/advisorfinder-cli/

- 下载页面：https://pypi.org/project/advisorfinder-cli/#files
- 运行要求：Python >=3.10
