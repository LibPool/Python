# adafruit-ampy-master

> 标签: Python

## 简介

Unofficial release of package ampy (Adafruit MicroPython tool), a command line tool to interact with a CircuitPython or MicroPython board over a serial connection.

## 官网

- 官网：https://github.com/damiencorpataux/ampy
- PyPI 项目页：https://pypi.org/project/adafruit-ampy-master/
