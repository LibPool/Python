# africa-speech-synth

> 标签: Python

## 简介

Generate synthetic speech datasets for African languages: source text, phoneme-coverage selection, africa-g2p normalisation, TTS synthesis, and a ready-to-train HuggingFace dataset.

## 官网

- 官网：https://github.com/AfriSpeech/africa-speech-synth
- PyPI 项目页：https://pypi.org/project/africa-speech-synth/
