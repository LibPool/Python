# aicqSDK

> 标签: Python

## 简介

AICQ AI Agent SDK — Lightweight Python SDK for AI agents to connect to AICQ server via WebSocket real-time mode (startLoop), E2EE, ephemeral rooms, QuickChat (agent-owner 1-on-1), stream output, temp numbers, and file transfer
