# aiskylagift

> 标签: Python

## 简介

An open-source Python helper library to build virtual gift configurations and e-cards for AISkyLa.

- 官网：https://aiskyla.com
- 源码仓库：https://github.com/pradeepoct/AstroRobot
- PyPI 项目页：https://pypi.org/project/aiskylagift/

- 下载页面：https://pypi.org/project/aiskylagift/#files
- 运行要求：Python >=3.6
