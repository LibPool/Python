# avito-ads

> 标签: Python

## 简介

Python SDK для публичного API кабинета Авито Реклама (Avito Ads). Синхронный и асинхронный режимы (httpx), Python 3.8+, интеграции с Django, Flask и FastAPI.

## 官网

- 官网：https://github.com/avito-tech/avito-ads-sdk-python3
- PyPI 项目页：https://pypi.org/project/avito-ads/

- 0.1.0

- 下载页面：https://pypi.org/project/avito-ads/#files
