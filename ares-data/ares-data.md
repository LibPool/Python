# ares-data

> 标签: Python

## 简介

`ares_data` je Python light weight knihovna pro snadné získávání dat o společnostech z Českého obchodního rejstříku ARES.

## 官网

- 官网：https://github.com/Newpaw/ares_data
- PyPI 项目页：https://pypi.org/project/ares-data/

## 历史版本号

- 当前版本：1.0.1

- 1.0.1

## 获取地址

- pip 安装：`pip install ares-data`
- 下载页面：https://pypi.org/project/ares-data/#files
- 运行要求：Python >=3.6
