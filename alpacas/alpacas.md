# alpacas

> 标签: Python

## 简介

Compute and plot sundials of different types and orientations; also contains some useful astronomical functions (equation of time, declination as function of date, sunset and sunrise)

- 官网：https://github.com/philipp-heinen/ALPACAS
- PyPI 项目页：https://pypi.org/project/alpacas/
