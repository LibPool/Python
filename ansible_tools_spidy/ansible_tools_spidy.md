# ansible_tools_spidy

> 标签: Python

## 简介

Store ansible inventory & playbooks in mongodb, run ansible by extracting inventory & playbooks from mongo db ; command :- /usr/local/bin/ansible_playbook ; /usr/local/bin/ansible_playbook_load ; /usr/local/bin/ansible_inventory_load ; Currently runs on only ubuntu or rhel; tests were performed on rhel systems successfully
