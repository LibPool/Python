# autourgos-core

> 标签: Python

## 简介

Stdlib-only shared utility library for the Autourgos framework -- extracted, cross-package-duplicated primitives (optional-import probing, versioning, retry/backoff, per-agent/run-scoped state, SQLite helpers). No domain knowledge, zero third-party dependencies.
