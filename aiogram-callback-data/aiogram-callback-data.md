# aiogram-callback-data

> 标签: Python

## 简介

aiogram 3 extension that lifts Telegram's 64-byte callback_data limit by storing payloads in an external storage keyed by a short hash.

## 官网

- 官网：https://github.com/kash1dd/aiogram-callback-data
- PyPI 项目页：https://pypi.org/project/aiogram-callback-data/

- 下载页面：https://pypi.org/project/aiogram-callback-data/#files
