# 3ncr

> 标签: Python

## 简介

Python implementation of the 3ncr.org v1 string encryption standard (AES-256-GCM).

## 官网

- 官网：https://3ncr.org/
- 源码仓库：https://github.com/3ncr/tokencrypt-python
- PyPI 项目页：https://pypi.org/project/3ncr/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install 3ncr`
- 下载页面：https://pypi.org/project/3ncr/#files
- 运行要求：Python >=3.9
