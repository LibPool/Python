# astrosylva

> 标签: Python

## 简介

Convert halo merger trees (Consistent-Trees, LHaloTree, SubLink, AHF) into the Galacticus HDF5 input format.

## 官网

- 官网：https://github.com/galacticusorg/astrosylva
- PyPI 项目页：https://pypi.org/project/astrosylva/
