# Adafruit-MCP9808

> 标签: Python

## 简介

Library for accessing the MCP9808 precision temperature sensor on a Raspberry Pi or Beaglebone Black.

- 官网：https://github.com/adafruit/Adafruit_Python_MCP9808/
- PyPI 项目页：https://pypi.org/project/Adafruit-MCP9808/
