# avro-to-python

> 标签: Python

## 简介

avro-to-python is a light tool for compiling avro schema files (.avsc) to python classes making using avro schemata easy.

## 官网

- 官网：https://github.com/srserves85/avro-to-python
- PyPI 项目页：https://pypi.org/project/avro-to-python/
