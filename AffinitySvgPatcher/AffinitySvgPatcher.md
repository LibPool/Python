# AffinitySvgPatcher

> 标签: Python

## 简介

A module for patching matplotlib-generated SVG files to make them work Affinity Designer.

## 官网

- 官网：https://https://github.com/LorenzoPeri17/AffinitySvgPatcher
- PyPI 项目页：https://pypi.org/project/AffinitySvgPatcher/

- 当前版本：1.0.0

- 1.0.0

- pip 安装：`pip install AffinitySvgPatcher`
- 下载页面：https://pypi.org/project/AffinitySvgPatcher/#files
- 运行要求：Python >=3.9
