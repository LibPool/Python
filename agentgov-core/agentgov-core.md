# agentgov-core

> 标签: Python

## 简介

Shared invoke-boundary core for agent-governance-demo: host adapters, entitlement/policy resolution, the governance envelope, and the registry Postgres schema. Published to PyPI via OIDC Trusted Publishing (.github/workflows/publish.yml) and installed into registry-api/workflows images.
