# altis-fipe

> 标签: Python

## 简介

Cliente oficial da Altis FIPE API — consulte a Tabela FIPE (carros, motos, caminhões) com uma chave de API.

## 官网

- 官网：https://fipe.altis.online/docs
- 源码仓库：https://github.com/altis/altisfipeapi
- PyPI 项目页：https://pypi.org/project/altis-fipe/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install altis-fipe`
- 下载页面：https://pypi.org/project/altis-fipe/#files
- 运行要求：Python >=3.8
