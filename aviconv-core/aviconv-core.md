# aviconv-core

> 标签: Python

## 简介

Shared utilities for the aviconv aviation-data converter family: coordinates, AIRAC dates, XML helpers, CLI dispatcher.

## 官网

- 官网：https://github.com/ams-mmd/aviconv
- PyPI 项目页：https://pypi.org/project/aviconv-core/
