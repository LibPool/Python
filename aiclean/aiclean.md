# aiclean

> 标签: Python

## 简介

Scan and safely clean local caches left by AI coding tools (Claude Code, Cursor, Ollama, npm/uv, HuggingFace, etc)

## 官网

- 官网：https://github.com/CodeHYY/aiclean
- PyPI 项目页：https://pypi.org/project/aiclean/

- 下载页面：https://pypi.org/project/aiclean/#files
