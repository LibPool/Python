# ardupyrpc

> 标签: Python

## 简介

Python client for an Arduino RPC bridge using MsgPack over serial.

## 官网

- 官网：https://github.com/lu-maca/pyrpc
- PyPI 项目页：https://pypi.org/project/ardupyrpc/
