# aural-features

> 标签: Python

## 简介

MERIDIAN Python package for computing a set of perceptual acoustic features chacterizing a sound as it is perceived by the human brain

## 官网

- 官网：https://gitlab.meridian.cs.dal.ca/public_projects/aural-features
- PyPI 项目页：https://pypi.org/project/aural-features/
