# arabizikit

> 标签: Python

## 简介

Open-source Arabizi (Romanized Arabic) -> Arabic-script transliteration toolkit with dialect tagging, LLM-assisted disambiguation, and a reproducible benchmark.

- 官网：https://pypi.org/project/arabizikit/
