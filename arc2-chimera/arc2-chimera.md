# arc2-chimera

> 标签: Python

## 简介

Research proof-of-concept. ~2-5% accuracy on ARC-AGI. NOT an ARC Prize submission. GPU compute-shader playground (OpenGL / moderngl) exploring primitives for symbolic reasoning.
