# autoinstaller-backendpk

> 标签: Python

## 简介

This will automatically install django, rest_framework, psycopg and everything else django needs to run properly.

## 官网

- 官网：https://github.com/Ezozbekdev/backendpk
- PyPI 项目页：https://pypi.org/project/autoinstaller-backendpk/

- 0.0.1

## 获取地址

- pip 安装：`pip install autoinstaller-backendpk`
- 下载页面：https://pypi.org/project/autoinstaller-backendpk/#files
- 运行要求：Python >=3.6
