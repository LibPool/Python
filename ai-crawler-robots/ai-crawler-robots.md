# ai-crawler-robots

> 标签: Python

## 简介

Lint a robots.txt and audit it against 150 AI crawlers: which ones it really blocks, which rules do nothing, and which fetchers robots.txt cannot stop at all. RFC 9309, zero dependencies, no network.
