# aiocomfoconnect

> 标签: Python

## 简介

aiocomfoconnect is an asyncio Python 3 library for communicating with a Zehnder ComfoAir Q350/450/600 ventilation system

## 官网

- 官网：https://github.com/michaelarnauts/aiocomfoconnect
