# astro-mmdc

> 标签: Python

## 简介

Python SDK for the MMDC astrophysics platform — SED data access, on-demand Swift UVOT/XRT analysis and blazar broadband emission modeling

## 官网

- 官网：https://mmdc.am
- 源码仓库：https://github.com/ICRANet/mmdc
- PyPI 项目页：https://pypi.org/project/astro-mmdc/
