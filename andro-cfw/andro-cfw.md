# andro-cfw

> 标签: Python

## 简介

Run Telegram bots from filtered/restricted regions via your own Cloudflare Worker proxy, with cross-platform auto Node.js setup, smart multi-account load balancing, and a live browser usage dashboard (no VPN required).
