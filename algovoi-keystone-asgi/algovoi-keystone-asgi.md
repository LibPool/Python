# algovoi-keystone-asgi

> 标签: Python

## 简介

Bind HTTP requests to the AlgoVoi keystone -- ASGI + WSGI middleware that gives every state-changing request a content-addressed execution_ref (keystone-only edition, Apache-2.0)
