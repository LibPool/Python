# agents-shipgate

> 标签: Python

## 简介

The deterministic merge gate for AI-generated agent capability changes. Shows what a PR changes in coding-agent configuration (Claude Code settings, .mcp.json, hooks, Codex, Cursor, VS Code MCP, GitHub workflow permissions) with no manifest. Agent release readiness for tool-using AI agents. CLI + GitHub Action. Scans MCP, OpenAPI, OpenAI Agents SDK, Anthropic, Google ADK, LangChain, CrewAI, OpenAI API, Codex config, Codex plugin, n8n, Conductor OSS workflow JSON.
