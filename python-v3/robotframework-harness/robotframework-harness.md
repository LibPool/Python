# robotframework-harness

> 标签: Python

## 简介

Agent harness for Robot Framework: an Agent Skill, agent hooks and a local robotcode-based live session for Claude Code, Codex, GitHub Copilot, VS Code and OpenCode.

- 官网：https://github.com/manykarim/robotframework-harness
- PyPI 项目页：https://pypi.org/project/robotframework-harness/
