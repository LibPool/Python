# xlsxflat

> 标签: Python

## 简介

Turn a tree of messy .xlsx reports into one flat table, with a report of every change.

- 官网：https://github.com/Rezarys/xlsxflat
- PyPI 项目页：https://pypi.org/project/xlsxflat/
