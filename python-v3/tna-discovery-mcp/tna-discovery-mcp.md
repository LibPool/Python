# tna-discovery-mcp

> 标签: Python

## 简介

MCP server for Discovery, the catalogue of the UK National Archives: search record descriptions, read one with its place in the hierarchy, browse a series or piece, and find a Chelsea pensioner's discharge papers (WO 97) by name, regiment, birthplace and dates. For genealogy and history.
