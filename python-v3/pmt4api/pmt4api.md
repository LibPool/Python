# pmt4api

> 标签: Python

## 简介

Complete Python interface to the wmt4api MetaTrader 4 client library (market data, account, sizing, order entry, events).

## 官网

- 官网：https://mtapi.one
- PyPI 项目页：https://pypi.org/project/pmt4api/

## 历史版本号

- pip 安装：`pip install pmt4api`
- 下载页面：https://pypi.org/project/pmt4api/#files
- 运行要求：Python >=3.9
