# py2apk

> 标签: Python

## 简介

Turn a Python script into an Android APK with a GUI - no Docker, no compiling on your machine

## 官网

- 官网：https://github.com/TwoPlasmaStudios/py2apk
- PyPI 项目页：https://pypi.org/project/py2apk/
