# localscreenshot

> 标签: Python

## 简介

Screenshot API client and CLI. Take a screenshot of any public web page from the command line or from Python, from 227 countries.

## 官网

- 官网：https://localscreenshot.com
- 源码仓库：https://github.com/Sambel/localscreenshot-cli
- PyPI 项目页：https://pypi.org/project/localscreenshot/
