# langchain-emaki

> 标签: Python

## 简介

LangChain tools for emaki (emaki.ai), the Japanese-language AI video generator for Seedance 2.5 and Seedance 2.0: text to video, image to video and AI images from an agent

- 源码仓库：https://github.com/hanshs474/langchain-emaki
