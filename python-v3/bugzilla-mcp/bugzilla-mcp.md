# bugzilla-mcp

> 标签: Python

## 简介

MCP server for Bugzilla: search, read, triage and update bugs from AI assistants. Read-only by default.

## 官网

- 官网：https://github.com/SanthoshSiddegowda/bugzilla-mcp
- PyPI 项目页：https://pypi.org/project/bugzilla-mcp/

- 下载页面：https://pypi.org/project/bugzilla-mcp/#files
