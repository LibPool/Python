# lomboksimhash

> 标签: deduplication, hashing, locality-sensitive-hashing, lombok, lsh, minhash, near-duplicate, simhash

## 简介

Locality-sensitive hashing for near-duplicate document detection. SimHash, MinHash, LSH, SHA-256, and shingling.
