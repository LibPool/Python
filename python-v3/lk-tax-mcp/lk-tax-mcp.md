# lk-tax-mcp

> 标签: Python

## 简介

MCP server that gives AI assistants exact, sourced Sri Lankan tax calculations (APIT, income tax, WHT, VAT, SSCL).

## 官网

- 官网：https://github.com/ShalomHunukumbura/lk-tax-mcp
- PyPI 项目页：https://pypi.org/project/lk-tax-mcp/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install lk-tax-mcp`
- 下载页面：https://pypi.org/project/lk-tax-mcp/#files
- 运行要求：Python >=3.10
