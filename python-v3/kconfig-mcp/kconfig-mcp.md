# kconfig-mcp

> 标签: Python

## 简介

MCP server that explains Kconfig to AI agents: why can't I enable CONFIG_X? Unmet dependencies with file:line, and a verified minimal fix. Linux, Zephyr, U-Boot, Buildroot.
