# autorun-inf-deobfuscator

> 标签: Python

## 简介

A cli script to deobfuscate obfuscated autorun.inf files as used by the Conficker / Downadup malware for example.

- 官网：https://github.com/wahlflo/AurorunInfDeobfuscator
