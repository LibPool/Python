# houdini-asset-library

> 标签: Python

## 简介

Houdini Asset Library: save Houdini nodes as Hscript (cmd) and whole scenes as hip, and recall them from a standalone browser app

## 官网

- 官网：https://pypi.org/project/houdini-asset-library/
- PyPI 项目页：https://pypi.org/project/houdini-asset-library/
