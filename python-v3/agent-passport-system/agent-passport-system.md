# agent-passport-system

> 标签: Python

## 简介

Python SDK for the Agent Passport System. Identity, delegation, governance, attribution, mutual authentication, evidentiary type safety, accountability receipts, Cognitive Attestation, Instruction Provenance. Byte parity with the TypeScript SDK.
