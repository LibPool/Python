# qrfile-mcp

> 标签: Python

## 简介

Send files automatically to Android over Wi-Fi, or share one-time HTTPS links and QR codes.

## 官网

- 官网：https://pypi.org/project/qrfile-mcp/
- PyPI 项目页：https://pypi.org/project/qrfile-mcp/
