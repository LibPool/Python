# TCRmeta

> 标签: Python

## 简介

Antigen-aware TCR repertoire embeddings: pretrained TCRmeta encoder + fine-tuning, with downstream RDS (Repertoire Dispersal Score) scoring, UMAP projection, and energy-distance shift analysis.
