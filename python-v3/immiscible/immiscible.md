# immiscible

> 标签: Python

## 简介

Approvals, spend limits and signed receipts for AI agents: ask before a tool pays, shares data or acts, wait for a person, settle and verify. Guards for the OpenAI Agents SDK, LangChain and LangGraph. Standard library only.
