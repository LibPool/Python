# vulnlens

> 标签: Python

## 简介

Security scanner that sorts code, dependency and secret findings into Act now / Review / Context, using CISA KEV, EPSS and CVSS.

- 官网：https://harishakshay.github.io/open-source-vulnerability-scanner/

- PyPI 项目页：https://pypi.org/project/vulnlens/
