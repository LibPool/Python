# aiyoplane-verify

> 标签: Python

## 简介

Offline Ed25519 verifier for Aiyo execution receipts. Verify a receipt against Aiyo's published JWKS with no Aiyo-side infrastructure available.

## 官网

- 官网：https://aiyoplane.com
- 源码仓库：https://github.com/aiyoplane/verify-python
- PyPI 项目页：https://pypi.org/project/aiyoplane-verify/
