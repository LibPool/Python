# motui

> 标签: Python

## 简介

A layered full-screen TUI toolkit for Python with the Ink & Signal theme: alternate-screen rendering, addressable blocks, viewport scrollback, role-based theming, configurable keymaps, and a pointer-aware widget library (wcwidth-only).
