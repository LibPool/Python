# localsharefile

> 标签: Python

## 简介

LocalShareFile —— 局域网文件共享工具：多目录共享、网页远程配置、FTP 式批量下载、拖拽上传、终端 CLI（lsf）、开机自启动

## 官网

- 官网：https://github.com/hemin0721/localsharefile
- PyPI 项目页：https://pypi.org/project/localsharefile/

- 下载页面：https://pypi.org/project/localsharefile/#files
