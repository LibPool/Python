# macuvc

> 标签: Python

## 简介

Sudo-free pyuvc stand-in for macOS: AVFoundation frames + libusb UVC controls

## 官网

- 官网：https://github.com/VimalMollyn/uvc-avf
- PyPI 项目页：https://pypi.org/project/macuvc/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install macuvc`
- 下载页面：https://pypi.org/project/macuvc/#files
- 运行要求：Python >=3.9
