# adanet

> 标签: Python

## 简介

adanet is a lightweight and scalable TensorFlow AutoML framework for training and deploying adaptive neural networks using the AdaNet algorithm [Cortes et al. ICML 2017](https://arxiv.org/abs/1607.01097).
