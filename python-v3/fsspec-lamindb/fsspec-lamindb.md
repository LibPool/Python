# fsspec-lamindb

> 标签: Python

## 简介

Read-only fsspec filesystem for LaminDB instances: lamin://<owner>/<instance>/... URIs resolved through the LaminHub REST API.

## 官网

- 官网：https://github.com/ap--/fsspec-lamindb
- PyPI 项目页：https://pypi.org/project/fsspec-lamindb/

- pip 安装：`pip install fsspec-lamindb`
- 下载页面：https://pypi.org/project/fsspec-lamindb/#files
- 运行要求：Python >=3.11
