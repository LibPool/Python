# fitzyracing-transformers-stream-generator

> 标签: Python

## 简介

This is a text generation method which returns a generator, streaming out each token in real-time during inference, based on Huggingface/Transformers. (Maintained fork of transformers-stream-generator that works with transformers 4.41+ and 5.x)
