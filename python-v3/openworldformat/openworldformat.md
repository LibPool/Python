# openworldformat

> 标签: Python

## 简介

The Open World Format research package: parse and fold a .world in pure Python, no engine required.

## 官网

- 官网：https://openworldformat.org
- 源码仓库：https://github.com/openworldformat/openworldformat
- PyPI 项目页：https://pypi.org/project/openworldformat/

- 下载页面：https://pypi.org/project/openworldformat/#files
- 运行要求：Python >=3.10
