# mkdocs-light-dark-toggle

> 标签: Python

## 简介

Material for MkDocs plugin: an always-visible two-button light/dark switch, replacing Material's native single-knob palette toggle.

- 官网：https://github.com/luka-sherman/mkdocs-light-dark-toggle
