# agent-fileview

> 标签: Python

## 简介

Read-only file viewer that turns a coding agent's file paths into links you can open on your phone over Tailscale

## 官网

- 官网：https://pypi.org/project/agent-fileview/
- 源码仓库：https://github.com/tbb300/agent-fileview
