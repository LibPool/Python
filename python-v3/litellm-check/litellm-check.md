# litellm-check

> 标签: incident-response, ioc, litellm, scanner, security, supply-chain

## 简介

Self-audit CLI: scan a codebase and local Python environments for exposure to the compromised LiteLLM v1.107.0 release (PyPI, Docker Hub, GHCR) and generate an evidence report, based solely on LiteLLM's official incident announcement.
