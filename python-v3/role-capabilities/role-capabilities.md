# role-capabilities

> 标签: Python

## 简介

App-agnostic capability-based roles: declare your own capabilities and role bundles, resolve a principal's role from a seed plus append-only overrides, and check has_capability(actor, capability) anywhere — web request or CLI. Extracted from Rulebook; guest-auth integrates as an optional adapter.
