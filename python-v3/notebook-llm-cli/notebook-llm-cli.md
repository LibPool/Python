# notebook-llm-cli

> 标签: Python

## 简介

Interactive CLI to run LLMs on Kaggle/Colab GPUs with Ollama, llama.cpp or vLLM: GPU detection, fit and tokens/sec estimates, Ollama + Hugging Face search, password-protected public link.
