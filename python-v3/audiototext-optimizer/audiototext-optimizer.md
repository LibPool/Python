# audiototext-optimizer

> 标签: Python

## 简介

A lightweight CLI tool to optimize audio and video files for AI Speech-to-Text transcription.

## 官网

- 官网：https://freeaudiototext.com
- 源码仓库：https://github.com/double2dev/audiototext
- PyPI 项目页：https://pypi.org/project/audiototext-optimizer/
