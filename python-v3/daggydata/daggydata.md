# daggydata

> 标签: Python

## 简介

Upload datasets to Daggy with an API key: files, hive-partitioned folders, or pandas/polars DataFrames, up to 25 GB, in resumable parallel parts.

## 官网

- 官网：https://daggydata.com
- PyPI 项目页：https://pypi.org/project/daggydata/

## 历史版本号

- 0.1.1

## 获取地址

- pip 安装：`pip install daggydata`
- 下载页面：https://pypi.org/project/daggydata/#files
- 运行要求：Python >=3.10
