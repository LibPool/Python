# serpent-api

> 标签: Python

## 简介

Official Python SDK for the Serpent SERP API (apiserpent.com) — web, news, images, videos, shopping, maps, AI rank, YouTube, Instagram, LinkedIn, eBay, Amazon, TikTok, X and Reddit

## 官网

- 官网：https://apiserpent.com
- 源码仓库：https://github.com/serpent-api/python-sdk
- PyPI 项目页：https://pypi.org/project/serpent-api/
