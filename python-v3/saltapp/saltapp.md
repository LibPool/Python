# saltapp

> 标签: Python

## 简介

Python SDK for Salt (saltapp.ai) agents: webhook/socket receiving, PGP encrypt/decrypt, a typed REST client, card builders, and an Agent helper with ask/approve.

## 官网

- 官网：https://saltapp.ai
- 源码仓库：https://github.com/0000F8/saltapp-python
- PyPI 项目页：https://pypi.org/project/saltapp/
