# acellera-pmmanifest

> 标签: Python

## 简介

Generate PlayMolecule v2 app manifests (JSON Schema + uiSchema) from typed Python function signatures, with a live RJSF GUI preview.

## 官网

- 官网：https://github.com/Acellera/pmmanifest
