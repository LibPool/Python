# brepgraph

> 标签: Python

## 简介

Turn B-rep CAD files (STEP) into ML-ready face-adjacency graphs. pip-installable, no conda.

## 官网

- 官网：https://github.com/usman7384/brepgraph
- PyPI 项目页：https://pypi.org/project/brepgraph/
