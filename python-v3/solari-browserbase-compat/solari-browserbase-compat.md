# solari-browserbase-compat

> 标签: Python

## 简介

Browserbase-style Python SDK surface for Solari Browser: sessions, connect_url (CDP), contexts, live view, replay events.

## 官网

- 官网：https://getsolari.com
- PyPI 项目页：https://pypi.org/project/solari-browserbase-compat/

## 历史版本号

- 0.1.0

## 获取地址

- pip 安装：`pip install solari-browserbase-compat`
- 下载页面：https://pypi.org/project/solari-browserbase-compat/#files
- 运行要求：Python >=3.9
