# ignition-test

> 标签: Python

## 简介

CI client for the Ignition Test Framework module: provision a token, wait for the gateway, run suites over REST, download JUnit/lcov, exit like pytest.

## 官网

- 官网：https://github.com/bw-design-group/ignition.modules.test-framework
