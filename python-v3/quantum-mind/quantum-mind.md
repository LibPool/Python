# quantum-mind

> 标签: Python

## 简介

Quantum robotics in one library: quantum computing for robot algorithms (robot QUBOs, classical baselines, Qiskit QAOA adapter), quantum sensing for robots, and quantum-probability cognition (the COBRA belief filter), each against classical baselines
