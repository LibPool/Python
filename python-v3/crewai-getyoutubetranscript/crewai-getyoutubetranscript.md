# crewai-getyoutubetranscript

> 标签: Python

## 简介

YouTube transcript tools for CrewAI agents: get YouTube video transcripts with timestamps, search YouTube, and list channel videos, via the GetYouTubeTranscript API.

## 官网

- 官网：https://getyoutubetranscript.com
- 源码仓库：https://github.com/tubeagentkit/crewai-getyoutubetranscript
- PyPI 项目页：https://pypi.org/project/crewai-getyoutubetranscript/
