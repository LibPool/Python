# certbot-dns-godaddy-v3

> 标签: Python

## 简介

A certbot plugin that implements letsencrypt dns wildcard support for godaddy using the GoDaddy Domains v3 API and Personal Access Tokens (rewrite of certbot-dns-godaddy by Dustyn Gibson)
