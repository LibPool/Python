# apitwitter-mcp

> 标签: Python

## 简介

MCP server for the apitwitter.com Twitter/X API — use X/Twitter from Claude, Cursor and any MCP client.

## 官网

- 官网：https://apitwitter.com
- 源码仓库：https://github.com/ApiTwitter/apitwitter-mcp
- PyPI 项目页：https://pypi.org/project/apitwitter-mcp/

## 历史版本号

- 0.1.0

## 获取地址

- pip 安装：`pip install apitwitter-mcp`
- 下载页面：https://pypi.org/project/apitwitter-mcp/#files
- 运行要求：Python >=3.10
