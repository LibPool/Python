# sportapi

> 标签: Python

## 简介

Official Python client for the SportAPI Sport Line API: Prematch and Live sports odds, scores and statistics.

- 官网：https://sportapi.net
- 源码仓库：https://github.com/SportApi-net/sportapi-python
- PyPI 项目页：https://pypi.org/project/sportapi/
