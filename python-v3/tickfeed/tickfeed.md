# tickfeed

> 标签: Python

## 简介

Official Python client for the TickFeed market data API: live bid/ask and OHLC candles for 60 forex pairs and 11 metals.

## 官网

- 官网：https://tickfeed.pro
- 源码仓库：https://github.com/TickFeedAPI/tickfeed
- PyPI 项目页：https://pypi.org/project/tickfeed/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

- pip 安装：`pip install tickfeed`
- 下载页面：https://pypi.org/project/tickfeed/#files
