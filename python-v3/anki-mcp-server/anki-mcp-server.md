# anki-mcp-server

> 标签: Python

## 简介

MCP server for Anki (via AnkiConnect): add, import, search, edit and organize notes and decks from Claude or any MCP client.

## 官网

- 官网：https://github.com/MeisamHakimi/anki-mcp-server
- PyPI 项目页：https://pypi.org/project/anki-mcp-server/

## 历史版本号

- 当前版本：0.2.0

- 0.2.0

## 获取地址

- pip 安装：`pip install anki-mcp-server`
- 下载页面：https://pypi.org/project/anki-mcp-server/#files
- 运行要求：Python >=3.10
