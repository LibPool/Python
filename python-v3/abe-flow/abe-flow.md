# abe-flow

> 标签: Python

## 简介

Send Abe escalations to Flow's judgment service (resolve.flowinfo.co). Only ESCALATE results are sent.

## 官网

- 官网：https://fjp.flowinfo.co/abe
- 源码仓库：https://github.com/flowinfosystems-index/abe
- PyPI 项目页：https://pypi.org/project/abe-flow/
