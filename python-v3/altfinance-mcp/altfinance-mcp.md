# altfinance-mcp

> 标签: Python

## 简介

MCP server for querying luxury asset auction data (watches, handbags, jewelry) via the ALT/FNDATA API

## 官网

- 源码仓库：https://github.com/altfinance/altfinance-mcp
- PyPI 项目页：https://pypi.org/project/altfinance-mcp/
