# duekit

> 标签: Python

## 简介

Configurable due-date monitoring: flexible daily scheduling (fixed times/intervals, one or more tasks), fully custom expiry levels with callbacks, and schema-driven extraction of irregular PDF/Excel/CSV tables. Core has zero third-party dependencies.
