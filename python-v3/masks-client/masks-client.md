# masks-client

> 标签: Python

## 简介

Sign a Python service or machine in to masks, hold its tokens to a key with DPoP, and check masks access tokens in an API.

## 官网

- 官网：https://masks.pages.dev
- 源码仓库：https://github.com/masksrb/masks/tree/main/python
- PyPI 项目页：https://pypi.org/project/masks-client/
