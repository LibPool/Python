# tyzarr

> 标签: Python

## 简介

把 xarray.Dataset 存成不可变 zarr v3 快照，支持本地目录与 MinIO，用带 CAS 的 metadata.json 做原子发布

## 官网

- 官网：https://pypi.org/project/tyzarr/
- PyPI 项目页：https://pypi.org/project/tyzarr/

## 历史版本号

- 当前版本：0.1.1

- 0.1.1

## 获取地址

- pip 安装：`pip install tyzarr`
- 下载页面：https://pypi.org/project/tyzarr/#files
- 运行要求：Python >=3.11
