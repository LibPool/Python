# scigantic-who

> 标签: Python

## 简介

Query every WHO Global Health Observatory indicator from a public parquet mirror over DuckDB (one query instead of 3,099 API calls), decode WHO's dimension codes, or fetch a fresh indicator from the live OData API in the same shape.
