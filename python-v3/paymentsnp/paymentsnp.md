# paymentsnp

> 标签: Python

## 简介

Official Python SDK for the Paymentsnp payment API (eSewa, Khalti, Fonepay checkout for Nepal).

## 官网

- 官网：https://paymentnp.com/developers
- PyPI 项目页：https://pypi.org/project/paymentsnp/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install paymentsnp`
- 下载页面：https://pypi.org/project/paymentsnp/#files
- 运行要求：Python >=3.9
