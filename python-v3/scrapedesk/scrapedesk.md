# scrapedesk

> 标签: Python

## 简介

A friendly desktop web scraper: grab images, tables, links and text from any website and export to Excel, CSV, JSON or SQLite.

## 官网

- 官网：https://pypi.org/project/scrapedesk/
- PyPI 项目页：https://pypi.org/project/scrapedesk/
