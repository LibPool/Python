# mcp-inegi

> 标签: Python

## 简介

Servidor MCP para consultar indicadores oficiales del INEGI: población, inflación (INPC), empleo, PIB e IGAE, a nivel nacional, estatal y municipal

## 官网

- 官网：https://github.com/itzamna-mx/mcp-inegi
- PyPI 项目页：https://pypi.org/project/mcp-inegi/

- 0.1.0

- 下载页面：https://pypi.org/project/mcp-inegi/#files
- 运行要求：Python >=3.10
