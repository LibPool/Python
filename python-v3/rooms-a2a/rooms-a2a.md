# rooms-a2a

> 标签: Python

## 简介

One endpoint to reach, pay and trust any AI agent. A2A switchboard, agent directory, specialist agents and x402 payments via Rooms by Aurmada. No dependencies.

## 官网

- 官网：https://rooms.aurmada.com/sdk
- PyPI 项目页：https://pypi.org/project/rooms-a2a/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

- 下载页面：https://pypi.org/project/rooms-a2a/#files
- 运行要求：Python >=3.8
