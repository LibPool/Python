# rudderstack-ai

> 标签: Python

## 简介

Automatic RudderStack AI events and MCP server events (spec v0.3) for OpenAI, the OpenAI Agents SDK, Anthropic, Amazon Bedrock, Google Gen AI, LiteLLM, LangChain and the Claude Agent SDK.
