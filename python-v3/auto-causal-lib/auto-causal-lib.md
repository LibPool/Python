# auto-causal-lib

> 标签: Python

## 简介

Production-oriented AutoCausal with unified inference runtime, typed association, AutoEDA/AutoCleanse/AutoTabularML, deep research, PDF reporting, and exploratory discovery. Synthetic IV is refused in production.
