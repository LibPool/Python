# postalcheck

> 标签: address, country, eircode, iso3166, libaddressinput, normalization, postal, postal-code, postcode, validation, zip, zip-code

## 简介

Validate and normalize postal and ZIP codes for the 182 countries and territories that use them, checked against Google libaddressinput data, zero dependencies, fully typed
