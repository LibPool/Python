# hugpy-browser

> 标签: Python

## 简介

Screen-driven browser control for bots, standalone and trainable: the browser-perfect engine (verbatim copy of the abstract-toolserver 0.0.70 browser stack), the operator guide, the benchmark kit and data, a native-grounding fine-tune exporter, e2e scripts and lab-VM assets.
