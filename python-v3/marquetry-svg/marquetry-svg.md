# marquetry-svg

> 标签: Python

## 简介

Turn a flat logo image into filament-ready multi-color SVGs for 3D printing: one path per color, plus a base disc.

## 官网

- 官网：https://github.com/Euda1mon1a/marquetry
- PyPI 项目页：https://pypi.org/project/marquetry-svg/

- 下载页面：https://pypi.org/project/marquetry-svg/#files
