# readystack-wcag22-css-lint

> 标签: Python

## 简介

Reads your stylesheet and names the success criterion each rule breaks, including the three WCAG 2.2 added that WCAG 2.1 linters never learned. (bundled Node.js runtime)

- 官网：https://getreadystack.com/tools/wcag22-css-lint?ref=pypi
- PyPI 项目页：https://pypi.org/project/readystack-wcag22-css-lint/
