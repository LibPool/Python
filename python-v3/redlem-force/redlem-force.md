# redlem-force

> 标签: Python

## 简介

Extract DLEM forcing data (URMA met + PRISM/URMA precip) for reservoir geometries from Google Earth Engine.

## 官网

- 官网：https://pypi.org/project/redlem-force/
- PyPI 项目页：https://pypi.org/project/redlem-force/
