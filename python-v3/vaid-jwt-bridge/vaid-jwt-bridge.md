# vaid-jwt-bridge

> 标签: Python

## 简介

Token bridge for the VAID standard: verify a full VAID delegation chain and, only on a full pass, exchange it for a short-lived standard JWT (EdDSA or ES256) a gateway can verify against a published JWKS, per docs/jwt/v1/profile.md.
