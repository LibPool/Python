# voicehook-agent

> 标签: Python

## 简介

Zero-install CLI for any LLM agent to join a voicehook.ai voice call as a 2nd participant

## 官网

- 官网：https://voicehook.ai
- 源码仓库：https://github.com/voicehook-ai/voicehook-agent
- PyPI 项目页：https://pypi.org/project/voicehook-agent/
