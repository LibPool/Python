# facturacion-electronica-sunat-sdk

> 标签: Python

## 简介

SUNAT (Peru) electronic invoicing: builds the UBL XML of invoices, receipts, credit and debit notes, daily summaries and void communications, signs it, zips it and reads SUNAT's answers.
