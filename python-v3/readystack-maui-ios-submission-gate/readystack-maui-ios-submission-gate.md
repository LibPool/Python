# readystack-maui-ios-submission-gate

> 标签: Python

## 简介

Reads a .NET MAUI app's iOS Info.plist and Entitlements.plist and names every App Store Review 5.1.1(i) purpose-string rejection and export-compliance defect before the build is uploaded. (bundled Node.js runtime)
