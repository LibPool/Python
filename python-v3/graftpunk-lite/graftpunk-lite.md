# graftpunk-lite

> 标签: Python

## 简介

Authenticated browser sessions, captured once and replayed over plain HTTP: stealth login, encrypted at rest, pluggable storage. Lite install: no browser stack, so it resolves under Pyodide and Cloudflare Workers; graftpunk-lite[browser] equals graftpunk.
