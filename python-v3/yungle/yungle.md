# yungle

> 标签: Python

## 简介

Python client for the Yungle API: send large files as private, EU-hosted transfers, build collections, sync contacts.

## 官网

- 官网：https://docs.yungle.co?ref=pypi
- 源码仓库：https://github.com/heindewilde/yungle-clients
- PyPI 项目页：https://pypi.org/project/yungle/
