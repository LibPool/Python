# neurones3d

> 标签: Python

## 简介

Neurones 3D (N3D): the Python package of the Neurones 3D point cloud engine. This first release reserves the name and points to the SDK.

## 官网

- 官网：https://neurones3d.com/
- PyPI 项目页：https://pypi.org/project/neurones3d/
