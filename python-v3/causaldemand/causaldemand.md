# causaldemand

> 标签: Python

## 简介

CausalDemand: synthetic and observed retail sales datasets for testing whether a method predicts how sales respond to price changes. Download, scoring and rerun tools (rerun needs Python >= 3.12).

- PyPI 项目页：https://pypi.org/project/causaldemand/
