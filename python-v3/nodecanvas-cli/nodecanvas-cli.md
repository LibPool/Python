# nodecanvas-cli

> 标签: Python

## 简介

Read, query, lint and edit NodeCanvas graphs (Behaviour Trees, FSMs, Dialogue Trees) in Unity projects from the command line

## 官网

- 官网：https://github.com/Primeer/nodecanvas-cli
- PyPI 项目页：https://pypi.org/project/nodecanvas-cli/

- 下载页面：https://pypi.org/project/nodecanvas-cli/#files
