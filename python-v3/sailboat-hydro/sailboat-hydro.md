# sailboat-hydro

> 标签: Python

## 简介

FairHelm sailboat hydrodynamic formulas (hull speed, CSF, D/L, comfort ratio) plus a bundled 93-model Nordic/European benchmark. Zero-Network: no HTTP to api.fairhelm.com.

## 官网

- 官网：https://fairhelm.com/en/yachts/formulas/
- 源码仓库：https://github.com/nareyko/fairhelm-2026/tree/main/packages/sailboat-hydro
- PyPI 项目页：https://pypi.org/project/sailboat-hydro/
