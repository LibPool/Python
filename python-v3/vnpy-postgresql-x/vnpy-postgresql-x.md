# vnpy-postgresql-x

> 标签: Python

## 简介

vnpy官方的vnpy_postgresql有一个问题，生成的表的主键是int不是bigint，在数据量巨大的情况下，容易触发主键值耗尽，特此改良

- PyPI 项目页：https://pypi.org/project/vnpy-postgresql-x/
