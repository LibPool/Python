# rapier3d

> 标签: Python

## 简介

Python bindings for Rapier (3D, f32) — a fast, deterministic physics engine.

## 官网

- 官网：https://rapier.rs
- 源码仓库：https://github.com/dimforge/rapier
- PyPI 项目页：https://pypi.org/project/rapier3d/
