# config-to-vault

> 标签: Python

## 简介

Replicate a folder of config files from git into HashiCorp Vault KV v2.

## 官网

- 官网：https://pypi.org/project/config-to-vault/
- PyPI 项目页：https://pypi.org/project/config-to-vault/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install config-to-vault`
- 下载页面：https://pypi.org/project/config-to-vault/#files
- 运行要求：Python >=3.11
