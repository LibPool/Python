# originet

> 标签: asn, bgp, caida, ip, longest-prefix-match, routeviews

## 简介

Fast IP-to-ASN lookups (longest-prefix match) on CAIDA's RouteViews prefix-to-AS snapshots, fetched on the fly or from a local file
