# repoharvester

> 标签: Python

## 简介

Clone a git repo or read a folder and compile its text files into one file for LLM context. CLI plus optional GUI, no dependencies.

## 官网

- 官网：https://github.com/octrow/RepoHarvester
- PyPI 项目页：https://pypi.org/project/repoharvester/
