# pxm2-playwright

> 标签: Python

## 简介

Official Playwright async/sync proxy rotator and mobile fingerprint helper for PXM2 4G/5G mobile proxies.

## 官网

- 官网：https://pxm2.io/
- PyPI 项目页：https://pypi.org/project/pxm2-playwright/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install pxm2-playwright`
- 下载页面：https://pypi.org/project/pxm2-playwright/#files
- 运行要求：Python >=3.8
