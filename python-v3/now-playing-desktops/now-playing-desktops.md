# now-playing-desktops

> 标签: Python

## 简介

Glass-style album-art tile on your desktop wallpaper for the Spotify track (or local player) you are playing now.

## 官网

- 官网：https://github.com/hippi345/nowPlayingDesktops
- PyPI 项目页：https://pypi.org/project/now-playing-desktops/
