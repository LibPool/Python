# vmnest

> 标签: Python

## 简介

Embeddable Python SDK + CLI for isolated microVM sandboxes on AWS Lambda MicroVMs (a Python fork of microsandbox concepts).

## 官网

- 官网：https://github.com/jnh12/agent-microvm
