# task-checkpoint-mcp

> 标签: Python

## 简介

MCP server adding checkpoint and resume to long agent tasks: roll back to any step, resume in a new session, hand off to another machine. Pure Python stdlib, zero dependencies.

- 官网：https://github.com/qddfxp/task-checkpoint-mcp
