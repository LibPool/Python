# fastdar

> 标签: Python

## 简介

FastDAR client: yes/no checks, labels and ticket sorting for lots of short texts.

- 官网：https://fastdar.com
- 源码仓库：https://github.com/FastDAR/fastdar
- PyPI 项目页：https://pypi.org/project/fastdar/
