# navig-media-core

> 标签: Python

## 简介

The shared media engine NAVIG's media packages run on — media types and the generator registry, the generation service, the refs library, the variant store, the provider key catalog, and the ffmpeg primitives (audio edit, video edit, frames, fx). A library: no commands of its own, runs without navig.
