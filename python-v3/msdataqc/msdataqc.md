# msdataqc

> 标签: Python

## 简介

Quality control for longitudinal multiple sclerosis MRI datasets: lesion ground-truth consistency, contrast drift between visits, protocol checks against the 2021 consensus, lesion counting conventions, probability maps, a one-page QC report, and MSLesSeg to BIDS.
