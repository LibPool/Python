# a3faker

> 标签: Python

## 简介

It's just a thin wrapper of Faker, because PyCharm cannot autocomplete Faker related code.

## 官网

- 官网：https://gitee.com/three-kinds/a3faker
- PyPI 项目页：https://pypi.org/project/a3faker/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install a3faker`
- 下载页面：https://pypi.org/project/a3faker/#files
- 运行要求：Python >=3.8
