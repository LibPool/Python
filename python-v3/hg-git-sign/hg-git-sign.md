# hg-git-sign

> 标签: Python

## 简介

Sign Mercurial changesets so hg-git pushes them to Git as signed commits

- 官网：https://github.com/stephenskory/hg-git-sign
- PyPI 项目页：https://pypi.org/project/hg-git-sign/

- 下载页面：https://pypi.org/project/hg-git-sign/#files
