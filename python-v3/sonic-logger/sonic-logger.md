# sonic-logger

> 标签: Python

## 简介

Lightweight, fast, clear structured logging for Python — FastAPI / Django / Flask integrations, auto error classification, request tracing with payload logging, an event-loop block watchdog, a resource monitor, and zero-dep OTLP logs/traces/metrics export to Loki, Tempo, Prometheus, Datadog & New Relic. Same wire format as the npm sonic-logger.
