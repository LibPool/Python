# voices-az

> 标签: Python

## 简介

Official Python client for the Voices.az API: text-to-speech, speech-to-text and video dubbing.

## 官网

- 官网：https://voices.az
- 源码仓库：https://github.com/Voices-az/voices-python
- PyPI 项目页：https://pypi.org/project/voices-az/

## 历史版本号

- 0.2.0

- pip 安装：`pip install voices-az`
- 下载页面：https://pypi.org/project/voices-az/#files
- 运行要求：Python >=3.9
