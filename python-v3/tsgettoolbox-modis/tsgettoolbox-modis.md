# tsgettoolbox-modis

> 标签: Python

## 简介

Plugin for tsgettoolbox to retrieve MODIS data from the LP DAAC Data Pool.

- 官网：https://pypi.org/project/tsgettoolbox-modis/
- PyPI 项目页：https://pypi.org/project/tsgettoolbox-modis/

- 下载页面：https://pypi.org/project/tsgettoolbox-modis/#files
