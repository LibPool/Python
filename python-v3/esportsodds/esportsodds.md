# esportsodds

> 标签: Python

## 简介

Python client and MCP server for the esportsodds.gg CS2 (Counter-Strike 2) match data and stats API.

## 官网

- 官网：https://esportsodds.gg/cs2-api
- 源码仓库：https://github.com/esportsodds/esportsodds-python
- PyPI 项目页：https://pypi.org/project/esportsodds/
