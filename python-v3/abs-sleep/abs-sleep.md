# abs-sleep

> 标签: Python

## 简介

Thin ctypes wrapper for calling Linux's `clock_nanosleep` with `TIMER_ABSTIME`

## 官网

- 官网：https://github.com/brandenburg/py-abs-sleep
- PyPI 项目页：https://pypi.org/project/abs-sleep/
