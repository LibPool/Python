# apiyi-sdk

> 标签: Python

## 简介

Python SDK for APIYi image & video APIs (GPT-Image-2, Nano Banana, VEO 3.1, Seedance 2.0, icover asset library)

## 官网

- 官网：https://docs.apiyi.com
- 源码仓库：https://github.com/suix-maker/apiyi_sdk
- PyPI 项目页：https://pypi.org/project/apiyi-sdk/

- 下载页面：https://pypi.org/project/apiyi-sdk/#files
- 运行要求：Python >=3.10
