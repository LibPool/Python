# glean-importer

> 标签: ai-agents, claude-code, crm, email, hotmail, imap, local-first, mcp, oauth2, outlook, personal-crm, rag

## 简介

Imports what your sources hold into orbit (a personal CRM) and sift (local RAG search), one sandboxed Claude Code agent run per item. Email works today: IMAP with OAuth2 (Outlook.com, Hotmail) or .eml files.
