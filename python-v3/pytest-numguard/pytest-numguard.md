# pytest-numguard

> 标签: Python

## 简介

pytest plugin for numerical edge-case testing: NaN, inf, overflow, cancellation and dtype bugs in array code (installs numguard-ci).

## 官网

- 官网：https://github.com/bhaskargurram-ai/numguard
- PyPI 项目页：https://pypi.org/project/pytest-numguard/

## 历史版本号

- 当前版本：1.0.1

- 1.0.1

## 获取地址

- pip 安装：`pip install pytest-numguard`
- 下载页面：https://pypi.org/project/pytest-numguard/#files
- 运行要求：Python >=3.10
