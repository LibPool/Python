# relayt

> 标签: Python

## 简介

Connect a running app to its Relayt control plane: self-registration, heartbeat, per-deployment config, entitlements/licensing, signed named commands, and error reports that become issues. Standard library only.

- 官网：https://relayt.studio
- PyPI 项目页：https://pypi.org/project/relayt/
