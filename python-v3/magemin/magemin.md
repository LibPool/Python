# magemin

> 标签: Python

## 简介

Python interface to MAGEMin, a C package that performs Gibbs energy minimization for thermodynamic equilibrium calculations.

## 官网

- 官网：https://github.com/ondrolexa/MAGEMin_py
- PyPI 项目页：https://pypi.org/project/magemin/
