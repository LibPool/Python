# forge-server-doctor

> 标签: Python

## 简介

Reads a modded Minecraft crash report and tells you which mod actually broke it. Forge and NeoForge, 1.16-1.21.

## 官网

- 官网：https://github.com/jaakoby/forge-server-doctor
- PyPI 项目页：https://pypi.org/project/forge-server-doctor/
