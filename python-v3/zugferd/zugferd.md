# zugferd

> 标签: Python

## 简介

Generate, validate (official KoSIT rules) and parse ZUGFeRD / Factur-X e-invoices via the xrechnung.dev API. Alias of the `xrechnung` package. No JVM required.

## 官网

- 官网：https://xrechnung.dev
- PyPI 项目页：https://pypi.org/project/zugferd/
