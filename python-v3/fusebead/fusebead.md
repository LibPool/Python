# fusebead

> 标签: Python

## 简介

Turn a photo into a fuse-bead pattern, with palette matching, bead counts, and a printable PNG.

## 官网

- 官网：https://www.rockimg.com/perler-bead-pattern-maker.html
- PyPI 项目页：https://pypi.org/project/fusebead/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install fusebead`
- 下载页面：https://pypi.org/project/fusebead/#files
- 运行要求：Python >=3.9
