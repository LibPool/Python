# experimentlens

> 标签: Python

## 简介

Python SDK for ExperimentLens: log ML and LLM/agent experiments to MLflow and Langfuse so they appear in the ExperimentLens UI.

## 官网

- 官网：https://experimentlens.imsi.athenarc.gr/
- 源码仓库：https://github.com/ExperimentLens
- PyPI 项目页：https://pypi.org/project/experimentlens/
