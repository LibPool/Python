# crewai-layrcake

> 标签: Python

## 简介

CrewAI tools for Layrcake: find leads, enrich and verify emails, check and research companies, and draft campaigns that a person approves before anything sends.

## 官网

- 官网：https://layrcake.dev
- 源码仓库：https://github.com/Layrcake-dev/crewai-layrcake
- PyPI 项目页：https://pypi.org/project/crewai-layrcake/
