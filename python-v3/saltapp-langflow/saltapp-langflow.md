# saltapp-langflow

> 标签: Python

## 简介

Langflow custom components exposing Salt (saltapp.ai) agent actions: send a message (encrypted or, in an open room, plain), ask a human and check for the tap, request payment, read a room on demand, manage interests, and check for new Salt events.
