# fxtensor-bayesnet

> 标签: Python

## 简介

Config-driven inference for discrete Bayesian networks: scenario comparison, Bayesian updating, root-cause inference, do-interventions and causal effects, sensitivity analysis and daily snapshots (built on fxtensor-salmon)
