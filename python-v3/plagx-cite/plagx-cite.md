# plagx-cite

> 标签: Python

## 简介

Free APA and MLA citation generator and reference checker: reference lists, in-text citations, BibTeX import/export, DOI to citation and duplicate reference detection. By Plagiarism Checker X.

## 官网

- 官网：https://github.com/plagiarismcheckerx/plagx-cite-python
- PyPI 项目页：https://pypi.org/project/plagx-cite/
