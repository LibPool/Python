# aveecare

> 标签: Python

## 简介

Official Python library for the AveeCare API: patients, visits, caregivers and billing for home care agencies.

## 官网

- 官网：https://www.aveecare.com/docs/api
- 源码仓库：https://github.com/aveecare/aveecare-python
- PyPI 项目页：https://pypi.org/project/aveecare/
