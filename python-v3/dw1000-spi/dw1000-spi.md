# dw1000-spi

> 标签: Python

## 简介

SPI driver for the Decawave DW1000 UWB transceiver (TX/RX, ranging timestamps, UWB configuration)

## 官网

- 官网：https://github.com/dy-dx-1/DW1000_SPI
- PyPI 项目页：https://pypi.org/project/dw1000-spi/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install dw1000-spi`
- 下载页面：https://pypi.org/project/dw1000-spi/#files
- 运行要求：Python >=3.10
