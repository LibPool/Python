# actionscript-polycall

> 标签: Python

## 简介

ActionScript 3 binding for Polycall, installed as source files (not a Python API)

- 官网：https://github.com/obinexus/actionscript-polycall
- PyPI 项目页：https://pypi.org/project/actionscript-polycall/

- pip 安装：`pip install actionscript-polycall`
- 下载页面：https://pypi.org/project/actionscript-polycall/#files
- 运行要求：Python >=3.8
