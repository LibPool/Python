# automateYT

> 标签: Python

## 简介

automateYT is lightweight library that automates downloading of youtube videos, subtitles (if available) and playlist.

## 官网

- 官网：https://github.com/umutambyi-gad/automateYT
- PyPI 项目页：https://pypi.org/project/automateYT/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install automateYT`
- 下载页面：https://pypi.org/project/automateYT/#files
- 运行要求：Python >=3.6
