# osmimage

> 标签: Python

## 简介

Render an OpenStreetMap tile image from latitude, longitude and zoom, returning a Pillow image ready for further drawing.

## 官网

- 官网：https://github.com/AngLaboratory/osmimage
- PyPI 项目页：https://pypi.org/project/osmimage/

- 下载页面：https://pypi.org/project/osmimage/#files
