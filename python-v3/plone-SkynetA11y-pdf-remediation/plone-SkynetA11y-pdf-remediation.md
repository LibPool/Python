# plone-SkynetA11y-pdf-remediation

> 标签: Python

## 简介

PDF accessibility (WCAG / PDF-UA) remediation dashboard: upload PDFs, scan a website for PDFs, download AI-remediated copies.

## 官网

- 官网：https://www.skynettechnologies.com/pdf-accessibility-remediation
- PyPI 项目页：https://pypi.org/project/plone-SkynetA11y-pdf-remediation/

- 下载页面：https://pypi.org/project/plone-SkynetA11y-pdf-remediation/#files
