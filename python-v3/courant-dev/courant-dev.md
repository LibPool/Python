# courant-dev

> 标签: Python

## 简介

Courant: physics acceptance testing for machine-produced simulation. A read-only, deterministic gate that accepts, rejects or abstains on an OpenFOAM run, with the reasons it read.

- 官网：https://courant.dev
- 源码仓库：https://github.com/courantdev/courant
