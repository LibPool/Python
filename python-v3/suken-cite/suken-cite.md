# suken-cite

> 标签: Python

## 简介

Trả lời bằng tuyến truyện vẽ trên khung UI, mỗi ô có ảnh chụp nguồn khoanh đỏ kèm dòng dịch (web, email, PDF, Word, Excel, PowerPoint, CSV, ảnh) và thẻ giải thích code.
