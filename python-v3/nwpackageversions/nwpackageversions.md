# nwpackageversions

> 标签: Python

## 简介

A library that helps with retrieving package information from PyPi.org and comparing them with what you have installed locally.

## 官网

- 官网：https://github.com/numbworks/nwpackageversions
- PyPI 项目页：https://pypi.org/project/nwpackageversions/

## 历史版本号

- 当前版本：2.0.1

- 2.0.1

## 获取地址

- pip 安装：`pip install nwpackageversions`
- 下载页面：https://pypi.org/project/nwpackageversions/#files
- 运行要求：Python >=3.12
