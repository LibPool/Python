# neuroviewer

> 标签: Python

## 简介

Freeview-like neuroimaging viewer in pure Python (PySide6 + vedo/VTK + nibabel)

- PyPI 项目页：https://pypi.org/project/neuroviewer/

- 下载页面：https://pypi.org/project/neuroviewer/#files
