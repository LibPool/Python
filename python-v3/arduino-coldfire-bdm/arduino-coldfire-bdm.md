# arduino-coldfire-bdm

> 标签: Python

## 简介

An interface to Motorola® Coldfire processors' Background Debug Interface (BDM) using an Arduino.

## 官网

- 官网：https://github.com/psobot/arduino_coldfire_bdm
- PyPI 项目页：https://pypi.org/project/arduino-coldfire-bdm/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install arduino-coldfire-bdm`
- 下载页面：https://pypi.org/project/arduino-coldfire-bdm/#files
- 运行要求：Python >=3.6, <4
