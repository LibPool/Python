# langchain-ambolt

> 标签: Python

## 简介

LangChain tools for Ambolt: company registers, EU and UK tenders, VAT and IBAN checks, domain and SSL expiry, URL metadata and more. Free through the hosted MCP server.

## 官网

- 官网：https://ambolt.dev
- 源码仓库：https://github.com/ambolt/ambolt-mcp
- PyPI 项目页：https://pypi.org/project/langchain-ambolt/

- pip 安装：`pip install langchain-ambolt`
- 下载页面：https://pypi.org/project/langchain-ambolt/#files
