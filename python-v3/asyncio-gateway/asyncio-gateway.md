# asyncio-gateway

> 标签: Python

## 简介

Any microservice will be able to use the “asyncio_gateway” can make an async request(HTTP/SOAP/XML/FTP/redis) with the given payload to given address

## 官网

- 官网：https://github.com/ajyadav013/asyncio-gateway
- PyPI 项目页：https://pypi.org/project/asyncio-gateway/
