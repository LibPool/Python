# plagx-preflight

> 标签: academic-writing, apa, citation-checker, draft-checker, essay-checker, flesch, grammar-checker, mla, punctuation, readability, reference-list, students, word-count

## 简介

Free draft checker for essays and papers: word count, citation and reference list checks, punctuation and basic grammar suggestions, readability stats. Runs offline. By Plagiarism Checker X.
