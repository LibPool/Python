# remote-fileshare

> 标签: Python

## 简介

Send screenshots and files from your browser to Claude Code, Codex CLI and other AI agents running on a remote Linux server, and download what they produce. One command, password, HTTPS, zero dependencies. 远程文件共享：在远程 Linux 机器上用 Claude Code、Codex CLI 写代码时，从浏览器把截图、文件传给 AI agent，并把结果下载回本地；一行 npx / uvx 启动，带密码、HTTPS、零依赖
