# nhl-contracts

> 标签: Python

## 简介

Open, provenance-first dataset of NHL player contracts built from official public sources (NHL.com club releases and staff stories, ESPN's transaction wire).

- 官网：https://github.com/ehlersio/nhl-contracts
- PyPI 项目页：https://pypi.org/project/nhl-contracts/
