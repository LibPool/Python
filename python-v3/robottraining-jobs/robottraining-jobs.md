# robottraining-jobs

> 标签: Python

## 简介

Open data on paid robot-training jobs (teleoperation, data collection, AV and drone test operation): open roles, advertised pay and the newest openings, from RobotTraining.jobs.

## 官网

- 官网：https://robottraining.jobs/data
- PyPI 项目页：https://pypi.org/project/robottraining-jobs/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install robottraining-jobs`
- 下载页面：https://pypi.org/project/robottraining-jobs/#files
- 运行要求：Python >=3.8
