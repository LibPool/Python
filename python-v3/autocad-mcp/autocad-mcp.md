# autocad-mcp

> 标签: Python

## 简介

AutoCAD-mcp 连接器：通过 MCP 协议用自然语言/AI 驱动本机 AutoCAD 完成 2D 制图、图框、标题栏、BOM、球标与标注。

## 官网

- 官网：https://github.com/liqi82/autocad-mcp
- PyPI 项目页：https://pypi.org/project/autocad-mcp/

## 历史版本号

- 1.1.2

## 获取地址

- pip 安装：`pip install autocad-mcp`
- 下载页面：https://pypi.org/project/autocad-mcp/#files
- 运行要求：Python >=3.10
