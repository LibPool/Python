# mangabinder

> 标签: Python

## 简介

Download manga chapters, convert them to PDF, bind them into volumes and export CBZ - from the command line or a local web UI.

## 官网

- 官网：https://github.com/Preygle/manga-downloader
- PyPI 项目页：https://pypi.org/project/mangabinder/

- 下载页面：https://pypi.org/project/mangabinder/#files
