# xfriend

> 标签: ai, boyfriend, companion, girlfriend, image, llm, qwen, secretaudio, secrevoice, tts, venice, wavespeed

## 简介

X/Friend — modular AI companion framework for AI girlfriends & boyfriends: swappable LLM (Venice/Grok/LongCat) + image (Qwen/Wavespeed + LoRAs) + voice (SecretVoice), with rolling-scene memory compaction.
