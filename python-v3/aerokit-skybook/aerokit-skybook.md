# aerokit-skybook

> 标签: Python

## 简介

Object-oriented airline domain library: PNR generation, fare calculation, route/timezone maths, seat allocation and e-ticket building. Built for the SkyBook cloud flight booking application (NCI Cloud Platform Programming).
