# django-environ

> 标签: 环境变量, 配置

## 简介

A package that allows you to utilize 12factor inspired environment variables to configure your Django application.

## 官网

- 官网：https://django-environ.readthedocs.org
- PyPI 项目页：https://pypi.org/project/django-environ/
