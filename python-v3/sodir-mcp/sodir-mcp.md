# sodir-mcp

> 标签: Python

## 简介

Read-only MCP server for Sodir (Norwegian Offshore Directorate) FactPages: wellbore facts and monthly field production, from a local cache you fetch yourself.

## 官网

- 官网：https://pypi.org/project/sodir-mcp/
- PyPI 项目页：https://pypi.org/project/sodir-mcp/
