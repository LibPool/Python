# docxsurgeon

> 标签: Python

## 简介

对 docx 做 zip 包级手术：替换/编辑嵌入的 xlsx、更新图表数据范围、修复复选框打印符号

## 官网

- 官网：https://github.com/txxcat/docxsurgeon
- PyPI 项目页：https://pypi.org/project/docxsurgeon/

- 下载页面：https://pypi.org/project/docxsurgeon/#files
- 运行要求：Python >=3.9
