# receivify

> 标签: Python

## 简介

Official Python SDK for Receivify, the non-custodial crypto payment gateway: invoices, forwarding addresses, payment links and signed webhooks.

## 官网

- 官网：https://receivify.io
- 源码仓库：https://github.com/receivify/receivify-sdks/tree/main/python
- PyPI 项目页：https://pypi.org/project/receivify/
