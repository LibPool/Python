# dog-geroscience-mcp

> 标签: Python

## 简介

MCP server giving agents dog-specific aging tools: HAGR (AnAge/DrugAge/GenAge) dog rows, dog orthologs of aging genes via Ensembl, FDA Km dose translation, Dog Aging Project codebooks, NIH RePORTER grants, and search over the canine aging literature corpus.
