# resdlem-force

> 标签: Python

## 简介

Extract DLEM forcing data (URMA met + PRISM/URMA precip) for reservoir geometries from Google Earth Engine.

## 官网

- 官网：https://pypi.org/project/resdlem-force/
- PyPI 项目页：https://pypi.org/project/resdlem-force/

## 历史版本号

- 1.0.0

## 获取地址

- pip 安装：`pip install resdlem-force`
- 下载页面：https://pypi.org/project/resdlem-force/#files
- 运行要求：Python >=3.9
