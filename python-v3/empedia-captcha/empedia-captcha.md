# empedia-captcha

> 标签: Python

## 简介

SDK für EMPEDIAcaptcha: Bot-Prüfung (siteverify) und Inhaltsprüfung (check). Ohne Abhängigkeiten.

- 官网：https://empedia.cloud/docs-guides/captcha.html
- 源码仓库：https://github.com/urbanstudioGmbH/empedia-captcha
- PyPI 项目页：https://pypi.org/project/empedia-captcha/
