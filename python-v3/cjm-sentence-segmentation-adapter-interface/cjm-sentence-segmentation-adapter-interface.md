# cjm-sentence-segmentation-adapter-interface

> 标签: Python

## 简介

Typed sentence-segmentation task-adapter interface — SentenceSegmentationAdapter ABC + GenericSentenceSegmentationAdapter (thin pass-through around a pure-compute segmenter tool) and the SentenceSegmentationToolProtocol. The SentenceSegmentationResult data noun lives in cjm-capability-primitives.
