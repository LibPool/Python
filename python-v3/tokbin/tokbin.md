# tokbin

> 标签: Python

## 简介

Pretraining data for language models: tokenize text once into resumable, verifiable binary shards (full install: write and read). Pretraining only; not for SFT or chat data.

## 官网

- 官网：https://github.com/krysyuk/tokbin
- PyPI 项目页：https://pypi.org/project/tokbin/
