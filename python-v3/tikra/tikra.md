# tikra

> 标签: Python

## 简介

TikZ and pgfplots figures to SVG and PNG, without a TeX install. Math labels typeset by mathra.

- 官网：https://matheusmota-dev-br.github.io/tikra/
- 源码仓库：https://github.com/matheusmota-dev-br/tikra
- PyPI 项目页：https://pypi.org/project/tikra/
