# metano-agent-sdk

> 标签: agent, ai, crewai, guardrails, langchain, llm, mcp, observability, security

## 简介

Instrument your own AI agents (LangChain, CrewAI, OpenAI Agents SDK, or plain Python) for Metano: session telemetry and runtime guardrails.
