# fleetml

> 标签: Python

## 简介

Python client for FleetML: push models, run and watch rollouts, A/B experiments and drift checks on a FleetML server.

## 官网

- 官网：https://github.com/fleetml/fleetml
- PyPI 项目页：https://pypi.org/project/fleetml/

## 历史版本号

- 当前版本：0.6.0

- 0.6.0

## 获取地址

- pip 安装：`pip install fleetml`
- 下载页面：https://pypi.org/project/fleetml/#files
- 运行要求：Python >=3.9
