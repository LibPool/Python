# parallelazy

> 标签: Python

## 简介

A lightweight multiprocess worker-plugin framework. Topic-based pub/sub, global enviroment, using process spawn and pipes, pytorch and CUDA ready.

- 官网：https://github.com/cesare-montresor/parallelazy
