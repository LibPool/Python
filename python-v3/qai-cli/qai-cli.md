# qai-cli

> 标签: Python

## 简介

Offline terminal coding agent. Runs Qwen2.5-Coder 1.5B locally via llama.cpp - no API key, no cloud, no telemetry.

## 官网

- 官网：https://github.com/Nodoubvt/local-coding-agent
- PyPI 项目页：https://pypi.org/project/qai-cli/
