# xnotebook

> 标签: Python

## 简介

Run notebooks and scripts on sandboxed xeus wasm kernels (emscripten-forge) inside headless Chromium

## 官网

- 官网：https://pypi.org/project/xnotebook/
- PyPI 项目页：https://pypi.org/project/xnotebook/
