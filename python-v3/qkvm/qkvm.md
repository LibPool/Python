# qkvm

> 标签: Python

## 简介

qKVM: the self-hosted screen wall and command center for IP KVMs and servers (GL.iNet Comet, PiKVM-style, JetKVM, Redfish)

## 官网

- 官网：https://qkvm.com
- 源码仓库：https://github.com/qkvm/qkvm
- PyPI 项目页：https://pypi.org/project/qkvm/
