# nexwall

> 标签: Python

## 简介

Tiny Python client and CLI for the NexWall free wallpaper API (categories, search, random wallpaper, downloads).

- 官网：https://nexwall.kodnextech.com/wallpaper-api/free-wallpaper-api
- 源码仓库：https://github.com/kodnextechnologies/nexwall-python
- PyPI 项目页：https://pypi.org/project/nexwall/
