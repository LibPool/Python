# duduppt

> 标签: Python

## 简介

Consulting-grade PPTX generation skill for AI agents: evidence-chain QA (blind-read review, claim tracing, audit report), native editable PPTX, native charts, edit existing decks, 16 style master templates, MCP server with 13 tools. First-class Chinese support.
