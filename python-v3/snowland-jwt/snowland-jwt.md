# snowland-jwt

> 标签: Python

## 简介

National-cryptography (guomi) JWT implementation based on PyJWT and snowland-smx (SM2/SM3).

## 官网

- 官网：https://github.com/snowland-gm/snowland-jwt
- PyPI 项目页：https://pypi.org/project/snowland-jwt/

- 0.1.0

## 获取地址

- pip 安装：`pip install snowland-jwt`
- 下载页面：https://pypi.org/project/snowland-jwt/#files
- 运行要求：Python >=3.9
