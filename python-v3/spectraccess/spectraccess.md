# spectraccess

> 标签: Python

## 简介

Python library to find and download Earth observation satellite imagery and cal/val reference data through one interface: Sentinel-2, Sentinel-3 SLSTR, Landsat 8 and 9, VIIRS, MTG FCI, MSG SEVIRI and NASA EMIT products, plus RadCalNet, GSICS, AERONET, CAMS, OLCI water vapour and GNSS data. Returns each provider's data as published, with no correction or calibration applied.
