# candlefeed-mcp

> 标签: Python

## 简介

MCP server for CandleFeed: download Binance USD-M order book days, rebuild the book, and query spreads and depth, plus candles, funding, open interest and liquidations.

## 官网

- 官网：https://candlefeed.ai
- PyPI 项目页：https://pypi.org/project/candlefeed-mcp/
