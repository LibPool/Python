# tsetmc-mcp

> 标签: bourse, iran, mcp, model-context-protocol, stocks, tehran-stock-exchange, tse, tsetmc

## 简介

Unofficial read-only MCP server for the Tehran Stock Exchange (tsetmc.com): quotes, market movers, order book, history, indices.
