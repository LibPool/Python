# hece-gdal

> 标签: Python

## 简介

GDAL 3.10.2 Python bindings for Windows: the wheels of Christoph Gohlke repackaged for wolfhece (HECE, University of Liege). Provides the osgeo package, do not install together with the GDAL distribution.

## 官网

- 官网：http://www.gdal.org
- PyPI 项目页：https://pypi.org/project/hece-gdal/

## 历史版本号

- 当前版本：3.10.2

- 3.10.2

## 获取地址

- pip 安装：`pip install hece-gdal`
- 下载页面：https://pypi.org/project/hece-gdal/#files
- 运行要求：Python >=3.8.0
