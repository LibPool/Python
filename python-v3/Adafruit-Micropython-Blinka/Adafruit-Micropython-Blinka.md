# Adafruit-Micropython-Blinka

> 标签: Python

## 简介

A selection of packages for mirroring the CircuitPython API on hosts running micropython.

## 官网

- 官网：https://github.com/adafruit/Adafruit_Micropython_Blinka
- PyPI 项目页：https://pypi.org/project/Adafruit-Micropython-Blinka/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install Adafruit-Micropython-Blinka`
- 下载页面：https://pypi.org/project/Adafruit-Micropython-Blinka/#files
- 运行要求：Python >=3.6.0
