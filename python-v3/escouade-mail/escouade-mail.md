# escouade-mail

> 标签: Python

## 简介

Python SDK for Escouade Mail (formerly Subagent): real mailboxes for AI agents, with sending rules enforced by the server.

## 官网

- 官网：https://escouade.io/mail
- 源码仓库：https://github.com/escouade-io/escouade-mail-python
- PyPI 项目页：https://pypi.org/project/escouade-mail/
