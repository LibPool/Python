# unripe

> 标签: Python

## 简介

Fail the build when a locked dependency is younger than you trust. One check for npm, pnpm, yarn, bun, Deno, PyPI, Cargo, Go, Composer, RubyGems, NuGet, Gradle, Dart, CocoaPods, Swift, Terraform and Conan lockfiles, GitHub Actions, and an MCP server for AI agents.
