# netcodex-agent-exporter

> 标签: Python

## 简介

Local-first exporter for AI agent conversations (Codex, Claude Code, Copilot, Cline, Cursor, Gemini CLI, OpenCode and more) to readable Markdown, HTML and PDF, in Spanish or English.

- 官网：https://gitlab.com/netcodex-tech/agent-conversation-exporter
