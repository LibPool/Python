# facetweak

> 标签: Python

## 简介

Face retouching from the command line or Python: bigger eyes, slimmer face, nose and lip tweaks with smooth landmark-guided warps. Runs on CPU.

## 官网

- 官网：https://github.com/Ekaghni/facetweak
