# lapviz

> 标签: Python

## 简介

Official Python client of the LapViz API: lap timing sessions, telemetry, imports, webhooks and circuits.

## 官网

- 官网：https://lapviz.com/developers
- PyPI 项目页：https://pypi.org/project/lapviz/

## 历史版本号

- 1.0.0

- pip 安装：`pip install lapviz`
- 下载页面：https://pypi.org/project/lapviz/#files
- 运行要求：Python >=3.10
