# kstock-mcp

> 标签: Python

## 简介

Read-only MCP server for Korean stocks: KIS quotes/OHLCV/balance, OpenDART disclosures/financials, IPO schedule and equal-allocation calculator.

## 官网

- 官网：https://github.com/ez2sarang/kstock-mcp
- PyPI 项目页：https://pypi.org/project/kstock-mcp/
