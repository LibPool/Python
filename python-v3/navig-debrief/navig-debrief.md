# navig-debrief

> 标签: Python

## 简介

Visual debrief of a work session: timeline, tool mix, mind map, files and UI mockups rendered to one navigable HTML report, with PNG exports.

## 官网

- 官网：https://navig.run
- PyPI 项目页：https://pypi.org/project/navig-debrief/

- 下载页面：https://pypi.org/project/navig-debrief/#files
