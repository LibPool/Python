# signunder

> 标签: Python

## 简介

Python client for SignUnder: sign AI-generated images with Content Credentials, an invisible watermark and a fingerprint, and verify them.

## 官网

- 官网：https://signunder.com
- PyPI 项目页：https://pypi.org/project/signunder/
