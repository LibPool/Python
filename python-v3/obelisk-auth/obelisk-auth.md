# obelisk-auth

> 标签: Python

## 简介

Drop-in OIDC client for the Obelisk Gate identity platform — login, tokens, refresh, userinfo, and local ES256 token verification.

## 官网

- 官网：https://obeliskgate.com
- PyPI 项目页：https://pypi.org/project/obelisk-auth/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install obelisk-auth`
- 下载页面：https://pypi.org/project/obelisk-auth/#files
- 运行要求：Python >=3.9
