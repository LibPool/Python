# tgart-keys

> 标签: Python

## 简介

Verified Typographics Art issuer signing keys (Ed25519) and sealing keys (X25519), published immutably so agents that can only reach PyPI can verify signed Typograms. No private keys.

## 官网

- 官网：https://typographics-art.org/keys
- 源码仓库：https://github.com/typographics-art/typogram
- PyPI 项目页：https://pypi.org/project/tgart-keys/
