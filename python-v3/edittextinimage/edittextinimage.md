# edittextinimage

> 标签: Python

## 简介

Reference package for EditTextInImage — freemium online tool to replace text in images while keeping font, color, and background.

## 官网

- 官网：https://edittextinimage.com/
- 源码仓库：https://github.com/wayperlee/edittextinimage
- PyPI 项目页：https://pypi.org/project/edittextinimage/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install edittextinimage`
- 下载页面：https://pypi.org/project/edittextinimage/#files
- 运行要求：Python >=3.9
