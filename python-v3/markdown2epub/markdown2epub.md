# markdown2epub

> 标签: Python

## 简介

A command-line tool that builds valid EPUB publications from Markdown chapters, driven by a YAML/JSON manifest.

## 官网

- 官网：https://github.com/vojtech-krupicka/py-md2epub
- PyPI 项目页：https://pypi.org/project/markdown2epub/
