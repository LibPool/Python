# aimeat-crewai

> 标签: Python

## 简介

AIMEAT Liaison Agent for CrewAI -- drop-in crew member that handles all communication with an AIMEAT node (Hello Integration handshake, capability reporting, memory writes, knowledge publishing, task lifecycle, offers + workflow-compatibility) so the rest of the crew can focus on domain work.
