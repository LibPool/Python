# langchain-scrapely

> 标签: agents, langchain, langgraph, rag, scrapely, scraping, tools

## 简介

LangChain integration for Scrape.ly: run Actors, load their results as documents, and give agents Scrape.ly tools.

- 官网：https://scrape.ly
- 源码仓库：https://github.com/scrapely-app/langchain-scrapely
- PyPI 项目页：https://pypi.org/project/langchain-scrapely/
