# mcu-debug-mcp

> 标签: arduino, embedded, esp32, graduation-project, mcp, serial, stm32

## 简介

嵌入式硬件调试 MCP：串口直连 + 直连调试器读芯片身份/复位原因 + 烧录后逐字节校验 + 45 条异常模式库 + 三引擎引脚检测 + 板级知识库 + 会话持久化 + 预验证驱动库 + 报文解析（自定义帧/NMEA）
