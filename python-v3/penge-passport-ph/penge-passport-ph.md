# penge-passport-ph

> 标签: Python

## 简介

PengePassportPH: read-only, rate-limited checker for DFA Philippine passport appointment availability on passport.gov.ph. Library and CLI.

## 官网

- 官网：https://alphaexperiments.com/pengepassportph/
- PyPI 项目页：https://pypi.org/project/penge-passport-ph/
