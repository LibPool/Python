# arduino-hid-controller

> 标签: Python

## 简介

Python library to control Arduino as HID (Keyboard/Mouse) via Serial

## 官网

- 官网：https://github.com/duelist-dev/arduino-hid-controller
- PyPI 项目页：https://pypi.org/project/arduino-hid-controller/

- 下载页面：https://pypi.org/project/arduino-hid-controller/#files
