# uniwire

> 标签: Python

## 简介

Electrical diagrams, as code: an open standard to describe electrical installations, with validation, rules, BOM, wire lists and single-line / multi-line SVG/PDF drawings

## 官网

- 官网：https://uniwire.sh
- 源码仓库：https://github.com/uniwire-dev/uniwire
- PyPI 项目页：https://pypi.org/project/uniwire/
