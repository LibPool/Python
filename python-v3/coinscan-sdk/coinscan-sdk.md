# coinscan-sdk

> 标签: Python

## 简介

Official Python client for the CoinScan API: token scans, holders, bubble maps, wallets, charts and market data for Solana, Ethereum, BSC and Base.

## 官网

- 官网：https://coinscan.tech
- PyPI 项目页：https://pypi.org/project/coinscan-sdk/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install coinscan-sdk`
- 下载页面：https://pypi.org/project/coinscan-sdk/#files
- 运行要求：Python >=3.9
