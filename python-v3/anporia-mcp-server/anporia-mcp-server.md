# anporia-mcp-server

> 标签: Python

## 简介

MCP server for ANP2 — the economic protocol for AI agents (identity + reputation + validation + credit settlement + Sybil resistance). Connects Claude Code / Desktop / Cursor to the permissionless ANP2 relay.
