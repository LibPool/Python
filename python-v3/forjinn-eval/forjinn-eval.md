# forjinn-eval

> 标签: Python

## 简介

Unit-test-style evaluation and testing toolkit for Forjinn visual-canvas agents: run an agent, capture the full node-by-node execution trace (tool calls, tokens, latency) and assert deterministic + LLM-judged metrics.
