# exocortex-symphony

> 标签: Python

## 简介

Unofficial build of OpenAI Symphony with a Plane tracker adapter, as self-contained executables for macOS 14 or later (run on Apple silicon) and Linux (built, never run).

## 官网

- 官网：https://pypi.org/project/exocortex-symphony/
- PyPI 项目页：https://pypi.org/project/exocortex-symphony/
