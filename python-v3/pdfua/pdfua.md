# pdfua

> 标签: Python

## 简介

Check the machine-checkable subset of PDF/UA-1 and WCAG 2.1 for PDFs in Python, built on pikepdf with no JVM

## 官网

- 官网：https://github.com/beduldul/pdfua
- PyPI 项目页：https://pypi.org/project/pdfua/
