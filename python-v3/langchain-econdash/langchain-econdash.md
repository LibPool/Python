# langchain-econdash

> 标签: Python

## 简介

LangChain tools for EconDash macroeconomic data. Same free trial, API key and pay-per-call rules as the econdash client.

- 官网：https://econdash.org
- 源码仓库：https://github.com/econdash/econdash-python
- PyPI 项目页：https://pypi.org/project/langchain-econdash/
