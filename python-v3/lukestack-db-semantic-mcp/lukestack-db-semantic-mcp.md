# lukestack-db-semantic-mcp

> 标签: Python

## 简介

Semantic intelligence layer for SQL Server and Oracle databases, exposed via MCP. A database understanding engine for AI agents (Claude Code CLI, Codex CLI, Claude Desktop, etc.).
