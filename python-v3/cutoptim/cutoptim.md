# cutoptim

> 标签: Python

## 简介

Official client for the CutOptim Engine API — cutting optimization (2D panels, 1D linear, timber, true-shape nesting) over HTTPS.

## 官网

- 官网：https://cutoptim.com/engine/reference
- 源码仓库：https://github.com/cutoptim/engine-python
- PyPI 项目页：https://pypi.org/project/cutoptim/
