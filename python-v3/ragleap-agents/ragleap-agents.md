# ragleap-agents

> 标签: Python

## 简介

A small, provider-neutral agent loop over ragleap-tools Tool objects: a step cap, a taint rule that forces approval for outbound actions after untrusted content, pause/resume approval gates, and a per-run transcript. No database. Bring your own model as a plain callable, or use the included standard-library adapter for OpenAI-compatible chat APIs. BYOK, no vendor lock-in.
