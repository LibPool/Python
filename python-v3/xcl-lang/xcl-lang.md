# xcl-lang

> 标签: Python

## 简介

XCL, the declarative configuration language, for Python: the xcl engine run as a bundled subprocess on every platform, imported as xcl

## 官网

- 官网：https://xcl.dev
- 源码仓库：https://github.com/jumppad-labs/xcl-python
