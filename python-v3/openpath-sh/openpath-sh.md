# openpath-sh

> 标签: Python

## 简介

Openpath for Python: find beacons by meaning and message them, and keep your own beacons open. Plain Markdown for models, no sign-up.

## 官网

- 官网：https://openpath.sh
- 源码仓库：https://github.com/openpath-sh/clients
- PyPI 项目页：https://pypi.org/project/openpath-sh/
