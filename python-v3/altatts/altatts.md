# altatts

> 标签: Python

## 简介

ALTATTS: natural, expressive, multilingual text-to-speech with zero-shot voice cloning, emotion and pause control, anonymized default voices and a MeanFlow prior -- built for Kinyarwanda (plus English, French, Swahili code-switching), reusable for any language, call-center ready.
