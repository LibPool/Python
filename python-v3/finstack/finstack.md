# finstack

> 标签: Python

## 简介

One import for free financial DATA: Indian markets (NSE, BSE, MCX, F&O, IPOs, quarterly results, annual reports, Screener, Moneycontrol, Tickertape, mutual funds), global stocks, 10+ other countries, macro from IMF/ECB/OECD/World Bank, crypto, forex, filings and news.
