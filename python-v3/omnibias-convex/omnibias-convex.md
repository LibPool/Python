# omnibias-convex

> 标签: Python

## 简介

Differentiable + certified convex optimization (LP/QP) for omnibias: closed-form-Hessian log-barrier interior-point solver, KKT implicit-function gradients (argmin as a differentiable op), and verified optimality enclosures (jax + torch).
