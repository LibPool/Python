# couryo

> 标签: Python

## 简介

Official Python SDK for the Couryo email API: typed, with retries, automatic Idempotency-Key, webhook verification and a Django email backend.

- 官网：https://couryo.com
- 源码仓库：https://github.com/Wunka-Tech/couryo-python
