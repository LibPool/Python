# bayesrisk

> 标签: Python

## 简介

Librería de riesgo de crédito: PD (scorecards, ML, survival), LGD y EAD, validación de modelos, provisiones IFRS 9/ECL, forward-looking y stress testing, con informe reproducible y su lineage.
