# india-xbrl-filings

> 标签: Python

## 简介

Discover and download Indian listed-company financial-result XBRL filings (NSE and BSE) with full provenance. Download + preserve + index only; parsing is out of scope for v1.

- PyPI 项目页：https://pypi.org/project/india-xbrl-filings/
