# bigpipe

> 标签: Python

## 简介

Python SDK for BigPipe, the high performance realtime stream processing platform (async producer, consumer groups, share groups, SSE streaming, admin). Dibuat oleh Gravicode Studios dipimpin oleh Kang Fadhil.
