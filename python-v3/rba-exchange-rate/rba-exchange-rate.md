# rba-exchange-rate

> 标签: Python

## 简介

Official Reserve Bank of Australia exchange rates - ~22 currencies vs AUD, history since 2023. Keyless, zero-dependency Python client.

## 官网

- 官网：https://allratestoday.com/central-bank-rates-api/rba/
- 源码仓库：https://github.com/AllRates-Today/exchange-rates-api
- PyPI 项目页：https://pypi.org/project/rba-exchange-rate/
