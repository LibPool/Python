# carmaker-mcp

> 标签: Python

## 简介

MCP server that lets an AI agent drive IPG CarMaker for Simulink: run test runs, edit vehicle/driver/test-run data and Simulink parameters, read results.

## 官网

- 官网：https://github.com/dimitr-io/carmaker-mcp
