# adf2dms

> 标签: Python

## 简介

Convert Amiga disk images from ADF to DMS (DiskMasher) format

## 官网

- 官网：https://github.com/dlitz/adf2dms
- PyPI 项目页：https://pypi.org/project/adf2dms/

## 历史版本号

- 0.0.1

## 获取地址

- pip 安装：`pip install adf2dms`
- 下载页面：https://pypi.org/project/adf2dms/#files
- 运行要求：Python >=3.9
