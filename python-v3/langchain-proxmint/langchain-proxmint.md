# langchain-proxmint

> 标签: Python

## 简介

LangChain tool and document loader that read web pages through Proxmint residential, datacenter and mobile proxies, with country, city and ASN targeting and sticky sessions.

## 官网

- 官网：https://proxmint.com
- 源码仓库：https://github.com/proxmint/langchain-proxmint
- PyPI 项目页：https://pypi.org/project/langchain-proxmint/

- 0.1.0

- pip 安装：`pip install langchain-proxmint`
- 下载页面：https://pypi.org/project/langchain-proxmint/#files
