# revdoku

> 标签: Python

## 简介

Revdoku API client for Python: mailboxes for AI agents, with attachments and private file storage.

- 官网：https://revdoku.com
- 源码仓库：https://github.com/revdoku/revdoku-python
- PyPI 项目页：https://pypi.org/project/revdoku/
