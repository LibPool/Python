# rulestamp-beancount-auslandsumsatz-lint

> 标签: Python

## 简介

Prüft Beancount- und hledger-Journale mit 10 rules auf Euro-Umrechnung, USt-IdNr., Reverse Charge und ZM-Frist (§ 18a UStG) (bundled Node.js runtime)
