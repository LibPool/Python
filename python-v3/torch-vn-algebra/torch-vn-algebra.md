# torch-vn-algebra

> 标签: Python

## 简介

PyTorch library for block-diagonal matrices with symmetry sectors (Type I von Neumann algebras): Haar random unitaries, quantum states, channels, Lindblad dynamics, spin chains; batched on GPU
