# ontocraft-check

> 标签: Python

## 简介

OWL 온톨로지 검사 도구: 모델링 함정, 메타데이터, OWL 2 RL 논리, SHACL, 한국 산업 용어 등록부 대조, CQ 커버리지를 한국어 보고서로 냅니다
