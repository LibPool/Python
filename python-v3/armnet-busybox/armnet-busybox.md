# armnet-busybox

> 标签: Python

## 简介

BusyBox instrumented-task-box environment for armnet: live state, semantic decoding, goal-state success checks and automated scene resets.

## 官网

- 官网：https://armnet.dev
- PyPI 项目页：https://pypi.org/project/armnet-busybox/
