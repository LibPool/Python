# rulestamp-gnu-global-cpp-vscode-config-pack

> 标签: Python

## 简介

21 rules that read the values in a shared .vscode folder, plus 45 snippets. VS Code loads a wrong value without a word - this names the line and the fix. (bundled Node.js runtime)
