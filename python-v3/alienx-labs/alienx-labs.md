# alienx-labs

> 标签: Python

## 简介

AlienX (Isomorphic Spatial Net): rotation/scale-equivariant neural operators for Darcy flow, Gross-Pitaevskii, and 3D Navier-Stokes, with pretrained weights bundled and a one-call model zoo.
