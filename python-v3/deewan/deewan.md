# deewan

> 标签: Python

## 简介

Official Python SDK for the Deewan video meetings API: rooms, join links, media tokens, participants, meetings, webinars, polls, breakout rooms, recordings and signed webhooks.

## 官网

- 官网：https://deewan.io
- PyPI 项目页：https://pypi.org/project/deewan/
