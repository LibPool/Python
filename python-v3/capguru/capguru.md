# capguru

> 标签: Python

## 简介

Automatic captcha solving for Playwright via the Cap.Guru service: reCAPTCHA v2, hCaptcha, GeeTest, FunCaptcha, TikTok, AWS WAF, Yandex SmartCaptcha

## 官网

- 官网：https://cap.guru
- PyPI 项目页：https://pypi.org/project/capguru/

- 0.4.0

- 下载页面：https://pypi.org/project/capguru/#files
