# navig-chats

> 标签: Python

## 简介

navig chats -- a local library for your AI conversations: import your ChatGPT data export, save chats from the page with the NAVIG Dock, search every message offline, organise them in folders, and export to Markdown, HTML, JSON or a checksummed zip.
