# qenvs

> 标签: Python

## 简介

QEnvS: physically validated quantum control environments (quantum batteries, state transfer, open systems) for RL and optimal control, built on JAX + dynamiqs.

## 官网

- 官网：https://github.com/beomdo-park/QEnvS
