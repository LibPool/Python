# postseed

> 标签: database, deterministic, fake-data, faker, fixtures, postgres, postgresql, seed, seed-data, test-data

## 简介

Realistic, relationship-correct seed data for PostgreSQL. Local-first and deterministic. Runs the Postseed CLI and Studio with Node.js.
