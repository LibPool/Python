# agent-auth-rs

> 标签: Python

## 简介

Agent Auth RS 校验 SDK(spec 010 P1b):MCP 资源服务器侧 access token 校验 — aud 强校验、命名空间 sub_type 策略、kid 强制 alg、未知 kid 重取限流+负缓存、WWW-Authenticate 发现头。
