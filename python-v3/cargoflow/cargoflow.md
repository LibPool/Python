# cargoflow

> 标签: Python

## 简介

CargoFlow Python SDK: typed read access to the CargoFlow API, pandas/polars data frames and portfolio risk analytics (exposure, excursions, conflicts, release latency, recoveries, Monte Carlo of default and recovery), plus gateway request signing.
