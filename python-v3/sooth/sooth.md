# sooth

> 标签: Python

## 简介

Claim-by-claim hallucination detection and fact-checking for AI-generated text, built for CI. PASS/FAIL/REVIEW verdicts, each naming the rule behind it and the source line it was judged against, powered by Jev (TypeSafe System One).
