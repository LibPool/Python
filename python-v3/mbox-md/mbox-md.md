# mbox-md

> 标签: Python

## 简介

Convert Gmail Takeout and other mbox archives into Markdown files with deduplicated attachments.

## 官网

- 官网：https://pypi.org/project/mbox-md/
- 源码仓库：https://github.com/dupontcyborg/mbox-md
- PyPI 项目页：https://pypi.org/project/mbox-md/
