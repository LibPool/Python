# aics-identity

> 标签: Python

## 简介

Cryptographic identity for AI agents: Ed25519 keys (raw, did:key, OpenSSH), deterministic derivation, signed JSON envelopes with sender chains, RFC 9421 HTTP message signatures with replay hooks, SSHSIG and text-protocol line signatures, X25519 sealed boxes.
