# fenolite

> 标签: Python

## 简介

Headless, agent-first PCB design automation in Python: generate, open, verify, compare, convert and export KiCad (and later Altium) projects from code or the CLI.

## 官网

- 官网：https://github.com/lgili/Fenolite
