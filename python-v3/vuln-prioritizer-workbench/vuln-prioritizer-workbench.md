# vuln-prioritizer-workbench

> 标签: Python

## 简介

Local-first Workbench for explainable CVE prioritization from scanner, SBOM, VEX, and asset-context evidence using CVSS, EPSS, KEV, and curated ATT&CK/TTP context.
