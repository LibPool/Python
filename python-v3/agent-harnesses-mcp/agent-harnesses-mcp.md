# agent-harnesses-mcp

> 标签: Python

## 简介

MCP server for best-of-Agent-Harnesses: opinionated harness recommendations (recommend/pick_harness), search, and head-to-head decision guides over a hand-curated, weekly-rescored list of agent harnesses
