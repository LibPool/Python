# apple-llm

> 标签: Python

## 简介

Apple's on-device (Foundation Models) and Private Cloud Compute LLMs from Python. No API key, no account, macOS 26+ on Apple Silicon.

- 官网：https://pypi.org/project/apple-llm/
- PyPI 项目页：https://pypi.org/project/apple-llm/
