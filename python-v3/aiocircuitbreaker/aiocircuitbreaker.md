# aiocircuitbreaker

> 标签: Python

## 简介

This is an async Python implementation of the circuitbreaker library https://github.com/fabfuel/circuitbreaker.

## 官网

- 官网：https://github.com/GenyaSol/aiocircuitbreaker
- PyPI 项目页：https://pypi.org/project/aiocircuitbreaker/

- 2.0.0

## 获取地址

- pip 安装：`pip install aiocircuitbreaker`
- 下载页面：https://pypi.org/project/aiocircuitbreaker/#files
- 运行要求：Python >=3.9.0,<4.0.0
