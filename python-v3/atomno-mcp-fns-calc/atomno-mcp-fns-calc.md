# atomno-mcp-fns-calc

> 标签: Python

## 简介

MCP server: Russian tax calculators (VAT, USN, ИП contributions, progressive NDFL 2025+, patent, penalty) offline + fiscal-status checks (self-employed/НПД, ИП/ОКВЭД, disqualified, account blocks, arrears) via hosted API.
