# evidence-deflator

> 标签: Python

## 简介

Evidence Deflator: how much of the evidence behind an AI trading result actually counts. Given a model's knowledge cutoff, a test window and the number of attempts, returns clean months, months needed and a verdict. Also separates factual from definitional disagreement between risk sources.
