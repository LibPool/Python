# matricula-mcp

> 标签: Python

## 简介

MCP server for Matricula Online, the church-book portal of dioceses and archives in Germany, Austria, Poland, Slovenia and beyond: find a parish, list its registers, and open any page in Matricula's own viewer. For genealogy and history.
