# langchain-send21

> 标签: Python

## 简介

send21 tools for LangChain. Crypto pay links and API for people and AI agents. The payer signs in their own wallet.

## 官网

- 官网：https://send21.io
- 源码仓库：https://github.com/send21io/send21-examples/tree/main/integrations/langchain
- PyPI 项目页：https://pypi.org/project/langchain-send21/
