# lovefengis

> 标签: Python

## 简介

Official Python client for the lovefengis REST API: services and prices of lovefengis (software studio, Izmir, Turkey). Read-only, no API key.

## 官网

- 官网：https://lovefengis.com
- 源码仓库：https://github.com/systemonster/lovefengis-agents
- PyPI 项目页：https://pypi.org/project/lovefengis/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install lovefengis`
- 下载页面：https://pypi.org/project/lovefengis/#files
- 运行要求：Python >=3.9
