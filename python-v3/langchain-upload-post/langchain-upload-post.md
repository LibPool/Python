# langchain-upload-post

> 标签: Python

## 简介

LangChain tools to publish, schedule and analyze social media posts with Upload-Post (TikTok, Instagram, YouTube, LinkedIn, X, Facebook and more).

## 官网

- 官网：https://www.upload-post.com
- 源码仓库：https://github.com/Upload-Post/langchain-upload-post
- PyPI 项目页：https://pypi.org/project/langchain-upload-post/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install langchain-upload-post`
- 下载页面：https://pypi.org/project/langchain-upload-post/#files
- 运行要求：Python <4.0,>=3.10
