# mmd-bone-tools

> 标签: Python

## 简介

Translate Japanese MMD bone names to English, map bones between MMD, Blender, Unity Humanoid, VRM and Mixamo, and retarget VMD motions (PMX, PMD, VMD)

## 官网

- 官网：https://qiangiq.github.io/MMD-bone-SDK/
- 源码仓库：https://github.com/QIangIQ/MMD-bone-SDK
- PyPI 项目页：https://pypi.org/project/mmd-bone-tools/
