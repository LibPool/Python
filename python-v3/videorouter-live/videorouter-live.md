# videorouter-live

> 标签: Python

## 简介

Python SDK for videorouter.sh: live video & world models (open, keep alive, settle a real-time session) and the /v1/videos generation API.

## 官网

- 官网：https://videorouter.sh/docs/live-video
- PyPI 项目页：https://pypi.org/project/videorouter-live/

## 历史版本号

- 当前版本：0.2.0

- 0.2.0

## 获取地址

- pip 安装：`pip install videorouter-live`
- 下载页面：https://pypi.org/project/videorouter-live/#files
- 运行要求：Python >=3.9
