# waqt-local

> 标签: Python

## 简介

Embeddable, no-server local computation library for Waqt (Maghrib-to-Maghrib civil time and Hijri calendar).

## 官网

- 官网：https://github.com/waqt-project/waqt-api
- PyPI 项目页：https://pypi.org/project/waqt-local/

## 历史版本号

- 当前版本：0.7.0

- 0.7.0

## 获取地址

- pip 安装：`pip install waqt-local`
- 下载页面：https://pypi.org/project/waqt-local/#files
- 运行要求：Python >=3.9
