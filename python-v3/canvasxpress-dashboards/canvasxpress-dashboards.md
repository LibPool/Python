# canvasxpress-dashboards

> 标签: Python

## 简介

Linked, multi-panel CanvasXpress dashboards in Python: Jupyter, Dash, Streamlit, Flask. Render a dashboards spec, or build a whole dashboard from a DataFrame.

## 官网

- 官网：https://www.canvasxpress.org
- 源码仓库：https://github.com/neuhausi/canvasxpress-dashboards
- PyPI 项目页：https://pypi.org/project/canvasxpress-dashboards/
