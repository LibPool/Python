# vendorcheck

> 标签: Python

## 简介

Check whether embedded/vendored Python packages are identical to the official PyPI release.

## 官网

- 官网：https://github.com/Ferdi-krbk/vendorcheck
- PyPI 项目页：https://pypi.org/project/vendorcheck/
