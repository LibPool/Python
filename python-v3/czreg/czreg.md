# czreg

> 标签: Python

## 简介

Typed async clients for the Czech public registers: ARES (VR, RES, RŽP, ROS, NRPZS, RPSH, RCNS, SZR, RŠ, CEÚ), ISIR, and the VAT payer register (DPH)
