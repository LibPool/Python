# langchain-comment-scraper

> 标签: Python

## 简介

LangChain document loader for Reddit and Hacker News threads exported with Comment Scraper. Reads local JSON files, makes no network requests.

## 官网

- 官网：https://comment-scraper.com/langchain
- 源码仓库：https://github.com/supertj/langchain-comment-scraper
- PyPI 项目页：https://pypi.org/project/langchain-comment-scraper/
