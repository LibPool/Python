# attestify-sdk

> 标签: Python

## 简介

Official Python SDK for Attestify OS — governed agent execution, signed authority envelopes, x402-native payments, and immutable receipts. Also ships Attestify Trust: portable identity, signed evidence, and free public verification for agents that never touch a wallet.
