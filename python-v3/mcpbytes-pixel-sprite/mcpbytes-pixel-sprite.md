# mcpbytes-pixel-sprite

> 标签: Python

## 简介

Generate 32x32 pixel-art character sprite sheets with walk animations, Godot and Unity exports, on your own GPU. CLI and MCP server.

- 官网：https://mcpbytes.com
- 源码仓库：https://github.com/MCPBytes/mcpbytes-pixel-sprite
