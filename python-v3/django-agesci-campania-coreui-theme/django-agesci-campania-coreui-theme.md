# django-agesci-campania-coreui-theme

> 标签: Python

## 简介

Tema CoreUI 5 per applicazioni Django dell'AGESCI Campania: estende django-agesci-campania-theme con il layout nativo CoreUI (sidebar + header) e i componenti free di CoreUI.
