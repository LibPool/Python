# ec2patcher

> 标签: Python

## 简介

Local web GUI that analyzes Ubuntu and Amazon Linux 2023 EC2 servers for CVE fixes and patches Ubuntu servers over SSH from an approved .deb plan

## 官网

- 官网：https://github.com/Amiri83/EC2Patcher
- PyPI 项目页：https://pypi.org/project/ec2patcher/

## 历史版本号

- 当前版本：1.0.1

- 1.0.1

## 获取地址

- pip 安装：`pip install ec2patcher`
- 下载页面：https://pypi.org/project/ec2patcher/#files
- 运行要求：Python >=3.10
