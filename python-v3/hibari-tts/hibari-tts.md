# hibari-tts

> 标签: Python

## 简介

Tiny English text-to-speech: 7.9 MB per voice (American and British), about 130x realtime on one CPU core, text in, 24 kHz audio out

## 官网

- 官网：https://github.com/MMWilliams/hibari
- PyPI 项目页：https://pypi.org/project/hibari-tts/
