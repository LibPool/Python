# sqlite-graph-memory

> 标签: Python

## 简介

Associative memory for LLM agents: Graph RAG over a folder of markdown notes, in one SQLite file, with no server to run.

## 官网

- 官网：https://github.com/tonydzi/sqlite-graph-memory
- PyPI 项目页：https://pypi.org/project/sqlite-graph-memory/
