# fairfax

> 标签: Python

## 简介

Check a Microsoft gov-cloud plan (GCC, GCC High, DoD, Azure Government) against Microsoft's own availability tables, from Azure to Microsoft 365 Copilot. Scan code for wrong-cloud hosts and decode AADSTS errors. Every finding cites the row it came from.
