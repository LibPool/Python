# nexctf-sandbox

> 标签: Python

## 简介

Sandboxed code execution for NexCTF, script checker and code runner via microsandbox microVMs.

## 官网

- 官网：https://github.com/NexCTF/Sandbox
- PyPI 项目页：https://pypi.org/project/nexctf-sandbox/

## 历史版本号

- 1.0.0

## 获取地址

- pip 安装：`pip install nexctf-sandbox`
- 下载页面：https://pypi.org/project/nexctf-sandbox/#files
- 运行要求：Python >=3.15
