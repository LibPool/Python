# repowatch

> 标签: Python

## 简介

Every git repo under a folder, compared across all its remotes, with fast-forward-only sync and safe branch pruning.

## 官网

- 官网：https://github.com/markgwharry/repowatch
- PyPI 项目页：https://pypi.org/project/repowatch/
