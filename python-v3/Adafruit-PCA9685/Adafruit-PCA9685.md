# Adafruit-PCA9685

> 标签: Python

## 简介

Python code to use the PCA9685 PWM servo/LED controller with a Raspberry Pi or BeagleBone Black.

## 官网

- 官网：https://github.com/adafruit/Adafruit_Python_PCA9685/
- PyPI 项目页：https://pypi.org/project/Adafruit-PCA9685/
