# url-guard

> 标签: Python

## 简介

SSRF guard for outbound URLs: canonical IP-literal parsing in every encoding, private/metadata/link-local classification, DNS-resolved validation, HTTPS and host allow-list rules. Zero dependencies. Wire-identical to the url-guard npm package.
