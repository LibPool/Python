# langchain-flatmark

> 标签: Python

## 简介

Document to Markdown API and MCP server for PDF, Word, PowerPoint, Excel and HTML. OCR queue for large files. Hosted in Germany.

## 官网

- 官网：https://flatmark.dev
- 源码仓库：https://github.com/flatmark-dev/flatmark-integrations
