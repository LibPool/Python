# anysearch-sdk

> 标签: anthropic, brave, brightdata, dataforseo, deepseek, exa, keenable, keiro, llm, mcp, openai, parallel, rag, search, search-api, serpapi, tavily, tinyfish, xai

## 简介

A unified adapter layer to call any web search API provider (Exa, Parallel, Brave, Tavily, Keenable, OpenAI, and more) with one interface — plus a stdio MCP server.
