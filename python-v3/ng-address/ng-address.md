# ng-address

> 标签: Python

## 简介

Alias for ng-address-resolver, which resolves Nigerian addresses to NIPOST digital postcodes.

## 官网

- 官网：https://pypi.org/project/ng-address/
- 源码仓库：https://github.com/Adeniyikayodee/ng-postcode
- PyPI 项目页：https://pypi.org/project/ng-address/

## 获取地址

- pip 安装：`pip install ng-address`
- 下载页面：https://pypi.org/project/ng-address/#files
- 运行要求：Python >=3.10
