# rindo-convert

> 标签: Python

## 简介

The Rindo converter agent: vision-grounded conversion of PDF and PPTX files into reviewable Rindo documents, run through rindo-runner

- 源码仓库：https://github.com/rindohq/rindo
- PyPI 项目页：https://pypi.org/project/rindo-convert/
