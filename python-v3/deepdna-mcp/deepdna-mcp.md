# deepdna-mcp

> 标签: Python

## 简介

Local MCP server that reads a raw DNA file on your computer and reports what it shows at the variants DeepDNA curates, with cited records. Nothing from the file is sent to deepdna.ai.

## 官网

- 官网：https://deepdna.ai/docs/#mcp
- 源码仓库：https://github.com/alfonsoguv/deepdna-mcp
