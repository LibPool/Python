# adversaria-mcp

> 标签: Python

## 简介

MCP server for Adversaria: read your local meeting notes and to-dos, and report completed work back for your approval. On-device, no network calls of its own.

## 官网

- 官网：https://pypi.org/project/adversaria-mcp/
- PyPI 项目页：https://pypi.org/project/adversaria-mcp/
