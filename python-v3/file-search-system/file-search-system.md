# file-search-system

> 标签: Python

## 简介

基于 Everything 的本地毫秒级文件搜索系统：Python 库 + 全功能 CLI + HTTP JSON API（非管理员文件夹索引、junction 死循环免疫、非阻塞搜索）

- PyPI 项目页：https://pypi.org/project/file-search-system/
