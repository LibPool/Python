# tungsten-finance

> 标签: Python

## 简介

Finance and accounts plugin for Tungsten: double-entry books with GST invoices, bills, quotes, notes, stock, P&L, balance sheet and GST returns.

## 官网

- 官网：https://tungsten.prisminfoways.com/
- 源码仓库：https://github.com/Prism-Infoways/Tungsten
- PyPI 项目页：https://pypi.org/project/tungsten-finance/
