# wiltech-labs-ai

> 标签: Python

## 简介

AI building blocks for Wiltech FastAPI apps: Workers AI / Groq / Ollama behind one protocol, OpenAI-compatible tool calling over httpx, embeddings, portable vector stores (database, Vectorize, Qdrant), hybrid-search fusion and a tool-calling agent loop.
