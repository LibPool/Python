# bkrc-chatlabel

> 标签: Python

## 简介

bkrc_chatlabel：LLM 网页对话自动标注工具（检测/分割/分类），提取标注、统计管理、按任务导出 YOLO 数据集、训练模型

- PyPI 项目页：https://pypi.org/project/bkrc-chatlabel/
