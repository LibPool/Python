# pipecat-duplexjev

> 标签: Python

## 简介

Audio end-of-turn detection for Pipecat with DuplexJev: turn state, emotion and non-verbal sounds from one forward pass, no transcript needed.

- 官网：https://github.com/adventists-ai/duplexjev/tree/main/integrations/pipecat
