# pystormflow

> 标签: Python

## 简介

Python interface to Stormflow, a CFD solver specialized for actuator line simulations with Stormbird.

## 官网

- 官网：https://github.com/NTNU-IMT/stormbird
- PyPI 项目页：https://pypi.org/project/pystormflow/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install pystormflow`
- 下载页面：https://pypi.org/project/pystormflow/#files
- 运行要求：Python >=3.12
