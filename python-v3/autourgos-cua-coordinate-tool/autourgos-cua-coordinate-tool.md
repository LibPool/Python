# autourgos-cua-coordinate-tool

> 标签: Python

## 简介

LLM-grounded UI coordinate finding for Autourgos computer-use agents — locates a described UI element in a screenshot and returns its position normalized to a 0-1000 scale (Gemini computer-use's coordinate convention).
