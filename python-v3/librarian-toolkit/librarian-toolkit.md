# librarian-toolkit

> 标签: Python

## 简介

Source-available local knowledge library with hybrid search and an MCP server for AI coding agents. Free for noncommercial use and small businesses; other companies need a paid license.

## 官网

- 官网：https://github.com/kevin-j-smith/librarian
- PyPI 项目页：https://pypi.org/project/librarian-toolkit/
