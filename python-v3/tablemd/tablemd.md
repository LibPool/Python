# tablemd

> 标签: Python

## 简介

Convert Markdown tables to CSV / TSV / JSON / Excel and back. Library + CLI, clipboard-aware, CJK-friendly.

- 官网：https://github.com/Aaron-lab-c/tablemd
- PyPI 项目页：https://pypi.org/project/tablemd/
