# agenttune

> 标签: Python

## 简介

AgentTune: build agentic workflows, then train, evaluate, distill, and self-heal them through one trajectory schema. A TRL-backed alignment + fine-tuning library (full RL coverage — DPO, PPO, GRPO) with an agentic integration spine on top: agent-design / memory-design / harness-design pillars, a Project lifecycle, and a FastAPI service.
