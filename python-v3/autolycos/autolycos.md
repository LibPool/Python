# autolycos

> 标签: Python

## 简介

Anti-bot fetching subsystem: escalating Fetcher tiers (http/tls/browser/uc) behind a stable port, with fail-closed SSRF guards. Domain-agnostic: the caller injects a DomainPolicy.
