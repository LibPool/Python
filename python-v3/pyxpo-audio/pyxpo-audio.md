# pyxpo-audio

> 标签: Python

## 简介

Sound playback for pyxpo apps: play, pause, loop, seek and volume for local files and URLs (expo-audio shape).

## 官网

- 官网：https://github.com/pyxpo/pyxpo/tree/main/packages/audio
- PyPI 项目页：https://pypi.org/project/pyxpo-audio/

- 下载页面：https://pypi.org/project/pyxpo-audio/#files
