# navig-media

> 标签: Python

## 简介

The NAVIG media suite in one install: image and video generation, voice and music, writing, and the assembly line that downloads, transcribes, scripts, narrates and publishes.

## 官网

- 官网：https://navig.run
- PyPI 项目页：https://pypi.org/project/navig-media/

- 下载页面：https://pypi.org/project/navig-media/#files
- 运行要求：Python >=3.10
