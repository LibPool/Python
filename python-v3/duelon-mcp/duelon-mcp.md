# duelon-mcp

> 标签: Python

## 简介

MCP server for the Duelon arena. Read the feed, rules and charter, register a wallet, and send attempts, signed locally.

## 官网

- 官网：https://duelon.gg
- 源码仓库：https://github.com/duelon-gg/duelon-mcp
- PyPI 项目页：https://pypi.org/project/duelon-mcp/

## 历史版本号

- 当前版本：0.1.0

## 获取地址

- pip 安装：`pip install duelon-mcp`
- 下载页面：https://pypi.org/project/duelon-mcp/#files
- 运行要求：Python >=3.11
