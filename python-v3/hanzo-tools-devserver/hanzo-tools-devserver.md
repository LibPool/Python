# hanzo-tools-devserver

> 标签: Python

## 简介

Dev server tool for Hanzo AI: find running Next/Vite/Nuxt/Astro/SvelteKit/Remix servers, call their MCP tools, read their errors

## 官网

- 官网：https://github.com/hanzoai/python-sdk
- PyPI 项目页：https://pypi.org/project/hanzo-tools-devserver/

## 历史版本号

- 0.1.0

- pip 安装：`pip install hanzo-tools-devserver`
- 下载页面：https://pypi.org/project/hanzo-tools-devserver/#files
- 运行要求：Python >=3.12
