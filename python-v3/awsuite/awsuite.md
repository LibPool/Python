# awsuite

> 标签: Python

## 简介

Let an agent use a Google Workspace -- Gmail, Drive, Calendar, Docs, Sheets, Directory -- from a CLI, an MCP server, an agent toolpack and skills, with every write gated behind an explicit confirm.
