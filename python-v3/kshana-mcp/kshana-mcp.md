# kshana-mcp

> 标签: Python

## 简介

Launcher for the Kshana MCP server: downloads the prebuilt kshana-mcp binary of the same version from the GitHub release, checks it against SHA256SUMS and runs it. Advisory, not type-approved navigation equipment.
