# hf-to-litertlm

> 标签: Python

## 简介

One command from a Hugging Face model repo to a .litertlm bundle for LiteRT-LM, on a pinned toolchain; rebuilding from its lock file gives the same bytes

## 官网

- 官网：https://github.com/john-rocky/hf-to-litertlm
- PyPI 项目页：https://pypi.org/project/hf-to-litertlm/
