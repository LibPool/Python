# rulestamp-pg14-upgrade-blocker-lint

> 标签: Python

## 简介

PostgreSQL upgrade 14 → 17: finds the SQL and config lines that PostgreSQL 15, 16 and 17 removed, with the fix on each line (bundled Node.js runtime)
