# seowebchecker-seoaudit-sdk

> 标签: Python

## 简介

Lightweight open-source client SDK and CLI tool for full website SEO audits, Core Web Vitals checks, and on-page optimization by SEOWebChecker.

- 官网：https://seowebchecker.com
- 源码仓库：https://github.com/seowebchecker/seowebchecker-seoaudit-sdk
