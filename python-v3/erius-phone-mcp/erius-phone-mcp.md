# erius-phone-mcp

> 标签: Python

## 简介

MCP server that gives your AI agent a real Android phone (ERIUS PHONE): read the screen, tap, type, launch apps, read crash logs.

## 官网

- 官网：https://eriusphone.com
- 源码仓库：https://github.com/Protremix/erius-phone-mcp
- PyPI 项目页：https://pypi.org/project/erius-phone-mcp/
