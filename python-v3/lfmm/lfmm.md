# lfmm

> 标签: Python

## 简介

Benchmark and toolkit for monitoring ML models before their labels arrive: performance estimation, drift detection and retraining under natural drift and label delay

## 官网

- 官网：https://github.com/rajkumar160798/label-free-model-monitoring
- PyPI 项目页：https://pypi.org/project/lfmm/
