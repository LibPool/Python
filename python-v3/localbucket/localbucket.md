# localbucket

> 标签: Python

## 简介

Minimal S3-compatible server that stores buckets as plain folders on disk, for local development and testing.

## 官网

- 官网：https://github.com/selcuk/localbucket
- PyPI 项目页：https://pypi.org/project/localbucket/

- 下载页面：https://pypi.org/project/localbucket/#files
- 运行要求：Python >=3.10
