# pith-h264

> 标签: Python

## 简介

H.264/AVC baseline-subset decoding SDK: Annex-B NAL/SPS/PPS, CAVLC slices, in-loop deblocking via the pith-h264 Rust cdylib (ctypes, zero-dep)
