# civitascope-data

> 标签: Python

## 简介

Civitascope data engine: fetches Eurostat data, checks it against dataset cards and computes verifiable, sourced figures for infographics. Early development.

## 官网

- 官网：https://civitascope.com
- 源码仓库：https://github.com/civitascope/civitascope-data
- PyPI 项目页：https://pypi.org/project/civitascope-data/
