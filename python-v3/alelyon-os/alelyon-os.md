# alelyon-os

> 标签: Python

## 简介

The open Alelyon developer surface: certified-number production and verification, exact coordinate registration and model morphometry, multi-session worktree coordination, a local-model conversation with constrained decoding, uncertainty-propagating compute, and the API client.
