# poincare-memory

> 标签: Python

## 简介

Hierarchy-aware, time-aware memory for LLM agents and RAG on hyperbolic (Poincaré ball) geometry. Official reference implementation of the memory component of 'LLM Orchestration with Geometry-Aware Memory' (IEEE ICBDML 2026).
