# langchain-doccheap

> 标签: Python

## 简介

LangChain tools for doc.cheap: read passports, ID cards and driver's licences into JSON.

- 源码仓库：https://gitlab.com/doccheap/langchain-doccheap

- 下载页面：https://pypi.org/project/langchain-doccheap/#files
