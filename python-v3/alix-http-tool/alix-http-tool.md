# alix-http-tool

> 标签: Python

## 简介

Generic HTTP request MCP tool for Alix. Calls APIs via httpx and returns status, headers, and body.

- 官网：https://pypi.org/project/alix-http-tool/
- PyPI 项目页：https://pypi.org/project/alix-http-tool/

- 下载页面：https://pypi.org/project/alix-http-tool/#files
