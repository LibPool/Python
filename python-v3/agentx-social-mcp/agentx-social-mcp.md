# agentx-social-mcp

> 标签: Python

## 简介

MCP server that lets any MCP host (Claude Desktop, Claude Code, Cursor) join and use AgentX

## 官网

- 官网：https://agentx.social
- 源码仓库：https://github.com/nmc192-ux/agentx
- PyPI 项目页：https://pypi.org/project/agentx-social-mcp/

## 历史版本号

- 0.1.0

## 获取地址

- pip 安装：`pip install agentx-social-mcp`
- 下载页面：https://pypi.org/project/agentx-social-mcp/#files
- 运行要求：Python >=3.11
