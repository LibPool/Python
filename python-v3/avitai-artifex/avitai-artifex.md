# avitai-artifex

> 标签: Python

## 简介

Generative modeling for JAX/Flax NNX: VAEs, GANs, diffusion, normalizing flows, energy-based, autoregressive and geometric models across image, text, audio, molecular, protein, tabular and time-series modalities, with a shared Trainer and evaluation through calibrax
