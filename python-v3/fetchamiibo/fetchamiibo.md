# fetchamiibo

> 标签: Python

## 简介

Download amiibo NFC dumps for a Flipper Zero from the command line. Pick by name, or browse by game and letter.

## 官网

- 官网：https://github.com/SamuelArther/fetchamiibo
- PyPI 项目页：https://pypi.org/project/fetchamiibo/

## 历史版本号

- 当前版本：1.1.0

- 1.1.0

## 获取地址

- pip 安装：`pip install fetchamiibo`
- 下载页面：https://pypi.org/project/fetchamiibo/#files
- 运行要求：Python >=3.9
