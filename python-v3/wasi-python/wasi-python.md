# wasi-python

> 标签: Python

## 简介

A statically linked CPython for WebAssembly hosts (wasm32-wasip1) with numpy, pandas and matplotlib compiled in.

## 官网

- 官网：https://wasipython.dev
- 源码仓库：https://github.com/claygendron/wasi_python
- PyPI 项目页：https://pypi.org/project/wasi-python/
