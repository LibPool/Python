# a2apay

> 标签: Python

## 简介

Secure, modular microtransaction framework for agent-to-agent (A2A) and agent-to-resource (MCP) payments.

## 官网

- 官网：https://github.com/DwirefS/a2a_payments_framework
- PyPI 项目页：https://pypi.org/project/a2apay/

- 当前版本：1.0.0

- 1.0.0

- pip 安装：`pip install a2apay`
- 下载页面：https://pypi.org/project/a2apay/#files
