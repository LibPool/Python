# cloudme-notify-django

> 标签: Python

## 简介

Django integration for the CloudMe Notify multi-channel notification API - built on top of cloudme-notify.

## 官网

- 官网：https://notify.cloudme.uz
- 源码仓库：https://github.com/Cloudmeuz/notify-django
- PyPI 项目页：https://pypi.org/project/cloudme-notify-django/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install cloudme-notify-django`
- 下载页面：https://pypi.org/project/cloudme-notify-django/#files
- 运行要求：Python >=3.9
