# filament-meter

> 标签: Python

## 简介

Measure 3D-print filament usage from .3mf / .gcode files, with automatic OrcaSlicer provisioning.

## 官网

- 官网：https://github.com/nimblemo/filament-meter
- PyPI 项目页：https://pypi.org/project/filament-meter/
