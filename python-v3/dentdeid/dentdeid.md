# dentdeid

> 标签: Python

## 简介

Open, tested de-identification for dental images: DICOM PS3.15 headers, burned-in text, EXIF/GPS, file names, faces and CBCT face risk.

## 官网

- 官网：https://github.com/Hezarani/dentdeid
- PyPI 项目页：https://pypi.org/project/dentdeid/
