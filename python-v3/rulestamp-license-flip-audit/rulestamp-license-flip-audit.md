# rulestamp-license-flip-audit

> 标签: Python

## 简介

Finds the dependencies whose licence changed under you - Terraform 1.6+ BUSL, Redis 7.4+ SSPL, Bitnami's August 2025 move, Elastic 7.11 - and names the exact version where each flip happened. (bundled Node.js runtime)
