# testteeth

> 标签: Python

## 简介

Grade AI-written tests with fast, git-diff-aware mutation testing (Python, TypeScript/JavaScript via StrykerJS, Rust via cargo-mutants), and hand coding agents precise briefs for the tests they are missing (CLI, pytest plugin, MCP server).
