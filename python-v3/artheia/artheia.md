# artheia

> 标签: Python

## 简介

Host-side DSL for Adaptive-AUTOSAR-style nodes that talk to Classical AUTOSAR via the Theia CAN/FR gateway. Inspired by ARText.

## 官网

- 官网：https://github.com/perotheia/artheia
- PyPI 项目页：https://pypi.org/project/artheia/
