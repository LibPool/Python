# rulestamp-bitnami-image-catalog-gate

> 标签: Python

## 简介

Finds the Bitnami image lines that broke on 2025-09-29, when versioned docker.io/bitnami tags moved to the frozen docker.io/bitnamilegacy archive (bundled Node.js runtime)
