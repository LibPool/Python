# Adafruit-PN532

> 标签: Python

## 简介

Python library for accessing a PN532 NFC breakout over a SPI connection from a Raspberry Pi, BeagleBone Black, etc.

## 官网

- 官网：https://github.com/adafruit/Adafruit_Python_PN532/
- PyPI 项目页：https://pypi.org/project/Adafruit-PN532/
