# langchain-mesharc

> 标签: Python

## 简介

LangChain integration for MeshArc: web pages as Documents, and web search and page reading as agent tools.

## 官网

- 官网：https://mesharc.dev
- 源码仓库：https://github.com/mesharc-org/langchain-mesharc
- PyPI 项目页：https://pypi.org/project/langchain-mesharc/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install langchain-mesharc`
- 下载页面：https://pypi.org/project/langchain-mesharc/#files
- 运行要求：Python >=3.10
