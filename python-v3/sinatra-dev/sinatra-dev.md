# sinatra-dev

> 标签: Python

## 简介

Official Python client for sinatra.dev, the AI coding agent that turns Linear and GitHub issues into pull requests: start, follow and stop tasks, and delegate issues.

## 官网

- 官网：https://www.sinatra.dev
- 源码仓库：https://github.com/sinatra-dev/sinatra-python
- PyPI 项目页：https://pypi.org/project/sinatra-dev/
