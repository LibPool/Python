# x402-market-data-mcp

> 标签: Python

## 简介

MCP server with 33 paid market-data tools (exchange hours, futures expiry, economic and central bank calendars, Treasury yields and auctions, ECB FX, CFTC COT, contract specs), paid per call with x402 (USDC on Base).
