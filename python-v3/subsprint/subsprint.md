# subsprint

> 标签: Python

## 简介

Offline CLI to generate subtitles for any video (faster-whisper + mlx-whisper, M-series fast defaults)

## 官网

- 官网：https://github.com/junwatu/subsprint
- PyPI 项目页：https://pypi.org/project/subsprint/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

- 下载页面：https://pypi.org/project/subsprint/#files
- 运行要求：Python >=3.10
