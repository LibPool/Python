# geosciml4china

> 标签: Python

## 简介

MapGIS → GeoSciML 4.1 conversion, DZ/T 0179-2025 semantic styling, rendering and verification for Chinese 1:250k geological map sheets

## 官网

- 官网：https://pypi.org/project/geosciml4china/
