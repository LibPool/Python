# langchain-bowmark

> 标签: Python

## 简介

LangChain tools for Bowmark: typed functions an agent calls to search, price-check and book on live websites.

- 官网：https://bowmark.ai
- 源码仓库：https://github.com/bowmark-ai/langchain-bowmark
- PyPI 项目页：https://pypi.org/project/langchain-bowmark/

- 下载页面：https://pypi.org/project/langchain-bowmark/#files
