# fiducial-check

> 标签: Python

## 简介

The reference mark a measurement is aligned against. Static checks for numbers that claim to be measured: bare literals with no provenance, names that contradict their contents, declared keys nothing asserts, documents that repeat a number wrongly, and index entries pointing at artefacts that are gone.
