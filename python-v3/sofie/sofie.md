# sofie

> 标签: Python

## 简介

Python bindings and parsers for SOFIE: translate Keras, PyTorch and ONNX models to standalone C++ inference code

- 官网：https://github.com/ML4EP/PySofie
- PyPI 项目页：https://pypi.org/project/sofie/
