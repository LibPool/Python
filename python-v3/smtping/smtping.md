# smtping

> 标签: Python

## 简介

Official SMTPing SDK for Python: verify email addresses, run bulk list jobs, and check spamtrap, disposable, spambot and complainer lists.

## 官网

- 官网：https://smtping.com
- 源码仓库：https://github.com/smtping/smtping-python
- PyPI 项目页：https://pypi.org/project/smtping/

- 下载页面：https://pypi.org/project/smtping/#files
