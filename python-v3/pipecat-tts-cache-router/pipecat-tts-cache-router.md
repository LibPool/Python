# pipecat-tts-cache-router

> 标签: Python

## 简介

Pipecat TTS service for tts-cache-router, a caching TTS router for Sarvam, Raya, ElevenLabs, OpenAI, Deepgram, xAI, Soniox, Smallest AI, Cartesia and Gemini
