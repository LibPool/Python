# factguard-check

> 标签: Python

## 简介

Catch LLMs inventing or misattributing numbers when they write from data. Deterministic, no LLM judge.

- 官网：https://github.com/Anirudh-Nadipally/factguard
- PyPI 项目页：https://pypi.org/project/factguard-check/
