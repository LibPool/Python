# sweep-tasks

> 标签: Python

## 简介

Typed, YAML-driven task layer for sweep — FWI/LSRTM/forward/wavefield tasks with a Pydantic schema, sync TaskRunner, distributed (torchrun) support, and a CLI suitable for LLM / programmatic invocation.
