# django-spec-cli

> 标签: Python

## 简介

Run a django-service-specs registry from manage.py: one subcommand per spec, options generated from its parameters, exit codes for every refusal.

## 官网

- 官网：https://github.com/Artui/django-spec-cli
- PyPI 项目页：https://pypi.org/project/django-spec-cli/
