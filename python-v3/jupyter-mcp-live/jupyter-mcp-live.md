# jupyter-mcp-live

> 标签: Python

## 简介

MCP server built into Jupyter Server: AI agents edit and run the notebooks open in JupyterLab, with outputs streaming into cells live.

## 官网

- 官网：https://github.com/zqfang/jupyter-mcp-live
- PyPI 项目页：https://pypi.org/project/jupyter-mcp-live/
