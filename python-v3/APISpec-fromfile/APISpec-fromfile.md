# APISpec-fromfile

> 标签: Python

## 简介

APISpec plugin to import OpenAPI specifications from a file instead of putting YAML into docstrings

## 官网

- 官网：https://github.com/ovh/python-apispec-fromfile
- PyPI 项目页：https://pypi.org/project/APISpec-fromfile/

- 下载页面：https://pypi.org/project/APISpec-fromfile/#files
- 运行要求：Python >=3.6
