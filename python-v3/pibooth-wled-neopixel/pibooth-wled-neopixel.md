# pibooth-wled-neopixel

> 标签: Python

## 简介

pibooth plugin that lights a NeoPixel/WS281x strip via an ESP32 running WLED over USB-serial

## 官网

- 官网：https://github.com/peteoheat/pibooth-wled-neopixel
- PyPI 项目页：https://pypi.org/project/pibooth-wled-neopixel/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install pibooth-wled-neopixel`
- 下载页面：https://pypi.org/project/pibooth-wled-neopixel/#files
- 运行要求：Python >=3.7
