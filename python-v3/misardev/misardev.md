# misardev

> 标签: Python

## 简介

Build, ship and run apps on MisarDev from Python: projects, files, builds, deploys, templates, OpenAI-compatible chat, code search, usage and billing — every API route, sync and async, with retries, typed plan-limit errors and SSE streaming.
