# aqara-ble

> 标签: Python

## 简介

Autonomous BLE control library for the Aqara U200 smart lock — cloud KDF, auth handshake and AES-CCM control channel, reimplemented in pure Python.

## 官网

- 官网：https://github.com/dani811/Aqara
