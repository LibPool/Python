# airprompter-agent-core

> 标签: Python

## 简介

The pure half of the AirPrompter agent SDK: the protocol (types, trust chain, canonical JSON, arm assignment and the ramp walk), rendering, output checks, golden sets, the judge, bundle reading, telemetry row schemas, the control-plane client, and the port interfaces. No side effects at import; no sibling dependencies.
