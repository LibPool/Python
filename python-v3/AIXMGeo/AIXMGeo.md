# AIXMGeo

> 标签: Python

## 简介

A Python module which wraps KMLPlus to produce kml files from AIXM 5.1 geographical data.

## 官网

- 官网：https://github.com/MHenderson1988/aixm_geo
- PyPI 项目页：https://pypi.org/project/AIXMGeo/

## 历史版本号

- 当前版本：0.0.2

- 0.0.2

## 获取地址

- pip 安装：`pip install AIXMGeo`
- 下载页面：https://pypi.org/project/AIXMGeo/#files
- 运行要求：Python >=3.8
