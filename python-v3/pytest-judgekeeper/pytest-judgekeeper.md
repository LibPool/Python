# pytest-judgekeeper

> 标签: Python

## 简介

pytest plugin that fails a test when an LLM judge stops agreeing with human labels (installs judgekeeper).

## 官网

- 官网：https://www.judgekeeper.com
- 源码仓库：https://github.com/judgekeeper/judgekeeper
- PyPI 项目页：https://pypi.org/project/pytest-judgekeeper/

- 下载页面：https://pypi.org/project/pytest-judgekeeper/#files
