# autourgos-micinput

> 标签: Python

## 简介

Standalone, provider-agnostic microphone capture for the Autourgos framework -- MicrophoneStream, usable by autourgos-live, autourgos-openaichat, autourgos-responses, autourgos-agent, or any other caller.
