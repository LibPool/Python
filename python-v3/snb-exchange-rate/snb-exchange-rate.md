# snb-exchange-rate

> 标签: Python

## 简介

Official Swiss National Bank exchange rates - ~25 currencies vs CHF, history since 1914. Keyless, zero-dependency Python client.

## 官网

- 官网：https://allratestoday.com/central-bank-rates-api/snb/
- 源码仓库：https://github.com/AllRates-Today/exchange-rates-api
- PyPI 项目页：https://pypi.org/project/snb-exchange-rate/
