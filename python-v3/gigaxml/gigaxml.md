# gigaxml

> 标签: Python

## 简介

Extract structured data from multi-gigabyte XML files with bounded memory, as a command line tool and a desktop application.

## 官网

- 官网：https://github.com/gg320324492-lgtm/GigaXML-Memory-Efficient-XML-Extraction-Toolkit
