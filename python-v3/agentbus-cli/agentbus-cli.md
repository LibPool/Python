# agentbus-cli

> 标签: Python

## 简介

Cross-session messaging between coding agents on the same machine (Claude Code, pi, opencode, kiro, codex, antigravity, hermes, and any MCP host).

## 官网

- 官网：https://github.com/ekinertac/agentbus
- PyPI 项目页：https://pypi.org/project/agentbus-cli/
