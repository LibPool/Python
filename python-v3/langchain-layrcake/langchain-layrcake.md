# langchain-layrcake

> 标签: Python

## 简介

LangChain tools for Layrcake: find leads, enrich and verify emails, check and research companies, and draft campaigns that a person approves before anything sends.

## 官网

- 官网：https://layrcake.dev
- 源码仓库：https://github.com/Layrcake-dev/langchain-layrcake
- PyPI 项目页：https://pypi.org/project/langchain-layrcake/

- 下载页面：https://pypi.org/project/langchain-layrcake/#files
