# 3d-dust-maps

> 标签: Python

## 简介

A lightweight 3D dust map tool with dynamic data downloading (Gaia + LAMOST).

## 官网

- 官网：https://github.com/Grapeknight/3d-dust-maps
- PyPI 项目页：https://pypi.org/project/3d-dust-maps/

## 历史版本号

- 1.0.1

## 获取地址

- pip 安装：`pip install 3d-dust-maps`
- 下载页面：https://pypi.org/project/3d-dust-maps/#files
- 运行要求：Python >=3.8
