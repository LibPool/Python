# tsgettoolbox-fawn

> 标签: Python

## 简介

Plugin for tsgettoolbox to retrieve data from the FAWN (Florida Automates Weather Network) REST API.

## 官网

- 官网：https://pypi.org/project/tsgettoolbox-fawn/
- PyPI 项目页：https://pypi.org/project/tsgettoolbox-fawn/

## 历史版本号

- 当前版本：27.0.0

- 27.0.0

## 获取地址

- pip 安装：`pip install tsgettoolbox-fawn`
- 下载页面：https://pypi.org/project/tsgettoolbox-fawn/#files
- 运行要求：Python >=3.10
