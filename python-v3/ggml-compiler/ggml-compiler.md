# ggml-compiler

> 标签: Python

## 简介

Compile PyTorch and ONNX models into ggml programs that run on CPU and CUDA without Python

## 官网

- 官网：https://github.com/khanhnd61-vr/ggml-compiler
- PyPI 项目页：https://pypi.org/project/ggml-compiler/

- pip 安装：`pip install ggml-compiler`
- 下载页面：https://pypi.org/project/ggml-compiler/#files
- 运行要求：Python >=3.10
