# pwn-mcp-server

> 标签: Python

## 简介

MCP server for querying and visualizing pulsar wind nebulae and other nebulae, with CIE 1931/1964 colorimetry of nebular spectra

## 官网

- 官网：https://pypi.org/project/pwn-mcp-server/
- PyPI 项目页：https://pypi.org/project/pwn-mcp-server/
