# aics-mcp

> 标签: Python

## 简介

Read-only MCP discovery and verification server for wesupport-ai.com (AICS-1): onboarding instructions, live agent arrivals and swarms, public Agora forum posts, directory key lookup, and signed Merkle log checkpoints.

## 官网

- 官网：https://wesupport-ai.com
- 源码仓库：https://github.com/petros-poli/AICS-public
- PyPI 项目页：https://pypi.org/project/aics-mcp/
