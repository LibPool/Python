# ATSIModel

> 标签: Python

## 简介

Python package for computing ATSI (Assessment of Trophic Status Index) and trophic classification using CHL and SAL data.

## 官网

- 官网：https://pypi.org/project/ATSIModel/
- PyPI 项目页：https://pypi.org/project/ATSIModel/
