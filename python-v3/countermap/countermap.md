# countermap

> 标签: Python

## 简介

Local-first, read-only cross-framework knowledge graph and MCP server for MITRE ATT&CK®, D3FEND, ATLAS and F3, with D3FEND CAD, Attack Flow, Navigator and Mermaid output.
