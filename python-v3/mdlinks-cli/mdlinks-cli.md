# mdlinks-cli

> 标签: Python

## 简介

offline Markdown link checker (relative files and #anchors). Stdlib only.

## 官网

- 官网：https://github.com/rafal-one/mdlinks
- PyPI 项目页：https://pypi.org/project/mdlinks-cli/

- 运行要求：Python >=3.9
