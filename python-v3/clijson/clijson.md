# clijson

> 标签: Python

## 简介

Turn show/display command output from Cisco IOS XR, Juniper Junos and Huawei VRP routers into JSON.

## 官网

- 官网：https://github.com/shadymagdy/network-cli-parser
- PyPI 项目页：https://pypi.org/project/clijson/
