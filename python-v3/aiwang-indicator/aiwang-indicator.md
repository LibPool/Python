# aiwang-indicator

> 标签: Python

## 简介

aiwang-indicator 是一个采用通达信指标接口的 Python 技术指标编辑公式库。用户可以像在通达信中一样,使用简洁的TDX style语法进行各类技术指标的编写与回测,非常适合量化研究和策略开发。
