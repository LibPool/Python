# PyImGui

> 标签: Python

## 简介

Python bindings for Dear ImGui, its SDL3, SDL_GPU, OpenGL 3, Vulkan, Direct3D 12 and Metal backends, ImPlot and ImGuizmo

## 官网

- 官网：https://github.com/fknfilewalker/PyImGui
- PyPI 项目页：https://pypi.org/project/PyImGui/

- 下载页面：https://pypi.org/project/PyImGui/#files
