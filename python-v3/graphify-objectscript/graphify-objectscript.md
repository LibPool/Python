# graphify-objectscript

> 标签: Python

## 简介

InterSystems ObjectScript (.cls/.mac/.inc/.rtn) support for graphify (graphifyy) on PyPI, until native support ships upstream

- 官网：https://github.com/intersystems-ib/graphify-objectscript
- PyPI 项目页：https://pypi.org/project/graphify-objectscript/

- 下载页面：https://pypi.org/project/graphify-objectscript/#files
- 运行要求：Python >=3.10
