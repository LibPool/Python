# langchain-anytomarkdown

> 标签: Python

## 简介

LangChain document loader for the AnyToMarkdown API: PDF, Word, Excel, PowerPoint and web pages to Markdown.

## 官网

- 官网：https://anymarkdownapi.gtgroup.dev/
- PyPI 项目页：https://pypi.org/project/langchain-anytomarkdown/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install langchain-anytomarkdown`
- 下载页面：https://pypi.org/project/langchain-anytomarkdown/#files
- 运行要求：Python >=3.9
