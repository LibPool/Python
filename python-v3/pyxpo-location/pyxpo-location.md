# pyxpo-location

> 标签: Python

## 简介

Device location, heading and geocoding for pyxpo apps (the expo-location API).

## 官网

- 官网：https://github.com/pyxpo/pyxpo/tree/main/packages/location
- PyPI 项目页：https://pypi.org/project/pyxpo-location/

## 历史版本号

- 当前版本：0.1.0a1

- 0.1.0a1

## 获取地址

- pip 安装：`pip install pyxpo-location`
- 下载页面：https://pypi.org/project/pyxpo-location/#files
- 运行要求：Python >=3.9
