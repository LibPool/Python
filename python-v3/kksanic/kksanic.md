# kksanic

> 标签: async, restful, sanic, scaffold, serializer, tortoise-orm, validator

## 简介

基于 Sanic + Tortoise 的后端小工具箱：统一响应、入参校验、出参序列化、RESTful 一键接口、后台管理站、接口文档、分表

- PyPI 项目页：https://pypi.org/project/kksanic/
