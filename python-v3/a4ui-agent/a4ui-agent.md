# a4ui-agent

> 标签: Python

## 简介

Agent-side A2UI chart producer for @haystackedai/a4react clients. Keep your agent (bedrock/agentcore/strands and your own biz logic are untouched); add a few lines where you already have the answer data and get a validated, drillable A2UI chart surface — richer than a hand-rolled chart. No a2ui-core wiring, catalog assembly, surface-message building or validation to write. Contract (catalogId + schemas) is baked, overridable.
