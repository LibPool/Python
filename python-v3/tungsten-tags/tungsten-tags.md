# tungsten-tags

> 标签: Python

## 简介

Tags plugin for Tungsten: put colored tags on any record (leads, tickets, employees, invoices) and filter by them.

## 官网

- 官网：https://tungsten.prisminfoways.com/plugins/tags
- 源码仓库：https://github.com/Prism-Infoways/Tungsten
- PyPI 项目页：https://pypi.org/project/tungsten-tags/
