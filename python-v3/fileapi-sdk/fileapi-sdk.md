# fileapi-sdk

> 标签: Python

## 简介

FileApi Open API 的 Python 客户端：请求签名、代理上传、直传与分片续传、秒传、游标列表、下载、访问链接与 Webhook 验签

## 官网

- 官网：https://pypi.org/project/fileapi-sdk/
- PyPI 项目页：https://pypi.org/project/fileapi-sdk/

- 0.1.1

## 获取地址

- pip 安装：`pip install fileapi-sdk`
- 下载页面：https://pypi.org/project/fileapi-sdk/#files
- 运行要求：Python >=3.9
