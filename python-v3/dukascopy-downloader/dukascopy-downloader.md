# dukascopy-downloader

> 标签: Python

## 简介

Download Dukascopy historical market data (ticks, 1-minute, hourly and daily candles) into Parquet files

## 官网

- 官网：https://github.com/tomas-charvat/Dukascopy_downloader
- PyPI 项目页：https://pypi.org/project/dukascopy-downloader/

## 历史版本号

- 当前版本：1.1.0

- 1.1.0

## 获取地址

- pip 安装：`pip install dukascopy-downloader`
- 下载页面：https://pypi.org/project/dukascopy-downloader/#files
- 运行要求：Python >=3.10
