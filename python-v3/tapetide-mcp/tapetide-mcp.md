# tapetide-mcp

> 标签: Python

## 简介

NSE BSE Indian stock market MCP server for Python — 55 tools for Indian stock market data & research: live NSE/BSE quotes, financials, technicals, 326-ratio stock screener, analyst ratings, FII/DII flows, option chains & IV, parsed filings, IPOs, portfolio tracking. Works with Claude, ChatGPT, Cursor, Codex & any MCP client.
