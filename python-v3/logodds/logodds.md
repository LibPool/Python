# logodds

> 标签: Python

## 简介

Log-odds ratio with a Dirichlet prior (Monroe et al. 2008), using plain word-count dictionaries. No scikit-learn, no dependencies.

## 官网

- 官网：https://github.com/juliamendelsohn/logodds
- PyPI 项目页：https://pypi.org/project/logodds/
