# flashcodec-kv

> 标签: compression, dct, inference, kv-cache, llm, transformer

## 简介

Compress Transformer time-series KV cache tensors as high-dimensional multimedia image signals: JPEG-style lossy frequency domain (DCT) plus PNG-style lossless time-domain deltas
