# pyloaderv

> 标签: Python

## 简介

Autocomplete and type stubs for PyloaderV (Python mods for GTA V), plus tools to create, pack and set up mods.

## 官网

- 官网：https://www.gta5-mods.com/tools/pyloader-python-scripts-for-gta-v-enhanced
- PyPI 项目页：https://pypi.org/project/pyloaderv/

## 历史版本号

- 当前版本：0.9.1

- 0.9.0
- 0.9.1

## 获取地址

- pip 安装：`pip install pyloaderv`
- 下载页面：https://pypi.org/project/pyloaderv/#files
- 运行要求：Python >=3.9
