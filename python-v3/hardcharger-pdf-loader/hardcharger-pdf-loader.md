# hardcharger-pdf-loader

> 标签: Python

## 简介

Load PDF files (bytes + extracted page text + metadata) into a Hardcharger server over Warp SQL / ADBC.

## 官网

- 官网：https://github.com/gizmodata/hardcharger-pdf-loader
- PyPI 项目页：https://pypi.org/project/hardcharger-pdf-loader/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install hardcharger-pdf-loader`
- 下载页面：https://pypi.org/project/hardcharger-pdf-loader/#files
- 运行要求：Python >=3.11
