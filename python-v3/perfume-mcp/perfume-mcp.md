# perfume-mcp

> 标签: Python

## 简介

Perfume MCP server: free fragrance knowledge for Claude, Cursor and any MCP client. 6,000+ perfumes, note pyramids, accords, similar scents and alternatives from the 10ML Fragrance Index. No API key.

## 官网

- 官网：https://mcp.10ml.com
- PyPI 项目页：https://pypi.org/project/perfume-mcp/
