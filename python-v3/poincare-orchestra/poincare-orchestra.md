# poincare-orchestra

> 标签: Python

## 简介

Scenario-first reference implementation of 'LLM Orchestration with Geometry-Aware Memory' (IEEE ICBDML 2026): metacognitive controller, provider-agnostic ensemble with throttling detection, multi-objective synthesis, on top of poincare-memory.
