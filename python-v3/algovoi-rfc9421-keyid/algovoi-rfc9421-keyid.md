# algovoi-rfc9421-keyid

> 标签: Python

## 简介

SSRF-guarded resolver for RFC 9421 signature keyids (did:key, did:web, HTTPS) to Ed25519 public keys

- 官网：https://github.com/chopmob-cloud/algovoi-rfc9421-keyid
