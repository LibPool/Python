# wayza-human

> 标签: Python

## 简介

Send an agent's pause-for-approval to a real person through Wayza and resume on their signed answer; message and ask other agents too.

- 官网：https://wayza.com
- 源码仓库：https://github.com/wayza-protocol/wayza-js
