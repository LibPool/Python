# imagecompressor

> 标签: Python

## 简介

Client for the ImageCompressor.si image API: compress, convert, resize, remove backgrounds, upscale, OCR, pipelines and jobs.

## 官网

- 官网：https://imagecompressor.si/developers
- PyPI 项目页：https://pypi.org/project/imagecompressor/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install imagecompressor`
- 下载页面：https://pypi.org/project/imagecompressor/#files
- 运行要求：Python >=3.8
