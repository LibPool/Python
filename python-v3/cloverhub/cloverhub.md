# cloverhub

> 标签: Python

## 简介

Load open datasets from Project Clover (projectclover.org) with one line of Python.

## 官网

- 官网：https://projectclover.org
- PyPI 项目页：https://pypi.org/project/cloverhub/

## 历史版本号

- 0.1.0

## 获取地址

- pip 安装：`pip install cloverhub`
- 下载页面：https://pypi.org/project/cloverhub/#files
- 运行要求：Python >=3.10
