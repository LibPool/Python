# alchemypose

> 标签: Python

## 简介

Whole-body human pose visualisation: 133 COCO-WholeBody keypoints from a photograph, as a typed Python library and a desktop application.

- 官网：https://github.com/kouya-marino/AlchemyPose
- PyPI 项目页：https://pypi.org/project/alchemypose/
