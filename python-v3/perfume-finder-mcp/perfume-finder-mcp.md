# perfume-finder-mcp

> 标签: Python

## 简介

10ML Perfume Finder: the free perfume MCP server and fragrance API for AI assistants. 6,000+ perfumes and 249 houses from the 10ML Fragrance Index with note pyramids, accords, similar scents and alternatives. Stdio for Claude Desktop, Cursor, Goose and any MCP client.
