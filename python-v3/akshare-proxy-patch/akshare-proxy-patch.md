# akshare-proxy-patch

> 标签: Python

## 简介

针对 AkShare 和 efinance 的底层补丁，自动为东财等接口注入代理认证头，从而避免 `stock_zh_a_spot_em` 等方法报错。

## 官网

- 官网：https://github.com/helloyie/akshare-proxy-patch
- PyPI 项目页：https://pypi.org/project/akshare-proxy-patch/

- 下载页面：https://pypi.org/project/akshare-proxy-patch/#files
