# tsgettoolbox-ndbc

> 标签: Python

## 简介

Plugin for tsgettoolbox to retrieve time series data from the National Data Buoy Center (NDBC).

## 官网

- 官网：https://pypi.org/project/tsgettoolbox-ndbc/
- PyPI 项目页：https://pypi.org/project/tsgettoolbox-ndbc/

## 历史版本号

- 当前版本：27.0.0

- 27.0.0

## 获取地址

- pip 安装：`pip install tsgettoolbox-ndbc`
- 下载页面：https://pypi.org/project/tsgettoolbox-ndbc/#files
- 运行要求：Python >=3.10
