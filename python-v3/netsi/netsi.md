# netsi

> 标签: Python

## 简介

Python SDK for netsi, the personal agent network, and splitsi, its shared-expense app. Tools are read live from the API.

## 官网

- 官网：https://netsi.io
- 源码仓库：https://github.com/bluedotsoft/netsi-agent
- PyPI 项目页：https://pypi.org/project/netsi/
