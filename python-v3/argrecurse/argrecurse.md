# argrecurse

> 标签: Python

## 简介

Provides the @auto wrapper (`from autofunc import auto`), which allows calling functions with the syntax e.g. `(foo)(1)(2)(c=3)` instead of `foo(1, 2, c=3)`. Also recurses, so `(foo)(foo)(1)(2)(3)(foo)(4)(5)(6)(7)` is viable.
