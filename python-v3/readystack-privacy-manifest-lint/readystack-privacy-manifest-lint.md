# readystack-privacy-manifest-lint

> 标签: Python

## 简介

Checks PrivacyInfo.xcprivacy and your C#, Dart, JS, Swift and Kotlin source for Apple required-reason APIs, and decodes all 17 reason codes back to the category they belong to. (bundled Node.js runtime)
