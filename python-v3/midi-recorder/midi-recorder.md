# midi-recorder

> 标签: Python

## 简介

Record all incoming MIDI events to timestamped .mid files, saved automatically when playing stops

## 官网

- 官网：https://github.com/maarten-boot/recording-midi-data
- PyPI 项目页：https://pypi.org/project/midi-recorder/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install midi-recorder`
- 下载页面：https://pypi.org/project/midi-recorder/#files
- 运行要求：Python >=3.10
