# awesome-core

> 标签: Python

## 简介

Offline-first catalog of tools from GitHub awesome lists, exposed as a read-only MCP server (stdio). Pure stdlib core, no network, no API keys.

## 官网

- 官网：https://github.com/twojlogin/awesome-core
- PyPI 项目页：https://pypi.org/project/awesome-core/
