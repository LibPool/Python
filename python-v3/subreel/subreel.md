# subreel

> 标签: Python

## 简介

Turn speech audio into subtitle reels: green-screen H.264, transparent WebM/ProRes, with word-by-word karaoke highlight.

## 官网

- 官网：https://github.com/paxoscn/subreel
- PyPI 项目页：https://pypi.org/project/subreel/
