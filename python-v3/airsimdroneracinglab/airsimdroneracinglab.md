# airsimdroneracinglab

> 标签: Python

## 简介

Python package for AirSim Drone Racing Lab, built on Microsoft AirSim - an open source simulator based on Unreal Engine for autonomous vehicles from Microsoft AI & Research

## 官网

- 官网：https://github.com/microsoft/AirSim-Drone-Racing-Lab
- PyPI 项目页：https://pypi.org/project/airsimdroneracinglab/
