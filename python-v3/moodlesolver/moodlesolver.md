# moodlesolver

> 标签: Python

## 简介

Moodle quiz automation library and MCP server with local OCR (tesseract + pix2tex) and AI modes (opencode / OpenAI-compatible)

## 官网

- 官网：https://pypi.org/project/moodlesolver/
