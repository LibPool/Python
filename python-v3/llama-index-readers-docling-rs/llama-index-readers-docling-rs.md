# llama-index-readers-docling-rs

> 标签: Python

## 简介

LlamaIndex reader for docling.rs: PDF with layout, tables and OCR, DOCX, PPTX, XLSX, HTML and 40-odd formats into LlamaIndex Documents as Markdown or docling JSON. docling in Rust, no PyTorch.
