# briskapi

> 标签: Python

## 简介

Unofficial Python API and brisk CLI for BRiSK auction data: sign in to your broker's BRiSK (SBI, Tachibana e-shiten, Matsui, Monex, SMBC Nikko) with a passkey, record the live feed through BRiSK's own decoder day after day, keep each day in your own private archive, and query your history and OHLCV bars through the cloud API
