# attestwire

> 标签: Python

## 简介

Validate EN 16931 e-invoices (XRechnung, Factur-X/ZUGFeRD, Peppol BIS 3) via the hosted Attestwire API or the local @attestwire/en16931 CLI. Standard library only, no runtime dependencies.
