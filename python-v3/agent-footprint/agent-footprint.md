# agent-footprint

> 标签: Python

## 简介

Live environmental footprint (energy, water, carbon) of AI coding agents: Claude Code, Codex CLI, Gemini CLI, OpenCode, Mistral Vibe and GitHub Copilot, computed with EcoLogits.

- 官网：https://github.com/warmelinks/agent-footprint
