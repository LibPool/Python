# tempmailc

> 标签: Python

## 简介

Official Python SDK for TempMailAPI (https://private.tempmailc.com). Instant OTP extraction, real-time SSE streaming, and Kopeechka 2.0 compatibility.

## 官网

- 官网：https://private.tempmailc.com
- 源码仓库：https://github.com/tempmailapi/tempmail-api-python
- PyPI 项目页：https://pypi.org/project/tempmailc/
