# Adafruit-ADXL345

> 标签: Python

## 简介

Python code to use the ADXL345 triple-axis accelerometer over I2C with a Raspberry Pi or BeagleBone Black.

## 官网

- 官网：https://github.com/adafruit/Adafruit_Python_ADXL345/
- PyPI 项目页：https://pypi.org/project/Adafruit-ADXL345/
