# bib2gbt

> 标签: Python

## 简介

Convert BibTeX references to GB/T 7714 style ([J]/[D]/[C]/[N] etc.)

## 官网

- 官网：https://pypi.org/project/bib2gbt/
- PyPI 项目页：https://pypi.org/project/bib2gbt/

- 下载页面：https://pypi.org/project/bib2gbt/#files
