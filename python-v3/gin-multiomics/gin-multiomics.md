# gin-multiomics

> 标签: Python

## 简介

Global Integrative Network (GIN) multi-omics toolkit: context extraction and SigPN (signaling Petri net; not stochastic PN), with GINv3.11a p53 recipes

## 官网

- 官网：https://github.com/BIGchix/GINv3-publication
- PyPI 项目页：https://pypi.org/project/gin-multiomics/

- 下载页面：https://pypi.org/project/gin-multiomics/#files
