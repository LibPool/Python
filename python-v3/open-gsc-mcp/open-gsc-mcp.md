# open-gsc-mcp

> 标签: Python

## 简介

Local MCP server for the Google Search Console API: search analytics, URL inspection, sitemaps and sites, with guards for the API's known quirks.

- 官网：https://github.com/onlymoein/google-search-console-mcp
