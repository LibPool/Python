# atengk-mcp-server-rabbitmq

> 标签: Python

## 简介

🐰 专为 LLM 打造的生产级 RabbitMQ Model Context Protocol (MCP) 服务端，支持 AMQP 拓扑声明、消息发布与消费、队列监控与管理能力
