# wordplus-realtime

> 标签: Python

## 简介

WordPlus Cloud's realtime SDK for Python outside WordPress: rooms with presence and history, online status, events to rooms and users, webhooks, calls between two people that ring in the browser, group calls, sealed end to end. Signs what the browser package (@wordplus/realtime) asks for and emits. Django, FastAPI and Flask included, and the browser files served from its own routes.
