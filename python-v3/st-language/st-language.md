# st-language

> 标签: Python

## 简介

ST-language: text music notation (notes, chords, drums, voices, lyrics) with MIDI, MusicXML, ABC and MTXT export

## 官网

- 官网：https://github.com/openssound/st-language
- PyPI 项目页：https://pypi.org/project/st-language/
