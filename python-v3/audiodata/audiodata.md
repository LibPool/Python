# audiodata

> 标签: Python

## 简介

Get accurate audio metadata from any audio file. Supports MP3, FLAC, WAV, OGG and more.

## 官网

- 官网：https://pypi.org/project/audiodata/
- PyPI 项目页：https://pypi.org/project/audiodata/

- 下载页面：https://pypi.org/project/audiodata/#files
- 运行要求：Python >=3.10
