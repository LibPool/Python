# muster-bridge

> 标签: Python

## 简介

Serve Muster's Bridge protocol, so that a bridge to a messenger is only the calls to that messenger.

- 官网：https://github.com/muster-io/muster-bridge-python
- PyPI 项目页：https://pypi.org/project/muster-bridge/
