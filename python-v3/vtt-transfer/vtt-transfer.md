# vtt-transfer

> 标签: Python

## 简介

Transfer VTT (Visual TrueType) hinting sources to a new version of a TrueType font, with an HTML report of what is left to hint

## 官网

- 官网：https://github.com/typedev/vtt-transfer
- PyPI 项目页：https://pypi.org/project/vtt-transfer/
