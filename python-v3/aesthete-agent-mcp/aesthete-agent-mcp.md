# aesthete-agent-mcp

> 标签: Python

## 简介

aesthete-agent MCP server — mechanically validated frontend aesthetics: palette library ranking, OKLCH generation, WCAG/APCA contrast, color-blind-safe data colors, theme packs, token exports (w3c/context); zero keys, zero telemetry
