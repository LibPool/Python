# pydiag

> 标签: CAN, CANFD, DoIP, ISO-14229, ISO-15765, ISO-TP, LIN, PCAN, UDS, Vector, ZLG, automotive, diagnostic, security-access

## 简介

UDS (ISO 14229) diagnostic toolkit with pluggable multi-vendor CAN/LIN devices (ZLG / PEAK PCAN / Vector / virtual), DoCAN / DoLIN / DoIP
