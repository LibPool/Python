# decision-toolkit

> 标签: Python

## 简介

Local-first toolkit for open-weights decision models: one ONNX engine, one adapter per model contract, typed choice/yes-no/score decisions with probabilities on CPU.

## 官网

- 官网：https://github.com/gia-uh/decision-toolkit
