# latex2code

> 标签: Python

## 简介

Transpile LaTeX math into readable Python functions for plain Python, NumPy, PyTorch, or JAX.

## 官网

- 官网：https://github.com/ThulioASB/latex2code
- PyPI 项目页：https://pypi.org/project/latex2code/

- 下载页面：https://pypi.org/project/latex2code/#files
