# pydantic-brasil

> 标签: Python

## 简介

Tipos de dados e validadores brasileiros de alta performance para Pydantic v2 e FastAPI (CPF, CNPJ 2026, NF-e, Boleto, IBAN, Rastreio Correios, GTIN, Chave PIX e mais)
