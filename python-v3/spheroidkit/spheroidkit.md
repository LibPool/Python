# spheroidkit

> 标签: Python

## 简介

Open, no-install toolkit for end-to-end tumour spheroid growth and drug-response analysis from brightfield microscopy

## 官网

- 官网：https://github.com/sharavdesai/spheroidkit
- PyPI 项目页：https://pypi.org/project/spheroidkit/

## 历史版本号

- 当前版本：1.1.0

- 1.1.0

## 获取地址

- pip 安装：`pip install spheroidkit`
- 下载页面：https://pypi.org/project/spheroidkit/#files
- 运行要求：Python >=3.10
