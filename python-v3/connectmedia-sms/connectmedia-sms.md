# connectmedia-sms

> 标签: Python

## 简介

Official Python client for the Connect Media SMS API: bulk SMS to Safaricom, Airtel and Telkom in Kenya and 190+ countries.

## 官网

- 官网：https://connectmedia.co.ke/
- 源码仓库：https://github.com/connectmedia-ke/connectmedia-python
- PyPI 项目页：https://pypi.org/project/connectmedia-sms/
