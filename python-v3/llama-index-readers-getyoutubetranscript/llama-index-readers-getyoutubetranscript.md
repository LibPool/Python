# llama-index-readers-getyoutubetranscript

> 标签: Python

## 简介

YouTube transcript reader for LlamaIndex: load YouTube video transcripts (optionally with timestamps) as Documents for RAG, via the GetYouTubeTranscript API. Works from cloud servers without proxies.
