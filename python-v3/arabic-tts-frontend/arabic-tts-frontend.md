# arabic-tts-frontend

> 标签: Python

## 简介

Make Arabic text speakable: numeral verbalisation, a pronunciation lexicon, and lexicon-first diacritisation, in front of any TTS engine.

- 官网：https://github.com/Syamjith-nk/arabic-tts-frontend
- PyPI 项目页：https://pypi.org/project/arabic-tts-frontend/
