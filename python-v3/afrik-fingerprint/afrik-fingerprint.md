# afrik-fingerprint

> 标签: Python

## 简介

Une boîte à outils Python légère pour interagir avec les capteurs d'empreintes digitales optiques ou capacitifs AS608, R307, R503 et compatibles.

## 官网

- 官网：https://github.com/bigdahaut/afrik-fingerprint
- PyPI 项目页：https://pypi.org/project/afrik-fingerprint/

- 下载页面：https://pypi.org/project/afrik-fingerprint/#files
