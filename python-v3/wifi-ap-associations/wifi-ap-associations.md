# wifi-ap-associations

> 标签: Python

## 简介

Read which Wi-Fi clients are associated to an access point (D-Link DAP, OpenWrt, UniFi, MikroTik, Cisco 9800 over SSH or SNMP), with signal, band and the AP's own health.
