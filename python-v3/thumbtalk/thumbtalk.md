# thumbtalk

> 标签: Python

## 简介

Hold a mouse button, talk, let go. Private, offline dictation for Windows that runs Whisper on your own PC.

- 官网：https://github.com/VW3st/thumbtalk
- PyPI 项目页：https://pypi.org/project/thumbtalk/
