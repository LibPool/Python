# smartcharts

> 标签: Python

## 简介

Smartchart是一个集智能体开发平台、数据中台与商业智能（BI）于一体的综合解决方案。专为Django应用设计，支持快速构建、编排和管理智能体（Agent），提供实时数据可视化、交互式仪表盘和全面的数据分析功能，助力企业轻松搭建一体化的智能数据应用与决策系统。
