# alpha-forge-launcher

> 标签: Python

## 简介

Thin launcher for the AlphaForge backtesting CLI — downloads and runs the AlphaForge binary (provides the alpha-forge command).

## 官网

- 官网：https://alforgelabs.com/
- 源码仓库：https://github.com/alforge-labs/alpha-forge-launcher
- PyPI 项目页：https://pypi.org/project/alpha-forge-launcher/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install alpha-forge-launcher`
- 下载页面：https://pypi.org/project/alpha-forge-launcher/#files
- 运行要求：Python >=3.9
