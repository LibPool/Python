# sportapi-mcp

> 标签: Python

## 简介

MCP server for SportAPI: Live and Prematch sports odds, scores and statistics for Claude, Cursor, VS Code and other AI assistants.

## 官网

- 官网：https://sportapi.net
- 源码仓库：https://github.com/SportApi-net/sportapi-mcp
- PyPI 项目页：https://pypi.org/project/sportapi-mcp/
