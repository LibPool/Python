# castpdf

> 标签: Python

## 简介

Official Python client for the CastPDF API: PDFs from templates or HTML, EU e-invoices, batches and webhooks.

- 官网：https://castpdf.com
- 源码仓库：https://github.com/castpdf/castpdf-python
