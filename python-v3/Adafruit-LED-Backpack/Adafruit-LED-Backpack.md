# Adafruit-LED-Backpack

> 标签: Python

## 简介

Library to control LED backpack displays such as 8x8 single and bi-color matrices, bargraphs, 7 segment, and 14 segment displays.

## 官网

- 官网：https://github.com/adafruit/Adafruit_Python_LED_Backpack/
- PyPI 项目页：https://pypi.org/project/Adafruit-LED-Backpack/
