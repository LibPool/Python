# pyxpo-mesh-view

> 标签: Python

## 简介

Plays a textured 2D mesh animation (vertex positions per frame) for pyxpo apps.

## 官网

- 官网：https://github.com/pyxpo/pyxpo/tree/main/packages/mesh-view
- PyPI 项目页：https://pypi.org/project/pyxpo-mesh-view/
