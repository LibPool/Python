# right-rudder

> 标签: Python

## 简介

Catch the step where an AI agent contradicts a decision it already made, and read how much functional life a run has left. Adapters and a CLI for the Right Rudder committed-state and expiry reads over LangGraph, CrewAI, Letta, OpenInference, DBOS, coding-agent traces, and the log files of ChatDev, MetaGPT, OpenManus, Magentic-One, HyperAgent, AppWorld and AG2.
