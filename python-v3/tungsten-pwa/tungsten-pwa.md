# tungsten-pwa

> 标签: Python

## 简介

PWA plugin for Tungsten: install your FastAPI admin panel like an app on phones and computers, with app icons, shortcuts, faster loading and an offline page.

## 官网

- 官网：https://tungsten.prisminfoways.com/
- 源码仓库：https://github.com/Prism-Infoways/Tungsten
- PyPI 项目页：https://pypi.org/project/tungsten-pwa/

- 下载页面：https://pypi.org/project/tungsten-pwa/#files
