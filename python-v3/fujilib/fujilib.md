# fujilib

> 标签: Python

## 简介

Async Python driver for Fuji Electric ZP-series NDIR gas analyzers (ZPA, also sold as the CAI / ENVEA ZPA) over Modbus RTU.

## 官网

- 官网：https://github.com/GraysonBellamy/fujilib
- PyPI 项目页：https://pypi.org/project/fujilib/

- 下载页面：https://pypi.org/project/fujilib/#files
