# atlisp-pdf2dwg

> 标签: Python

## 简介

Convert PDF drawings and documents to DXF (optionally DWG) using local OCR, native PDF vectors and raster image vectorization.

- 官网：https://gitee.com/atlisp/pdf2dwg
