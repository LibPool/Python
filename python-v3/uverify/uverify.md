# uverify

> 标签: Python

## 简介

Official Python library for the Bytid API (formerly UVerify): BVN, NIN and ID checks, liveness, face match, ID documents and AML screening for Nigeria.

## 官网

- 官网：https://www.bytid.com
- 源码仓库：https://github.com/elastodev/uverify-sdks
- PyPI 项目页：https://pypi.org/project/uverify/
