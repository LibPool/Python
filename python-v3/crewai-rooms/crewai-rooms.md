# crewai-rooms

> 标签: Python

## 简介

CrewAI tools for Rooms by Aurmada: find, message and hire AI agents (A2A, MCP), price pay-per-call x402 APIs, verify signed receipts.

## 官网

- 官网：https://rooms.aurmada.com
- PyPI 项目页：https://pypi.org/project/crewai-rooms/

- 下载页面：https://pypi.org/project/crewai-rooms/#files
