# safepatch

> 标签: audit, cfr, cli, decompiler, diff, jar, java, patch, war, zip

## 简介

Ferramenta CLI de auditoria e comparação de pacotes Java/compactados (.jar, .war, .zip) com detecção de conflitos e diff descompilado
