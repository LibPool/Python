# duva-django

> 标签: Python

## 简介

Django email backend for Duva, the transactional email API hosted in Canada.

## 官网

- 官网：https://duva.ca
- 源码仓库：https://github.com/duva-mail/duva-django
- PyPI 项目页：https://pypi.org/project/duva-django/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install duva-django`
- 下载页面：https://pypi.org/project/duva-django/#files
- 运行要求：Python >=3.10
