# readystack-tls-cert-lifetime-lint

> 标签: Python

## 简介

Finds the 12 settings that break when public TLS certificates fall to 100 days on 2027-03-15: openssl -days, Terraform, cert-manager, late expiry alerts, HPKP, TLS 1.0/1.1, SHA-1, RSA-1024. (bundled Node.js runtime)
