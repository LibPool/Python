# ebooks-cli

> 标签: Python

## 简介

Private, self-hosted ebook library: stores, ingests, converts and serves books (API, OPDS, MCP) from hardware you own. Split from xteink, which keeps the e-reader/device side.

## 官网

- 官网：https://github.com/agentculture/ebooks-cli
- PyPI 项目页：https://pypi.org/project/ebooks-cli/
