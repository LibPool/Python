# factframe-mcp

> 标签: Python

## 简介

Local MCP server that turns folders of PDF, docx and xlsx files into citable markdown. Runs entirely on your machine.

## 官网

- 官网：https://github.com/Plinsboorg/factframe
- PyPI 项目页：https://pypi.org/project/factframe-mcp/

- 下载页面：https://pypi.org/project/factframe-mcp/#files
