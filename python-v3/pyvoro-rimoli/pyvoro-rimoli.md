# pyvoro-rimoli

> 标签: Python

## 简介

2D and 3D Voronoi tessellations: a Python entry point for the Voro++ library, built with the current Voro++.

## 官网

- 官网：https://github.com/rimoli/pyvoro
- PyPI 项目页：https://pypi.org/project/pyvoro-rimoli/

- 下载页面：https://pypi.org/project/pyvoro-rimoli/#files
