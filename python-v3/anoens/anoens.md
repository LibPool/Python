# anoens

> 标签: Python

## 简介

Companion Module to my Paper "Evaluating and Comparing Heterogeneous Ensemble Methods for Unsupervised Anomaly Detection" (2023, IJCNN). Provides method to combine the scores of multiple anomaly detectors into an ensemble.
