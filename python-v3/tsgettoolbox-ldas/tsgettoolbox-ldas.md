# tsgettoolbox-ldas

> 标签: Python

## 简介

Plugin for tsgettoolbox to retrieve data from the Land Data Assimmilation System (LDAS) web service.

## 官网

- 官网：https://pypi.org/project/tsgettoolbox-ldas/
- PyPI 项目页：https://pypi.org/project/tsgettoolbox-ldas/

- 下载页面：https://pypi.org/project/tsgettoolbox-ldas/#files
- 运行要求：Python >=3.10
