# sigrix-launcher

> 标签: Python

## 简介

Start a Sigrix-delivered MCP server you bought from the MCP client you already use: checks the purchase, fetches and verifies the package, installs it and hands over stdio.

- 官网：https://github.com/sigrix-io/sigrix-launcher
- PyPI 项目页：https://pypi.org/project/sigrix-launcher/
