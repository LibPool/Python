# wolfhece-core

> 标签: Python

## 简介

Data models of the WOLF toolkit (HECE, University of Liege): arrays, vectors, parameters, 2D simulation files - no GUI, no native library

## 官网

- 官网：https://gitlab.uliege.be/HECE/wolfhece-core
- PyPI 项目页：https://pypi.org/project/wolfhece-core/

## 历史版本号

- 当前版本：3.0.0

- 3.0.0

## 获取地址

- pip 安装：`pip install wolfhece-core`
- 下载页面：https://pypi.org/project/wolfhece-core/#files
- 运行要求：Python <3.14,>=3.10
