# kalibra-sdk

> 标签: Python

## 简介

Send what happens inside your AI app to Kalibra: traces, steps, tool record/replay, and evals from your tests.

## 官网

- 官网：https://github.com/LibreGuild/kalibra
- PyPI 项目页：https://pypi.org/project/kalibra-sdk/

- 下载页面：https://pypi.org/project/kalibra-sdk/#files
