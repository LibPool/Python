# ocrroute

> 标签: Python

## 简介

OCR gateway: one API in front of 56 OCR engines (Tesseract, PaddleOCR, EasyOCR, Surya, Mistral OCR, Google Vision, OCR.Space, Claude/GPT/Gemini and other vision models) with routing, automatic fallback, a web dashboard, a desktop app and multi-server clusters.
