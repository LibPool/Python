# redact-secret-vault

> 标签: Python

## 简介

Native Python server authority for redact-secret-vault, implementing the same server-authority contract as the JavaScript @redact-secret/vault-server: principal/tenant resolution, fail-closed decision tuple evaluation, denial vocabulary, and audit events over an in-memory store.
