# thermodiagrammes

> 标签: Python

## 简介

Diagrammes thermodynamiques (P, h), (T, s), (h, s), (P, v) et (P, T) d'un fluide réel avec CoolProp : isolignes étiquetées, états et cycles, pour des figures d'exercices
