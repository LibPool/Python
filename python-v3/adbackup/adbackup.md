# adbackup

> 标签: Python

## 简介

Backs up photos and videos from an Android phone over adb - copies only what's missing and keeps the real capture dates.

## 官网

- 官网：https://github.com/EmilHaase/adbackup
- PyPI 项目页：https://pypi.org/project/adbackup/
