# financialkit

> 标签: Python

## 简介

Quantitative-finance toolkit: time value of money, fixed income, option pricing (closed form, trees, Monte Carlo, PDE, FFT), exotic options, stochastic volatility, interest-rate and credit models, portfolio optimization, asset pricing, risk, financial time series, and market microstructure -- built on numpy/scipy, hand-rolling algorithms only where no library equivalent exists.
