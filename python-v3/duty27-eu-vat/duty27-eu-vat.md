# duty27-eu-vat

> 标签: Python

## 简介

EU standard VAT rates by date: every change since 2016, for all 27 member states. No dependencies, works offline.

## 官网

- 官网：https://duty27.com/vat-rates/history
- 源码仓库：https://github.com/duty27/eu-vat
- PyPI 项目页：https://pypi.org/project/duty27-eu-vat/

- pip 安装：`pip install duty27-eu-vat`
- 下载页面：https://pypi.org/project/duty27-eu-vat/#files
