# shortcut-forge

> 标签: Python

## 简介

Apple Shortcuts MCP server: let Claude, Codex or any LLM build, lint and sign real iOS Shortcuts (.shortcut) that run on iPhone. iOS 27 aware.

## 官网

- 官网：https://github.com/Hyunki6040/shortcut-forge
- PyPI 项目页：https://pypi.org/project/shortcut-forge/
