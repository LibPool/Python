# osdev-wiki-mcp

> 标签: Python

## 简介

MCP server giving AI agents offline, searchable access to the OSDev wiki (wiki.osdev.org) - full-text search, sections, links.

## 官网

- 官网：https://github.com/0xmortuex/osdev-wiki-mcp
- PyPI 项目页：https://pypi.org/project/osdev-wiki-mcp/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install osdev-wiki-mcp`
- 下载页面：https://pypi.org/project/osdev-wiki-mcp/#files
- 运行要求：Python >=3.10
