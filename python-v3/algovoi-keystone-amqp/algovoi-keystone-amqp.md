# algovoi-keystone-amqp

> 标签: Python

## 简介

Bind AMQP / RabbitMQ publishes to the AlgoVoi keystone -- wrap any pika channel and every publish gets a content-addressed execution_ref (keystone-only edition, Apache-2.0)
