# voidcaptcha

> 标签: Python

## 简介

Official Python client for the VoidCaptcha CAPTCHA solving API: Turnstile, reCAPTCHA, Cloudflare Clearance, AWS WAF, DataDome and more.

## 官网

- 官网：https://voidcaptcha.com
- 源码仓库：https://github.com/voidcaptcha-api/voidcaptcha-python
- PyPI 项目页：https://pypi.org/project/voidcaptcha/

## 历史版本号

- 0.1.0

## 获取地址

- pip 安装：`pip install voidcaptcha`
- 下载页面：https://pypi.org/project/voidcaptcha/#files
- 运行要求：Python >=3.9
