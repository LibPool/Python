# trekr

> 标签: Python

## 简介

Early release of TREKR, a pose-tracking tool: its label checker (a window to find and fix label errors; reads DeepLabCut projects for now), and checks of the GPU against the PyTorch build, of OpenCV's colours on camera video, and of whether a video file changed.
