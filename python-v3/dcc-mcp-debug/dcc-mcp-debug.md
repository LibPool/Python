# dcc-mcp-debug

> 标签: Python

## 简介

MCP server that drives and debugs a locally running MotionBuilder / 3ds Max through its commandPort (TCP port == PID) and debugpy.

## 官网

- 官网：https://pypi.org/project/dcc-mcp-debug/
- PyPI 项目页：https://pypi.org/project/dcc-mcp-debug/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install dcc-mcp-debug`
- 下载页面：https://pypi.org/project/dcc-mcp-debug/#files
- 运行要求：Python >=3.8
