# uv-wheel-download

> 标签: Python

## 简介

Download every wheel/sdist pinned in uv.lock into a local folder for offline installs (a pip-free `pip download`)

## 官网

- 官网：https://pypi.org/project/uv-wheel-download/
- 源码仓库：https://github.com/bmsuisse/uv-wheel-download
- PyPI 项目页：https://pypi.org/project/uv-wheel-download/

## 历史版本号

- 当前版本：0.1.1

- 0.1.0
- 0.1.1

## 获取地址

- pip 安装：`pip install uv-wheel-download`
- 下载页面：https://pypi.org/project/uv-wheel-download/#files
- 运行要求：Python >=3.11
