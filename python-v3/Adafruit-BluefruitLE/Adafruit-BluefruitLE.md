# Adafruit-BluefruitLE

> 标签: Python

## 简介

Python library for interacting with Bluefruit LE (Bluetooth low energy) devices on Linux or OSX.

- 官网：https://github.com/adafruit/Adafruit_Python_BluefruitLE/
