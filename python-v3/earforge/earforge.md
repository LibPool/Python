# earforge

> 标签: Python

## 简介

Local GPU-accelerated learn-by-ear workbench: any recording into multi-instrument MIDI, a live piano roll, and a play-along practice mixer, built on MuScriptor.

## 官网

- 官网：https://github.com/Booyaka101/earforge
- PyPI 项目页：https://pypi.org/project/earforge/
