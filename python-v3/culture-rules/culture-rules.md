# culture-rules

> 标签: Python

## 简介

Rules engine for the AgentCulture mesh: rules -> conditions -> workflows -> actions, executed by actors (agents, humans, code). Python backend library culture_rules; React Flow (Node.js) visual editor with Rules, Workflows and Actors tabs.
