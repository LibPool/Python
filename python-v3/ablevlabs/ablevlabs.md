# ablevlabs

> 标签: Python

## 简介

AbleVLabs tools: kami, a machine-learning tutor that builds models and explains them in plain English, now including a PyTorch half that trains a network for you, shows you the code it ran, and reads the training loop you wrote yourself; lana, a weighted record-comparison engine that weighs records attribute by attribute and tells you which wins; and agoge, a resistance-training coach that estimates reps in reserve and tracks fatigue, powered by the Vivanco Proximity-to-Failure Model.
