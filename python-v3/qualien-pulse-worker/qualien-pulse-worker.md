# qualien-pulse-worker

> 标签: Python

## 简介

Pulse — AI mobile-test worker for qualien.ai. Runs on the user's own machine (bring-your-own-compute), driving Android (Appium/UiAutomator2) and iOS (Appium/XCUITest) devices.

## 官网

- 官网：https://qualien.ai
- PyPI 项目页：https://pypi.org/project/qualien-pulse-worker/
