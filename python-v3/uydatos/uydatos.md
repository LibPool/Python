# uydatos

> 标签: Python

## 简介

Lectores estrictos de datos públicos de Uruguay y la región: BCU, ANCAP, INIA, INUMET, Salto Grande, INDEC, IBGE, IDE.uy, RUT y cédula.

- 源码仓库：https://github.com/manusabbath-arch/uy-datos-abiertos
