# easyemailverification

> 标签: Python

## 简介

Official Python client for the Easy Email Verification API: verify email addresses one by one, in batches of 50 or as bulk lists.

## 官网

- 官网：https://www.easyemailverification.com/en-US/api
- 源码仓库：https://github.com/EasyEmailVerification/easyemailverification-python
- PyPI 项目页：https://pypi.org/project/easyemailverification/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install easyemailverification`
- 下载页面：https://pypi.org/project/easyemailverification/#files
- 运行要求：Python >=3.8
