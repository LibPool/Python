# jp-verify-mcp

> 标签: Python

## 简介

MCP server for JP-Verify: verify Japanese companies (invoice T-numbers, Corporate Numbers, English names, major shareholders).

## 官网

- 官网：https://jp-verify.obolpay.xyz
- 源码仓库：https://github.com/Hiroshi-Ichiyanagi/jp-verify-mcp
- PyPI 项目页：https://pypi.org/project/jp-verify-mcp/
