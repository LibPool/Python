# hsbc-tradetrack-mcp

> 标签: Python

## 简介

Unofficial MCP server for HSBC TradeTrack (汇丰交易追踪): trending stocks and top-5% traders' buy/sell/hold lists for US & HK, from HSBC's public no-login endpoints.
