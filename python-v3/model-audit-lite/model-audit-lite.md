# model-audit-lite

> 标签: Python

## 简介

Lightweight safety audit for Hugging Face models: file-distribution audit, a conversion-integrity diff (chat_template + safety-probe regressions between a source and a converted repo), and a small known-pattern prompt-injection probe suite.
