# glyd-gpu

> 标签: Python

## 简介

Glyd on the GPU: a bf16 model's weights held compressed in GPU memory, bit for bit, and multiplied from there. The GPU half of glyd (pip install "glyd[gpu]"), compiled.

## 官网

- 官网：https://getglyd.com
- PyPI 项目页：https://pypi.org/project/glyd-gpu/
