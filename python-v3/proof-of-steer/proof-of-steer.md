# proof-of-steer

> 标签: ai-agents, claude-code, cli, code-review, codex, provenance

## 简介

Local tool that turns an AI coding session or a document's git history into a steering receipt and a steerprint, a map of which parts the human shaped, so a reviewer can price their attention. Steered, not slop.
