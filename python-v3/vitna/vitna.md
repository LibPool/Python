# vitna

> 标签: Python

## 简介

VITNA for agent code: check every tool call before it runs. Adapters for LangChain/LangGraph, the OpenAI Agents SDK, Pydantic AI, Microsoft Agent Framework, Google ADK and CrewAI. Calls you mark as risky wait for a person. Fails closed.
