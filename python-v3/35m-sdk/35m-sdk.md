# 35m-sdk

> 标签: Python

## 简介

35pay Python SDK · 5 行接入聚合支付（WeChat / Alipay / Stripe / Creem / 易支付），单文件零依赖；async 可选启用。pip install 35m-sdk[async] 启用 AsyncPay。

## 官网

- 官网：https://pay.35team.com
- 源码仓库：https://github.com/guo2001china/35m-sdk
- PyPI 项目页：https://pypi.org/project/35m-sdk/
