# aisay

> 标签: Python

## 简介

OpenAI-backed TTS CLIs: aisay (short-form, like macOS `say`) and aitts (long-form → playlist).

## 官网

- 官网：https://github.com/orlenko/aitts
- PyPI 项目页：https://pypi.org/project/aisay/
