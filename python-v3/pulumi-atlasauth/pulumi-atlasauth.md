# pulumi-atlasauth

> 标签: Python

## 简介

A Pulumi package for managing Atlas authentication-platform resources (OAuth clients, SSO connections, resource servers, JWT templates, webhooks, roles, organizations, custom domains, sign-in page design, messaging providers, Sign in with Atlas apps and more) as code.

- 源码仓库：https://github.com/Atlas-Authorization/pulumi-atlas
