# iran-downloads-mcp

> 标签: Python

## 简介

Unofficial read-only MCP server for searching Iranian software and game download sites (metadata only): Soft98, P30Download, Downloadly, VGDL.

## 官网

- 官网：https://github.com/sepehr071/iran-downloads-mcp
- PyPI 项目页：https://pypi.org/project/iran-downloads-mcp/

## 获取地址

- pip 安装：`pip install iran-downloads-mcp`
- 下载页面：https://pypi.org/project/iran-downloads-mcp/#files
- 运行要求：Python >=3.10
