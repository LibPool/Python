# coospo-cli

> 标签: Python

## 简介

Command-line tool for COOSPO CS500/CS600 bike computers: device info, battery, memory usage and FIT file download over Bluetooth LE

## 官网

- 官网：https://github.com/blshkv/coospo-cli
- PyPI 项目页：https://pypi.org/project/coospo-cli/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

- 下载页面：https://pypi.org/project/coospo-cli/#files
- 运行要求：Python >=3.9
