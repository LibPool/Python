# ragleap-voice

> 标签: Python

## 简介

Pre-alpha model manager for open, local speech-to-text and text-to-speech: licence-checked manifest, hash-verified downloads. No speech engines yet.

## 官网

- 官网：https://github.com/ragleap/ragleap-core
- PyPI 项目页：https://pypi.org/project/ragleap-voice/
