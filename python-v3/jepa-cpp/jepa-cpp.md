# jepa-cpp

> 标签: Python

## 简介

Name reserved for jepa-cpp. Python bindings for jepa.cpp, an inference runtime for action-conditioned JEPA world models with planners, on ggml.

- 官网：https://github.com/agentic-learning-ai-lab/jepa.cpp
