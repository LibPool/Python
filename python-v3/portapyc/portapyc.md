# portapyc

> 标签: Python

## 简介

PortaPyC, a python 3 port of RPyC version 3.3.0, allows communicating with python 2 clients and servers.

## 官网

- 官网：https://portapyc.readthedocs.io/en/latest/
- PyPI 项目页：https://pypi.org/project/portapyc/

## 历史版本号

- 当前版本：3.3.0.post4

- 3.3.0.post4

## 获取地址

- pip 安装：`pip install portapyc`
- 下载页面：https://pypi.org/project/portapyc/#files
- 运行要求：Python >=3.7
