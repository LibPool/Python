# strands-comment-scraper

> 标签: Python

## 简介

Strands Agents tools that read, filter and summarise Reddit and Hacker News threads exported with Comment Scraper. Local JSON files only, no network requests.

## 官网

- 官网：https://comment-scraper.com/strands
- 源码仓库：https://github.com/supertj/strands-comment-scraper
- PyPI 项目页：https://pypi.org/project/strands-comment-scraper/
