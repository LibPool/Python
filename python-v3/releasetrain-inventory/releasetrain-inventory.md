# releasetrain-inventory

> 标签: Python

## 简介

Cross-platform scanner for installed software (not OS/library packages) and their versions, with SBOM output (CycloneDX, SPDX) and optional upload to a ReleaseTrain account.

## 官网

- 官网：https://github.com/SE4CPS/releasetrain-inventory
- PyPI 项目页：https://pypi.org/project/releasetrain-inventory/
