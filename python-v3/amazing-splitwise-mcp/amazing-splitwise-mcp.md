# amazing-splitwise-mcp

> 标签: Python

## 简介

MCP server for the Splitwise API v3.0 (personal API key, stdio by default, streamable-http behind a bearer).

## 官网

- 官网：https://github.com/trustxai/splitwise-mcp
- PyPI 项目页：https://pypi.org/project/amazing-splitwise-mcp/

- 下载页面：https://pypi.org/project/amazing-splitwise-mcp/#files
