# wattsonic-modbus-docs

> 标签: ems, inverter, mcp, modbus, sunspec, wattsonic

## 简介

Read-only MCP server with the Modbus documentation of Wattsonic MATIC hybrid inverters (native EMS registers, SunSpec models, closed-loop control recipes). Never connects to a device.
