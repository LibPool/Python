# spritehatch-mcp

> 标签: Python

## 简介

MCP server for SpriteHatch: AI agents generate 2D game sprites, animations, effects, items, UI, scenes and tilesets and export them for Godot, Unity, GameMaker and RPG Maker.

## 官网

- 官网：https://spritehatch.com
- PyPI 项目页：https://pypi.org/project/spritehatch-mcp/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install spritehatch-mcp`
- 下载页面：https://pypi.org/project/spritehatch-mcp/#files
- 运行要求：Python >=3.11
