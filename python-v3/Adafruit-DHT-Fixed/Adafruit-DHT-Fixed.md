# Adafruit-DHT-Fixed

> 标签: Python

## 简介

Library to get readings from the DHT11, DHT22, and AM2302 humidity and temperature sensors on a Raspberry Pi or Beaglebone Black.

## 官网

- 官网：https://github.com/adafruit/Adafruit_Python_DHT/
- PyPI 项目页：https://pypi.org/project/Adafruit-DHT-Fixed/
