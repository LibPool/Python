# cascadeaihub

> 标签: Python

## 简介

Scaffold a new dev_kit-generated pyqt or jinja frontend project via your cascadeaihub API key -- no local dev_kit install required.

## 官网

- 官网：https://www.cascadeaihub.com
- PyPI 项目页：https://pypi.org/project/cascadeaihub/

## 历史版本号

- 当前版本：0.2.0

- 0.1.0
- 0.2.0

## 获取地址

- pip 安装：`pip install cascadeaihub`
- 下载页面：https://pypi.org/project/cascadeaihub/#files
- 运行要求：Python >=3.10
