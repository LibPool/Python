# narrapy

> 标签: Python

## 简介

Turn PDFs into audiobooks with chapters, using local neural text-to-speech (Kokoro or Piper).

## 官网

- 官网：https://github.com/rakishere/narrapy
- PyPI 项目页：https://pypi.org/project/narrapy/
