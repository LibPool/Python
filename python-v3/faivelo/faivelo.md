# faivelo

> 标签: Python

## 简介

Official Faivelo SDK for Python: email inboxes for your code and your AI agents. Send, receive, drafts, labels, threads, domains, DNS and webhooks.

- 官网：https://faivelo.com
- PyPI 项目页：https://pypi.org/project/faivelo/
