# dre-cli

> 标签: Python

## 简介

Reports as code: SQL and YAML in git, built into Excel, CSV or fixed-width files and headline messages, delivered to email, SFTP, cloud storage or Slack

- 官网：https://getdre.com
- 源码仓库：https://github.com/get-dre/dre
