# idl2proto

> 标签: Python

## 简介

Convert OMG IDL (IDL 4.x / DDS-XTypes) into Protocol Buffers (proto3)

## 官网

- 官网：https://github.com/DominikTUM/idl2proto
- PyPI 项目页：https://pypi.org/project/idl2proto/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install idl2proto`
- 下载页面：https://pypi.org/project/idl2proto/#files
- 运行要求：Python >=3.9
