# aiohttp-client-rate-limiter

> 标签: Python

## 简介

This is a mini tool that overwrite aiohttp session to provide rate limit function within a same session.

## 官网

- 官网：https://github.com/peteropensource/aiohttp_rate_limiter
- PyPI 项目页：https://pypi.org/project/aiohttp-client-rate-limiter/
