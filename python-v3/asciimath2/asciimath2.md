# asciimath2

> 标签: Python

## 简介

LaTeX -> AsciiMath2 conversion (AsciiMath2 = asciimath.org + the asciimath-parser extensions, see SPEC.md)

## 官网

- 官网：https://github.com/iasandcb/asciimath2
- PyPI 项目页：https://pypi.org/project/asciimath2/

- 0.1.0

## 获取地址

- pip 安装：`pip install asciimath2`
- 下载页面：https://pypi.org/project/asciimath2/#files
- 运行要求：Python >=3.12
