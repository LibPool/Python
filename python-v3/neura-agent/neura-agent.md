# neura-agent

> 标签: Python

## 简介

Agent client for NEURA Compute: OpenAI-compatible inference where the agent pays for itself. HTTP 402 -> wallet sign-in -> USDC on Base -> credited -> retry, as a drop-in http_client for the OpenAI Python SDK.
