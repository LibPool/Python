# xrdcore

> 标签: Python

## 简介

The dependency-free core shared by xrdclient, xgfalclient and xrdarc: safe XML, checksums, log redaction, cancellation, the copy pipeline, thread fan-out, the shared CLI exit codes and the CLI report format
