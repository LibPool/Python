# jenkins-mcp-toolkit

> 标签: Python

## 简介

Servidor MCP do Jenkins: consulta de builds, detecção por commit, navegação de multibranch e input de promoção.

## 官网

- 官网：https://pypi.org/project/jenkins-mcp-toolkit/
- PyPI 项目页：https://pypi.org/project/jenkins-mcp-toolkit/

- 下载页面：https://pypi.org/project/jenkins-mcp-toolkit/#files
