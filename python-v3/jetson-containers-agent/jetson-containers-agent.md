# jetson-containers-agent

> 标签: Python

## 简介

Agent + CLI (jca) wrapping the jetson-containers family (dusty-nv, NVIDIA-AI-IOT, jetson-ai-lab forks): track upstreams, diff packages across forks, and build/run containers on Jetson.
