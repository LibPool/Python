# msclinical

> 标签: Python

## 简介

Multiple sclerosis clinical rules in one package: confirmed disability and cognitive worsening, RAW/PIRA/PIRMA, NEDA, relapse hygiene, treatment epochs, EDSS noise, definition multiverse, table schema, feasibility, Table 1, report parsing, and simulated cohorts with known truth.
