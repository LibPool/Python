# jetsonrun

> 标签: Python

## 简介

jetsonrun - launch, manage and stop LLM inference workloads on NVIDIA Jetson (Orin, Thor) with one command. A Jetson port of sparkrun: recipes, runtimes, containers tuned for Jetson, drawing on thor-arena/mjolnir for Thor-optimized vLLM serving.
