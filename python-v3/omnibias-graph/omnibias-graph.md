# omnibias-graph

> 标签: Python

## 简介

Differentiable spectral graph operators (Laplacians, spectral embedding, heat kernel) and continuous combinatorial relaxations (Gumbel-Sinkhorn, SoftSort, soft top-k) with torch + jax bit-parity.
