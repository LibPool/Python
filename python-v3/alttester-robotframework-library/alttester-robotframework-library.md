# alttester-robotframework-library

> 标签: Python

## 简介

Robot Framework Library for the AltTester® framework. AltTester® is an UI driven test automation tool that helps you find objects in your game and interacts with them.

## 官网

- 官网：https://alttester.com/docs/sdk/latest/
- 源码仓库：https://github.com/alttester/AltTester-Unity-SDK
- PyPI 项目页：https://pypi.org/project/alttester-robotframework-library/
