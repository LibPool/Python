# sentinel-2-cog-downloader

> 标签: Python

## 简介

Download Sentinel-2 L2A COGs from Element 84 STAC, stitch full bbox coverage, and load selected bands as xarray.

- 官网：https://pypi.org/project/sentinel-2-cog-downloader/
