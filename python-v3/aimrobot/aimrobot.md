# aimrobot

> 标签: Python

## 简介

A library to run Robotic Assembly Digital Model (RADM) files directly on Universal Robots.

## 官网

- 官网：https://github.com/ALharchi/aimrobot
- PyPI 项目页：https://pypi.org/project/aimrobot/
