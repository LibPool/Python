# datatool-cli

> 标签: Python

## 简介

Diagnostica, perfila, limpa e converte arquivos de dados (CSV, Excel, JSON, Parquet) pela linha de comando, com suporte nativo a CSV do Excel brasileiro, CPF/CNPJ e R$.
