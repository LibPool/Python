# astron-tieba-mcp

> 标签: Python

## 简介

Astron-Tieba-MCP: 基于百度贴吧游客态公开接口的自包含 MCP Server，支持匿名热榜、吧内信息流、全站帖子搜索、帖子详情和作者主页能力。
