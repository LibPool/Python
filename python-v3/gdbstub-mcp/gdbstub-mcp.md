# gdbstub-mcp

> 标签: Python

## 简介

MCP server that lets AI agents debug kernels through QEMU's gdbstub - no gdb binary needed. Breakpoints, registers, memory, backtraces, triple-fault diagnosis.

## 官网

- 官网：https://github.com/0xmortuex/gdbstub-mcp
- PyPI 项目页：https://pypi.org/project/gdbstub-mcp/
