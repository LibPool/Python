# Adafruit-VCNL40xx

> 标签: Python

## 简介

Python code to use the VCNL4000 & VCNL4010 proximity sensors with the Raspberry Pi & BeagleBone Black.

- PyPI 项目页：https://pypi.org/project/Adafruit-VCNL40xx/
