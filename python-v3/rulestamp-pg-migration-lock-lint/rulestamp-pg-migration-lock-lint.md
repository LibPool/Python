# rulestamp-pg-migration-lock-lint

> 标签: Python

## 简介

Names every statement in a Rails, Django or raw SQL migration that takes a table-blocking Postgres lock, and prints the non-blocking rewrite. 36 rules, PostgreSQL 12-17. (bundled Node.js runtime)
