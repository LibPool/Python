# lithovox-exports

> 标签: Python

## 简介

Export LithoVox corridor voxel models (model.nc) to D-Stability, D-Geo Flow, XSLOPE, DXF, GLB, 3D Tiles and LAZ

## 官网

- 官网：https://www.lithovox.com
- PyPI 项目页：https://pypi.org/project/lithovox-exports/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install lithovox-exports`
- 下载页面：https://pypi.org/project/lithovox-exports/#files
- 运行要求：Python >=3.12
