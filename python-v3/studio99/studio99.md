# studio99

> 标签: Python

## 简介

Official Python client for the Studio99 Indic Typography API: exact Hindi, Marathi, Gujarati and English typography as editable SVG and PNG.

## 官网

- 官网：https://studio99.app/developers
- 源码仓库：https://github.com/studio99-app/studio99-python
- PyPI 项目页：https://pypi.org/project/studio99/
