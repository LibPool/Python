# pytest-shm

> 标签: Python

## 简介

Put pytest's temporary files on the /dev/shm tmpfs so fsync-heavy suites stop waiting on the disk

## 官网

- 官网：https://github.com/basnijholt/pytest-shm
- PyPI 项目页：https://pypi.org/project/pytest-shm/
