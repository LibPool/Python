# autodiff-team44

> 标签: Python

## 简介

This package is an automatic differentiation package which will evaluate derivatives with machine-precision almost instantaneously. The speed and precision of autodifferentiation is paramount to applications such as deep learning models, and mitigates inefficiencies that compound with larger and more complex functions.
