# trackfetch

> 标签: Python

## 简介

Turn a text file of songs into tagged MP3s: Spotify metadata and cover art, best-match YouTube audio via yt-dlp.

## 官网

- 官网：https://github.com/ByteMe6/trackfetch
- PyPI 项目页：https://pypi.org/project/trackfetch/
