# notefeed

> 标签: Python

## 简介

Client and CLI for notefeed, a self-hosted inbox for markdown notes that you read back as RSS.

- 官网：https://docs.notefeed.me/
- 源码仓库：https://github.com/notefeed/notefeed
- PyPI 项目页：https://pypi.org/project/notefeed/
