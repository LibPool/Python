# korean-tax-calc-mcp

> 标签: Python

## 简介

Korea (South Korea) tax calculator MCP server — 50 tools: tax calculation (incl. end-to-end adjustments from raw facts) + tax audit judgment (related party, tunnelling gift, return precheck, PDF review). 한국 세금 계산 + 세무조사 판정 MCP
