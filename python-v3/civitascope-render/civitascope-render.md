# civitascope-render

> 标签: Python

## 简介

Civitascope infographic renderer: draws charts, map SVGs and social images from verified Eurostat figures. Early development.

## 官网

- 官网：https://civitascope.com
- 源码仓库：https://github.com/civitascope/civitascope-render
- PyPI 项目页：https://pypi.org/project/civitascope-render/
