# facett-demo

> 标签: Python

## 简介

facett's components in a Streamlit app: every Rust component drawn by wasm on WebGPU, grouped like facett-demo, graphs generated in the wasm up to 100 000 nodes — no server needed; live korp data with the [korp] extra.
