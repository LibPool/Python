# atc-mi-interface

> 标签: Python

## 简介

Python tools and API for the "atc1441" and "pvvx" Xiaomi Mijia Thermometer custom firmware (ATC_MiThermometer)

## 官网

- 官网：https://github.com/pvvx/ATC_MiThermometer/tree/master/python-interface
- PyPI 项目页：https://pypi.org/project/atc-mi-interface/
