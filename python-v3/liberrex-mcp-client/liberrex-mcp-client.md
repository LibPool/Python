# liberrex-mcp-client

> 标签: Python

## 简介

Call other platforms' tools on the Liberrex MCP mesh, from async or sync code, and hand them to an LLM as function-calling tools.

## 官网

- 官网：https://ai.liberrex.com
- PyPI 项目页：https://pypi.org/project/liberrex-mcp-client/

- 下载页面：https://pypi.org/project/liberrex-mcp-client/#files
