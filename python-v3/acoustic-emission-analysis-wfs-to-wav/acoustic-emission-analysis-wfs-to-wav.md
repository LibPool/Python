# acoustic-emission-analysis-wfs-to-wav

> 标签: Python

## 简介

A updated and adjusted forked project for importing acoustic emission analysis data from wfs files and converting them to wav files.

## 官网

- 官网：https://pypi.org/project/acoustic-emission-analysis-wfs-to-wav/
- PyPI 项目页：https://pypi.org/project/acoustic-emission-analysis-wfs-to-wav/

- pip 安装：`pip install acoustic-emission-analysis-wfs-to-wav`
- 下载页面：https://pypi.org/project/acoustic-emission-analysis-wfs-to-wav/#files
- 运行要求：Python <4.0,>=3.9
