# changeset-second-opinion

> 标签: changeset, decision-support, fastapi, openstreetmap, osm, review, strands

## 简介

Second-opinion review tool for flagged OpenStreetMap changesets: evidence, typed decisions, a lane-ordered queue and comment drafts for a person to edit.
