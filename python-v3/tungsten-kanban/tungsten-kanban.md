# tungsten-kanban

> 标签: Python

## 简介

Kanban boards for Tungsten: show any resource as drag-and-drop columns, with ready boards for leads, tickets and leave.

## 官网

- 官网：https://tungsten.prisminfoways.com/plugins/kanban
- 源码仓库：https://github.com/Prism-Infoways/Tungsten
- PyPI 项目页：https://pypi.org/project/tungsten-kanban/
