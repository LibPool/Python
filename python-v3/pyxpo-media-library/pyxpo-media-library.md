# pyxpo-media-library

> 标签: Python

## 简介

Save files to the device photo library from pyxpo apps (expo-media-library shape).

## 官网

- 官网：https://github.com/pyxpo/pyxpo/tree/main/packages/media-library
- PyPI 项目页：https://pypi.org/project/pyxpo-media-library/

## 历史版本号

- 当前版本：0.1.0a1

- 0.1.0a1

## 获取地址

- pip 安装：`pip install pyxpo-media-library`
- 下载页面：https://pypi.org/project/pyxpo-media-library/#files
- 运行要求：Python >=3.9
