# pagelens-ocr

> 标签: Python

## 简介

CPU-only OCR for scanned documents (PDF, JPG, JPEG, PNG) that keeps headings, tables and layout

- 官网：https://pypi.org/project/pagelens-ocr/
- PyPI 项目页：https://pypi.org/project/pagelens-ocr/

- 下载页面：https://pypi.org/project/pagelens-ocr/#files
