# omnibias-boolean

> 标签: Python

## 简介

Differentiable Boolean algebra: exact ANF/Reed-Muller and Walsh spectra, Boolean differential calculus, reproductive equation solving, and a beta-annealed soft-gate system solver built on the omnibias closed-form derivative towers (torch + jax).
