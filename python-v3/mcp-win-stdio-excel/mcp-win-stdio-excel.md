# mcp-win-stdio-excel

> 标签: Python

## 简介

Windows-optimized Model Context Protocol (MCP) server for Excel: 34 tools for Pandas queries, bulk 2D writes, cell styling, conditional formatting, chart generation, data deduplication/cleaning, in-memory transformations, RapidFuzz reconciliation, and native Excel COM automation (PDF export, recalc, pivots, macros).
