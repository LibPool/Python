# particlefx

> 标签: Python

## 简介

纯 Python + NumPy 粒子系统库 — 多渲染器（pygame/PIL/ModernGL）+ 效果工厂 + Taichi 流体后端 + GPU 模拟

## 官网

- 官网：https://gitee.com/siwpan/particlefx
- PyPI 项目页：https://pypi.org/project/particlefx/

- 1.0.0

- pip 安装：`pip install particlefx`
- 下载页面：https://pypi.org/project/particlefx/#files
- 运行要求：Python >=3.10
