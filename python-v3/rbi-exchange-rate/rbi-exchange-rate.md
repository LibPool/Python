# rbi-exchange-rate

> 标签: Python

## 简介

Official Reserve Bank of India exchange rates - 6 currencies vs INR, history since 2003. Keyless, zero-dependency Python client.

- 官网：https://allratestoday.com/central-bank-rates-api/rbi/
- 源码仓库：https://github.com/AllRates-Today/exchange-rates-api
- PyPI 项目页：https://pypi.org/project/rbi-exchange-rate/
