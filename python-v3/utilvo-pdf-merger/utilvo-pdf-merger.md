# utilvo-pdf-merger

> 标签: Python

## 简介

Lightweight library for inspecting PDF binary headers, counting pages, validating xref tables, and merging multiple PDF byte streams.

- 官网：https://utilvo.com/pdf-tools/merge-pdf
- 源码仓库：https://github.com/utilvo/utilvo-pdf-merger
