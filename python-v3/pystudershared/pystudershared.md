# pystudershared

> 标签: Python

## 简介

Python shared interface definition to communicate with Studer-Innotec devices; used by pystudernext and pystuderxcom libaries.

## 官网

- 官网：https://github.com/ankohanse/pystudershared
- PyPI 项目页：https://pypi.org/project/pystudershared/

- 1.0.0

- pip 安装：`pip install pystudershared`
- 下载页面：https://pypi.org/project/pystudershared/#files
- 运行要求：Python >=3.8
