# arena-predictions

> 标签: Python

## 简介

Python SDK for Arena Predictions: resolve bets in words to Arena instrument ids, read cross-venue quotes and price gaps, Arena's public records and your own account. Paper trading only; this SDK places no trades.

## 官网

- 官网：https://arena-predictions.com
- PyPI 项目页：https://pypi.org/project/arena-predictions/
