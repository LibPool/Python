# store-resource-bootstrap-py

> 标签: Python

## 简介

Optional resource bootstrap plugin for common-store: registers caller-injected schemas (optional; the three resource schemas ship as an optional reference, not force-registered), wires the host resource capability (providers / url / sign) and produces the store-api fileResolver seam, for py-store hosts
