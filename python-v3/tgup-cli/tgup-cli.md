# tgup-cli

> 标签: Python

## 简介

Upload files to a Telegram channel and use it as a drive (parallel transfers, auto split/merge past the size limit)

- 官网：https://pypi.org/project/tgup-cli/
- PyPI 项目页：https://pypi.org/project/tgup-cli/
