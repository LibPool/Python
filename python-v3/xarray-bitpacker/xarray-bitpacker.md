# xarray-bitpacker

> 标签: Python

## 简介

Xarray extension that leverages xarray's metadata to automate and enhance numpy's bitpacking functionality.

## 官网

- 官网：https://github.com/zyjux/xarray_bitpacker
- PyPI 项目页：https://pypi.org/project/xarray-bitpacker/
