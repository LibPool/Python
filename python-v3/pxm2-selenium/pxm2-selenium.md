# pxm2-selenium

> 标签: Python

## 简介

Official Selenium WebDriver & Selenium-Wire proxy extension injector and mobile rotator for PXM2 4G/5G mobile proxies.

## 官网

- 官网：https://pxm2.io/
- PyPI 项目页：https://pypi.org/project/pxm2-selenium/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install pxm2-selenium`
- 下载页面：https://pypi.org/project/pxm2-selenium/#files
- 运行要求：Python >=3.8
