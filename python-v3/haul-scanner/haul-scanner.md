# haul-scanner

> 标签: Python

## 简介

Credential exposure scanner: finds the API keys, tokens, SSH keys, .env files and AI-chat leaks an infostealer would grab on your machine, without ever reading a secret out. Read-only, zero network, zero dependencies.
