# agentic-wallet-guardian-mcp

> 标签: Python

## 简介

Decision infrastructure for autonomous AI agents: evaluates a proposed blockchain action intent and returns an explainable ALLOW/WARN/BLOCK decision before execution, signed as a verifiable OAA token.
