# airpyy

> 标签: Python

## 简介

airpy: the provider-aware Python SDK layer on top of aircore -- ModelAgent, providers (MockProvider, LiteLLMProvider, native OpenAIProvider), consensus strategies, structured output, MCP tool registry, streaming, sessions, PromptTemplate. Imports aircore; aircore never imports this package. PyPI distribution name is `airpyy`; the importable package remains `airpy`.
