# mkp-forge

> 标签: Python

## 简介

This is a tool to build mkp packages directly without the need to install checkmk.

## 官网

- 官网：https://makanu.github.io/mkp-forge/
- 源码仓库：https://github.com/makanu/mkp-forge
- PyPI 项目页：https://pypi.org/project/mkp-forge/

## 历史版本号

- 当前版本：0.0.1

- 0.0.1
- 0.0.1rc1

## 获取地址

- pip 安装：`pip install mkp-forge`
- 下载页面：https://pypi.org/project/mkp-forge/#files
- 运行要求：Python <4.0,>=3.11
