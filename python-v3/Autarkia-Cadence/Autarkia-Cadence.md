# Autarkia-Cadence

> 标签: agent, autarkia, cooldown, notification, proactive, quiet-hours, rate-limit, scheduling, self-hosted

## 简介

Proactive message cadence governance: cooldowns, quiet hours, daily caps, adaptive intervals, backoff jitter, and sleep-window probes. Extracted from the Autarkia agent runtime.
