# canvod-filemap

> 标签: Python

## 简介

Naming recipes that map non-canonical GNSS-T filenames to canVOD names

## 官网

- 官网：https://github.com/TUW-GEO/canvodpy-extensions
- PyPI 项目页：https://pypi.org/project/canvod-filemap/

- pip 安装：`pip install canvod-filemap`
- 下载页面：https://pypi.org/project/canvod-filemap/#files
- 运行要求：Python >=3.14
