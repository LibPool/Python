# algovoi-keystone-connect

> 标签: Python

## 简介

Build and test Keystone bolt-ons with almost no boilerplate -- declare a connector in ~12 lines and verify any bolt-on at any stage of the flow offline (keystone toolkit, Apache-2.0)
