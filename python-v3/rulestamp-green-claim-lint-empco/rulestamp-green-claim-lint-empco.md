# rulestamp-green-claim-lint-empco

> 标签: Python

## 简介

Reads your HTML and Markdown product copy and flags the environmental claims Directive (EU) 2024/825 turns into banned practices on 27 September 2026, with the clause and a compliant rewrite for each  (bundled Node.js runtime)
