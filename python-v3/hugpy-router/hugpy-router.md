# hugpy-router

> 标签: Python

## 简介

hugpy's router: one OpenAI-compatible address in front of every box's hugpy-wrapper front door. Picks the box per call (a model already serving with the same settings first, else a box that can load it), proxies the call (streaming, uploads, binary), bounces a refused call to the next box, and logs one row per decision.
