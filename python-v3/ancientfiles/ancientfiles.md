# ancientfiles

> 标签: Python

## 简介

Moves ancient files from a directory to another selecting is age. Then you can backup them.

## 官网

- 官网：https://pypi.org/project/ancientfiles/
- PyPI 项目页：https://pypi.org/project/ancientfiles/
