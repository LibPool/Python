# prozorro-mcp

> 标签: Python

## 简介

MCP server and CLI over Prozorro, Ukraine's public procurement data: tender search, upcoming plans, market and competitor analysis, red flags. Local sync, no keys.

- 官网：https://github.com/kotiniiqq/prozorro-mcp
