# coderifts-verifier

> 标签: Python

## 简介

Offline verifier for CodeRifts chain receipts and DSSE/in-toto envelopes. Ed25519, no network.

## 官网

- 官网：https://github.com/coderifts/receipt-verifier
- PyPI 项目页：https://pypi.org/project/coderifts-verifier/
