# limma-ai

> 标签: Python

## 简介

The Limma client: the Python SDK for Limma's agent verbs, and `limma sync`, which keeps a folder, an S3 / Azure / GCS bucket, a Google Drive folder or a SharePoint library equal to a workspace.

## 官网

- 官网：https://limma.ai
- PyPI 项目页：https://pypi.org/project/limma-ai/
