# erdilrf-lrf

> 标签: Python

## 简介

Host-side UART driver for ERDI 905 nm laser rangefinder modules (LR1000E2 protocol family)

## 官网

- 官网：https://erdilrf.com
- 源码仓库：https://github.com/erdilrf/erdilrf-drivers
- PyPI 项目页：https://pypi.org/project/erdilrf-lrf/

- pip 安装：`pip install erdilrf-lrf`
- 下载页面：https://pypi.org/project/erdilrf-lrf/#files
- 运行要求：Python >=3.9
