# misscat

> 标签: Python

## 简介

Watch a GitHub repository and run an AI review on every new PR HEAD (plus BadCat, a review-state watcher with opt-in merge, badcat-host, its read-only Native Messaging host, and nastycat-host, the read-only merge-state host of the NastyCat Chrome mode)
