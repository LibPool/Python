# ipyd3geo

> 标签: Python

## 简介

An interactive map widget for Jupyter that uses D3 Geo as its renderer.

## 官网

- 官网：https://pypi.org/project/ipyd3geo/
- 源码仓库：https://github.com/geojupyter/prototype-ipyd3geo
