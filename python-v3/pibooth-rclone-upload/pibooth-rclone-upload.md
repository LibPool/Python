# pibooth-rclone-upload

> 标签: Python

## 简介

Pibooth plugin that uploads pictures, GIFs, videos and QR codes to any rclone remote

## 官网

- 官网：https://github.com/peteoheat/pibooth-rclone-upload
- PyPI 项目页：https://pypi.org/project/pibooth-rclone-upload/

## 历史版本号

- 当前版本：1.5.0

- 1.5.0

## 获取地址

- pip 安装：`pip install pibooth-rclone-upload`
- 下载页面：https://pypi.org/project/pibooth-rclone-upload/#files
- 运行要求：Python >=3.9
