# tts-studio

> 标签: Python

## 简介

Local-first text-to-speech studio: run 'tts-studio' and your browser opens - Kokoro, Kitten, Pocket and Piper in one app, no API keys

## 官网

- 官网：https://github.com/opengptloop/tts-studio
- PyPI 项目页：https://pypi.org/project/tts-studio/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install tts-studio`
- 下载页面：https://pypi.org/project/tts-studio/#files
- 运行要求：Python >=3.10
