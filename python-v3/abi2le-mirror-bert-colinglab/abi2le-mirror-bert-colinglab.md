# abi2le-mirror-bert-colinglab

> 标签: Python

## 简介

This is an adaptation of the original MirrorBERT repository, with minor tweaks to use it within the Abi2le project. Original repo description: Code repo for the EMNLP 2021 paper: Fast, Effective, and Self-Supervised: Transforming Masked Language Models into Universal Lexical and Sentence Encoders by Fangyu Liu, Ivan Vulić, Anna Korhonen, and Nigel Collier.
