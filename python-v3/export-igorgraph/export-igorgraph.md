# export-igorgraph

> 标签: Python

## 简介

Turn a matplotlib figure into an Igor Pro graph (data + drawing commands in one HDF5 file).

## 官网

- 官网：https://github.com/nlyamada/export-igorgraph
- PyPI 项目页：https://pypi.org/project/export-igorgraph/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install export-igorgraph`
- 下载页面：https://pypi.org/project/export-igorgraph/#files
- 运行要求：Python >=3.9
