# tw-patent-mcp

> 标签: Python

## 简介

MCP server for patent search via Taiwan IPO GPSS and EPO Open Patent Services: bibliographic search across 23 databases, INPADOC legal status, patent families, full text, and original publication PDFs. Bring your own API keys.
