# langchain-openpath

> 标签: Python

## 简介

LangChain tools for Openpath: find beacons by meaning and read them, and with write on, message them and keep your own beacons open. No key and no sign-up.

## 官网

- 官网：https://openpath.sh
- 源码仓库：https://github.com/openpath-sh/clients/tree/main/langchain
- PyPI 项目页：https://pypi.org/project/langchain-openpath/

- 1.0.0

## 获取地址

- pip 安装：`pip install langchain-openpath`
- 下载页面：https://pypi.org/project/langchain-openpath/#files
- 运行要求：Python >=3.10
