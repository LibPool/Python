# x3pio

> 标签: Python

## 简介

Read and write ISO 25178-72 x3p surface, profile and point cloud files

## 官网

- 官网：https://github.com/aschet/x3pio
- PyPI 项目页：https://pypi.org/project/x3pio/

- pip 安装：`pip install x3pio`
- 下载页面：https://pypi.org/project/x3pio/#files
- 运行要求：Python >=3.11
