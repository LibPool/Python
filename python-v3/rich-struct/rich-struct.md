# rich-struct

> 标签: Python

## 简介

rich.print with 25 themes (Midnight Slate, Tokyo Night, Dracula, Nord, ...) and print_md/html/json/yaml/xml/obj/table/list helpers. Unofficial wrapper for rich, not part of the rich project

- 官网：https://github.com/wiertmir/rich-struct
