# thulpar

> 标签: Python

## 简介

Thulpar client for Python: the check API 0.3.x, sentence-level stream guard, decisions applied to text, hold and resume, trajectories, canaries and counters; FastAPI, OpenAI, NeMo Guardrails, Guardrails AI and LangChain integrations as extras
