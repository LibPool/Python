# fast-ccsds-parser

> 标签: Python

## 简介

Fast, dependency-free parsing of CCSDS Space Packets (CCSDS 133.0-B): primary headers, payload extraction, streaming file parsing, and columnar export to Arrow, Polars, pandas, and Parquet.
