# mfatsftp

> 标签: Python

## 简介

Pure-Python SFTP client that speaks through your system OpenSSH (no crypto to maintain).

## 官网

- 官网：https://github.com/mfat/mfatsftp
- PyPI 项目页：https://pypi.org/project/mfatsftp/

- 下载页面：https://pypi.org/project/mfatsftp/#files
