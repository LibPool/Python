# tungsten-backups

> 标签: Python

## 简介

Backups plugin for Tungsten: back up your database and uploaded files from the panel and download the zip.

## 官网

- 官网：https://tungsten.prisminfoways.com/plugins/backups
- 源码仓库：https://github.com/Prism-Infoways/Tungsten
- PyPI 项目页：https://pypi.org/project/tungsten-backups/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install tungsten-backups`
- 下载页面：https://pypi.org/project/tungsten-backups/#files
- 运行要求：Python >=3.10
