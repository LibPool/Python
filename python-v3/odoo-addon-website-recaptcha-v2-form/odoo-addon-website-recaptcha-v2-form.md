# odoo-addon-website-recaptcha-v2-form

> 标签: Python

## 简介

Module that allows you to use recaptcha v2 for login, password reset, signup and snippet form on the website.

## 官网

- 官网：https://github.com/OCA/website
- PyPI 项目页：https://pypi.org/project/odoo-addon-website-recaptcha-v2-form/
