# dspyui-gradio

> 标签: Python

## 简介

A Gradio user interface for DSPy: define a signature, add data, optimize the prompt and test it, without writing code.

## 官网

- 官网：https://github.com/hammer-mt/DSPyUI
- PyPI 项目页：https://pypi.org/project/dspyui-gradio/

- 下载页面：https://pypi.org/project/dspyui-gradio/#files
