# forjio-malapos

> 标签: Python

## 简介

Malapos SDK — typed Python client for the malapos.com point-of-sale REST API: every route of the API as client.api.<area>_<action>(). Sister to the JS + Go SDKs.

## 官网

- 源码仓库：https://github.com/hachimi-cat/saas-malapos
