# ecommerce-package

> 标签: Python

## 简介

Ecommerce site package for the Core boilerplate: catalog with filtering, cart, checkout/orders with PDF invoices, wallet, a pluggable payment gateway (mock by default), a support-ticket system, and client/seller/super-admin panels. Single-store or multi-vendor marketplace, switchable via ECOMMERCE_MULTI_VENDOR — same codebase either way. Depends on core-package for auth (including OTP login), RBAC, and the shared User model — it does not define its own.
