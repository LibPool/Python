# baremacgui

> 标签: Python

## 简介

BareMacGUI: a thin Python layer for native macOS GUIs on AppKit via PyObjC.

## 官网

- 官网：https://github.com/bastian-fluegel/baremacgui
- PyPI 项目页：https://pypi.org/project/baremacgui/
