# anumana-mcp

> 标签: Python

## 简介

Catch the costly query your AI agent just wrote — before it runs. An MCP server that predicts query cost, explains how it runs, and rewrites it, grounded in your real schema via EXPLAIN (never ANALYZE), across 12 database engines: Postgres, MySQL, SQLite, pgvector, MongoDB, DynamoDB, Cassandra, FalkorDB, Redshift, BigQuery, Snowflake, ClickHouse.
