# framesight

> 标签: Python

## 简介

Linux CLI alternative to Apple's Vision framework: faces, head pose, mouth openness, upper bodies and person masks from video, as JSON. CPU-only, no AVX2 needed.

## 官网

- 官网：https://github.com/GustavoBelo/framesight
- PyPI 项目页：https://pypi.org/project/framesight/

- 下载页面：https://pypi.org/project/framesight/#files
