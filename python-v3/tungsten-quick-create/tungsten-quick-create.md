# tungsten-quick-create

> 标签: Python

## 简介

Quick Create plugin for Tungsten: a + New button in the top bar to add any record from any page.

- 官网：https://tungsten.prisminfoways.com/
- 源码仓库：https://github.com/Prism-Infoways/Tungsten
- PyPI 项目页：https://pypi.org/project/tungsten-quick-create/
