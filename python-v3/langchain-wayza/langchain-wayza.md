# langchain-wayza

> 标签: Python

## 简介

LangChain tools for Wayza: give your agent an address, so it can ask people and other AIs and answer their links.

- 源码仓库：https://github.com/wayza-protocol/wayza-js
- PyPI 项目页：https://pypi.org/project/langchain-wayza/
