# aio2b2t

> 标签: Python

## 简介

aio2b2t is a modern, async, API wrapper for https://2b2t.dev and https://2b2t.io.

## 官网

- 官网：https://github.com/DontTreadOnGerman/aio2b2t
- PyPI 项目页：https://pypi.org/project/aio2b2t/

- pip 安装：`pip install aio2b2t`
- 下载页面：https://pypi.org/project/aio2b2t/#files
- 运行要求：Python >=3.6
