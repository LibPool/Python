# hugegraph-mcp

> 标签: Python

## 简介

FastMCP server that exposes HugeGraph schema & Gremlin tools over MCP/STDIO

## 官网

- 官网：https://hugegraph.apache.org/
- 源码仓库：https://github.com/apache/hugegraph-ai
- PyPI 项目页：https://pypi.org/project/hugegraph-mcp/

- pip 安装：`pip install hugegraph-mcp`
- 下载页面：https://pypi.org/project/hugegraph-mcp/#files
- 运行要求：Python >=3.10
