# vfvfa

> 标签: Python

## 简介

VFA (VulpFin Archive): archiver with a deterministic integer-only codec (vulp-lz), dedup and encryption

## 官网

- 官网：https://github.com/VulpFin/VFA
- PyPI 项目页：https://pypi.org/project/vfvfa/
