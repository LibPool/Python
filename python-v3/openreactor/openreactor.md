# openreactor

> 标签: Python

## 简介

Supervise benchtop lab reactors from a Raspberry Pi: temperature, mixing, dosing and water chemistry, with recorded runs.

## 官网

- 官网：https://github.com/uwo-fast/openreactor
- PyPI 项目页：https://pypi.org/project/openreactor/
