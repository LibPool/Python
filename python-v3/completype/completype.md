# completype

> 标签: Python

## 简介

Serverless autocompletion engine for Rust and Python: exact, prefix, infix, abbreviation, spelling-tolerant, word-decomposing and semantic completions from object storage

## 官网

- 官网：https://github.com/sayef/completype
- PyPI 项目页：https://pypi.org/project/completype/
