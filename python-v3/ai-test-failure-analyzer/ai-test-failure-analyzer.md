# ai-test-failure-analyzer

> 标签: Python

## 简介

Root cause in seconds. Evidence, not intuition. Analyzes 24 frameworks (Playwright, Jest, Cypress, pytest, Go, RSpec, and more) by tracing git history, logs, and config with a 10-phase pipeline. No guesses, no fixture noise.
