# swiss-moodle-mcp

> 标签: Python

## 简介

MCP server for the Moodle of Swiss universities (ZHAW, FHNW, ETH, EPFL, ...): courses, learning materials, downloads and sync via browser login (SWITCH edu-ID)

## 官网

- 官网：https://github.com/Dathis/swiss-moodle-mcp
- PyPI 项目页：https://pypi.org/project/swiss-moodle-mcp/

- 下载页面：https://pypi.org/project/swiss-moodle-mcp/#files
