# xnatbidscli

> 标签: Python

## 简介

CLI for logging into XNAT, downloading neuroimaging experiments, and converting them to BIDS.

## 官网

- 官网：https://github.com/nimh-dsst/xnat-bids-cli
- PyPI 项目页：https://pypi.org/project/xnatbidscli/

## 历史版本号

- 当前版本：2.0.0

- 2.0.0

## 获取地址

- pip 安装：`pip install xnatbidscli`
- 下载页面：https://pypi.org/project/xnatbidscli/#files
- 运行要求：Python >=3.11
