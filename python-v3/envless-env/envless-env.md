# envless-env

> 标签: Python

## 简介

The Envless runtime for Python. Load your encrypted environment when your app starts, decrypt it on the machine that runs it, and read it typed, with a server and client split.

## 官网

- 官网：https://envless.cloud
- PyPI 项目页：https://pypi.org/project/envless-env/
