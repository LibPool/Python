# meetwave-stream

> 标签: Python

## 简介

MeetWave streaming client: live English text over WebSocket, the full transcript at stop.

## 官网

- 官网：https://meetwave.io/docs/api/streaming-sdk
- PyPI 项目页：https://pypi.org/project/meetwave-stream/

- 下载页面：https://pypi.org/project/meetwave-stream/#files
