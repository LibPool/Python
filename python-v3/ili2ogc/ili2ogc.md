# ili2ogc

> 标签: Python

## 简介

A pure-Python INTERLIS 2 toolkit: build a live metamodel from .ili, validate .xtf transfers, and convert to/from JSON Schema, OGC JSON-FG, PostgreSQL/GeoPackage SQL, and CQL2-JSON filters, with multi-language (TRANSLATION OF) output
