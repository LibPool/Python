# pushizo

> 标签: email, notifications, push, pushizo, sms, webhooks

## 简介

Pushizo sunucu SDK'sı: bildirim gönderme, kullanıcı/abonelik yönetimi, segment/şablon/kampanya ve webhook imza doğrulaması
