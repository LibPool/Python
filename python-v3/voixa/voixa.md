# voixa

> 标签: Python

## 简介

Python client for the Voixa AI speech API: text-to-speech, voice design from a description, voice cloning, podcasts, streaming and speech-to-text. Zero dependencies.

## 官网

- 官网：https://voixa.vovix.io
- 源码仓库：https://github.com/vovix-ai/voixa-ai/tree/main/packages/sdk-python
- PyPI 项目页：https://pypi.org/project/voixa/
