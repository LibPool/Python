# remote-pc-mcp

> 标签: Python

## 简介

Expose any PC's capabilities - shell, filesystem, background processes, system stats, screenshots, UI control, and file transfer - to any MCP client over streamable HTTP.

- 官网：https://github.com/raghibrm/remote-pc-mcp
