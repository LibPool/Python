# tdee-calculator

> 标签: Python

## 简介

Lightweight Python utility for TDEE, BMR (Mifflin-St Jeor, Harris-Benedict, Katch-McArdle) and macronutrient calculations.

## 官网

- 官网：https://freetdeecalculator.app
- 源码仓库：https://github.com/Free-TDEE-Calculator/tdee-calculator-js
- PyPI 项目页：https://pypi.org/project/tdee-calculator/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install tdee-calculator`
- 下载页面：https://pypi.org/project/tdee-calculator/#files
- 运行要求：Python >=3.8
