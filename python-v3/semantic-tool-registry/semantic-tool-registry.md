# semantic-tool-registry

> 标签: Python

## 简介

语义注册表基底 + 领域子类（工具域 / 文档域）：向量与全文双检索、R1/R2 精准锚定、录入去重、CRUD、领域存储扩展（指定数据库 / 指定表 / 扩展字段，初始化期定型，注册查询自动适配）
