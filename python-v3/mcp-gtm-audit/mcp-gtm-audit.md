# mcp-gtm-audit

> 标签: Python

## 简介

MCP server for Google Tag Manager: audit containers, validate GA4/Google Ads/Meta tracking, diff workspaces against versions, export importable container JSON and, in opt-in write mode, apply reviewed changes inside a workspace. Never publishes. For Claude, Cursor, Codex and any MCP client.
