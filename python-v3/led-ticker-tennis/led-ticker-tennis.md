# led-ticker-tennis

> 标签: Python

## 简介

Live tennis scores (ATP, WTA, Challenger, ITF) widget for led-ticker, fed by the Live Tennis API free tier.

## 官网

- 官网：https://docs.ledticker.dev
- 源码仓库：https://github.com/JamesAwesome/led-ticker-plugins
- PyPI 项目页：https://pypi.org/project/led-ticker-tennis/

- 下载页面：https://pypi.org/project/led-ticker-tennis/#files
- 运行要求：Python >=3.14
