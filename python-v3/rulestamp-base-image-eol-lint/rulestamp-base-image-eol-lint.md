# rulestamp-base-image-eol-lint

> 标签: Python

## 简介

Marks every base image in your Dockerfiles, compose files and CI workflows whose security patches have already stopped - or stop before 13 November 2026 - and prints the tag that replaces it. (bundled Node.js runtime)
