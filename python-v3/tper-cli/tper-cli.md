# tper-cli

> 标签: agents, bologna, bus, claude-code, cli, emilia-romagna, ferrara, hellobus, public-transport, tper

## 简介

An agent-friendly command-line interface for TPER public transport in Bologna and Ferrara: live buses, fares, zones, news and complaints (unofficial).
