# eval-judge-mcp

> 标签: Python

## 简介

Judges agent/RAG outputs (relevance, hallucination, accuracy, routing, prompt injection) using Laya instead of LLM-as-judge -- usable as an MCP server or as a plain Python library.

## 官网

- 官网：https://github.com/Ayanshefeek/eval_laya_mcp
- PyPI 项目页：https://pypi.org/project/eval-judge-mcp/
