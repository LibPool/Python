# adiresi

> 标签: Python

## 简介

Python client for the Adiresi API — Nigerian address resolution, NIPOST postcodes, geofencing and validation.

## 官网

- 官网：https://adiresi.com.ng
- PyPI 项目页：https://pypi.org/project/adiresi/
