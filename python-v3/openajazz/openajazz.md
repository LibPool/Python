# openajazz

> 标签: ajazz, ak820, hid, hidraw, keyboard, linux, macro, max, mechanical, plus, rgb, tui

## 简介

Unofficial control for AJAZZ keyboards (AK820 Max Plus so far): lighting, per-key RGB, remaps, macros, music sync. CLI, TUI and web.

## 官网

- 官网：https://github.com/shrey715/openajazz
- PyPI 项目页：https://pypi.org/project/openajazz/

- 下载页面：https://pypi.org/project/openajazz/#files
