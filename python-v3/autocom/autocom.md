# autocom

> 标签: Python

## 简介

一款用于自动化执行串口指令的命令行工具，支持多设备、多指令的串行和并行执行

## 官网

- 官网：https://github.com/iFishin/AutoCom
- PyPI 项目页：https://pypi.org/project/autocom/
