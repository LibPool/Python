# nz-supermarket-scraper

> 标签: Python

## 简介

CLI to scrape fresh produce and meat prices from PAK'nSAVE, New World and Woolworths NZ (Countdown) stores.

- PyPI 项目页：https://pypi.org/project/nz-supermarket-scraper/
