# waqt-core

> 标签: Python

## 简介

Independently distributable computation layer for Waqt (Maghrib-to-Maghrib civil time and Hijri calendar): astronomy, Hijri calendars, scheduling, institutional calendars.

## 官网

- 官网：https://github.com/waqt-project/waqt-api
- PyPI 项目页：https://pypi.org/project/waqt-core/

## 历史版本号

- 0.7.0

- pip 安装：`pip install waqt-core`
- 下载页面：https://pypi.org/project/waqt-core/#files
