# pulumi-codecapsules

> 标签: Python

## 简介

A Pulumi provider for Code Capsules platform resources: teams, spaces, and capsules (MySQL, Redis, storage, WordPress).

- 官网：https://www.codecapsules.io
- 源码仓库：https://github.com/codecapsules-io/pulumi-codecapsules
- PyPI 项目页：https://pypi.org/project/pulumi-codecapsules/
