# sweep-io

> 标签: Python

## 简介

File and dataset I/O for seismic full-waveform inversion: velocity models, SEG-Y, acquisition geometry, shot-gather datasets.

## 官网

- 官网：https://github.com/DeepWave-KAUST/sweep-io
- PyPI 项目页：https://pypi.org/project/sweep-io/

- 下载页面：https://pypi.org/project/sweep-io/#files
