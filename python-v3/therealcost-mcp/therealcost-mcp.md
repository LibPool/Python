# therealcost-mcp

> 标签: Python

## 简介

Free money calculators for AI agents, from The Real Cost (therealcost.nohumannearby.com): credit card payoff, debt consolidation, loan cost by term, crypto trading fees and emergency fund, each with the formula in words and a pre-filled calculator link. Education only.

- 源码仓库：https://github.com/NoBanks/therealcost-mcp
