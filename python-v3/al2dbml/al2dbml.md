# al2dbml

> 标签: Python

## 简介

Convert compiled Microsoft Dynamics 365 Business Central AL packages (.app) into DBML schemas.

## 官网

- 官网：https://github.com/panda-coop/al2dbml
- PyPI 项目页：https://pypi.org/project/al2dbml/
