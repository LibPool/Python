# ext2py

> 标签: Python

## 简介

Pure-Python, read-only ext2/ext3/ext4 filesystem reader and browsing shell, no root or kernel drivers needed

## 官网

- 官网：https://github.com/sciciliani/ext2py
- PyPI 项目页：https://pypi.org/project/ext2py/

- pip 安装：`pip install ext2py`
- 下载页面：https://pypi.org/project/ext2py/#files
- 运行要求：Python >=3.9
