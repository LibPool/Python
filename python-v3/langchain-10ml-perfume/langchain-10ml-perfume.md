# langchain-10ml-perfume

> 标签: Python

## 简介

LangChain tools for the free 10ML Perfume Finder: search perfumes, note pyramids, accords, similar scents, alternatives, notes and houses from the 10ML Fragrance Index. No API key.

## 官网

- 源码仓库：https://gitlab.com/10ml/perfume-finder-mcp
