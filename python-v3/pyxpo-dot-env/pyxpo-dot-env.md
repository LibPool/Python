# pyxpo-dot-env

> 标签: Python

## 简介

Environment variables for pyxpo apps: .env files per build mode, typed access, and a build-time guard that stops secrets from shipping inside the app.

## 官网

- 官网：https://github.com/pyxpo/pyxpo/tree/main/packages/env
- PyPI 项目页：https://pypi.org/project/pyxpo-dot-env/
