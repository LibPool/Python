# ktw-lint

> 标签: Python

## 简介

Name reservation for Keep the Why, the agent skill and repo-native convention that preserves the reasoning behind a codebase. Not a Python library - install the skill via your agent's skill tooling; the pip-installable linter is keep-the-why-lint.
