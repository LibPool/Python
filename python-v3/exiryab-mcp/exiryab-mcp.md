# exiryab-mcp

> 标签: Python

## 简介

Official read-only MCP server for ExirYab (exiryab.com): find Iranian doctors by name, city and specialty, with profile links, clinic phones, hours and map locations.

## 官网

- 官网：https://exiryab.com
- 源码仓库：https://github.com/sshnevis/exiryab-mcp
- PyPI 项目页：https://pypi.org/project/exiryab-mcp/
