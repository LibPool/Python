# postali-api

> 标签: Python

## 简介

Cliente oficial de la API gratuita de códigos postales de Postali (México, Colombia, España). Sin dependencias.

## 官网

- 官网：https://postali.app
- 源码仓库：https://github.com/gomflo/postali-py
- PyPI 项目页：https://pypi.org/project/postali-api/

- 下载页面：https://pypi.org/project/postali-api/#files
