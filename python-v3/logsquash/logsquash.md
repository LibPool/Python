# logsquash

> 标签: Python

## 简介

Collapse repeated log lines (ignoring timestamps, numbers, ids) into counted groups. Stdlib only.

## 官网

- 官网：https://github.com/rafal-one/logsquash
- PyPI 项目页：https://pypi.org/project/logsquash/
