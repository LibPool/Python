# femforge-workbench

> 标签: Python

## 简介

Interactive workbench for femforge: a trame React shell whose dock holds scene, figure and table panels over runs, artifacts, logs and lab data.

## 官网

- 官网：https://femforge.io
- 源码仓库：https://github.com/femforge-io/femforge
- PyPI 项目页：https://pypi.org/project/femforge-workbench/
