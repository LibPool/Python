# ezmd-mcp

> 标签: Python

## 简介

MCP server for ezmd: convert files, URLs and text to LLM-ready Markdown from any MCP client.

## 官网

- 官网：https://github.com/larpey/ezmd
- PyPI 项目页：https://pypi.org/project/ezmd-mcp/
