# ipjudge

> 标签: Python

## 简介

Check whether an IP is residential, datacenter or proxy, and whether ChatGPT / Claude / Gemini / Muse support its region.

## 官网

- 官网：https://ipjudge.org
- 源码仓库：https://github.com/ipjudge/ipjudge
- PyPI 项目页：https://pypi.org/project/ipjudge/
