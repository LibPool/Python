# adafruit-circuitpython-maptiles

> 标签: Python

## 简介

Download and display map tiles from XYZ tile servers such as Open Street Maps. Tiles are cached on SD card.

## 官网

- 官网：https://github.com/adafruit/Adafruit_CircuitPython_MapTiles
- PyPI 项目页：https://pypi.org/project/adafruit-circuitpython-maptiles/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install adafruit-circuitpython-maptiles`
- 下载页面：https://pypi.org/project/adafruit-circuitpython-maptiles/#files
