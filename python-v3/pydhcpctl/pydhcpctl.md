# pydhcpctl

> 标签: Python

## 简介

One interface to DHCP servers: arm a reservation on dnsmasq, Kea, ISC dhcpd or Windows DHCP, then remove or keep it.

## 官网

- 官网：https://github.com/jose-pr/dhcpctl/
- PyPI 项目页：https://pypi.org/project/pydhcpctl/
