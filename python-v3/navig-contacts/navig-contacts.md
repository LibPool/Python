# navig-contacts

> 标签: Python

## 简介

NAVIG Contacts module — `navig contacts`: the address book and the alias-to-route table dispatch resolves against, in one store. Imports vCard and Telegram exports, merges the same person out of many records, and keeps only contacts with a phone number that validates.
