# finzdata-mcp

> 标签: Python

## 简介

FinzData MCP server: US market data (prices, intraday, COT, macro, short interest, 13F) inside AI assistants. Free tier: last 12 months.

## 官网

- 官网：https://finzdata.com
- 源码仓库：https://github.com/FinzData/finzdata-mcp
- PyPI 项目页：https://pypi.org/project/finzdata-mcp/
