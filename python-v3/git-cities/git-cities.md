# git-cities

> 标签: Python

## 简介

Turn a git repository's history into an animated 3D neon city, live in the browser or exported to 4K video.

## 官网

- 官网：https://github.com/elwoodradley/git-cities
- PyPI 项目页：https://pypi.org/project/git-cities/
