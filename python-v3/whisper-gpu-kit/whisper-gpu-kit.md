# whisper-gpu-kit

> 标签: Python

## 简介

GPU (faster-whisper) transcription primitives: cuDNN/cuBLAS preload, lazy model cache, GPU-OOM detection with CPU fallback, plus VTT/SRT caption parsing

## 官网

- 官网：https://github.com/octrow/whisper-gpu
- PyPI 项目页：https://pypi.org/project/whisper-gpu-kit/
