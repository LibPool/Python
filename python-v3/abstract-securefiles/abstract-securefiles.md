# abstract-securefiles

> 标签: Python

## 简介

Secure Files: share local files and folders through abstractendeavors.com (or your own server) without uploading them. Includes the desktop agent, the shared tar/resume core and the server relay.

## 官网

- 官网：https://abstractendeavors.com/secure-files
- PyPI 项目页：https://pypi.org/project/abstract-securefiles/
