# synqtune-mcp

> 标签: aws, claude-code, fine-tuning, llm, mcp, model-context-protocol, small-language-models

## 简介

MCP server for SynqTune: check runs and comparison reports, estimate costs and launch fine-tuning pipelines in your own AWS account from your coding agent.
