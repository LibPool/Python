# kk-codeimg

> 标签: Python

## 简介

把代码渲染成精美的代码图片：12 套主题、16 种预设风格，支持窗口标题与中英文混排，纯 Pillow + Pygments 离线渲染

## 官网

- 官网：https://github.com/kapikkkk/kk_codeimg
- PyPI 项目页：https://pypi.org/project/kk-codeimg/

## 历史版本号

- 当前版本：0.0.1

- 0.0.1

## 获取地址

- pip 安装：`pip install kk-codeimg`
- 下载页面：https://pypi.org/project/kk-codeimg/#files
- 运行要求：Python >=3.8
