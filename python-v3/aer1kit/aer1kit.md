# aer1kit

> 标签: Python

## 简介

AER-1 conformance kit: mint and verify verifiable execution receipts for AI agents. Implements IETF Internet-Draft draft-zambo-aer1-24. Kit 1.5.6, 119 test vectors, offline verification, no dependencies.
