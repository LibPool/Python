# crfix

> 标签: Python

## 简介

Correctly rounded fixed-point functions on NumPy integer arrays: exp, exp2, log, log2, sigmoid, tanh, sqrt, rsqrt, reciprocal and division in four rounding modes, int8 kernels' lookup tables, TFLite's affine formats and softmax; integer arithmetic only; on crnumerics' libcrfix
