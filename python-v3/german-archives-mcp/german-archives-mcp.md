# german-archives-mcp

> 标签: Python

## 简介

MCP server for German archives: search the finding aids and digitised objects of the Deutsche Digitale Bibliothek and Archivportal-D, find the online civil and church registers of Baden, Württemberg, Hohenzollern, North Rhine-Westphalia, Rhineland-Palatinate and Hesse at their state archives, and download their page images. For genealogy and history.
