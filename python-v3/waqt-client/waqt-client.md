# waqt-client

> 标签: Python

## 简介

Official thin Python SDK for the Waqt API (Maghrib-to-Maghrib civil time and Hijri calendar).

## 官网

- 官网：https://github.com/waqt-project/waqt-api
- PyPI 项目页：https://pypi.org/project/waqt-client/

## 历史版本号

- 当前版本：0.3.1

- 0.3.1

## 获取地址

- pip 安装：`pip install waqt-client`
- 下载页面：https://pypi.org/project/waqt-client/#files
- 运行要求：Python >=3.9
