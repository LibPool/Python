# gaeb

> 标签: Python

## 简介

Python library for reading, writing, converting and diffing GAEB files (AVA data exchange format, DA XML 2.0–3.3, GAEB 90, GAEB 2000)

## 官网

- 官网：https://github.com/Attackwave/gaeb-python
- PyPI 项目页：https://pypi.org/project/gaeb/
