# singularis-mcp

> 标签: Python

## 简介

Singularis is unlimited computation. Bring us your hardest problems. Free tryout, credits up front; sharing results is requested, not required. Free keys run hosted (nothing to install). Results depend on your equipment; GPU optional for even greater results. MCP server for AI agents; client shell only, no engine code.
