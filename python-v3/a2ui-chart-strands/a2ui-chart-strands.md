# a2ui-chart-strands

> 标签: Python

## 简介

Agent-side A2UI chart producer for @haystackedai/a2ui-chart-react clients. Keep your agent (bedrock/agentcore/strands and your own biz logic untouched); add a few lines where you already have the answer data and get a validated, drillable A2UI chart surface. Contract (catalogId + schemas) is baked, overridable.
