# lineartization

> 标签: Python

## 简介

Convert color illustrations and posters into clean black-and-white line art.

## 官网

- 官网：https://git.dvscloud.net/dvs/lineartization
- PyPI 项目页：https://pypi.org/project/lineartization/

## 历史版本号

- 当前版本：1.7.0

- 1.7.0

## 获取地址

- pip 安装：`pip install lineartization`
- 下载页面：https://pypi.org/project/lineartization/#files
- 运行要求：Python >=3.8
