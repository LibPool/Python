# tryaii-minilm-int8

> 标签: Python

## 简介

The embedding model of the tryaii SDK: all-MiniLM-L6-v2 as an int8 ONNX file (no PyTorch).

## 官网

- 官网：https://github.com/Tryaii-Admin/tryaii
- PyPI 项目页：https://pypi.org/project/tryaii-minilm-int8/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install tryaii-minilm-int8`
- 下载页面：https://pypi.org/project/tryaii-minilm-int8/#files
- 运行要求：Python >=3.9
