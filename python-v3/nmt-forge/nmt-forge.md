# nmt-forge

> 标签: Python

## 简介

Model training on the Champollion rails: an NMT training suite that makes catalogued training/eval mistakes structurally hard — group-disjoint splits, dev fencing, leak audits, CIs by default, preregistration — from a CPU-sized first model to an exported, servable one.
