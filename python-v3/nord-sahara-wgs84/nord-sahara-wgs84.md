# nord-sahara-wgs84

> 标签: Python

## 简介

Nord Sahara 1959 <-> WGS 84 datum transformations (EPSG Helmert sets) and UTM zones 29-32N, as a small library and CLI.

- 官网：https://github.com/AbdeldjalilChougui/nord-sahara-wgs84
- PyPI 项目页：https://pypi.org/project/nord-sahara-wgs84/
