# avaril-cli

> 标签: Python

## 简介

Command-line tool that checks your codebase against privacy constraints, verifies enforcement of your processing activities and reports results to Avaril.

## 官网

- 官网：https://avaril.net
- PyPI 项目页：https://pypi.org/project/avaril-cli/

## 历史版本号

- 0.1.0

- 下载页面：https://pypi.org/project/avaril-cli/#files
- 运行要求：Python >=3.10
