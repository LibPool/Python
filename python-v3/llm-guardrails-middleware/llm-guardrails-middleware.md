# llm-guardrails-middleware

> 标签: Python

## 简介

Drop-in guardrails wrapper for LLM API calls: PII redaction, prompt-injection detection, output schema validation, and usage/latency logging.

## 官网

- 官网：https://github.com/tonasoft/llm-guardrails
- PyPI 项目页：https://pypi.org/project/llm-guardrails-middleware/
