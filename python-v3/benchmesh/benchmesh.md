# benchmesh

> 标签: automation, benchmesh, instruments, lab, multimeter, power-supply, scpi, test-equipment

## 简介

Python client for BenchMesh: control and record lab instruments (power supplies, meters, loads, generators, scopes) from scripts and notebooks

- 官网：https://benchmesh.online
- 源码仓库：https://github.com/BenchMesh/benchmesh-python
- PyPI 项目页：https://pypi.org/project/benchmesh/
