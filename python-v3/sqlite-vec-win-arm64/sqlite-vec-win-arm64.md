# sqlite-vec-win-arm64

> 标签: Python

## 简介

sqlite-vec vector search extension for Python on Windows ARM64 (win_arm64). The `sqlite-vec` distribution only publishes a win_amd64 wheel, which cannot be installed on Windows on ARM.

## 官网

- 官网：https://pypi.org/project/sqlite-vec-win-arm64/
- 源码仓库：https://github.com/peerf-eco/sqlite-vec
- PyPI 项目页：https://pypi.org/project/sqlite-vec-win-arm64/
