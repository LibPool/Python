# citysmith

> 标签: Python

## 简介

Command line toolkit for CityGML 2.0 buildings: derive lower LODs, complete semantics, validate, crop, merge and convert to CityJSON.

## 官网

- 官网：https://github.com/banecronotse/CitySmith
- PyPI 项目页：https://pypi.org/project/citysmith/
