# capguru-mcp

> 标签: Python

## 简介

MCP server for the Cap.Guru captcha solving service: lets AI assistants open pages and solve reCAPTCHA v2/v3, Cloudflare Turnstile, text captchas, hCaptcha, GeeTest, FunCaptcha, TikTok, AWS WAF and Yandex SmartCaptcha

## 官网

- 官网：https://cap.guru
- PyPI 项目页：https://pypi.org/project/capguru-mcp/
