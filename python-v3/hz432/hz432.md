# hz432

> 标签: 432hz, audio, mp3, music, pitch-shift, tuning

## 简介

Convert MP3 files (single file or whole folder trees) to A4 = 432 Hz tuning, measuring the original tuning first.

## 官网

- 官网：https://pypi.org/project/hz432/
- PyPI 项目页：https://pypi.org/project/hz432/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install hz432`
- 下载页面：https://pypi.org/project/hz432/#files
- 运行要求：Python >=3.10
