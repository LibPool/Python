# hyisp-util

> 标签: Python

## 简介

Firmware flasher for the Heng Yu (HYISP) USB HID bootloader, as used by the Metadot Das Keyboard 4 (Professional, Ultimate, Professional for Mac)

## 官网

- 官网：https://github.com/giannello/hyisp-util
- PyPI 项目页：https://pypi.org/project/hyisp-util/
