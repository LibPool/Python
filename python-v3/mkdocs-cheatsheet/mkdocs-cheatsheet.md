# mkdocs-cheatsheet

> 标签: Python

## 简介

Material for MkDocs plugin: builds a linked cheatsheet card grid from flagged headings across your site.

## 官网

- 官网：https://github.com/luka-sherman/mkdocs-cheatsheet
- PyPI 项目页：https://pypi.org/project/mkdocs-cheatsheet/

- 下载页面：https://pypi.org/project/mkdocs-cheatsheet/#files
