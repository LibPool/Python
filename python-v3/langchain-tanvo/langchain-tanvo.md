# langchain-tanvo

> 标签: Python

## 简介

LangChain tools for Tanvo: let agents generate images, video and songs on Nano Banana, Seedream, Kling, Veo, Seedance and Suno, and run 80 ready-made photo apps. The house image engine works without an API key.
