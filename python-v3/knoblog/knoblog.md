# knoblog

> 标签: Python

## 简介

Plain-English changelogs, feeds and X-ready post text for parameter, gain, threshold, flag and config changes in any git repo.

## 官网

- 官网：https://github.com/fitzyracing1/knoblog
- PyPI 项目页：https://pypi.org/project/knoblog/
