# lightgbm-takt

> 标签: Python

## 简介

LightGBM 4.7.0 with faster repeated-call analyses (permutation importance, PDP/ICE, MDA, what-if) on models up to 300 trees; output identical to the official wheel bit for bit

## 官网

- 官网：https://taktcycles.com
- PyPI 项目页：https://pypi.org/project/lightgbm-takt/
