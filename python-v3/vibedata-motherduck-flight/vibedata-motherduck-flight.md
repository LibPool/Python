# vibedata-motherduck-flight

> 标签: Python

## 简介

VibeData run-time delivery for a MotherDuck Flight: check the Domain repository out at a given ref, authenticated by the Flight's own secret, and hand the project directory back. The Flight program names the load; this gets the code to it.
