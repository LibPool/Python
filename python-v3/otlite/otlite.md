# otlite

> 标签: cli, installer, otinstaller, package-manager, tools

## 简介

Install, run and update command line tools by name, without Docker. The lightweight edition of OTInstaller.

## 官网

- 官网：https://otinstaller.com
- 源码仓库：https://github.com/OTInstaller/otinstaller/tree/main/otlite
- PyPI 项目页：https://pypi.org/project/otlite/
