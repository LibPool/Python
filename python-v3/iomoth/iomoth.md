# iomoth

> 标签: Python

## 简介

Check whether your computer is ready for iomoth, verify a download against its published SHA-256, and find the official places to get iomoth. No network, no writes.

## 官网

- 官网：https://iomoth.ai
- PyPI 项目页：https://pypi.org/project/iomoth/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install iomoth`
- 下载页面：https://pypi.org/project/iomoth/#files
- 运行要求：Python >=3.9
