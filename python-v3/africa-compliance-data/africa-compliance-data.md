# africa-compliance-data

> 标签: Python

## 简介

Client library for the Africa Compliance Data API: public holidays, business days, holiday watch, VAT and VAT rate history, withholding tax and tax-treaty rates, tax ID formats, filing deadlines, finance-law digests and change webhooks for 54 African countries, each value with its source. MIT covers this client code only; API data is governed by the Terms of Service. Not legal or tax advice.
