# tanzania-postcodes

> 标签: Python

## 简介

Real Tanzania postal codes, sourced directly from TCRA's official gazetted National Postcode System -- not a third-party compilation.

## 官网

- 官网：https://github.com/nyandajr/tanzania-postcodes
- 源码仓库：https://www.tcra.go.tz/services/publication-of-postcode-list
- PyPI 项目页：https://pypi.org/project/tanzania-postcodes/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install tanzania-postcodes`
- 下载页面：https://pypi.org/project/tanzania-postcodes/#files
- 运行要求：Python >=3.9
