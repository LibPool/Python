# cyberonto

> 标签: Python

## 简介

A small, dependency-free toolkit for security data: IOC extraction/classification/defanging and an offline model of the open security frameworks (ATT&CK, D3FEND, kill chain, Diamond, Pyramid of Pain, STIX, NIST CSF) with cross-mappings.
