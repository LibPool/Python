# hanzo-kai

> 标签: Python

## 简介

Python client for Kai decisions on the Hanzo API: typed answers to choice, yes/no and score questions.

## 官网

- 官网：https://hanzo.ai
- 源码仓库：https://github.com/hanzoai/python-sdk
- PyPI 项目页：https://pypi.org/project/hanzo-kai/
