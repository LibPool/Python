# hasdata-chatgpt-mcp

> 标签: Python

## 简介

MCP server for the ChatGPT Scraper API through HasData's hosted API. No OpenAI account.

## 官网

- 官网：https://hasdata.com/apis/chatgpt-api
- 源码仓库：https://github.com/HasData/chatgpt-mcp
- PyPI 项目页：https://pypi.org/project/hasdata-chatgpt-mcp/

## 历史版本号

- 1.0.0

## 获取地址

- pip 安装：`pip install hasdata-chatgpt-mcp`
- 下载页面：https://pypi.org/project/hasdata-chatgpt-mcp/#files
- 运行要求：Python >=3.10
