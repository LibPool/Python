# ani-scrapy

> 标签: Python

## 简介

Async-first Python library for scraping anime websites. Supports some anime websites with unified interface, detailed metadata, and download links from multiple servers.

## 官网

- 官网：https://github.com/ElPitagoras14/ani-scrapy
