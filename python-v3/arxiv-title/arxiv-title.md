# arxiv-title

> 标签: Python

## 简介

Rename arXiv PDFs from opaque IDs to descriptive, title-based filenames

## 官网

- 官网：https://github.com/cms-pm/arxiv-title
- PyPI 项目页：https://pypi.org/project/arxiv-title/

- 下载页面：https://pypi.org/project/arxiv-title/#files
- 运行要求：Python >=3.10
