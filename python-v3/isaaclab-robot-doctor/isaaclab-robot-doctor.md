# isaaclab-robot-doctor

> 标签: Python

## 简介

Sanity-check a URDF/USD robot for NVIDIA Isaac Lab and generate a starting ArticulationCfg. No GPU, no Isaac Sim.

- 官网：https://github.com/Lynn-hh/isaaclab-robot-doctor
