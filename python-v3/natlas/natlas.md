# natlas

> 标签: Python

## 简介

Python SDK for N-ATLaS, Nigeria's sovereign multilingual LLM (Hausa, Igbo, Yoruba, Nigerian English) and its ASR models.

## 官网

- 官网：https://natlas-docs.vercel.app
- 源码仓库：https://github.com/Kambah123/N-ATLAS-Kit
- PyPI 项目页：https://pypi.org/project/natlas/
