# pypando

> 标签: Python

## 简介

Pure-Python Pando — gene regulatory network inference from paired single-cell RNA + ATAC (regions, motifs, per-gene TF x binding-site models, modules), AnnData-native, parity-tested against R.

## 官网

- 官网：https://github.com/omicverse/py-Pando
