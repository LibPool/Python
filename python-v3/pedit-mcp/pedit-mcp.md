# pedit-mcp

> 标签: Python

## 简介

Open-source AI image editor and MCP server: layers, masks, generative fill, image-to-image, background removal. A Photoshop/GIMP alternative an AI agent can drive, local or with your OpenAI, Gemini or Stability API key.

## 官网

- 官网：https://github.com/metiutek/editorimage-ai
- PyPI 项目页：https://pypi.org/project/pedit-mcp/
