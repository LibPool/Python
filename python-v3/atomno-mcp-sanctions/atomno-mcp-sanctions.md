# atomno-mcp-sanctions

> 标签: Python

## 简介

MCP server: sanctions and watchlist screening for persons and entities — Rosfinmonitoring, OFAC SDN, EU, UK OFSI, UN lists. Neutral match results with confidence levels; advisory KYC/AML compliance tool.
