# lunasrim

> 标签: Python

## 简介

Pure Python 3 re-implementation of SRIM-2013: TRIM Monte Carlo and stopping/range tables, reproduced digit for digit

## 官网

- 官网：https://github.com/skowrons94/LunaSRIM
- PyPI 项目页：https://pypi.org/project/lunasrim/

- 1.0.0

- 下载页面：https://pypi.org/project/lunasrim/#files
