# samplab-url-tools

> 标签: Python

## 简介

Offline URL builder for SampLab Pro, a browser audio and MIDI tool suite. Not an official SDK.

## 官网

- 官网：https://samplab.pro/
- 源码仓库：https://github.com/bbwdadfg/samplab-url-tools
- PyPI 项目页：https://pypi.org/project/samplab-url-tools/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install samplab-url-tools`
- 下载页面：https://pypi.org/project/samplab-url-tools/#files
- 运行要求：Python >=3.9
