# model2data-studio

> 标签: Python

## 简介

Generate a model2data studio project's data from the command line, so CI can rebuild fixtures instead of committing them.

## 官网

- 官网：https://www.jbanalytica.com/model2data/
- PyPI 项目页：https://pypi.org/project/model2data-studio/

## 获取地址

- pip 安装：`pip install model2data-studio`
- 下载页面：https://pypi.org/project/model2data-studio/#files
- 运行要求：Python >=3.10
