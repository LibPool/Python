# arabic-itn

> 标签: Python

## 简介

Turn spoken-form Arabic ASR transcripts into exact values: phones, money, dates, times, emails, order IDs.

## 官网

- 官网：https://github.com/sohaibt/arabic-itn
- PyPI 项目页：https://pypi.org/project/arabic-itn/

- 下载页面：https://pypi.org/project/arabic-itn/#files
- 运行要求：Python >=3.8
