# getyoutubetranscript

> 标签: Python

## 简介

YouTube transcript API for Python: get YouTube video transcripts, captions and subtitles with timestamps, search YouTube, and list channel and playlist videos. No proxies or headless browser.

## 官网

- 官网：https://getyoutubetranscript.com
- 源码仓库：https://github.com/tubeagentkit/youtube-transcript-api-python
