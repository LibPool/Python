# coursesitetolectures

> 标签: Python

## 简介

Turn a folder of course materials (lecture notes, slides, example code) into lecture transcripts and narrated audio

## 官网

- 官网：https://github.com/ExNumberless/CourseSiteToLectures
- PyPI 项目页：https://pypi.org/project/coursesitetolectures/

- 0.1.0

- pip 安装：`pip install coursesitetolectures`
- 下载页面：https://pypi.org/project/coursesitetolectures/#files
- 运行要求：Python >=3.11
