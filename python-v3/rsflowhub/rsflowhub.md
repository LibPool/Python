# rsflowhub

> 标签: Python

## 简介

Official Python SDK for the RSFlowHub AI API: sentiment analysis, translation, chat, PII redaction, review and ticket AI, knowledge bases (RAG) and chatbots. Sync and async. New APIs work without an SDK update.

## 官网

- 官网：https://rsflowhub.com
- 源码仓库：https://github.com/RSFlowHub/rsflowhub-python
- PyPI 项目页：https://pypi.org/project/rsflowhub/
