# lybase-ex

> 标签: Python

## 简介

按组织分库（org sharding）的 Django 公共库：org_router app（分库路由、org 上下文、公共数据同步、组织感知事务与分库组织创建任务）+ model_ext app（动态扩展字段配置与 provider 注册挂载）。
