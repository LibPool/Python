# razladka

> 标签: Python

## 简介

Generate synthetic time series with a given number of change points (Markov regime switching, Weierstrass–Mandelbrot roughness) with ground-truth labels, saved to CSV, Parquet, HDF5, NetCDF, Trosna and more
