# rphonenumbers

> 标签: Python

## 简介

Drop-in replacement for phonenumbers that runs parsing, formatting and validation on the rlibphonenumber Rust crate

## 官网

- 官网：https://github.com/thevilledev/python-rlibphonenumber
- PyPI 项目页：https://pypi.org/project/rphonenumbers/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install rphonenumbers`
- 下载页面：https://pypi.org/project/rphonenumbers/#files
- 运行要求：Python >=3.10
