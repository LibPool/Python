# readiness-kit

> 标签: ai-agents, cyclonedx, evaluation, llm, mcp, owasp, readiness, sbom, security

## 简介

The open-source frame under the Agent Readiness Gate: an evaluation harness with a held-out split, a starter attack pack mapped to OWASP ASI01-ASI10, adapters for the open agent scanners, an eight-area readiness scorecard, a CycloneDX Agent BOM emitter and a cost-per-task baseline.
