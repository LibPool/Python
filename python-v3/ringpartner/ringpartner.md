# ringpartner

> 标签: Python

## 简介

Unofficial Python SDK for the Ring Partner API (Amazon Vision): typed REST client, WHEP live video, webhook verification, signed webhook simulator and fixture replay.

- 官网：https://github.com/HaDeZIB/ringpartner
