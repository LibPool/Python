# xrdhttp

> 标签: Python

## 简介

The HTTP pieces shared by xrdclient, xgfalclient and xrdarc: a pooled HTTP session, connections, WebDAV, byte ranges, WLCG Tape REST, HTTP third-party copy, Metalink, S3 SigV4 and a fake storage element for tests
