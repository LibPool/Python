# agent-skills-library

> 标签: Python

## 简介

100 curated bilingual (EN+RU) skills in the universal Agent Skills format for Claude Code, OpenCode, Cursor, Windsurf and every LLM/GLM agent. Python SDK + CLI with CI-enforced validation and quality scoring.
