# wiktionary-de-mcp

> 标签: Python

## 简介

MCP server for the German Wiktionary (de.wiktionary.org): check if words exist, look up grammar, meanings and conjugations.

## 官网

- 官网：https://github.com/joelbarmettlerUZH/wiktionary-mcp
- PyPI 项目页：https://pypi.org/project/wiktionary-de-mcp/

- 下载页面：https://pypi.org/project/wiktionary-de-mcp/#files
- 运行要求：Python >=3.10
