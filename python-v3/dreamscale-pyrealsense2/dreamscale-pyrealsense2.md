# dreamscale-pyrealsense2

> 标签: Python

## 简介

pyrealsense2 for Linux aarch64 (Jetson), built from unmodified librealsense with its RSUSB backend.

## 官网

- 官网：https://app.dreamscalelabs.com
- 源码仓库：https://github.com/IntelRealSense/librealsense
- PyPI 项目页：https://pypi.org/project/dreamscale-pyrealsense2/
