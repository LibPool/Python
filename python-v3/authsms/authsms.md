# authsms

> 标签: Python

## 简介

Official Python client for the AuthSMS API: virtual numbers, SMS verification codes, rentals and webhooks.

## 官网

- 官网：https://authsms.net
- 源码仓库：https://github.com/AuthSMS/authsms-sdk
- PyPI 项目页：https://pypi.org/project/authsms/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install authsms`
- 下载页面：https://pypi.org/project/authsms/#files
- 运行要求：Python >=3.8
