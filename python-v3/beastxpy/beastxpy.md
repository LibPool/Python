# beastxpy

> 标签: 1, BEAST, MCMC, divergence, phylogenetics, reproducibility, time

## 简介

A Python framework for reproducible BEAST 1 divergence-time estimation with automated model specification, validation and diagnostics (LGPL-2.1 applies only to the bundled BEAST jars)
