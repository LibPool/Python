# perfume-api

> 标签: Python

## 简介

Free perfume API client: perfumes, note pyramids, accords, similar scents, notes and houses from the 10ML Fragrance Index. No API key, JSON over HTTPS.

## 官网

- 官网：https://mcp.10ml.com
- PyPI 项目页：https://pypi.org/project/perfume-api/
