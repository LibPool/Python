# socials-homes

> 标签: Python

## 简介

Official Python SDK and CLI for the Socials Homes API: covered cities, plans and prices, and live rental listing counts per city and budget. Read-only, no API key.

## 官网

- 官网：https://www.socials.homes/developers
- 源码仓库：https://github.com/yosocials/socials-homes-python
- PyPI 项目页：https://pypi.org/project/socials-homes/
