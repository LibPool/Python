# py-tbparse

> 标签: Python

## 简介

Native Python port of the twbparser R package: parse Tableau .twb/.twbx workbooks into pandas DataFrames.

## 官网

- 官网：https://github.com/DDSNA/py-tbparse
- PyPI 项目页：https://pypi.org/project/py-tbparse/
