# navig-vm

> 标签: Python

## 简介

NAVIG VM module — local VMware Workstation VMs from verified cloud images, provisioned on first boot with cloud-init and driven from `navig vm` (create, start, ssh, snapshots). A first-party navig plugin (free, toggleable).
