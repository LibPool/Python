# groundwright

> 标签: Python

## 简介

A retrieval grounding gate: for a golden set, check that retrieval returns the expected source (provenance) and the anchor chunk, and that the run stays above a regression threshold. Not answer-quality eval — the step before it. Zero dependencies.
