# zotero-fulltext-mcp

> 标签: Python

## 简介

Convert a Zotero library's linked PDF attachments to Markdown, build a full-text search index, and expose it via an MCP server.

- 官网：https://github.com/matthiaskloft/zotero-fulltext-mcp
