# getyoutubetranscript-haystack

> 标签: Python

## 简介

YouTube transcript fetcher for Haystack pipelines and agents: get YouTube video transcripts (optionally with timestamps) as Documents, via the GetYouTubeTranscript API.

## 官网

- 官网：https://getyoutubetranscript.com
- 源码仓库：https://github.com/tubeagentkit/getyoutubetranscript-haystack
- PyPI 项目页：https://pypi.org/project/getyoutubetranscript-haystack/
