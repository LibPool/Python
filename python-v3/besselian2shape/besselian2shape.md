# besselian2shape

> 标签: Python

## 简介

Generate ESRI Shapefiles and Google Earth KML/KMZ files describing a solar eclipse's path from NASA Besselian elements

- 官网：https://github.com/rtphokie/besselian2shape
- PyPI 项目页：https://pypi.org/project/besselian2shape/
