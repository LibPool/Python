# airprompter-datastore-s3

> 标签: Python

## 简介

The AirPrompter release datastore over an S3 bucket: a KvStore with S3's own conditional writes (IfNoneMatch, IfMatch), for kv_release_datastore — the puller writes sealed releases, every runtime hydrates from them.
