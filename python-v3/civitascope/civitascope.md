# civitascope

> 标签: Python

## 简介

Verifiable, sourced infographics from Eurostat data. Meta-package: installs civitascope-data and civitascope-render. Early development.

## 官网

- 官网：https://civitascope.com
- 源码仓库：https://github.com/civitascope/civitascope-data
- PyPI 项目页：https://pypi.org/project/civitascope/
