# google-ads-mcp-write

> 标签: Python

## 简介

Self-hosted MCP server for Google Ads Search campaigns. Forks googleads/google-ads-mcp and adds a guardrailed write layer (validate -> diff -> confirm -> commit), shaped reporting tools, and a local undo journal.
