# ceps-api

> 标签: Python

## 简介

Unofficial Python client for the ČEPS (Czech TSO) data web service, returning pandas DataFrames.

## 官网

- 官网：https://github.com/Frantis3k/ceps-api
- PyPI 项目页：https://pypi.org/project/ceps-api/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

- pip 安装：`pip install ceps-api`
- 下载页面：https://pypi.org/project/ceps-api/#files
- 运行要求：Python >=3.10
