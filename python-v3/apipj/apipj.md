# apipj

> 标签: Python

## 简介

API CNPJ gratuita para Python: consultar CNPJ na Receita Federal, validar CNPJ e CNPJ alfanumérico. Razão social, situação, endereço, CNAE, sócios. Plano grátis com 50 mil consultas/mês.
