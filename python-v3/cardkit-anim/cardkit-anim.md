# cardkit-anim

> 标签: Python

## 简介

Write an animated scene once in Python and export it as GIF, WebP, MP4 and a looping, script-free animated SVG that look identical.

## 官网

- 官网：https://github.com/carloalbertobarbano/cardkit
- PyPI 项目页：https://pypi.org/project/cardkit-anim/
