# innards

> 标签: Python

## 简介

See inside open-weight models while they run: read-only hooks on the model you loaded, one analyzer per architectural feature (Gated DeltaNet, LatentMoE, mHC, CSA/HCA, MLA), KV and memory predicted vs measured, and a live web view on the same machine.
