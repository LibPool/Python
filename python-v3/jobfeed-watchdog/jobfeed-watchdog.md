# jobfeed-watchdog

> 标签: Python

## 简介

GitHub Action / CLI that detects silent job-feed (JSON API) breakage: schema drift, count collapse, and outages. Stdlib-only.

## 官网

- 官网：https://github.com/earnnova-dev/jobfeed-watchdog
- PyPI 项目页：https://pypi.org/project/jobfeed-watchdog/
