# babyseat

> 标签: Python

## 简介

babyseat (formerly membrane): a local-first seat for AI with a memory field (membrane) -- its own web UI (`babyseat`) or inside Home Assistant (HACS).

## 官网

- 官网：https://github.com/chedim/membrane
- PyPI 项目页：https://pypi.org/project/babyseat/
