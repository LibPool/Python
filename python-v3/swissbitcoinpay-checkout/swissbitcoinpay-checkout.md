# swissbitcoinpay-checkout

> 标签: Python

## 简介

Take Lightning and on-chain payments for a Swiss Bitcoin Pay merchant from an online shop's server: invoices, deposit addresses, registry declarations, payment checks.

## 官网

- 官网：https://github.com/SwissBitcoinPay/checkout-python
- PyPI 项目页：https://pypi.org/project/swissbitcoinpay-checkout/
