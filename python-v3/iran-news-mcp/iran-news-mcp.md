# iran-news-mcp

> 标签: Python

## 简介

Unofficial read-only MCP server for Persian news RSS feeds: Mehr, Khabaronline, Hamshahri, Tabnak, Entekhab, Asriran, Zoomit, Digiato, Varzesh3, Khabarvarzeshi.
