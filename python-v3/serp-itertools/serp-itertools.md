# serp-itertools

> 标签: Python

## 简介

Serpentine drop-in facade for CPython's itertools (lazy iterator classes: count/cycle/repeat/chain/islice/takewhile/...)

## 官网

- 官网：https://github.com/avijitbhuin21/Serpentine
- PyPI 项目页：https://pypi.org/project/serp-itertools/

## 历史版本号

- 当前版本：0.2.0

- 0.2.0

## 获取地址

- pip 安装：`pip install serp-itertools`
- 下载页面：https://pypi.org/project/serp-itertools/#files
- 运行要求：Python >=3.11
