# haven-client

> 标签: Python

## 简介

Python client for Haven, the Vault-compatible secret manager: KV, transit, PKI, database credentials, AppRole and Kubernetes login, with token renewal and safe retries.

## 官网

- 官网：https://haven.rodmena.co.uk
- PyPI 项目页：https://pypi.org/project/haven-client/
