# liquidvision

> 标签: Python

## 简介

Client for LiquidVision.app, exchange-exact crypto derivatives data for bots and AI agents: open interest, funding, liquidations, measured Hyperliquid and Lighter liquidation maps, cascades, tokenized stocks on DEXs, history exports and Parquet packages, x402 pay-per-call
