# livekit-plugins-readaloud

> 标签: Python

## 简介

ReadAloud text-to-speech plugin for LiveKit Agents (Piper voices, ~200 ms to first audio, 8 kHz telephony output)

## 官网

- 官网：https://readaloudai.org
- 源码仓库：https://github.com/tsushanth/livekit-plugins-readaloud
- PyPI 项目页：https://pypi.org/project/livekit-plugins-readaloud/
