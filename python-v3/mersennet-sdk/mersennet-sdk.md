# mersennet-sdk

> 标签: Python

## 简介

Python SDK for Mersennet: JSON-RPC, the on-chain order book (MersennetOrders precompile), shielded notes and viewing keys

## 官网

- 官网：https://mersennet.com
- 源码仓库：https://github.com/mersennet/sdk-python
- PyPI 项目页：https://pypi.org/project/mersennet-sdk/

## 历史版本号

- 当前版本：0.1.1

- 0.1.1

## 获取地址

- pip 安装：`pip install mersennet-sdk`
- 下载页面：https://pypi.org/project/mersennet-sdk/#files
- 运行要求：Python >=3.10
