# tungsten-filament

> 标签: Python

## 简介

Move a Laravel Filament admin to Tungsten: converts models, resources, forms, tables, filters, actions and relation managers, on the same database and logins.

- 官网：https://tungsten.prisminfoways.com/plugins/filament-migrate
- 源码仓库：https://github.com/Prism-Infoways/Tungsten
- PyPI 项目页：https://pypi.org/project/tungsten-filament/
