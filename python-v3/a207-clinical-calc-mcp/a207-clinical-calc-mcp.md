# a207-clinical-calc-mcp

> 标签: Python

## 简介

儿童 CKD 临床计算 MCP（M6）：eGFR-Schwartz 估算肾小球滤过率、KDIGO 儿童 CKD 分期（G/A 与合并分期）。医生独占（MX-1），只读计算，无跨包依赖。
