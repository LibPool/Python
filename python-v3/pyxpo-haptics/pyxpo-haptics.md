# pyxpo-haptics

> 标签: Python

## 简介

Haptic feedback for pyxpo apps: impact, notification and selection feedback (expo-haptics shape).

## 官网

- 官网：https://github.com/pyxpo/pyxpo/tree/main/packages/haptics
- PyPI 项目页：https://pypi.org/project/pyxpo-haptics/
