# karni

> 标签: Python

## 简介

Django + React framework that stays a versioned dependency, not a boilerplate: declare models and access, get the REST API, admin, permissions, tests and seed data. Built so AI coding agents (Claude Code, Cursor, Copilot) write only the domain code.
