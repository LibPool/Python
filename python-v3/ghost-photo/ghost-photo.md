# ghost-photo

> 标签: Python

## 简介

Local-first CLI to strip EXIF and add small pixel perturbations in an effort to improve visual privacy.

## 官网

- 官网：https://github.com/adurnos/ghost-image
- PyPI 项目页：https://pypi.org/project/ghost-photo/
