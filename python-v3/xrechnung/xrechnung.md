# xrechnung

> 标签: Python

## 简介

Python client for the xrechnung.dev API: generate, validate (official KoSIT rules) and parse XRechnung and ZUGFeRD e-invoices. Zero dependencies, no JVM required.

## 官网

- 官网：https://xrechnung.dev
