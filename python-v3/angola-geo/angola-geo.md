# angola-geo

> 标签: Python

## 简介

Biblioteca Python completa para divisões administrativas de Angola (províncias, municípios, comunas) de acordo com a Lei n.º 14/24

## 官网

- 官网：https://github.com/cornelioteixeira/angola_geo
- PyPI 项目页：https://pypi.org/project/angola-geo/

## 历史版本号

- 当前版本：0.2.0

- 0.2.0

## 获取地址

- pip 安装：`pip install angola-geo`
- 下载页面：https://pypi.org/project/angola-geo/#files
- 运行要求：Python >=3.8
