# segmetric-toolkit

> 标签: Python

## 简介

SegMetric: tools for segmenting, cropping, and measuring. Includes segmetric.tag (crop + name), segmetric.set (filename preset builder), segmetric.scale (ArUco scale + crop), and segmetric.prepare (combined tag+set+scale workflow).
