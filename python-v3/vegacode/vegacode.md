> 标签: AI, CLI, LLM, Ollama, Python, TUI, Textual, agent, agents, assistant, coding, developer, local, offline, open-source, open-weight, privacy, self-hosted, terminal, tools, vegacode

## 简介

Local coding agent that runs on your laptop: an offline AI coding assistant for the terminal, powered by open-weight LLMs through Ollama. Your code never leaves your machine. Vega writes, runs your tests in a sandbox and repairs what fails. Python CLI and TUI, built for small models (under 10B) on 16 GB.
