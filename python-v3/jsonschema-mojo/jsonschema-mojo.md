# jsonschema-mojo

> 标签: Python

## 简介

Drop-in faster replacement for the jsonschema package (draft 2020-12 subset), powered by a Mojo kernel (pure-Python fallback included).

## 官网

- 官网：https://pypi.org/project/jsonschema-mojo/
- 源码仓库：https://github.com/thyn-ai/mojo-kernels
