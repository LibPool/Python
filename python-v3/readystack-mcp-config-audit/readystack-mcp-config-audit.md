# readystack-mcp-config-audit

> 标签: Python

## 简介

Audit one mcp.json for what an agent config gives away — inline API keys, unpinned npx launches, plaintext remote servers, shell wrappers, auto-approved tools, whole-machine filesystem roots — with li (bundled Node.js runtime)
