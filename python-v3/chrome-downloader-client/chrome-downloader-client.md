# chrome-downloader-client

> 标签: Python

## 简介

让 Chrome 替你下载：本机 Bridge + 扩展搬运字节的零依赖客户端（Bridge/CLI/MCP 都不碰文件字节）

## 官网

- PyPI 项目页：https://pypi.org/project/chrome-downloader-client/

- 0.3.0

## 获取地址

- pip 安装：`pip install chrome-downloader-client`
- 下载页面：https://pypi.org/project/chrome-downloader-client/#files
- 运行要求：Python >=3.10
