# arduino-python3

> 标签: Python

## 简介

A light-weight Python library that provides a serial   bridge for communicating with Arduino microcontroller boards. Extended to work with Python 3

## 官网

- 官网：https://github.com/mkals/Arduino-Python3-Command-API
