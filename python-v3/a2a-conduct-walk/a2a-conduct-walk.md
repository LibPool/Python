# a2a-conduct-walk

> 标签: Python

## 简介

Witness walk for the A2A Conduct Extension v1: walk an agent from your own machine, file the observation under your name, get a sha256 that anyone can recompute. Standard library only. Also an MCP server (conduct-witness-mcp) so any agent can be a witness in one tool call.
