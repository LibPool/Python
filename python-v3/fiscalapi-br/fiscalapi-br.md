# fiscalapi-br

> 标签: Python

## 简介

SDK da FiscalAPI (Brasil): Inscrição Estadual, CNPJ, certidões, NF-e, SIGEF, CNIR e perfil do produtor rural.

## 官网

- 官网：https://fiscalapi.com.br
- 源码仓库：https://github.com/fiscaIapi/fiscalapi-python
- PyPI 项目页：https://pypi.org/project/fiscalapi-br/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install fiscalapi-br`
- 下载页面：https://pypi.org/project/fiscalapi-br/#files
- 运行要求：Python >=3.9
