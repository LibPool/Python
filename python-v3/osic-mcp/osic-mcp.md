# osic-mcp

> 标签: circuit-simulation, eda, ic-design, ltspice, mcp, model-context-protocol, ngspice, spice

## 简介

Alias for ltspice-mcp: an MCP server and Python library for open-source IC design work (SPICE simulation with ngspice and LTspice, schematic editing). Installs and runs ltspice-mcp.

## 官网

- 官网：https://github.com/cognitohazard/ltspice-mcp
- PyPI 项目页：https://pypi.org/project/osic-mcp/

- pip 安装：`pip install osic-mcp`
- 下载页面：https://pypi.org/project/osic-mcp/#files
- 运行要求：Python >=3.11
