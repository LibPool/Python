# pulumi-asyntai

> 标签: Python

## 简介

Manage Asyntai AI chatbots as code: websites (AI agents), widget settings, AI instructions, knowledge base items and webhooks.

## 官网

- 官网：https://asyntai.com/documentation/integrations/pulumi/
- 源码仓库：https://github.com/asyntai/pulumi-asyntai
- PyPI 项目页：https://pypi.org/project/pulumi-asyntai/

## 历史版本号

- 当前版本：1.0.1

- 1.0.1

## 获取地址

- pip 安装：`pip install pulumi-asyntai`
- 下载页面：https://pypi.org/project/pulumi-asyntai/#files
- 运行要求：Python >=3.9
