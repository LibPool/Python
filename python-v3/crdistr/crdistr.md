# crdistr

> 标签: Python

## 简介

The normal distribution over NumPy arrays, correctly rounded in binary32, binary16 and bfloat16 (erfinv, erfcinv, probit, ndtr, log_ndtr, normpdf, logit), and samplers with the same bits on every machine; on crnumerics' libcrdist
