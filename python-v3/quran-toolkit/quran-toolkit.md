# quran-toolkit

> 标签: Python

## 简介

Detect, tag, tokenize, diacritize and retrieve Qur'anic quotations inside Arabic/Persian text.

- 官网：https://github.com/asdoost/quran-toolkit
- PyPI 项目页：https://pypi.org/project/quran-toolkit/
