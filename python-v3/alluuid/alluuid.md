# alluuid

> 标签: Python

## 简介

AllUUID is a versatile Python library and cli tool for generating universally unique identifiers (UUIDs). It supports multiple versions of UUIDs, including version 1 (time-based), version 4 (random), and version 7 (timestamp-based). Features an easy-to-use CLI for UUID generation. This tool is ideal for developers looking to create unique identifiers for databases, session tokens, or any other use cases where uniqueness is critical.
