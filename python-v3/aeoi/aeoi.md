# aeoi

> 标签: Python

## 简介

Open toolkit for Automatic Exchange of Information reporting: CRS (OECD XML Schema 2.0/3.0), CARF, FATCA. Swiss ESTV portal first.

## 官网

- 官网：https://github.com/aeoi-com/aeoi
- PyPI 项目页：https://pypi.org/project/aeoi/
