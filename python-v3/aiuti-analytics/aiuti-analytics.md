# aiuti-analytics

> 标签: Python

## 简介

Libreria modulare per l'analisi degli aiuti di stato italiani (OpenData 2014-2025): data-access DuckDB, motore di analisi componibile e agnostico, classificatori pluggable, pipeline, export.

## 官网

- 官网：https://github.com/Vinello28/aiuti-lab
- PyPI 项目页：https://pypi.org/project/aiuti-analytics/
