# aevrin-scanner-core

> 标签: Python

## 简介

Shared scanning engine for Aevrin: models, OWASP MCP Top 10 mapping, scoring, and containerized scanner adapters. Imported by backend/api and backend/cli so findings never drift into different vocabularies.
