# us-places-mcp

> 标签: Python

## 简介

MCP server for where things were, then: which county held a spot on a given date (Newberry county-boundary atlas via OpenHistoricalMap), federal land descriptions and PLSS locations, the route from a land patent to its case file, GNIS place names (with the 2021 archive of cemeteries, churches and schools), historical USGS topographic maps, and US post offices 1639-2000. For genealogy and history.
