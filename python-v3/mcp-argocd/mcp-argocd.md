# mcp-argocd

> 标签: Python

## 简介

Argo CD MCP server for the MCP 2026-07-28 specification (MCP 2.0): application status, sync, rollback, drift, logs, ApplicationSets and clusters for assistants. Runs with writes, or locked read-only via MCP_READ_ONLY
