# liberrex-mcp-server

> 标签: Python

## 简介

Publish a platform's tools on the Liberrex MCP mesh (peer keys, per-call user identity, permissions), plus the Liberrex AI MCP server.

## 官网

- 官网：https://ai.liberrex.com
- PyPI 项目页：https://pypi.org/project/liberrex-mcp-server/
