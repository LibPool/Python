# oteltap

> 标签: Python

## 简介

Embeddable OTLP receiver (http/protobuf format). Listens to all the telemetry on a given HTTP port, then allows you to stream it and await/assert it in tests. Optionally re-emits it to given endpoints. Also optionally prints it as NDJSON into standard output, so that your agents can instantly read, analyze and learn from it.
