# patch-linter

> 标签: Python

## 简介

Static analyzer that forbids unittest.mock.patch and pytest monkeypatch in tests

## 官网

- 官网：https://github.com/pavelmaksimov/patch-linter
- PyPI 项目页：https://pypi.org/project/patch-linter/

- 1.0.0

- 下载页面：https://pypi.org/project/patch-linter/#files
- 运行要求：Python >=3.11
