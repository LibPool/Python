# mcp-ssh-gateway

> 标签: Python

## 简介

MCP server that gives an AI agent real SSH terminals: sessions that return the moment a command ends, scrollable output, prompt and question detection, Keenetic router CLI support.

## 官网

- 官网：https://github.com/d00mus/MCP-SSH
