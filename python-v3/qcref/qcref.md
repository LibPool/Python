# qcref

> 标签: Python

## 简介

Lightweight, dependency-free chemistry reference data (CODATA constants, periodic table, solvents) where every value carries its source.

## 官网

- 官网：https://github.com/atomsforhumanity/qcref
- PyPI 项目页：https://pypi.org/project/qcref/
