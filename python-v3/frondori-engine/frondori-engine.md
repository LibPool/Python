# frondori-engine

> 标签: Python

## 简介

Frondori research environments: the common contract (PettingZoo API), registry, rendering format and contract tests. Environments are installed separately (frondori-football, frondori-kitchen...).

- 源码仓库：https://github.com/Melvin-klein/frondori-engine
