# etims

> 标签: Python

## 简介

Open-source Python client for KRA eTIMS (OSCU): register items and sign invoices and credit notes directly with the Kenya Revenue Authority.

## 官网

- 官网：https://github.com/MutaiT/etims
- PyPI 项目页：https://pypi.org/project/etims/

- 下载页面：https://pypi.org/project/etims/#files
