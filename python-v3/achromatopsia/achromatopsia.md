# achromatopsia

> 标签: Python

## 简介

Simulate total color blindness (achromatopsia / complete monochromacy) — collapse a color or image to WCAG luminance.

## 官网

- 官网：https://opticquiz.com/
- 源码仓库：https://github.com/vince-gonzalez/opticquiz.com
- PyPI 项目页：https://pypi.org/project/achromatopsia/
