# anycfg

> 标签: Python

## 简介

Another Config lib for python, basically load config/yaml/toml/... files and add some features like relative import and templating.

## 官网

- 官网：https://github.com/jose-pr/anycfg/
- PyPI 项目页：https://pypi.org/project/anycfg/
