# livekit-plugins-tts-cache-router

> 标签: Python

## 简介

LiveKit Agents plugin for tts-cache-router, a caching TTS router for Sarvam, Raya, ElevenLabs, OpenAI, Deepgram, xAI, Soniox, Smallest AI, Cartesia and Gemini
