# aevrin-scanner

> 标签: Python

## 简介

Shared scanning engine for Aevrin: models, OWASP MCP Top 10 mapping, scoring, and containerized scanner adapters. Imported by backend/apps/api and backend/apps/cli so findings never drift into different vocabularies.
