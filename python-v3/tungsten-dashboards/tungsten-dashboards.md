# tungsten-dashboards

> 标签: Python

## 简介

Custom dashboards for Tungsten: people build their own dashboards by drag and drop, with widgets from every installed plugin.

## 官网

- 官网：https://tungsten.prisminfoways.com/plugins/dashboards
- 源码仓库：https://github.com/Prism-Infoways/Tungsten
- PyPI 项目页：https://pypi.org/project/tungsten-dashboards/

## 历史版本号

- 0.1.0

## 获取地址

- pip 安装：`pip install tungsten-dashboards`
- 下载页面：https://pypi.org/project/tungsten-dashboards/#files
- 运行要求：Python >=3.10
