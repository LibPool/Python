# Autarkia

> 标签: agent, autarkia, function-calling, llm, role-based-access, self-hosted, tool-governance, tool-registry, tools

## 简介

Tool governance for AI agents: registry, risk levels, role-based access, visibility rules, and execution guards. The tool layer of the Autarkia agent runtime.
