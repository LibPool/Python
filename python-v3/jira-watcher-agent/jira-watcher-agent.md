# jira-watcher-agent

> 标签: Python

## 简介

AI-powered JIRA planner, organizer, and triage CLI. Fetch tickets assigned to you, get an LLM digest by category, and investigate potential resolutions — powered by Claude Code, OpenAI Codex, or Cursor Agent.
