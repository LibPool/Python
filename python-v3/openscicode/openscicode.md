# openscicode

> 标签: Python

## 简介

Open Scientific Code Registry on the command line (the `oscr` command): sign in, link a repository to its paper, trace lines to the paper's Methods, check and cite research code, and work with its GitHub repository. Standard library only.

## 官网

- 官网：https://openscicode.org
- 源码仓库：https://github.com/NeuraCrypt/OSCR
- PyPI 项目页：https://pypi.org/project/openscicode/
