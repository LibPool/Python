# langchain-serpkite

> 标签: Python

## 简介

LangChain integration for SerpKite, the Google search API built for AI agents: tools, a retriever and a webpage loader.

- 官网：https://serpkite.com/integrations/langchain
- 源码仓库：https://github.com/serpkite/langchain-serpkite
- PyPI 项目页：https://pypi.org/project/langchain-serpkite/
