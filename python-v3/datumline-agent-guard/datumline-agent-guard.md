# datumline-agent-guard

> 标签: Python

## 简介

Independent verifier for AI agent completion claims (VERIFIED, FAILED, FALSE_DONE, UNVERIFIABLE): CLI, Python library, MCP server, GitHub Action and LangChain tool.
