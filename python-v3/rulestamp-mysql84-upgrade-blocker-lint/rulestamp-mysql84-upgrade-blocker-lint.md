# rulestamp-mysql84-upgrade-blocker-lint

> 标签: 8.4, extended, lint, migration, mysql, rds, replication, sql, support, upgrade

## 简介

MySQL upgrade 8.0 → 8.4: finds the SQL, my.cnf and parameter-group lines that MySQL 8.4 removed, with the fix on each line (bundled Node.js runtime)
