# trackmod

> 标签: Python

## 简介

Read, write and convert tracker music modules: Impulse Tracker, FastTracker 2, ProTracker, Scream Tracker 3 and Soundtracker

## 官网

- 官网：https://github.com/JakimPL/TrackMod
- PyPI 项目页：https://pypi.org/project/trackmod/

## 历史版本号

- 当前版本：0.2.0

- 0.2.0

## 获取地址

- pip 安装：`pip install trackmod`
- 下载页面：https://pypi.org/project/trackmod/#files
- 运行要求：Python >=3.12
