# styletransfer-lite

> 标签: Python

## 简介

Fast neural style transfer in Python: 26 built-in styles, any painting as a style, CLI, GUI and video. Small install, no TensorFlow or PyTorch.

## 官网

- 官网：https://github.com/Ekaghni/styletransfer-lite
- PyPI 项目页：https://pypi.org/project/styletransfer-lite/
