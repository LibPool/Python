# waqt-api

> 标签: Python

## 简介

Waqt HTTP API v1 — a Makkah-anchored, Maghrib-to-Maghrib civil time and Hijri calendar API, built on the waqt-core computation package.

## 官网

- 官网：https://github.com/waqt-project/waqt-api
- PyPI 项目页：https://pypi.org/project/waqt-api/
