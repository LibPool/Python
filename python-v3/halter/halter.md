# halter

> 标签: Python

## 简介

Audits a change to a Python tree (its tests, changed-line coverage, lint, dead code, public deletions, a red-phase proof and a mutation run) and exits 0 accept, 1 refuse, 2 could not audit, 3 nothing to audit.
