# langchain-fairseal

> 标签: Python

## 简介

LangChain callback handler that notarizes every tool call on FairSeal (on-chain non-repudiation)

## 官网

- 源码仓库：https://github.com/ned-del/fairseal
- PyPI 项目页：https://pypi.org/project/langchain-fairseal/
