# vn-money

> 标签: Python

## 简介

Vietnamese money on integers, because VND has no minor unit. Format, parse, apportion without losing a single dong, and read an amount out in Vietnamese words. Standard library only.

- PyPI 项目页：https://pypi.org/project/vn-money/
