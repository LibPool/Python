# literium

> 标签: Python

## 简介

The lit command-line tool: version control for literary texts, where the atom of change is the sentence (prose) or the line (poetry), not the line of code

## 官网

- 官网：https://literium.org
- 源码仓库：https://gitlab.com/literium/literium-rs
- PyPI 项目页：https://pypi.org/project/literium/
