# lgc-toolkit

> 标签: Python

## 简介

Local Geometric Consistency (LGC) for cross-subject EEG transfer learning: Riemannian aggregation of covariance matrices within recording segments, with unsupervised (RCT + MDM) and calibration-based (TSA-LR) domain adaptation and leave-one-subject-out evaluation.
