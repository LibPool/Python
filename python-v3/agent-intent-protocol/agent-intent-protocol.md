# agent-intent-protocol

> 标签: Python

## 简介

Pay-per-request access for AI agents over the open x402 protocol: 21 intent types that resolve a task to a provider, plus a searchable marketplace of 2,700+ priced API endpoints. Settles on Base or Solana with a single signature, and every receipt verifies offline.
