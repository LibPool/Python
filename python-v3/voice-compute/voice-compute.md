# voice-compute

> 标签: Python

## 简介

Local GPU-accelerated voice compute server with STT (Whisper), TTS (F5/Edge-TTS), and voice conversion.

## 官网

- 官网：https://nouverse.com
- PyPI 项目页：https://pypi.org/project/voice-compute/

## 历史版本号

- 0.1.0

- pip 安装：`pip install voice-compute`
- 下载页面：https://pypi.org/project/voice-compute/#files
- 运行要求：Python >=3.9
