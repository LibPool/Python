# cloudrepo-migrate

> 标签: Python

## 简介

Move a Nexus 2 or Nexus 3 server's Maven and npm repositories into CloudRepo, verifying every file.

## 官网

- 官网：https://www.cloudrepo.io
- PyPI 项目页：https://pypi.org/project/cloudrepo-migrate/

## 历史版本号

- 0.1.0
- 0.2.0

## 获取地址

- pip 安装：`pip install cloudrepo-migrate`
- 下载页面：https://pypi.org/project/cloudrepo-migrate/#files
- 运行要求：Python >=3.8
