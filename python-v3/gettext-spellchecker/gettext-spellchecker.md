# gettext-spellchecker

> 标签: Python

## 简介

Check the spelling of msgid or msgstr strings in gettext .po and .pot files using hunspell dictionaries.

## 官网

- 官网：https://github.com/rgglez/gettext-spellchecker
- PyPI 项目页：https://pypi.org/project/gettext-spellchecker/
