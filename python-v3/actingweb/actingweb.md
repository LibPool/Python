# actingweb

> 标签: Python

## 简介

Python framework for AI-ready, per-user micro-services — per-actor MCP servers, OAuth2, and peer-to-peer data sharing over the ActingWeb REST protocol.

- 官网：https://actingweb.org
- 源码仓库：https://github.com/actingweb/actingweb
- PyPI 项目页：https://pypi.org/project/actingweb/
