# medhaocr

> 标签: Python

## 简介

CPU-only OCR for scanned and digital documents (PDF, JPG, JPEG, PNG) that keeps headings, tables and layout

## 官网

- 官网：https://pypi.org/project/medhaocr/
- PyPI 项目页：https://pypi.org/project/medhaocr/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

- pip 安装：`pip install medhaocr`
- 下载页面：https://pypi.org/project/medhaocr/#files
- 运行要求：Python >=3.10
