# pipxclip

> 标签: Python

## 简介

Generate Markdown context of a git repository and copy it straight to your clipboard, ready to paste into an LLM chat.

## 官网

- 官网：https://github.com/effessdev/pipxclip
- PyPI 项目页：https://pypi.org/project/pipxclip/
