# amp-push

> 标签: Python

## 简介

A small, dependency-light client for pushing metrics to AWS Managed Prometheus (AMP) via SigV4-signed Prometheus remote_write.

## 官网

- 官网：https://github.com/philhendren/amp_push
- PyPI 项目页：https://pypi.org/project/amp-push/
