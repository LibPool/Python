# pyniftireg

> 标签: Python

## 简介

PyTorch reimplementation of NiftyReg-style registration: affine + B-spline stationary velocity fields.

- 官网：https://github.com/lochungtin/pyNiftiReg
- 源码仓库：https://github.com/lochungtin/pyNiftiReg.git
