# rulestamp-docker-hub-pull-limit-lint

> 标签: Python

## 简介

Finds every anonymous Docker Hub pull in GitHub Actions, compose, GitLab CI, Kubernetes and Dockerfiles, including the service containers your login step never covers. Docker Hub limit: 100 pulls per  (bundled Node.js runtime)
