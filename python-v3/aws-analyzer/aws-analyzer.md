# aws-analyzer

> 标签: Python

## 简介

Readable reports on your S3 buckets, DynamoDB tables, Bedrock knowledge bases, SageMaker notebooks, OpenSearch vector indexes and Lambda functions, from a Jupyter notebook: what's there, what it costs, and what to do next. And an agent that answers questions about them in plain English.
