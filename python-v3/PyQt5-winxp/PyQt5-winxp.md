# PyQt5-winxp

> 标签: Python

## 简介

PyQt5 5.15.2 bindings (bundling Qt 5.15.17) rebuilt for 32-bit Windows XP - VC-LTL msvcrt CRT + YY-Thunks, works with R-YaTian's Python 3.7.17 WinXP build

## 官网

- 官网：https://github.com/HIllya51/python3.7_qt5.15_pyqt5_winxp
- PyPI 项目页：https://pypi.org/project/PyQt5-winxp/

- 当前版本：5.15.2.1

- 5.15.2.1

- 下载页面：https://pypi.org/project/PyQt5-winxp/#files
