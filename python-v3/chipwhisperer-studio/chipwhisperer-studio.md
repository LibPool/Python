# chipwhisperer-studio

> 标签: Python

## 简介

Desktop app for ChipWhisperer hardware: live waveforms, capture, CPA, glitch sweeps, UART/SPI/JTAG/SWD interfaces, a logic analyser, firmware code on the power trace, notebooks, firmware builds and an MCP server
