# dataclean-csv

> 标签: Python

## 简介

Dependency-free CSV cleaner and data-quality reporter: normalize headers, drop duplicate rows, fill blanks, and emit a machine-readable JSON report. Standard library only.

## 官网

- 官网：https://github.com/omniforgelabs-dev/csv-cleaner
- PyPI 项目页：https://pypi.org/project/dataclean-csv/
