# pyvisualfx

> 标签: Python

## 简介

Effects for a Pyctures scene, done by the graphics card: kaleidoscopes, glow, trails, blurs, old televisions, glitches and backdrops that need no drawing, each one line to turn on, with settings you can animate and tie to music.
