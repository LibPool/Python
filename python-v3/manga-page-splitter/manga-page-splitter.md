# manga-page-splitter

> 标签: Python

## 简介

Split scanned manga double-page spreads into single pages in right-to-left reading order.

## 官网

- 官网：https://mangatranslator.me
- PyPI 项目页：https://pypi.org/project/manga-page-splitter/

- 1.0.0

## 获取地址

- 下载页面：https://pypi.org/project/manga-page-splitter/#files
- 运行要求：Python >=3.9
