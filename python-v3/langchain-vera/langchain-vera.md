# langchain-vera

> 标签: agents, ai, geo, keyword, langchain, markdown, rag, research, scraping, search, seo, serp, vera, waggle, web

## 简介

LangChain integration for Vera by Waggle: read pages, search the web, results pages, keyword ideas, AI answers, GEO radar, company footprints and a document loader.
