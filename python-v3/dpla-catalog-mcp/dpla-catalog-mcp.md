# dpla-catalog-mcp

> 标签: Python

## 简介

MCP server for the Digital Public Library of America: search descriptions of 50 million digitised items held by US libraries, archives and museums (county atlases, city directories, local histories, photographs), and find the holding institution's record and page images. For genealogy and history.
