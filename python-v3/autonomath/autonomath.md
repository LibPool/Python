# autonomath

> 标签: Python

## 简介

Python SDK for the jpcite API (Japanese institutional data: subsidies, loans, tax rulesets, 採択事例).

## 官网

- 官网：https://jpcite.com
- 源码仓库：https://github.com/shigetosidumeda-cyber/jpintel-mcp
- PyPI 项目页：https://pypi.org/project/autonomath/

## 历史版本号

- 0.1.0

- 下载页面：https://pypi.org/project/autonomath/#files
