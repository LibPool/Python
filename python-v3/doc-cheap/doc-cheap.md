# doc-cheap

> 标签: Python

## 简介

Typed Python client for the doc.cheap document-recognition API: read passports, ID cards and driver's licences into JSON.

## 官网

- 官网：https://doc.cheap
- 源码仓库：https://gitlab.com/doccheap/doc-cheap-python
- PyPI 项目页：https://pypi.org/project/doc-cheap/

- 下载页面：https://pypi.org/project/doc-cheap/#files
