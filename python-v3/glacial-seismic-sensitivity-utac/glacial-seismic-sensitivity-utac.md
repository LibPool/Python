# glacial-seismic-sensitivity-utac

> 标签: Python

## 简介

Does the same seasonal ice/snow unloading trigger more earthquakes over time? Pre-registered sensitivity ('early-stage') tests, distribution/dynamics indicators and a viscoelastic lag/detectability model for seismicity near shrinking glaciers vs. controls -- no UTAC/CREP/AFET bridge
