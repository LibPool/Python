# usb-reverse-tether

> 标签: Python

## 简介

Share a PC's internet with a USB-connected Android phone (reverse tethering over adb, no root) using gnirehtet

## 官网

- 官网：https://github.com/Pandiyarajk/usb-reverse-tether
- PyPI 项目页：https://pypi.org/project/usb-reverse-tether/

- 下载页面：https://pypi.org/project/usb-reverse-tether/#files
