# sphinx-pss

> 标签: Python

## 简介

Sphinx autodoc support for Accellera PSS (Portable Test and Stimulus Standard) source

## 官网

- 官网：https://accellera.org/downloads/standards/portable-stimulus
- 源码仓库：https://github.com/psstools/sphinx-pss
- PyPI 项目页：https://pypi.org/project/sphinx-pss/
