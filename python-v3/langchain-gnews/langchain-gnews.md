# langchain-gnews

> 标签: Python

## 简介

LangChain tools for the GNews API: top headlines by country and category, and news search over an archive since 2020.

## 官网

- 官网：https://gnews.io
- 源码仓库：https://github.com/gnews-io/langchain-gnews
- PyPI 项目页：https://pypi.org/project/langchain-gnews/

- 下载页面：https://pypi.org/project/langchain-gnews/#files
