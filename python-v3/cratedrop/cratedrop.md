# cratedrop

> 标签: Python

## 简介

Headless CDJ USB builder: analyze audio and write Pioneer-native USB sticks (export.pdb + ANLZ) without Rekordbox

## 官网

- 官网：https://github.com/maurycyw/cratedrop
- PyPI 项目页：https://pypi.org/project/cratedrop/
