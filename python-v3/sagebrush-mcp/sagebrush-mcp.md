# sagebrush-mcp

> 标签: Python

## 简介

An MCP server for computational mathematics: number theory, number fields, class groups, modular forms, elliptic curves, exact linear algebra and polynomials, with Sage syntax, for AI agents (Sagebrush; MIT OR Apache-2.0)
