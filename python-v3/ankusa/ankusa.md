# ankusa

> 标签: Python

## 简介

Client SDK for Ankusa deployments. Bundles the claim-check gateway client, the route-management and operator (admin) clients, the source-management client, a webhook-receiving header helper, and the queue-message decoder with its idempotency-key helper; more clients (ingest) land here as they're built.
