# crudecode

> 标签: Python

## 简介

Decline-curve forecast echo and valuation economics for oil & gas wells, run in your own sandbox. Pairs with the Crude Code MCP data server.

- 官网：https://crudecode.dev
- PyPI 项目页：https://pypi.org/project/crudecode/
