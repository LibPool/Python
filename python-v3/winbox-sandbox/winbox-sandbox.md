# winbox-sandbox

> 标签: Python

## 简介

Windows 10/11 应用沙箱:把 Job Object、伪造 C 盘、Dokan 虚拟盘、独立账户、进程内 API 伪装、出口控制与自研 minifilter 逐层叠加,自动选出本机可用的最强后端;纯标准库、随包部署,统一入口是 SandboxManager。
