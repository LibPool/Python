# nuuduu

> 标签: Python

## 简介

Python SDK and CLI for Nuuduu Atlas — sync robotics training datasets (LeRobot, MCAP, HEVC) to your local machine.

## 官网

- 官网：https://nuuduu.ai/atlas
- 源码仓库：https://bitbucket.org/nuuduu/nuuduu
- PyPI 项目页：https://pypi.org/project/nuuduu/
