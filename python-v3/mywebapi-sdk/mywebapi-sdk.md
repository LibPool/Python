# mywebapi-sdk

> 标签: Python

## 简介

Python SDK for CPlugin WebAPI: REST and WebSocket client that works with MetaTrader 4 and MetaTrader 5 servers - accounts, positions, deposits, trade history, groups and symbols for brokers. MetaTrader is a trademark of MetaQuotes Ltd.; not affiliated with MetaQuotes.
