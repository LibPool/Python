# django-admin-loading

> 标签: Python

## 简介

Shows a loading spinner whenever a form is submitted in the Django admin (works with django-unfold).

## 官网

- 官网：https://github.com/cheverebe/django-admin-loading
- PyPI 项目页：https://pypi.org/project/django-admin-loading/
