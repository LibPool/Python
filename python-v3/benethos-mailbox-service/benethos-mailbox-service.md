# benethos-mailbox-service

> 标签: Python

## 简介

Self-hosted REST API and web UI for all your mailboxes (IMAP, JMAP, POP3, Gmail, Microsoft 365, Outlook.com): users, rights and encrypted credentials, a change feed, signed webhooks and an audit.
