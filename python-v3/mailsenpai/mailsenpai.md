# mailsenpai

> 标签: Python

## 简介

Python client for SMTP Senpai by MailSenpai: EU SMTP relay and transactional email API, with a Django email backend and a CrewAI tool.

## 官网

- 官网：https://en.mailsenpai.com/integrations/
- 源码仓库：https://gitlab.com/smtp-senpai/mailsenpai-python
- PyPI 项目页：https://pypi.org/project/mailsenpai/
