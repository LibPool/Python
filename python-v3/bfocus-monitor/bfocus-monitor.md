# bfocus-monitor

> 标签: Python

## 简介

Monitoramento de erros do bFocus para Python: captura os erros não tratados e manda para o bFocus, onde viram demanda.

## 官网

- 官网：https://bfocus.com.br
- 源码仓库：https://github.com/bernisoftware/bfocus-monitor-python
- PyPI 项目页：https://pypi.org/project/bfocus-monitor/

## 获取地址

- pip 安装：`pip install bfocus-monitor`
- 下载页面：https://pypi.org/project/bfocus-monitor/#files
- 运行要求：Python >=3.9
