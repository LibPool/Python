# attest-py

> 标签: Python

## 简介

Rust storage engine for AttestDB — 1.3M claims/sec, LMDB, ~12µs queries. Install with: pip install attestdb attest-py

## 官网

- 官网：https://attestdb.com
- 源码仓库：https://github.com/omic/attest
- PyPI 项目页：https://pypi.org/project/attest-py/
