# gitignore-check

> 标签: Python

## 简介

find tracked files that should be gitignored (junk, build output, secret-looking files). Stdlib only.

- 官网：https://github.com/rafal-one/gitignore-check
- PyPI 项目页：https://pypi.org/project/gitignore-check/
