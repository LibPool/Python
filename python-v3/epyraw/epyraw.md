# epyraw

> 标签: Python

## 简介

Python wrapper for Thermo Fisher RawFileReader library - read .raw mass spectrometry files in Python

## 官网

- 官网：https://pypi.org/project/epyraw/
- PyPI 项目页：https://pypi.org/project/epyraw/

- 0.1.0

- pip 安装：`pip install epyraw`
- 下载页面：https://pypi.org/project/epyraw/#files
- 运行要求：Python >=3.12
