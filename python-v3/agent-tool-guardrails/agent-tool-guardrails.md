# agent-tool-guardrails

> 标签: Python

## 简介

Typed policy rails for agent-tool calls: a policy compiler that turns declarative requirements into executable (Type, Predicate, Evidence, Action) rails, a tamper-evident evidence store, trust-scored governance, and an MCP proxy that enforces it all with zero code changes.
