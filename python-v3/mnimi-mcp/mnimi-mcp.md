# mnimi-mcp

> 标签: Python

## 简介

A stdio MCP server over mnimi: remember, recall, context, export, consolidate; one SQLite file, no server process beyond this one.

## 官网

- 官网：https://github.com/IasonasKokkalos/mnimi
- PyPI 项目页：https://pypi.org/project/mnimi-mcp/
