# langchain-getyoutubetranscript

> 标签: Python

## 简介

YouTube transcript tools and document loader for LangChain: get YouTube video transcripts with timestamps and search YouTube from agents and RAG pipelines, via the GetYouTubeTranscript API.

## 官网

- 官网：https://getyoutubetranscript.com
- 源码仓库：https://github.com/tubeagentkit/langchain-getyoutubetranscript
- PyPI 项目页：https://pypi.org/project/langchain-getyoutubetranscript/
