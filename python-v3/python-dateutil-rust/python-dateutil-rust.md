# python-dateutil-rust

> 标签: Python

## 简介

Pure-Rust dateutil engine: rrule, relativedelta, tz and parser/isoparser with the dateutil interface (rustsmith Stage-1 mirror of dateutil/dateutil)

## 官网

- 官网：https://github.com/dateutil/dateutil
- PyPI 项目页：https://pypi.org/project/python-dateutil-rust/

## 历史版本号

- 当前版本：2.9.0

- 2.9.0

## 获取地址

- pip 安装：`pip install python-dateutil-rust`
- 下载页面：https://pypi.org/project/python-dateutil-rust/#files
- 运行要求：Python <4.0,>=3.9
