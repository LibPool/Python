# jaxbessel

> 标签: Python

## 简介

Differentiable Bessel functions of the first kind in JAX: J_n, spherical j_n and J_nu(x)/x^nu for real order.

- 官网：https://pypi.org/project/jaxbessel/
- PyPI 项目页：https://pypi.org/project/jaxbessel/
