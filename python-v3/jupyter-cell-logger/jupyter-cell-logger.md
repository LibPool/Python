# jupyter-cell-logger

> 标签: Python

## 简介

Jupyter server extension that logs the code of every executed cell to JSONL files under the user's home directory.

## 官网

- 官网：https://pypi.org/project/jupyter-cell-logger/
- PyPI 项目页：https://pypi.org/project/jupyter-cell-logger/

- pip 安装：`pip install jupyter-cell-logger`
- 下载页面：https://pypi.org/project/jupyter-cell-logger/#files
- 运行要求：Python >=3.6
