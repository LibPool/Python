# netbox-macadress

> 标签: Python

## 简介

Enrich NetBox MAC addresses with IEEE vendor data from macadress.com.

## 官网

- 官网：https://macadress.com
- 源码仓库：https://github.com/sapisos/netbox-macadress
- PyPI 项目页：https://pypi.org/project/netbox-macadress/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install netbox-macadress`
- 下载页面：https://pypi.org/project/netbox-macadress/#files
- 运行要求：Python >=3.12.0
