# fwshift

> 标签: Python

## 简介

Converts firewall policies between 25 platforms (PAN-OS, FortiOS, Check Point, Cisco, Juniper, cloud security groups, Linux and more), says rule by rule how faithful the result is, and audits policies against a zone and conduit model
