# sigmabam2openbis

> 标签: Python

## 简介

Mapper script to convert SigmaBAM chemical inventory exports into openBIS-compatible format.

- 官网：https://github.com/BAMresearch/sigmabam2openbis
- PyPI 项目页：https://pypi.org/project/sigmabam2openbis/
