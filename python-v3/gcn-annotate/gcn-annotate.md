# gcn-annotate

> 标签: Python

## 简介

Outil d'annotation de datasets GCN-NL v4.0 — LLM (Anthropic/OpenAI) ou analyse UD structurelle, normalisation vers 8 types D5 et 19 relations causales, équilibrage automatique des quotas par relation
