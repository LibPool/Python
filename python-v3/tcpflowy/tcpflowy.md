# tcpflowy

> 标签: dpi, ids, network-analysis, pcap, suricata, tcp, tshark, wireshark

## 简介

A network capture analysis and DPI/IDS signature discovery tool for isolating TCP streams, correlating DNS/TLS/HTTP metadata, and generating Suricata/Wireshark rules.
