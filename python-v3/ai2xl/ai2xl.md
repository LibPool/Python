# ai2xl

> 标签: Python

## 简介

ai2xl is a free Python library that allows using Excel for ML data preparation, zero dependency ML model deployment, model debugging, model explainability and collaboration.

## 官网

- 官网：https://ai2xl.github.io
- PyPI 项目页：https://pypi.org/project/ai2xl/
