# pdf2zugferd

> 标签: e-invoice, en16931, factur-x, pdf, xrechnung, zugferd

## 简介

Convert invoice PDFs from LibreOffice/MS Office into ZUGFeRD (EN 16931) PDFs

- PyPI 项目页：https://pypi.org/project/pdf2zugferd/

- pip 安装：`pip install pdf2zugferd`
- 下载页面：https://pypi.org/project/pdf2zugferd/#files
