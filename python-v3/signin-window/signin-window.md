# signin-window

> 标签: login, mcp, model-context-protocol, novnc, playwright, remote-browser, sign-in

## 简介

Let a person sign in to a website themselves, from their own browser, in a remote browser window your server runs (noVNC sign-in links for MCP servers and other headless services)
