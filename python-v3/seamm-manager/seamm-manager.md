# seamm-manager

> 标签: Python

## 简介

The manager for SEAMM (Simulation Environment for Atomistic and Molecular Simulations): installs, updates and configures SEAMM in a uv-managed environment.

## 官网

- 官网：https://github.com/molssi-seamm/seamm_manager
- PyPI 项目页：https://pypi.org/project/seamm-manager/
