# mcp-cookidoo

> 标签: Python

## 简介

MCP server for Thermomix & Cookidoo: create recipes with guided cooking (TM6/TM7 modes, Varoma, Turbo), search recipes, plan your week and fill your shopping list

## 官网

- 官网：https://github.com/tobilektri/mcp-cookidoo
- PyPI 项目页：https://pypi.org/project/mcp-cookidoo/

- 1.0.0

- 下载页面：https://pypi.org/project/mcp-cookidoo/#files
