# serp-math

> 标签: Python

## 简介

Serpentine math library: sqrt/sin/cos/tan/log/exp/pow/floor/ceil + pi/e/inf/nan (runtime-backed; delegates to CPython's math when interpreted)

- PyPI 项目页：https://pypi.org/project/serp-math/
