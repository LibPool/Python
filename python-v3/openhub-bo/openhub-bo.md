# openhub-bo

> 标签: Python

## 简介

Clientes para las APIs de cobro de Red Enlace (ATC) OpenHub, Bolivia. Instala solo los productos que necesitas con extras: openhub-bo[qr], openhub-bo[fx], openhub-bo[accounts], openhub-bo[payouts]

## 官网

- 官网：https://github.com/drkpkg/openhub-bo-integration
- PyPI 项目页：https://pypi.org/project/openhub-bo/

## 历史版本号

- 0.1.0

## 获取地址

- pip 安装：`pip install openhub-bo`
- 下载页面：https://pypi.org/project/openhub-bo/#files
- 运行要求：Python >=3.10
