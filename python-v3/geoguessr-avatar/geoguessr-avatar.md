# geoguessr-avatar

> 标签: Python

## 简介

Fetch GeoGuessr avatars, render them in any win/lose/emote animation pose, or export them as 3D models

## 官网

- 官网：https://github.com/vonkoro/geoguessr-avatar
- PyPI 项目页：https://pypi.org/project/geoguessr-avatar/

## 获取地址

- pip 安装：`pip install geoguessr-avatar`
- 下载页面：https://pypi.org/project/geoguessr-avatar/#files
- 运行要求：Python >=3.10
