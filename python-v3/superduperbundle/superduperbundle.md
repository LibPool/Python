# superduperbundle

> 标签: Python

## 简介

Client for the free SuperDuperBundle Game Price API: lowest listed PC game key prices by name, Steam app ID or store URL.

## 官网

- 官网：https://superduperbundle.com/tools/api/
- 源码仓库：https://github.com/superduperbundle/game-price-api
- PyPI 项目页：https://pypi.org/project/superduperbundle/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install superduperbundle`
- 下载页面：https://pypi.org/project/superduperbundle/#files
- 运行要求：Python >=3.9
