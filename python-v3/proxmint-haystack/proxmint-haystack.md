# proxmint-haystack

> 标签: Python

## 简介

Haystack component that fetches web pages through Proxmint residential, datacenter and mobile proxies, with country, city and ASN targeting and sticky sessions.

## 官网

- 官网：https://proxmint.com
- 源码仓库：https://github.com/proxmint/proxmint-haystack
- PyPI 项目页：https://pypi.org/project/proxmint-haystack/
