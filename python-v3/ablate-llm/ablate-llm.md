# ablate-llm

> 标签: Python

## 简介

Directional ablation (abliteration) toolkit for open-source language models: extract, ablate, and optimize the removal of refusal / behavioral directions in the residual stream.

## 官网

- 官网：https://github.com/AIAnytime/ablate
- PyPI 项目页：https://pypi.org/project/ablate-llm/
