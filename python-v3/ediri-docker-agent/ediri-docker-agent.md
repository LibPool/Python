# ediri-docker-agent

> 标签: Python

## 简介

A Pulumi provider for Docker Agent (docker-agent): define AI agent configurations as typed, validated code and share them as OCI artifacts, the same way `docker agent share push` does.

- 官网：https://github.com/dirien/pulumi-docker-agent
