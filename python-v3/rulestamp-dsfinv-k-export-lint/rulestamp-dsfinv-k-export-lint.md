# rulestamp-dsfinv-k-export-lint

> 标签: Python

## 简介

Prüft eine DSFinV-K-CSV gegen die amtliche Spaltenliste, die Wertelisten und die Formate der DSFinV-K 2.4. (bundled Node.js runtime)
