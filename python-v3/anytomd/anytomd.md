# anytomd

> 标签: Python

## 简介

Python binding of anytomd-rs: DOCX, PPTX, XLSX, HTML, CSV, images and more to clean Markdown for LLMs.

## 官网

- 官网：https://github.com/damvolkov/anytomd
- PyPI 项目页：https://pypi.org/project/anytomd/
