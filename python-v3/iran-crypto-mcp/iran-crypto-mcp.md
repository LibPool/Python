> 标签: bitcoin, bitpin, crypto, exir, iran, mcp, model-context-protocol, nobitex, ompfinex, ramzinex, tabdeal, toman, wallex

## 简介

Unofficial read-only MCP server for Iranian crypto exchanges: public prices, order books, trades and candles in Toman.
