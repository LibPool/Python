# artefact-mcp

> 标签: Python

## 简介

The AI-native operational layer for HubSpot. Free tier: 9 tools (5 GTM OS builders + 4 HubSpot audit tools — lifecycle stages, pipeline hygiene, AI readiness, property governance). Pro tier: live HubSpot revenue intelligence (RFM, ICP triangulation, pipeline health) gated by Lemon Squeezy.
