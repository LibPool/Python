# atengk-mcp-server-redis

> 标签: Python

## 简介

基于 Python 与 FastMCP 构建的高性能 Redis 模型上下文协议（MCP）服务。专为大语言模型提供混合命令执行网关、双重写门禁、键值检索、单键多维诊断与大集合防 OOM 截断能力。
