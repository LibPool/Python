# docling-rs-mcp

> 标签: Python

## 简介

MCP server that converts documents to Markdown for AI agents: PDF with layout, tables and OCR, DOCX, PPTX, XLSX, HTML, scans. docling in Rust, MarkItDown's convert_to_markdown tool.

- 官网：https://github.com/docling-project/docling.rs
- PyPI 项目页：https://pypi.org/project/docling-rs-mcp/
