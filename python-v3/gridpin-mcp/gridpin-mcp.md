# gridpin-mcp

> 标签: Python

## 简介

MCP server for offline geocoding with GridPin: addresses to coordinates and back from one local file per country, no API key

## 官网

- 官网：https://gridpin.dev
- 源码仓库：https://github.com/gridpin/gridpin
- PyPI 项目页：https://pypi.org/project/gridpin-mcp/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install gridpin-mcp`
- 下载页面：https://pypi.org/project/gridpin-mcp/#files
- 运行要求：Python >=3.10
