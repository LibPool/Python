# Autarkia-Textkit

> 标签: autarkia, chat, chinese, containment, jaccard, nlp, similarity, text-segmentation

## 简介

Chinese chat text segmentation and set similarity measures: bubble splitting, cleaning, numbered lists, emoji gluing, Markdown span repair, IoMax/containment/Jaccard/ngram.
