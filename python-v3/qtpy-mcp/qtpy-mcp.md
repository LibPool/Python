# qtpy-mcp

> 标签: blender, desktop-automation, gif, houdini, mcp, pyqt, pyside, qt, qt.py, screenshot

## 简介

MCP server to inspect, screenshot, GIF-record and drive Qt apps and DCCs (Houdini, Blender, ...) through Qt.py.

## 官网

- 官网：https://pypi.org/project/qtpy-mcp/
- PyPI 项目页：https://pypi.org/project/qtpy-mcp/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install qtpy-mcp`
- 下载页面：https://pypi.org/project/qtpy-mcp/#files
- 运行要求：Python >=3.10
