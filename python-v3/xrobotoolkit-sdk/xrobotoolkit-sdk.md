# xrobotoolkit-sdk

> 标签: Python

## 简介

Python bindings for the XRoboToolkit PC Service SDK (PICO XR controller, hand, and body tracking).

## 官网

- 官网：https://github.com/XR-Robotics/XRoboToolkit-PC-Service-Pybind
- PyPI 项目页：https://pypi.org/project/xrobotoolkit-sdk/

## 历史版本号

- 当前版本：1.1.0

- 1.1.0

## 获取地址

- pip 安装：`pip install xrobotoolkit-sdk`
- 下载页面：https://pypi.org/project/xrobotoolkit-sdk/#files
- 运行要求：Python >=3.10
