# pyxpo-whiteboard

> 标签: Python

## 简介

A whiteboard with pen, marker, eraser, fill bucket, shapes, undo, redo and PNG export for pyxpo apps.

## 官网

- 官网：https://github.com/pyxpo/pyxpo/tree/main/packages/whiteboard
- PyPI 项目页：https://pypi.org/project/pyxpo-whiteboard/

- 下载页面：https://pypi.org/project/pyxpo-whiteboard/#files
