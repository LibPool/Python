# mujoco-stubs

> 标签: Python

## 简介

An unofficial stub-only package providing type hints for MuJoCo, a physics engine for robotics and biomechanics.

## 官网

- 官网：https://pypi.org/project/mujoco-stubs/
- 源码仓库：https://github.com/horizon-blue/mujoco-stubs
