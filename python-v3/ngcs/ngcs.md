# ngcs

> 标签: Python

## 简介

Quick and simple access to clean images of NGC galaxies (SGA-2020 catalog, Legacy Surveys / Pan-STARRS cutouts, Gaia star removal)

## 官网

- 官网：https://github.com/MickaelRigault/ngcs
- PyPI 项目页：https://pypi.org/project/ngcs/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

- 下载页面：https://pypi.org/project/ngcs/#files
- 运行要求：Python >=3.10
