# buildsweep

> 标签: Python

## 简介

Find and remove regenerable build and dependency folders (node_modules, .venv, target, ...) in old projects.

## 官网

- 官网：https://github.com/tigranmk/buildsweep
- PyPI 项目页：https://pypi.org/project/buildsweep/
