# Adafruit-BME280

> 标签: Python

## 简介

Python code to use the BME280 temperature/humidity/pressure sensor with a Raspberry Pi or BeagleBone black.

## 官网

- 官网：https://github.com/adafruit/Adafruit_Python_BME280
- PyPI 项目页：https://pypi.org/project/Adafruit-BME280/

## 历史版本号

- 当前版本：1.0.1

- 1.0.1

## 获取地址

- pip 安装：`pip install Adafruit-BME280`
- 下载页面：https://pypi.org/project/Adafruit-BME280/#files
