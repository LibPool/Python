# xml-audit-viewer

> 标签: Python

## 简介

Python GUI viewer and live-tail tool for NetApp ONTAP and Huawei OceanStor CIFS Security Audit XML logs — stdlib only, no install.

- 官网：https://github.com/ozdemirumit/XMLAuditViewer
