# boj-exchange-rate

> 标签: Python

## 简介

Official Bank of Japan exchange rates - 1 (USD/JPY spot + central) currencies vs JPY, history since 1998. Keyless, zero-dependency Python client.

- 官网：https://allratestoday.com/central-bank-rates-api/boj/
- 源码仓库：https://github.com/AllRates-Today/exchange-rates-api
