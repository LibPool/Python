# goodrecmovies

> 标签: Python

## 简介

Official client for the goodrecmovies API — every movie above 7.0, ranked by math, not vibes. Ranked lists, title lookup, search, and NLWeb /ask.

## 官网

- 官网：https://goodrecmovies.com
- 源码仓库：https://github.com/0xm0w/goodrecmovies-agents
- PyPI 项目页：https://pypi.org/project/goodrecmovies/
