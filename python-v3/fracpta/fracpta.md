# fracpta

> 标签: Python

## 简介

GeoType catalogues of fractured-reservoir pressure transients: analytic ensembles, GeoDFN networks and descriptors, open-DARTS discrete-fracture simulation, the clustering ladder, conformal assignment and attribution.
