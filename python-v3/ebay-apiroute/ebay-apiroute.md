# ebay-apiroute

> 标签: Python

## 简介

Python clients for eBay's REST and Trading APIs, generated with apiroute from eBay's published API specs.

- 官网：https://github.com/dougyouch/ebay-apiroute
- PyPI 项目页：https://pypi.org/project/ebay-apiroute/

- 0.1.0

- pip 安装：`pip install ebay-apiroute`
- 下载页面：https://pypi.org/project/ebay-apiroute/#files
- 运行要求：Python >=3.10
