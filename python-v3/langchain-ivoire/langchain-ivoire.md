# langchain-ivoire

> 标签: Python

## 简介

LangChain integration for Ivorian languages (Baoulé first): speech recognition, translation, speech synthesis, a language wrapper for any chat model and a voice agent.

## 官网

- 官网：https://github.com/AbyshireAI/langchain-ivoire
- PyPI 项目页：https://pypi.org/project/langchain-ivoire/
