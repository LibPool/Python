# scrapeunblocker-scrapy-middleware

> 标签: Python

## 简介

Scrapy downloader middleware that routes your spider's requests through the ScrapeUnblocker web scraping API - real-browser rendering that gets past Cloudflare, DataDome, PerimeterX and Akamai, with no spider changes.
