# acla-agentic-context-runtime

> 标签: Python

## 简介

ACLA Agentic Context Runtime: persistent project context, a deterministic Context Compiler and governed Mission Working Sets for AI agents, with lifecycle, observation, REST, UI and MCP surfaces.
