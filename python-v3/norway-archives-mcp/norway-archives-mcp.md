# norway-archives-mcp

> 标签: Python

## 简介

MCP server for Norway's National Archives (Digitalarkivet: church books, censuses, emigrant lists and their scans), the National Library's books and newspapers, and Kartverket's place names. Read-only, for genealogy and history.
