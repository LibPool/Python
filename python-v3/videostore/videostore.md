# videostore

> 标签: Python

## 简介

Small, single-window yt-dlp wrapper. Paste, download, close. No memory.

## 官网

- 官网：https://github.com/CallMeBakugo/VideoStore
- PyPI 项目页：https://pypi.org/project/videostore/

- pip 安装：`pip install videostore`
- 下载页面：https://pypi.org/project/videostore/#files
- 运行要求：Python >=3.10
