# mainsheet

> 标签: Python

## 简介

An agent runtime with guardrails: a policy gate at the tool-call boundary, sandboxing, budgets, OpenTelemetry traces, a signed audit trail, and taxonomy-driven evals. Define an agent in one file, run it governed, prove what it did.
