# mcp-chinese-counter

> 标签: Python

## 简介

MCP 服务：统计一段话里的中文字数（不含标点、空格、英文字母、数字）

## 官网

- 官网：https://pypi.org/project/mcp-chinese-counter/
- PyPI 项目页：https://pypi.org/project/mcp-chinese-counter/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install mcp-chinese-counter`
- 下载页面：https://pypi.org/project/mcp-chinese-counter/#files
- 运行要求：Python >=3.11
