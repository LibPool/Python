# cs2-api-client

> 标签: Python

## 简介

CS2 API client: Counter-Strike 2 live scores, match results, player stats, teams, rankings (world + VRS), events and skin prices. Standard library only.

## 官网

- 官网：https://cs2-api.org
- 源码仓库：https://github.com/achillesscriptsvip/cs2-api
- PyPI 项目页：https://pypi.org/project/cs2-api-client/

## 历史版本号

- 1.0.0

## 获取地址

- pip 安装：`pip install cs2-api-client`
- 下载页面：https://pypi.org/project/cs2-api-client/#files
- 运行要求：Python >=3.8
