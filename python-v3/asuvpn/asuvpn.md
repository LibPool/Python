# asuvpn

> 标签: Python

## 简介

GNOME tray applet and CLI for ASU's SSL VPN: openconnect with SSO, a tunnel watchdog, and split DNS that stays put

## 官网

- 官网：https://github.com/Qing-LAB/ASU_VPN_SSO
