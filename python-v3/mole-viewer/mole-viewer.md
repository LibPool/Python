# mole-viewer

> 标签: Python

## 简介

Lightweight viewer for ensembles of molecular structures with an interactive E vs n plot, fast over SSH/X11

## 官网

- 官网：https://github.com/Padalher/MOLE
- PyPI 项目页：https://pypi.org/project/mole-viewer/
