# vishap-analyzer

> 标签: audit-trail, code-review, compliance, deepseek, llm, multi-material, owasp, pii, sarif, sast, sca, security, vishap, vishap-analyzer

## 简介

Vishap - multi-material IT analyst (code, config, spec, logs, data). 6-stage LLM pipeline with SAST/SCA, SARIF 2.1.0, OWASP Top 10, audit trail (SHA-256), provenance, exploitability.
