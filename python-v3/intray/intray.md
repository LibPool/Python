# intray

> 标签: Python

## 简介

An in-tray for AI agents: publish markdown and html documents to a private page the owner reads on the phone, and get back a link.

## 官网

- 官网：https://github.com/thorwhalen/tray
- PyPI 项目页：https://pypi.org/project/intray/
