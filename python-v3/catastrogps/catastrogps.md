# catastrogps

> 标签: Python

## 简介

Official Python client for the Catastro GPS API: parcels from 29 European countries (including the Basque Country and Navarre foral cadastres) by reference, coordinates or address; building units, terrain, ground motion, solar and more

## 官网

- 官网：https://www.parcelgps.com/developers
