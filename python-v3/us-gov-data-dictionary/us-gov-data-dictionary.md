# us-gov-data-dictionary

> 标签: Python

## 简介

Machine-readable data dictionaries for U.S. government datasets (SEC N-PORT, 13F, Forms 3/4/5, Form D, N-MFP, Reg A, N-CEN): official field definitions with citations, code lists and observed values.
