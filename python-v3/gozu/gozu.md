# gozu

> 标签: Python

## 简介

Scan code with a pluggable choice of scanners (currently SonarQube, Trivy, and Semgrep) and auto-create tickets in a pluggable choice of ticket-tracking backends (currently Jira), orchestrated with Temporal.
