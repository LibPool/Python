# djfernet-redux

> 标签: Python

## 简介

Fernet-encrypted Django model fields: a maintained drop-in replacement for djfernet and django-fernet-fields.

## 官网

- 官网：https://github.com/amanjain/djfernet-redux
- PyPI 项目页：https://pypi.org/project/djfernet-redux/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install djfernet-redux`
- 下载页面：https://pypi.org/project/djfernet-redux/#files
- 运行要求：Python >=3.8
