# oak-forecast

> 标签: Python

## 简介

The shared forecasting instrument for the OakQuant platform: overlap-aware evaluation, baseline boards, purged walk-forward, a trials ledger, deflation, and hierarchical partial pooling — domain-free, and held that way by a purity gauge.
