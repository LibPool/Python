# mq-bridge

> 标签: Python

## 简介

Async ETL and messaging engine (Rust core): brokers (Kafka, NATS, AMQP, MQTT), databases incl. Postgres/MongoDB CDC, Parquet on S3/GCS/Azure object storage, HTTP/gRPC.
