# xrdsec

> 标签: Python

## 简介

Grid security and credentials shared by xrdclient, xgfalclient and xrdarc: X.509 and RFC 3820 proxies, delegation profiles, VOMS, bearer tokens, Kerberos, GSI, credential discovery and client TLS
