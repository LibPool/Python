# es-python

> 标签: Python

## 简介

es-python is the EyalSec Python runtime, the best Python security product there is. It installs from your EyalSec dashboard, not from pip; this package points you to it.

## 官网

- 官网：https://eyalsec.com
- 源码仓库：https://github.com/EyalSec/es-python
- PyPI 项目页：https://pypi.org/project/es-python/
