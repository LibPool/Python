# audial-mcp

> 标签: Python

## 简介

MCP server for Audial: stem splitting, mastering, MIDI, music generation, resynthesis and vocal synthesis from any MCP client.

## 官网

- 官网：https://audialmusic.ai
- 源码仓库：https://github.com/AudialAI/audial-mcp
