# navig-browser

> 标签: Python

## 简介

Launch an isolated Chrome/Edge/Brave or Electron app, drive it over CDP, keep named profiles and stop only what it launched — the browser engine navig uses; runs on its own as `navig-browser`.

## 官网

- 官网：https://navig.run
- PyPI 项目页：https://pypi.org/project/navig-browser/
