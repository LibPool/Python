# wavguard

> 标签: audio, riff, validation, wav

## 简介

Strict validator for WAV files: reports truncated, misaligned and inconsistent data chunks instead of silently accepting them.

## 官网

- 官网：https://github.com/perc123/wavguard
- PyPI 项目页：https://pypi.org/project/wavguard/
