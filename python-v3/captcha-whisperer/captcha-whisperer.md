# captcha-whisperer

> 标签: Python

## 简介

Read image-based character captchas with a CRNN + CTC model on ONNX Runtime. No PyTorch, no OpenCV.

## 官网

- 官网：https://github.com/fxaxg/captcha-whisperer
- PyPI 项目页：https://pypi.org/project/captcha-whisperer/
