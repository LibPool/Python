# aidiff-lint

> 标签: Python

## 简介

Static linter for git diffs generated by AI coding agents (Kimi, Aider, Copilot, Cursor, etc.)

- 官网：https://github.com/hyntg/aidiff-lint
- PyPI 项目页：https://pypi.org/project/aidiff-lint/

- 下载页面：https://pypi.org/project/aidiff-lint/#files
