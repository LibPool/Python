# speckify

> 标签: Python

## 简介

Launches the Speckify CLI (a Node package) via npx, so `pip install speckify` works without a separate Node install step for the package manager itself.

## 官网

- 官网：https://github.com/branchLeft/speckify
- PyPI 项目页：https://pypi.org/project/speckify/
