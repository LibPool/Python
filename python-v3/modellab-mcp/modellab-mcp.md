# modellab-mcp

> 标签: Python

## 简介

An MCP server that draws game gun models in Blender from parameters, real parts at real proportions, rigged and animated, and checks each build against a photo of the real gun.

- 官网：https://github.com/hpdkhoa/modellab-mcp
