# napari-kavel

> 标签: Python

## 简介

Generate an AI image from a prompt with Kavel and add it to napari as an image layer. Free tier, no API key needed.

- 官网：https://www.kavel.ai/?utm_source=napari&utm_medium=package
- 源码仓库：https://github.com/hanshs474/napari-kavel
