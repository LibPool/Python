# lope-agent

> 标签: agent, ai, claude, cli, codex, ensemble, gemini, opencode, sprint, validation

## 简介

Multi-CLI validator ensemble for AI work — sprint mode (negotiate/execute/implement/audit), single-shot verbs (ask/review/vote/compare/pipe), declarative graph workflows (flow), natural-language roster management (team), and paste-a-curl onboarding for any AI API. Any AI CLI implements; any AI CLI validates.
