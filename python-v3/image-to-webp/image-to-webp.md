# image-to-webp

> 标签: Python

## 简介

Convert images in almost any format (PNG, JPEG, GIF, TIFF, HEIC, AVIF, RAW, SVG, ...) to WebP.

## 官网

- 官网：https://github.com/stakmi/image-to-webp
- PyPI 项目页：https://pypi.org/project/image-to-webp/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install image-to-webp`
- 下载页面：https://pypi.org/project/image-to-webp/#files
- 运行要求：Python >=3.9
