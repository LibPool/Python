# transcript-studio

> 标签: Python

## 简介

Transcribe any English video (any length) to SRT/TXT/VTT/JSON with speaker labels — 100% local, no cloud.

- 官网：https://pypi.org/project/transcript-studio/
- PyPI 项目页：https://pypi.org/project/transcript-studio/
