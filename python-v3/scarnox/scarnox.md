# scarnox

> 标签: Python

## 简介

Official Python client for the Scarnox captcha-solving API: one call, one token, pay only for successful solves.

## 官网

- 官网：https://solver.scarnox.com
- PyPI 项目页：https://pypi.org/project/scarnox/

- 0.1.0

- 下载页面：https://pypi.org/project/scarnox/#files
- 运行要求：Python >=3.8
