# transcriptout

> 标签: Python

## 简介

Drop-in replacement for youtube-transcript-api that works from servers and clouds. Hosted by TranscriptOut, no proxies to run.

## 官网

- 官网：https://transcriptout.com
- 源码仓库：https://github.com/artemchuikin/youtube-transcript-python
- PyPI 项目页：https://pypi.org/project/transcriptout/
