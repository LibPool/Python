# rbfgpu

> 标签: Python

## 简介

GPU/CPU agnostic Radial Basis Function interpolation (thin plate splines and friends) on top of XuPy.

## 官网

- 官网：https://github.com/pietroferraiuolo/rbfgpu
- PyPI 项目页：https://pypi.org/project/rbfgpu/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install rbfgpu`
- 下载页面：https://pypi.org/project/rbfgpu/#files
- 运行要求：Python >=3.10
