# authring

> 标签: Python

## 简介

Authring is an MCP-driven guardrails system that evaluates code modification proposals based on historical impact, contributor expertise, and production risk assessment. The system utilizes: Astra DB for historical data storage, Unstructured.io for document parsing, Langflow for AI-driven decision-making, Twilio for real-time human validation, and GitHub CLI (gh) for managing patch review links.
