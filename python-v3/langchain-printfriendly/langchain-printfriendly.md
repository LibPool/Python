# langchain-printfriendly

> 标签: Python

## 简介

LangChain integration for the PrintFriendly API: load any web page as clean, ad-free Markdown.

## 官网

- 官网：https://www.printfriendly.com/api
- 源码仓库：https://github.com/printfriendly/langchain-printfriendly
- PyPI 项目页：https://pypi.org/project/langchain-printfriendly/
