# pdfluent-mcp

> 标签: agent, claude, cursor, mcp, model-context-protocol, pdf, pdfluent, rag

## 简介

MCP server for PDFluent: read, search and fill local PDFs from Claude, Cursor, VS Code and other MCP clients. Your documents stay on your machine.

## 官网

- 官网：https://pdfluent.com
- 源码仓库：https://github.com/pdfluent/pdfluent-mcp
- PyPI 项目页：https://pypi.org/project/pdfluent-mcp/
