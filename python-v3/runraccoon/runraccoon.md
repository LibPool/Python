# runraccoon

> 标签: Python

## 简介

Local-only, drop-in replacement for Weights & Biases: same API and file layout, per-epoch and summary plots, and a localhost dashboard. No cloud.

## 官网

- 官网：https://github.com/Gene-Weaver/RunRaccoon
- PyPI 项目页：https://pypi.org/project/runraccoon/
