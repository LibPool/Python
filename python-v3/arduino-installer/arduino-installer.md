# arduino-installer

> 标签: Python

## 简介

Now lib-installer: install embedded C libraries into STM32, Zephyr, ESP-IDF, Arduino and PlatformIO projects

## 官网

- 官网：https://github.com/nimaltd/arduino-installer
- PyPI 项目页：https://pypi.org/project/arduino-installer/

## 获取地址

- pip 安装：`pip install arduino-installer`
- 下载页面：https://pypi.org/project/arduino-installer/#files
- 运行要求：Python >=3.8
