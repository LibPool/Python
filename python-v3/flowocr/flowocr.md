# flowocr

> 标签: Python

## 简介

从视频里抽全部屏幕文字、带起止时间、按区域聚类，导出 SRT / ASS

## 官网

- 官网：https://github.com/caca2331/FlowOCR
- PyPI 项目页：https://pypi.org/project/flowocr/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install flowocr`
- 下载页面：https://pypi.org/project/flowocr/#files
- 运行要求：Python <3.13,>=3.12
