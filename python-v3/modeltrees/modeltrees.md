# modeltrees

> 标签: Python

## 简介

Model-based recursive partitioning (MOB) ported from R's partykit, with negative binomial, safe logit and multinomial node models

- 官网：https://github.com/Shamiri-Institute/modeltrees
- PyPI 项目页：https://pypi.org/project/modeltrees/
