# sloptools

> 标签: Python

## 简介

Deterministic code-quality tools for Python codebases: sloptrace (complexity erosion over git history) and slopmerge (duplicated code to consolidate).

## 官网

- 官网：https://github.com/sjtechdev/sloptools
