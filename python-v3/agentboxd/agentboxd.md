# agentboxd

> 标签: Python

## 简介

Python client for Agentboxd: real email inboxes for AI agents. Send, receive, wait for replies, extract OTP codes and magic links.

- 官网：https://agentboxd.com
- 源码仓库：https://github.com/agentboxd/agentboxd
- PyPI 项目页：https://pypi.org/project/agentboxd/
