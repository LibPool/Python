# pandoc-md-to-docx

> 标签: Python

## 简介

CLI to convert Markdown to Word (.docx) with correct image paths, GFM support, and bundled Pandoc.

## 官网

- 官网：https://github.com/thelifeisstrange/pandoc-md-to-docx
- PyPI 项目页：https://pypi.org/project/pandoc-md-to-docx/
