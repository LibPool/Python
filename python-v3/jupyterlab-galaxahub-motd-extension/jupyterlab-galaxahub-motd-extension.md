# jupyterlab-galaxahub-motd-extension

> 标签: Python

## 简介

JupyterLab extension that shows the GalaxaHub message of the day in a lab tab: the welcome content of the user's groups and the broadcasts sent to the user. Its jupyterlab-galaxahub-motd command line tool prints the message of the day in a terminal
