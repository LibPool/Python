# django-templatetag-renderer

> 标签: Python

## 简介

Динамический рендерер для получения html-кода, возвращаемого шаблонными тегами Django (templatetags).

- 官网：https://github.com/mandalay-rp/django-templatetag-renderer
- PyPI 项目页：https://pypi.org/project/django-templatetag-renderer/

- pip 安装：`pip install django-templatetag-renderer`
- 下载页面：https://pypi.org/project/django-templatetag-renderer/#files
