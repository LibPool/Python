# quackd-huebot

> 标签: Python

## 简介

The Huebot adapter for quackd. Install it as quackd[huebot].

- 官网：https://github.com/rokbenko/quackd
- PyPI 项目页：https://pypi.org/project/quackd-huebot/

- 下载页面：https://pypi.org/project/quackd-huebot/#files
