# anime365

> 标签: Python

## 简介

Python-клиент для API anime365 (smotret-anime.app / anime365.ru): каталог, переводы, видео, аккаунт и загрузка через tus — sync и async на httpx

## 官网

- 官网：https://github.com/ragedrugg/anime365
- PyPI 项目页：https://pypi.org/project/anime365/
