# AEcroscopyWave

> 标签: Python

## 简介

AEcroscopyWave is a cross-platform, modular Python package within the ecosystem of AEcroscopy (Automated Experiments in Microscopy). It provides an API to generate and prepare experiment waveforms to enable reliable microscopy automation workflows.
