# icon-mcp

> 标签: Python

## 简介

MCP server: parametric Lucide icon sets for AI assistants. Search 2000+ icons, style them, batch-export SVG. Fully offline, no API key.

- 官网：https://pypi.org/project/icon-mcp/
- PyPI 项目页：https://pypi.org/project/icon-mcp/
