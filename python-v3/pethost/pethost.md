# pethost

> 标签: Python

## 简介

The Python SDK for Pethost, hosting for Docker Compose projects: deploy, read logs and requests, run commands and move files through its API.

## 官网

- 官网：https://pethost.dev
- 源码仓库：https://github.com/pethost-dev/sdk
- PyPI 项目页：https://pypi.org/project/pethost/
