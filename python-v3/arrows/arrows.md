# arrows

> 标签: Python

## 简介

Universal data wrangling tool built around Apache Arrow, DuckDB, Polars, S3 for efficiently transferring and transforming data between different data sources with pluggable, independently loadable components

- 官网：https://github.com/George-Jiang/arrows
