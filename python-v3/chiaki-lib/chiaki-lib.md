# chiaki-lib

> 标签: Python

## 简介

Low-level pybind11 bindings around chiaki-ng, the PS4/PS5 Remote Play client library

## 官网

- 官网：https://github.com/Rothen/chiaki-lib
- PyPI 项目页：https://pypi.org/project/chiaki-lib/

## 历史版本号

- 0.1.0

## 获取地址

- pip 安装：`pip install chiaki-lib`
- 下载页面：https://pypi.org/project/chiaki-lib/#files
- 运行要求：Python >=3.11
