# rulestamp-dividenden-quellensteuer-lint

> 标签: Python

## 简介

Ausländische Dividenden versteuern ohne Überhang: Die Beispiel CSV mit 10 Dividenden ergibt 8 Findings und 495,00 € Quellensteuer über dem DBA-Satz, davon 120,00 € verfallen (Roche 2022, Frist 2025-12 (bundled Node.js runtime)
