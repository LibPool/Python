# mmd2vsdx

> 标签: Python

## 简介

Convert Mermaid flowcharts into editable Microsoft Visio .vsdx files that match Mermaid's render

## 官网

- 官网：https://github.com/high-frequensy/mmd2vsdx
- PyPI 项目页：https://pypi.org/project/mmd2vsdx/

- pip 安装：`pip install mmd2vsdx`
- 下载页面：https://pypi.org/project/mmd2vsdx/#files
- 运行要求：Python >=3.9
