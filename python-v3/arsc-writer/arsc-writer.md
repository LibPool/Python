# arsc-writer

> 标签: Python

## 简介

A pure-Python library for generating Android resource tables (ARSC) with support for strings, plurals, and styled text.

- 官网：https://github.com/WeblateOrg/arsc-writer
- PyPI 项目页：https://pypi.org/project/arsc-writer/
