# zwave-qr-fix

> 标签: Python

## 简介

Repair malformed Z-Wave SmartStart QR codes that Z-Wave JS rejects (ZW1406), e.g. on Heatit Z-TRM6 thermostats.

## 官网

- 官网：https://github.com/AMThie/zwave-qr-fix
- PyPI 项目页：https://pypi.org/project/zwave-qr-fix/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

- pip 安装：`pip install zwave-qr-fix`
- 下载页面：https://pypi.org/project/zwave-qr-fix/#files
- 运行要求：Python >=3.9
