# pypad-notebook

> 标签: Python

## 简介

Read, write and convert PyPad notebooks (.pypad.py) and Jupyter notebooks (.ipynb).

## 官网

- 官网：https://pypad.dev
- 源码仓库：https://github.com/pypad-dev/pypad
- PyPI 项目页：https://pypi.org/project/pypad-notebook/

- 下载页面：https://pypi.org/project/pypad-notebook/#files
- 运行要求：Python >=3.10
