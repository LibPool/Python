# access-vba

> 标签: Python

## 简介

Edit, export and import Access VBA code from the command line. Thin entry-point wrapper for vba-edit.

## 官网

- 官网：https://github.com/markuskiller/vba-edit
- PyPI 项目页：https://pypi.org/project/access-vba/
