# agento11y-hermes

> 标签: Python

## 简介

Grafana Agent Observability plugin for Hermes Agent. Records LLM calls and tool executions as generations and OTel traces+metrics.

- 官网：https://github.com/grafana/agento11y/tree/main/plugins/hermes
- 源码仓库：https://github.com/grafana/agento11y
