# thinwrap-llm

> 标签: Python

## 简介

Lightweight, SDK-free, zero-dependency Python wrapper for chat completions (with streaming) and embeddings across 18 LLM providers behind one normalized surface.

## 官网

- 官网：https://thinwrap.dev
- 源码仓库：https://github.com/thinwrap/llm-py
- PyPI 项目页：https://pypi.org/project/thinwrap-llm/
