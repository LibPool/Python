# nxr-convert

> 标签: Python

## 简介

Convert Brainstorm MEG/EEG protocols into nxr datastores (SQLite rows + Zarr v3 arrays) for the Cortical Flow desktop app.

## 官网

- 官网：https://corticalflow.app
- 源码仓库：https://github.com/neurodynamics-xr/nxr-convert
- PyPI 项目页：https://pypi.org/project/nxr-convert/
