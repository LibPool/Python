# 32word

> 标签: Python

## 简介

The game engine for 3-2-Word: Solve Wordle in three guesses. Includes standardized response schema (Phase 4.2), custom first guess selection from 32 optimal options (Phase 4.3), remaining words tracking, and comprehensive strategy lookup.
