# pith-mp4

> 标签: Python

## 简介

ISO-BMFF demuxing SDK: ftyp/moov sample tables, stts/stsc/stsz/stco/co64/stss and stsd sample entries via the pith-mp4 Rust cdylib (ctypes, zero-dep)

- PyPI 项目页：https://pypi.org/project/pith-mp4/
