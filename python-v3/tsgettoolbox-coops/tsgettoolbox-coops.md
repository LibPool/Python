# tsgettoolbox-coops

> 标签: Python

## 简介

Plugin for tsgettoolbox to retrieve data from the US National Oceanic and Atmospheric Administration (NOAA) Center for Operational Oceanographic Products and Services (CO-OPS).

## 官网

- 官网：https://pypi.org/project/tsgettoolbox-coops/
- PyPI 项目页：https://pypi.org/project/tsgettoolbox-coops/

## 历史版本号

- 当前版本：27.0.0

- 27.0.0

## 获取地址

- pip 安装：`pip install tsgettoolbox-coops`
- 下载页面：https://pypi.org/project/tsgettoolbox-coops/#files
- 运行要求：Python >=3.10
