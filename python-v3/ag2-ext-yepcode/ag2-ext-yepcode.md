# ag2-ext-yepcode

> 标签: Python

## 简介

An AG2 (formerly Autogen) extension that allows code execution using YepCode's secure serverless runtime

## 官网

- 官网：https://yepcode.io/
- PyPI 项目页：https://pypi.org/project/ag2-ext-yepcode/

- 下载页面：https://pypi.org/project/ag2-ext-yepcode/#files
- 运行要求：Python <3.13,>=3.12
