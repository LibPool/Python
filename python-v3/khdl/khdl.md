# khdl

> 标签: Python

## 简介

Python bindings for KHDL, an experimental new language for hardware design.

- 官网：https://khdl-lang.org/
- 源码仓库：https://github.com/khdl-lang/khdl
- PyPI 项目页：https://pypi.org/project/khdl/

- 下载页面：https://pypi.org/project/khdl/#files
