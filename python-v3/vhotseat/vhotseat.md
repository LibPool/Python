# vhotseat

> 标签: Python

## 简介

Take turns on one GPU: hand it between a local LLM (e.g. Strata, driven by an agent like pi), ComfyUI and any other workload, never interrupting running work.

## 官网

- 官网：https://github.com/wandermyz/vhotseat
- PyPI 项目页：https://pypi.org/project/vhotseat/
