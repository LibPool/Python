# ancilla-live

> 标签: Python

## 简介

Status client for the Ancilla platform. Fetches and renders the current project status from ancilla.live. Installs as the `ancilla` command. Not the Ancilla platform itself.

## 官网

- 官网：https://ancilla.live
- 源码仓库：https://github.com/ancilla-live/ancilla-status-client
- PyPI 项目页：https://pypi.org/project/ancilla-live/

## 历史版本号

- 当前版本：0.0.1

- 0.0.1

## 获取地址

- pip 安装：`pip install ancilla-live`
- 下载页面：https://pypi.org/project/ancilla-live/#files
- 运行要求：Python >=3.9
