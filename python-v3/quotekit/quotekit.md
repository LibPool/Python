# quotekit

> 标签: Python

## 简介

A股/北交所/场内ETF统一行情工具箱: 新浪默认源(五档盘口,逗号分割字段) + 腾讯/mootdx 回退, 统一DataFrame返回, 实时行情/K线(8频度)/股票列表/搜索
