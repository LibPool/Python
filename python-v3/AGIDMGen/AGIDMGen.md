# AGIDMGen

> 标签: Python

## 简介

Generates identity mods (a character's own model, written out as a mod) for 3DMigoto-based anime game mod loaders

## 官网

- 官网：https://github.com/Alex-Au1/Anime-Game-Identity-Mod-Generator
- PyPI 项目页：https://pypi.org/project/AGIDMGen/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install AGIDMGen`
- 下载页面：https://pypi.org/project/AGIDMGen/#files
- 运行要求：Python >=3.9
