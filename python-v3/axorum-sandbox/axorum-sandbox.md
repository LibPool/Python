# axorum-sandbox

> 标签: Python

## 简介

The Axorum sandbox: a world's agent plane on 127.0.0.1, a clock that moves only when a test moves it, and the ledger to assert on.

## 官网

- 官网：https://axorum.com/docs/sandbox
