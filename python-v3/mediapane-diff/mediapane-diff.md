# mediapane-diff

> 标签: diff, difftool, git, images, mediapane, terminal

## 简介

mediapane plugin: compare two images side by side, as a flicker and as a difference heatmap; works as a git difftool.

## 官网

- 官网：https://github.com/hematteo/mediapane
- PyPI 项目页：https://pypi.org/project/mediapane-diff/

- 下载页面：https://pypi.org/project/mediapane-diff/#files
