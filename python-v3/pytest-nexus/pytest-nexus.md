# pytest-nexus

> 标签: Python

## 简介

pytest plugin that sends each run's JUnit XML results to Nexus for Jira.

## 官网

- 官网：https://nexus.resync.nz
- PyPI 项目页：https://pypi.org/project/pytest-nexus/
