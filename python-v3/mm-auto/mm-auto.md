# mm-auto

> 标签: automation, browser, cli, drissionpage, maimai, typer

## 简介

基于 DrissionPage 的脉脉(maimai.cn)自动化工具包：企业搜索、加好友、发消息

- PyPI 项目页：https://pypi.org/project/mm-auto/

- 下载页面：https://pypi.org/project/mm-auto/#files
- 运行要求：Python >=3.8
