# familysearch-mcp

> 标签: Python

## 简介

MCP server for genealogical research on FamilySearch: a historical place gazetteer, indexed record search, page images, and shared-tree reads. Bring your own registered application.

## 官网

- 官网：https://github.com/ianderso/familysearch-mcp
