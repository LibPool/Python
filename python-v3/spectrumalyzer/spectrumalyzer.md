# spectrumalyzer

> 标签: Python

## 简介

Audio-reactive analysis toolkit for motion graphics — real spectral flux beat detection, frequency bands, song sections, and frame-native exports for Remotion, HyperFrames, After Effects, FCPXML and CSV workflows
