# gm-x402-tools

> 标签: Python

## 简介

Pay-per-call tools for AI agents (LangChain, CrewAI, plain Python): crypto safety checks on Base, a web/PDF reader and a cheapest-API finder. Free daily allowance; pay beyond it with x402 (USDC on Base).
