# caeli-data

> 标签: Python

## 简介

Python client of the Caeli data repository API (data.caeli.space): load tables, publish rasters, read the catalogue

## 官网

- 官网：https://data.caeli.space
- PyPI 项目页：https://pypi.org/project/caeli-data/
