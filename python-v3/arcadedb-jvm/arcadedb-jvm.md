# arcadedb-jvm

> 标签: Python

## 简介

ArcadeDB for Python, JVM build: for now installs arcadedb-embedded, the embedded multi-model database with a bundled JRE.

## 官网

- 官网：https://arcadedb.com
- 源码仓库：https://github.com/ArcadeData/arcadedb-python
- PyPI 项目页：https://pypi.org/project/arcadedb-jvm/

## 历史版本号

- 当前版本：0.0.1

- 0.0.1

## 获取地址

- pip 安装：`pip install arcadedb-jvm`
- 下载页面：https://pypi.org/project/arcadedb-jvm/#files
- 运行要求：Python >=3.11
