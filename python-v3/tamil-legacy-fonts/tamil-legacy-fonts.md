# tamil-legacy-fonts

> 标签: Python

## 简介

Convert Bamini and Shree-Lipi legacy (non-Unicode) Tamil font text to Unicode

## 官网

- 官网：https://pypi.org/project/tamil-legacy-fonts/
- 源码仓库：https://github.com/e4c5/tamil-legacy-fonts
- PyPI 项目页：https://pypi.org/project/tamil-legacy-fonts/

- 下载页面：https://pypi.org/project/tamil-legacy-fonts/#files
- 运行要求：Python >=3.10
