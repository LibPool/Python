# gov-gazetteer-mcp

> 标签: Python

## 简介

MCP server for GOV, the Geschichtliches Orts-Verzeichnis of CompGen: find a German or once-Prussian place, its name and civil chain in a given year, the parish and Standesamt that kept its registers, and its dated enclosures for a place tree. For genealogy and history.
