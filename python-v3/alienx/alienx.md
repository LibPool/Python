# alienx

> 标签: Python

## 简介

AlienX: a general fluid solver - rotation/scale-invariant neural operators (AlienX 2D + AlienX 3D) for Darcy flow, Navier-Stokes, MHD, Gross-Pitaevskii and any fluid PDE. Pure architecture - no checkpoints, no weights. Train on your own fields.
