# fastapi-user-manager

> 标签: Python

## 简介

User management for FastAPI with SQLModel: registration, verification, password reset and OAuth accounts, using PASETO tokens.

## 官网

- 官网：https://gitlab.com/Soralsei/user_manager
- PyPI 项目页：https://pypi.org/project/fastapi-user-manager/
