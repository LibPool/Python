# epokio

> 标签: Python

## 简介

Watch, compare, queue and report ML training runs (Ultralytics, Hugging Face, Lightning, Keras, TensorBoard) from a menu bar, tray, terminal or web page.

- 官网：https://github.com/8rulerstar/epokio
