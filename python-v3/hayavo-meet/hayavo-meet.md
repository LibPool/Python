# hayavo-meet

> 标签: Python

## 简介

Official Python SDK for Hayavo Meet, providing real-time communication (RTC) and messaging (RTM) APIs for video conferencing, audio conferencing, screen sharing, chat, rich text messaging, and file sharing.

## 官网

- 官网：https://meet.hayavo.com
- 源码仓库：https://github.com/hayavo/hayavo-meet-python
- PyPI 项目页：https://pypi.org/project/hayavo-meet/
