# aitoolkit-esp32

> 标签: Python

## 简介

Arduino风格的ESP32控制库 - 通过串口控制ESP32，提供完整的Arduino API

## 官网

- 官网：https://github.com/dianx12/aitoolkit-esp32
- PyPI 项目页：https://pypi.org/project/aitoolkit-esp32/

## 历史版本号

- 1.0.0

## 获取地址

- pip 安装：`pip install aitoolkit-esp32`
- 下载页面：https://pypi.org/project/aitoolkit-esp32/#files
- 运行要求：Python >=3.8
