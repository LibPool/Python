# software-intake-gatekeeper

> 标签: Python

## 简介

Local, evidence-first intake checks for third-party apps and binaries: SBOM (Go, Rust, npm, NuGet, Python, Maven), known vulnerabilities, Electron hardening and code-signing changes.
