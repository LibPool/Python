# fetch-hackkit

> 标签: agents, agentverse, asi1, fetch.ai, hackathon, uagents

## 简介

Batteries for Fetch.ai hackathon agents: chat protocol, ASI:One interactive cards, ASI:One LLM + tools, payments, MCP, and Agentverse registration.
