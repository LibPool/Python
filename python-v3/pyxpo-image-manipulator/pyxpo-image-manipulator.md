# pyxpo-image-manipulator

> 标签: Python

## 简介

On-device image processing for pyxpo apps: info, crop, resize, convert, strip metadata, compress under a size.

- 官网：https://github.com/pyxpo/pyxpo/tree/main/packages/image-manipulator
- PyPI 项目页：https://pypi.org/project/pyxpo-image-manipulator/
