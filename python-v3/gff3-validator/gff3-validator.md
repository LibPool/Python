# gff3-validator

> 标签: Python

## 简介

One-stop GFF3 validator: GFF3 1.26 syntax, structure and Sequence Ontology rules, plus optional FAIR-bioHeaders (FHGFF3) header checks

## 官网

- 官网：https://github.com/FAIR-bioHeaders/gff3-validator
- PyPI 项目页：https://pypi.org/project/gff3-validator/
