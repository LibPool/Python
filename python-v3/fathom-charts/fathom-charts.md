# fathom-charts

> 标签: Python

## 简介

Fathom Charts client: real-time order-flow indicator streams (WebSocket) and history (REST), for Python 3.11+ (asyncio).

## 官网

- 官网：https://fathomcharts.com/docs/sdk/python
