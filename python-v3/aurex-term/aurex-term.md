# aurex-term

> 标签: Python

## 简介

Connect your Termux/Linux terminal to spruky.qzz.io/term and access it from any browser.

## 官网

- 官网：https://spruky.qzz.io/term
- PyPI 项目页：https://pypi.org/project/aurex-term/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install aurex-term`
- 下载页面：https://pypi.org/project/aurex-term/#files
- 运行要求：Python >=3.7
