# hodlodds

> 标签: Python

## 简介

Python client for HodlOdds: pay-per-answer crash odds for Solana memecoins over x402 (USDC on Solana or Base).

## 官网

- 官网：https://hodlodds.com
- 源码仓库：https://github.com/hodlodds/hodlodds-sdk
