# gh-download-embedai

> 标签: Python

## 简介

China-friendly GitHub Release downloader: multi-mirror parallel ranged download + sha256, zero external binaries (no aria2/curl/gh/jq). By embedai.com.cn

## 官网

- 官网：https://github.com/zishuowang696/gh-download
- PyPI 项目页：https://pypi.org/project/gh-download-embedai/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install gh-download-embedai`
- 下载页面：https://pypi.org/project/gh-download-embedai/#files
- 运行要求：Python >=3.8
