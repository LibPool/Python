# rulestamp-geg-87-listing-lint

> 标签: Python

## 简介

13 rules over German property-ad HTML: the five mandatory Section 87 GModG fields, the ten-year certificate limit, and the Anlage 10 class band that has to match the kWh value. The bundled broken Leip (bundled Node.js runtime)
