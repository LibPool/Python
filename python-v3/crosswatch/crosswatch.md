# crosswatch

> 标签: data-quality, evals, llm, mcp, observability, opentelemetry

## 简介

Unified observability for DATA and AI products — wraps and composes best-in-class OSS (OpenTelemetry, Great Expectations, Evidently, DeepEval/Ragas) behind one plugin-driven API.
