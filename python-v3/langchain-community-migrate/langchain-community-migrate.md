# langchain-community-migrate

> 标签: Python

## 简介

Unofficial migration helper for the sunset langchain-community: finds every langchain_community import, the standalone package that replaces it, rewrites 1:1 moves and vendors orphaned classes.

## 官网

- 官网：https://github.com/rafal-one/langchain-community-migrate
- PyPI 项目页：https://pypi.org/project/langchain-community-migrate/
