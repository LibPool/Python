# langchain-urlpipe

> 标签: Python

## 简介

LangChain tools, toolkit and document loader for URLpipe: read any web page as Markdown, or get its metadata, data in your own fields, its technologies, console errors or a Lighthouse audit, rendered in real Chrome.
