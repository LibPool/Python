# athena-python-xlsx

> 标签: Python

## 简介

Drop-in replacement for openpyxl that connects to XLSX Studio for real-time collaboration

## 官网

- 官网：https://github.com/xlsx-studio/python-sdk
- PyPI 项目页：https://pypi.org/project/athena-python-xlsx/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

- pip 安装：`pip install athena-python-xlsx`
- 下载页面：https://pypi.org/project/athena-python-xlsx/#files
- 运行要求：Python >=3.10
