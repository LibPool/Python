# abr-brush-importer

> 标签: Python

## 简介

Import Adobe Photoshop .abr brush files into Krita with full dynamics and 17 paint medium modes

## 官网

- 官网：https://github.com/kennethyork/abr_brush_importer
- PyPI 项目页：https://pypi.org/project/abr-brush-importer/
