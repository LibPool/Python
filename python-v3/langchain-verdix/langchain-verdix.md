# langchain-verdix

> 标签: Python

## 简介

LangChain tools: check an EVM address on Base before sending it funds (safe/caution/danger, or a $0.01 lite screen that never says safe). Pays per call via x402 in USDC from your agent's wallet, within caps you set.
