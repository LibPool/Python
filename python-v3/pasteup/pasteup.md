# pasteup

> 标签: Python

## 简介

Turn a folder of clip art into listing images: preview sheets, cover collages and preview videos.

## 官网

- 官网：https://pypi.org/project/pasteup/
- 源码仓库：https://github.com/ftymoshchuk/pasteup
