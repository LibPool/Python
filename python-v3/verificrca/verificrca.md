# verificrca

> 标签: Python

## 简介

SDK Python oficial pentru API-ul verificrca.ro: verificare RCA, ITP, rovinieta si ARR, monitorizarea flotei si webhook-uri de expirare.

## 官网

- 官网：https://www.verificrca.ro/api-acces
- 源码仓库：https://github.com/verificrca/sdk_python
- PyPI 项目页：https://pypi.org/project/verificrca/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install verificrca`
- 下载页面：https://pypi.org/project/verificrca/#files
- 运行要求：Python >=3.10
