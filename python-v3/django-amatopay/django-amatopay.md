# django-amatopay

> 标签: Python

## 简介

Django app that plugs the AmatoPay payment gateway into your project: local models, admin UI, webhook receiver and Django signals, built on the amatopay client library

## 官网

- 官网：https://amatopay.bi
- PyPI 项目页：https://pypi.org/project/django-amatopay/

- 下载页面：https://pypi.org/project/django-amatopay/#files
