# navig-obs

> 标签: Python

## 简介

Control OBS Studio from navig — scenes, sources, streams, recording, studio mode, whole obs-websocket v5 surface — its own navig-obs command, and `navig obs` inside navig.

## 官网

- 官网：https://navig.run
- PyPI 项目页：https://pypi.org/project/navig-obs/

## 历史版本号

- 0.6.0

- pip 安装：`pip install navig-obs`
- 下载页面：https://pypi.org/project/navig-obs/#files
- 运行要求：Python >=3.10
