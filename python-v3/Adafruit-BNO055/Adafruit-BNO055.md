# Adafruit-BNO055

> 标签: Python

## 简介

Library for accessing the Bosch BNO055 absolute orientation sensor on a Raspberry Pi or Beaglebone Black.

## 官网

- 官网：https://github.com/adafruit/Adafruit_Python_BNO055/
- PyPI 项目页：https://pypi.org/project/Adafruit-BNO055/
