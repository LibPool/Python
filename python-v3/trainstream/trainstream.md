# trainstream

> 标签: Python

## 简介

Zero-dependency PyTorch training offload: optimizer, gradients, activations and weights to host RAM, with a memory planner and built-in int8/NF4 quantization.

## 官网

- 官网：https://github.com/johnanishg/TrainStream
