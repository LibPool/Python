# hilspy

> 标签: Python

## 简介

HILS I/O for Python on a Rust core: pluggable transports (SocketCAN, UDP, TCP, serial, in-process, files) and codecs (DBC, FIBEX, SOME/IP, SBF, NMEA, UBX, RTCM, Hesai/Velodyne LiDAR) behind one tiny API
