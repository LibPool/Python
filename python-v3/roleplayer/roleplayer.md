# roleplayer

> 标签: Python

## 简介

融合 D&D 三宝书 / GURPS 4e / CoC 的跑团模拟器：角色构建 + GM 模拟（Oracle）+ 战斗/法术/补给 + 存档重演，纯标准库

## 官网

- 官网：https://gitee.com/siwpan/roleplayer
- PyPI 项目页：https://pypi.org/project/roleplayer/

## 历史版本号

- 当前版本：3.0.1

- 3.0.1

## 获取地址

- pip 安装：`pip install roleplayer`
- 下载页面：https://pypi.org/project/roleplayer/#files
- 运行要求：Python >=3.10
