# aegis-desktop

> 标签: Python

## 简介

AEGIS Desktop, runnable via pip — a thin wrapper that fetches and runs the real npm package through npx. Requires Node.js.

## 官网

- 官网：https://aegiscloud.org
- PyPI 项目页：https://pypi.org/project/aegis-desktop/
