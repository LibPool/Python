# edifabric-x12

> 标签: Python

## 简介

Python bindings for ediFabric Native X12: convert X12 EDI to JSON and back, validate, and generate acknowledgments.

## 官网

- 官网：https://www.edifabric.com/edifabric-native.html
- 源码仓库：https://github.com/EdiFabric/edifabric-python-bindings
- PyPI 项目页：https://pypi.org/project/edifabric-x12/

## 历史版本号

- 当前版本：1.1.1

- 1.1.1

## 获取地址

- pip 安装：`pip install edifabric-x12`
- 下载页面：https://pypi.org/project/edifabric-x12/#files
- 运行要求：Python >=3.8
