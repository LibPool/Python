# cloudme-notify

> 标签: Python

## 简介

Official Python SDK for the CloudMe Notify multi-channel notification API (SMS, Telegram, WhatsApp, Voice, Email, Push).

## 官网

- 官网：https://notify.cloudme.uz
- 源码仓库：https://github.com/Cloudmeuz/notify-python
- PyPI 项目页：https://pypi.org/project/cloudme-notify/

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- pip 安装：`pip install cloudme-notify`
- 下载页面：https://pypi.org/project/cloudme-notify/#files
- 运行要求：Python >=3.9
