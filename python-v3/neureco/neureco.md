# neureco

> 标签: adagos, neureco

## 简介

NeurEco is an ANN (artificial neural network) factory. It generates parsimonious ANN models automatically, using only the learning data provided by the user. The real NeurEco ships from the Adagos package index, not PyPI.

## 官网

- 官网：https://www.adagos.com
- PyPI 项目页：https://pypi.org/project/neureco/
