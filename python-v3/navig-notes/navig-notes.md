# navig-notes

> 标签: Python

## 简介

navig notes -- your web sticky notes on this computer: the NAVIG Dock syncs every note you keep on a page, a site or everywhere, so you can list, search, add and export them from the command line, and NAVIG's Recall can find them (never sent to an AI unless you allow it).

- PyPI 项目页：https://pypi.org/project/navig-notes/
