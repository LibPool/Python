# pgn-postmortem

> 标签: Python

## 简介

Turn a folder of PGN chess games into browsable Markdown post-mortems of every blunder, analyzed locally with Stockfish.

## 官网

- 官网：https://pypi.org/project/pgn-postmortem/
- PyPI 项目页：https://pypi.org/project/pgn-postmortem/

- 下载页面：https://pypi.org/project/pgn-postmortem/#files
