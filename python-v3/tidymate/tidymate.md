# tidymate

> 标签: Python

## 简介

Python file organizer: sort your Downloads folder by type, bulk rename, find duplicates, archive old files and undo anything. Safe preview, no dependencies.

## 官网

- 官网：https://github.com/Anand2k29/TidyMate
- PyPI 项目页：https://pypi.org/project/tidymate/
