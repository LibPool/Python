# apidoc-to-openapi

> 标签: Python

## 简介

A python package which converts apidoc comments in various languages to OpenApi Spec .json files.

## 官网

- 官网：https://github.com/GrahamMThomas/apidoc_to_openapi
- PyPI 项目页：https://pypi.org/project/apidoc-to-openapi/
