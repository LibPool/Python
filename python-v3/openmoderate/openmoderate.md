# openmoderate

> 标签: Python

## 简介

Open-source, self-hosted image and video content moderation (nudity, violence, hate, weapons, drugs...) — a pip-installable alternative to cloud moderation APIs.

## 官网

- 官网：https://github.com/karammm/openmoderate-image-moderation
- PyPI 项目页：https://pypi.org/project/openmoderate/
