# pystdcge

> 标签: CGE, Philippines, VAR, accounting, computable, equilibrium, general, input-output, matrix, social, structural

## 简介

Open-source Python implementation of the IFPRI standard CGE model, validated against IFPRI's GAMS code, with SAM and input-output multipliers, a recursive-dynamic extension and structural VARs
