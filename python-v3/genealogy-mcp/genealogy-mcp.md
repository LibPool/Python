# genealogy-mcp

> 标签: Python

## 简介

Genealogy research toolkit for AI assistants (MCP server): 171 archives and databases (Russia and the former USSR, Europe, Latin America, US), where a province's records are kept today, live search, name variants and Daitch–Mokotoff, Julian/Hebrew/Republican calendars, church feasts, kinship and DNA, evidence checks, a research project that remembers, your own GEDCOM tree read and changed in place without losing anything, GEDCOM import/export.
