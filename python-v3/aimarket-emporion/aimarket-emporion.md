# aimarket-emporion

> 标签: Python

## 简介

EMPORION — public-record facts for agents that trade: EU VAT validity (VIES), legal entities (GLEIF LEI), ECB reference rates, sanctions-list lookups (OFAC, EU, UN), and Bitcoin-anchored timestamps (OpenTimestamps), each answer signed with its sources
