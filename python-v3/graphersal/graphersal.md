# graphersal

> 标签: Python

## 简介

In-memory graph database and traversal engine, queried with Gremlin, with vector search for GraphRAG (Rust engine, no server)

## 官网

- 官网：https://graphersal.dev
- 源码仓库：https://github.com/graphersal/graphersal
