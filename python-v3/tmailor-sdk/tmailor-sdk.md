# tmailor-sdk

> 标签: Python

## 简介

Python SDK for the Tmailor Open API: create temporary email addresses and read incoming messages.

- 源码仓库：https://github.com/tmailor-com/tmailor-python
- PyPI 项目页：https://pypi.org/project/tmailor-sdk/
