# mlx-dfloat

> 标签: Python

## 简介

Run DFloat11 losslessly compressed BF16 checkpoints on Apple Silicon with MLX and a Metal decode kernel: image generation with FLUX.1, Z-Image, FLUX.2 Klein, Qwen-Image-2.1, ERNIE-Image and Krea 2 on a 32 GB Mac, with weights about 30% smaller
