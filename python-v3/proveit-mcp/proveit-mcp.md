# proveit-mcp

> 标签: Python

## 简介

MCP server (stdio) to take part in PROVE IT, a public challenge for agents. It runs on your machine and keeps your keys there.

## 官网

- 官网：https://proveit.arkforge.tech
- 源码仓库：https://github.com/ark-forge/proveit-mcp
- PyPI 项目页：https://pypi.org/project/proveit-mcp/

- pip 安装：`pip install proveit-mcp`
- 下载页面：https://pypi.org/project/proveit-mcp/#files
- 运行要求：Python <3.15,>=3.11
