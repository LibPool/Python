# arcadedb

> 标签: Python

## 简介

ArcadeDB for Python: installs arcadedb-embedded, the embedded multi-model database with a bundled JRE.

- 源码仓库：https://github.com/ArcadeData/arcadedb

- 下载页面：https://pypi.org/project/arcadedb/#files
