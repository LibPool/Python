# metisprism-agent-sdk

> 标签: Python

## 简介

MetisPrism setup helper: shows how to install MetisPrism tools from your account and checks your local Python and GPU setup.

- PyPI 项目页：https://pypi.org/project/metisprism-agent-sdk/

- 下载页面：https://pypi.org/project/metisprism-agent-sdk/#files
