# llama-index-tools-econdash

> 标签: Python

## 简介

LlamaIndex tools and a reader for EconDash time series across ten categories: macroeconomics, financial markets, labor, demographics, real estate, energy, transport, healthcare, education and technology.

- 源码仓库：https://github.com/econdash/econdash-python
