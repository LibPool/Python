# platform-mcp-hub

> 标签: Python

## 简介

MCP servers for 450+ platform APIs (jobs, freelance, ads, e-commerce, messaging, social, sales, trading, market data, automotive) from one evidence-only catalog: one package, one CLI, `platform-mcp-hub serve <id>`.
