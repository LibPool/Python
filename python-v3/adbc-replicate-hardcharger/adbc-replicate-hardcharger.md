# adbc-replicate-hardcharger

> 标签: Python

## 简介

Config-driven ADBC-to-ADBC replication into Hardcharger: stream whole schemas from Oracle, PostgreSQL, Snowflake, DuckDB or Hardcharger, with no data materialised on the client.
