# cvode4py

> 标签: Python

## 简介

A CVODE wrapper for Python with a similar API to scikits-odes but backed by sundials4py

## 官网

- 官网：https://pypi.org/project/cvode4py/
- PyPI 项目页：https://pypi.org/project/cvode4py/

- 下载页面：https://pypi.org/project/cvode4py/#files
- 运行要求：Python >=3.10
