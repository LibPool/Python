# a2y-fef

> 标签: Python

## 简介

此模块实现了一个总线设备管理器。所有被管理的设备使用 Mewtocol 协议通信，作为从机。通常总线类型是 RS485。对内核科技RS485接口的输入输出模块、单轴运动控制模块提供高层次API支持。
