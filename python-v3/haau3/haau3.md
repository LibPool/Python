# haau3

> 标签: Python

## 简介

Python SDK for the haau3 platform API: appointment slots from SMART Scheduling Links publishers, Medicare Advantage and ACA Marketplace plan benefits, medication list reconciliation, RxNorm and LOINC terminology, the CMS National Provider Directory and FHIR Questionnaires, as typed calls.
