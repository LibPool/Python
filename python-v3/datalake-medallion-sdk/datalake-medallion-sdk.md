# datalake-medallion-sdk

> 标签: Python

## 简介

Build and serve multi-tenant medallion data lakes on S3: contract-checked Bronze ingestion, Silver and Gold Iceberg writes and maintenance, and tenant-scoped Parquet/Iceberg reads without Athena. Per-call tenancy, any input (Arrow, Polars, DuckDB, JSON, files), optional PII protection. Rust core, Python API
