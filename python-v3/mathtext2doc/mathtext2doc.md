# mathtext2doc

> 标签: Python

## 简介

把 AI 生成的数学文本快速转成带公式和函数图像的文档图片

- 官网：https://github.com/HelloWorld-b/LaTeX-tool
- PyPI 项目页：https://pypi.org/project/mathtext2doc/

- pip 安装：`pip install mathtext2doc`
- 下载页面：https://pypi.org/project/mathtext2doc/#files
- 运行要求：Python >=3.10
