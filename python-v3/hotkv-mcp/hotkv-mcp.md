# hotkv-mcp

> 标签: Python

## 简介

A Model Context Protocol (MCP) server for HotKV, a RESP2/RESP3-compatible in-memory data store with built-in AI and LLM-serving features. Lets AI agents read and write keys, agent memory, prompts and RAG documents.
