# openbim-ifcx

> 标签: Python

## 简介

Read, write, validate, compose and export (GLB) IFC5 / IFCX files -- Python bindings for the openbim-ifcx Rust crate.

## 官网

- 官网：https://github.com/openbimrs/ifcx
- PyPI 项目页：https://pypi.org/project/openbim-ifcx/
