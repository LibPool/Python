# trystencil-url-tools

> 标签: Python

## 简介

Offline URL builder for TryStencil tattoo generator, try-on, stencil, and idea pages. Not an official SDK.

## 官网

- 官网：https://trystencil.org/
- 源码仓库：https://github.com/bbwdadfg/trystencil-url-tools
- PyPI 项目页：https://pypi.org/project/trystencil-url-tools/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install trystencil-url-tools`
- 下载页面：https://pypi.org/project/trystencil-url-tools/#files
- 运行要求：Python >=3.9
