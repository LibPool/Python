# pdfmd-cli

> 标签: Python

## 简介

One command from Markdown to a good-looking PDF: a Pandoc wrapper with smart defaults, project-file discovery and a multi-engine fallback chain

## 官网

- 官网：https://github.com/aliperdehan/pdfmd
