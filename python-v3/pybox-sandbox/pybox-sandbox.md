# pybox-sandbox

> 标签: Python

## 简介

Run Python you don't trust in a fresh, sealed box on your Mac, and get a receipt for what it did. Works with AI agents over MCP.

## 官网

- 官网：https://ctxnn.github.io/pybox
- 源码仓库：https://github.com/ctxnn/pybox
- PyPI 项目页：https://pypi.org/project/pybox-sandbox/
