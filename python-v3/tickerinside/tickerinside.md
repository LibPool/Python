# tickerinside

> 标签: Python

## 简介

Python client for the free TickerInside API: full holdings of US ETFs and mutual funds with dates and sources, which funds hold a stock, ETF overlap and portfolio look-through. No API key.

## 官网

- 官网：https://tickerinside.com
- PyPI 项目页：https://pypi.org/project/tickerinside/
