# readystack-einvoice-mandate-lint

> 标签: Python

## 简介

Lints UBL and CII invoice XML against EN 16931 and the national e-invoicing mandates that are live in 2026 (bundled Node.js runtime)

## 官网

- 官网：https://getreadystack.com/tools/einvoice-mandate-lint?ref=pypi
