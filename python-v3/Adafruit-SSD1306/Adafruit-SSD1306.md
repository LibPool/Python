# Adafruit-SSD1306

> 标签: Python

## 简介

Python library to use SSD1306-based 128x64 or 128x32 pixel OLED displays with a Raspberry Pi or Beaglebone Black.

## 官网

- 官网：https://github.com/adafruit/Adafruit_Python_SSD1306/
- PyPI 项目页：https://pypi.org/project/Adafruit-SSD1306/
