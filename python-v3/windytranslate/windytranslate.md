# windytranslate

> 标签: Python

## 简介

Find, license-check and run Windstorm Labs' open translation and speech models (windytranslate.com).

## 官网

- 官网：https://windytranslate.com
- 源码仓库：https://github.com/sneakyfree/windytranslate-python
- PyPI 项目页：https://pypi.org/project/windytranslate/

- 下载页面：https://pypi.org/project/windytranslate/#files
- 运行要求：Python >=3.9
