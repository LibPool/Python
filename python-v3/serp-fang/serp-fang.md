# serp-fang

> 标签: Python

## 简介

Fang — Serpentine's httpx-style sync HTTP(S) client: Client/Response/stream, redirects, cookies, auth, forms, JSON, multipart, gzip, streamed downloads (pure Serpentine over serp-socket TLS, dual-runs under CPython)
