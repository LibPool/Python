# mnemo-protocol

> 标签: Python

## 简介

Python client for the Mnemo API: watermark embedding vectors and verify whether a vector was issued to your own account (API key). Import as mnemo_sdk.

## 官网

- 官网：https://www.trymnemo.com
- 源码仓库：https://github.com/MnemoProtocol/mnemo-sdk
- PyPI 项目页：https://pypi.org/project/mnemo-protocol/
