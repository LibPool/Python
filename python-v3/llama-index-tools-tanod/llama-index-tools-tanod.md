# llama-index-tools-tanod

> 标签: Python

## 简介

LlamaIndex tool spec for Tanod: web search, page/PDF/document to Markdown, screenshots, OCR, DNS and email checks, phishing URL check, address risk, contract and package scans for AI agents. Free daily tier, then x402 USDC.
