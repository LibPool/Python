# indiquant-sdk

> 标签: Python

## 简介

Python client for the IndiQuant tournament: sign in, read a round, load its data, validate and submit predictions.

## 官网

- 官网：https://platform.indiquantresearch.in
- PyPI 项目页：https://pypi.org/project/indiquant-sdk/

## 历史版本号

- 当前版本：3.3.5

- 3.3.5

## 获取地址

- pip 安装：`pip install indiquant-sdk`
- 下载页面：https://pypi.org/project/indiquant-sdk/#files
- 运行要求：Python >=3.11
