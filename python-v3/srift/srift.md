# srift

> 标签: Python

## 简介

Decentralized, end-to-end encrypted P2P file transfer, chat and calls: human to human, human to AI agent, and AI agent to AI agent. Send any file as a download link from the CLI, Python or an MCP server; Peerknock for agent-to-agent. No account. Bundles the SRIFT CLI.
