# readystack-nuget-commercial-license-gate

> 标签: Python

## 简介

Flags AutoMapper 15+, MediatR 13+, FluentAssertions 8+, MassTransit 9+ and other NuGet versions past their licence line, with the pin (bundled Node.js runtime)
