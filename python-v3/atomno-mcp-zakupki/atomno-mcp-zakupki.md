# atomno-mcp-zakupki

> 标签: Python

## 简介

MCP-сервер для российских госзакупок (zakupki.gov.ru, 44-ФЗ / 223-ФЗ / 615-ПП): поиск, карточка закупки, карточка организации, справочник ОКПД2.
