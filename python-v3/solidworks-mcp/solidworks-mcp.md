# solidworks-mcp

> 标签: Python

## 简介

MCP server that drives a local SolidWorks instance over COM for parametric part modelling.

## 官网

- 官网：https://github.com/hjbaard/SolidWorks-MCP
- PyPI 项目页：https://pypi.org/project/solidworks-mcp/
