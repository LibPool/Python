# quantx-engine

> 标签: Python

## 简介

Block-sparse tensor-network engine for quantum many-body physics: symmetric DMRG, TDVP and fermionic HVA circuits, with a Python API

## 官网

- 官网：https://github.com/ThisIsBarney/quantx
