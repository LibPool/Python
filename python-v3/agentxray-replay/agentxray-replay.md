# agentxray-replay

> 标签: Python

## 简介

Zero-instrumentation, fully local X-ray for coding-agent sessions: interactive timeline, tool-call tree, token/cost curves and failure highlights in a single shareable HTML file.

## 官网

- 官网：https://github.com/jinlio/agent-xray
- PyPI 项目页：https://pypi.org/project/agentxray-replay/
