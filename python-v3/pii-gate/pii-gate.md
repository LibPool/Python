# pii-gate

> 标签: Python

## 简介

Pre-execution hook for Codex CLI, Claude Code and Gemini CLI that blocks tool calls carrying national IDs, IBANs, card numbers, secrets, upload commands or PII-selecting SQL.

## 官网

- 官网：https://github.com/sdursun1979/pii-gate
- PyPI 项目页：https://pypi.org/project/pii-gate/
