# beam-model

> 标签: Python

## 简介

Probability models of biological sequences such as T cell receptor CDR3s: sequence probabilities, sampling depth, publicness and repertoire comparison, summed over every possible sequence without simulation

- 官网：https://github.com/MuteJester/BEAM
