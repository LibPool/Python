# ExeWatchMCP

> 标签: Python

## 简介

Let your AI agent fix the bugs your users hit. An MCP server that gives Claude Code, Codex and KAI (RAD Studio) the errors, slow operations, metrics and versions your apps report to ExeWatch, so they can find the cause in your code and fix it.
