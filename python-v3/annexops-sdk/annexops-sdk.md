# annexops-sdk

> 标签: Python

## 简介

AnnexOps SDK (Python) — zero-dependency, hash-at-source clients for EU AI Act & GDPR: runtime logging (Article 12), consent receipts (Article 7), and private-database schema discovery for data mapping. Raw content and row values never leave your process.
