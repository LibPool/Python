# annzarro

> 标签: Python

## 简介

Read-only browser viewer for AnnData (zarr, h5ad) built around cell-by-cell and gene-by-gene matrices

## 官网

- 官网：https://github.com/settylab/annzarro
- PyPI 项目页：https://pypi.org/project/annzarro/
