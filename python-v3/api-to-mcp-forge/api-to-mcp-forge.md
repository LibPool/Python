# api-to-mcp-forge

> 标签: Python

## 简介

Turn API documentation (a docs URL, OpenAPI/Swagger, Postman, RAML, WSDL, GraphQL, an HTML page or pasted text) into an MCP server: an evidence-only entry, tested and live-verified, served by platform-mcp-hub. MCP server, CLI and Claude Code plugin.
