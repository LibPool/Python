# csoai-evidence-fabric

> 标签: Python

## 简介

csoai.evidence-event/0.1: one evidence event rendered as OCSF 1.9, OTel gen_ai.evaluation.result, SARIF 2.1.0, in-toto, ECS/HEC and W3C ACR v0.1, with an offline Ed25519 verifier. States, never grades.
