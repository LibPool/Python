# patch-browser

> 标签: Python

## 简介

官方 Chrome / Edge 调试补丁：默认用户数据目录下直连 CDP，并让 JS 的 debugger 语句失效

## 官网

- 官网：https://github.com/DreamXiaoJing/debug-default-profile
- PyPI 项目页：https://pypi.org/project/patch-browser/

## 历史版本号

- 当前版本：0.2.1

- 0.2.1

## 获取地址

- pip 安装：`pip install patch-browser`
- 下载页面：https://pypi.org/project/patch-browser/#files
- 运行要求：Python >=3.11
