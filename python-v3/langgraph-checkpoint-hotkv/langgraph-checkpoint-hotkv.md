# langgraph-checkpoint-hotkv

> 标签: Python

## 简介

LangGraph checkpointer and long-term memory store backed by HotKV, a RESP2/RESP3-compatible in-memory data store with built-in AI and LLM-serving features.

## 官网

- 官网：https://hotkv.com
- 源码仓库：https://github.com/hotkv-ltd/hotkv-langgraph
- PyPI 项目页：https://pypi.org/project/langgraph-checkpoint-hotkv/
