# readystack-angular-removed-api-lint

> 标签: Python

## 简介

32 checks for Angular APIs that were removed or deprecated, plus the support window on your version pin. The bundled legacy fixture — one NgModule file and its spec — returns 34 findings, 9 of them er (bundled Node.js runtime)
