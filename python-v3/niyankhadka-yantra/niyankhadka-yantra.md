# niyankhadka-yantra

> 标签: Python

## 简介

Build Yantra step-by-step diagrams and one-page answers from Python; compiled to single offline HTML files by the Yantra CLI (Node.js >= 20.19).

## 官网

- 官网：https://yantra.nbk.com.np/
