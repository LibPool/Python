# kdeconnect-mcp

> 标签: Python

## 简介

MCP server que expone llamadas, SMS y notificaciones de un movil via KDE Connect, con redaccion de PII (OTP, tarjetas, IBAN, telefonos).

## 官网

- 官网：https://github.com/DaBlitzStein/kdeconnect-mcp
- PyPI 项目页：https://pypi.org/project/kdeconnect-mcp/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install kdeconnect-mcp`
- 下载页面：https://pypi.org/project/kdeconnect-mcp/#files
- 运行要求：Python >=3.11
