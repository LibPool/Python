# devsecure-intelligence

> 标签: Python

## 简介

Python client for the DevSecure Intelligence API: rank CVEs by real-world risk (RPS from CVSS, EPSS and CISA KEV), with the reason for every rank.

## 官网

- 官网：https://intelligence.devsecure.io
- PyPI 项目页：https://pypi.org/project/devsecure-intelligence/
