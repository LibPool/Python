# snakeboot

> 标签: ddd, dependency-injection, django, django-ninja, hexagonal-architecture, spring-boot, transactional, wireup

## 简介

Spring Boot ergonomics for hexagonal Python: @transactional, application events, a component scan and singleton REST controllers on Django Ninja, wired by wireup.
