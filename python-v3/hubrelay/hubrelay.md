# hubrelay

> 标签: Python

## 简介

Self-hosted LLM gateway & relay station, from LAN to the public internet (tunnel-friendly): multi-upstream key pool, downstream tokens, quota & usage accounting, MCP & A2A routing, E2E envelope encryption, one-line Python station setup; OpenAI/Anthropic-compatible (自托管大模型中转站/网关，局域网与公网两用)
