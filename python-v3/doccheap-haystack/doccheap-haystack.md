# doccheap-haystack

> 标签: Python

## 简介

A Haystack component for doc.cheap: read passports, ID cards and driver's licences into documents.

## 官网

- 官网：https://doc.cheap
- 源码仓库：https://gitlab.com/doccheap/doccheap-haystack
- PyPI 项目页：https://pypi.org/project/doccheap-haystack/

- 下载页面：https://pypi.org/project/doccheap-haystack/#files
