# julialang

> 标签: Python

## 简介

Install and switch Julia versions from pip: a tiny wheel plus a GitHub-mirrored copy of the official binaries.

## 官网

- 官网：https://pypi.org/project/julialang/
- 源码仓库：https://github.com/mohammadraziei/julialang
- PyPI 项目页：https://pypi.org/project/julialang/

## 获取地址

- pip 安装：`pip install julialang`
- 下载页面：https://pypi.org/project/julialang/#files
- 运行要求：Python >=3.9
