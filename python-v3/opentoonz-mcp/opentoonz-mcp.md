# opentoonz-mcp

> 标签: 2d-animation, ai, animation, claude, mcp, model-context-protocol, opentoonz

## 简介

MCP server that lets AI assistants animate in OpenToonz: real vector levels, xsheet timing, keyframes, physics and studio-style line work.

- 官网：https://github.com/konkomaji/opentoonz-mcp
