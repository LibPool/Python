# szl-guardrail-receipt

> 标签: Python

## 简介

Thin, dependency-light adapter that wraps any LLM guardrail verdict (Llama-Guard / NeMo-Guardrails / guardrails-ai / your own callable) and emits a signed, hash-chained DSSE decision receipt aligned with SZL's governed-receipt-spec. UNSIGNED-honest fallback; never fabricates a signature, an energy joule, or a Λ 'proven'.
