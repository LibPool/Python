# sympy-poly-rust

> 标签: Python

## 简介

Rust port of the sympy/sympy polys-domain kernel (dense arithmetic over QQ)

## 官网

- 官网：https://github.com/John-Cusack/sympy-rust
- PyPI 项目页：https://pypi.org/project/sympy-poly-rust/

- pip 安装：`pip install sympy-poly-rust`
- 下载页面：https://pypi.org/project/sympy-poly-rust/#files
- 运行要求：Python >=3.9
