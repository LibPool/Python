# Autarkia-Msgqueue

> 标签: at-least-once, autarkia, message-replay, offline-queue, reconnect, ttl, websocket

## 简介

Reliable offline message queue for WebSocket clients: per-type TTL, message-id dedupe, discard-after-elsewhere-delivery, atomic replay, per-user locks and a receiver-side staleness guard.
