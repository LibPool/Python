# shapesoda

> 标签: Python

## 简介

Shapesoda API client: convert raster images into SVG, PDF, EPS or DXF vectors, or a rendered PNG.

## 官网

- 官网：https://shapesoda.com/api
- PyPI 项目页：https://pypi.org/project/shapesoda/
