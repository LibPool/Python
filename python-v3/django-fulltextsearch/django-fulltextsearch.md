# django-fulltextsearch

> 标签: Python

## 简介

Drop-in PostgreSQL full-text search for Django: auto-maintained search_vector, GIN/GiST index, boolean query syntax, admin/DRF/forms integration.

## 官网

- 官网：https://github.com/yasincakirgithub/django-fulltextsearch
- PyPI 项目页：https://pypi.org/project/django-fulltextsearch/
