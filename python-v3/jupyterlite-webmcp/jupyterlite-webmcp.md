# jupyterlite-webmcp

> 标签: Python

## 简介

Expose the live JupyterLite workspace to a compatible browser agent through WebMCP.

- 官网：https://github.com/alliecatowo/jupyterlite-web-mcp
- PyPI 项目页：https://pypi.org/project/jupyterlite-webmcp/
