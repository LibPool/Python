# safesmm

> 标签: Python

## 简介

Dependency-free Python client for the SafeSMM SMM panel API v2 (orders, status, refill, balance).

## 官网

- 官网：https://safesmm.net
- 源码仓库：https://github.com/safesmmnet/safesmm-api-examples
- PyPI 项目页：https://pypi.org/project/safesmm/

- pip 安装：`pip install safesmm`
- 下载页面：https://pypi.org/project/safesmm/#files
- 运行要求：Python >=3.8
