# pakdatakit

> 标签: Python

## 简介

Utilities for Pakistani data: CNIC, phone, IBAN, postal codes, address parsing, Hijri dates, holidays, amounts in words and Raast QR codes

- 官网：https://github.com/chmuzamil/pakdatakit
- PyPI 项目页：https://pypi.org/project/pakdatakit/
