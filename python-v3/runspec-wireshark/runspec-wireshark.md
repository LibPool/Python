# runspec-wireshark

> 标签: mcp, network, packet-capture, pcap, runnable, runspec, troubleshooting, tshark, wireshark

## 简介

Wireshark runnable for runspec — read pcap files with tshark (summary, packets, decoded packets, conversations, followed streams, DNS/HTTP/TLS problems, expert info) and capture, filter, or merge them
