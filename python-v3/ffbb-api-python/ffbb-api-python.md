# ffbb-api-python

> 标签: Python

## 简介

API FFBB (Python SDK) — Client officiel et asynchrone pour l'API de la Fédération Française de BasketBall (clubs, classements, calendriers, scores live).

- 源码仓库：https://github.com/nickdesi/ffbb-data-client
- PyPI 项目页：https://pypi.org/project/ffbb-api-python/
