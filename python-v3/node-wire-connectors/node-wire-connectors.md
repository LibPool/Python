# node-wire-connectors

> 标签: Python

## 简介

Install the Node Wire runtime and all eight official connectors (HTTP, SMTP, Stripe, Slack, Salesforce, Google Drive, Epic and Cerner FHIR) in one step

## 官网

- 官网：https://github.com/AOT-Technologies/node-wire
- PyPI 项目页：https://pypi.org/project/node-wire-connectors/

- 下载页面：https://pypi.org/project/node-wire-connectors/#files
