# evolution-api-mcp

> 标签: Python

## 简介

Operate one Evolution API (WhatsApp) instance from any MCP host: chats, history, sending, groups and configuration.

## 官网

- 官网：https://github.com/singleflo/evolution-api-mcp
- PyPI 项目页：https://pypi.org/project/evolution-api-mcp/

- 下载页面：https://pypi.org/project/evolution-api-mcp/#files
