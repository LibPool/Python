# doconda

> 标签: Python

## 简介

Python SDK for Doconda: generate, review and edit Word, PowerPoint, Excel and PDF documents from AI agents (Amazon Bedrock, Vertex AI, OpenAI, Claude, LangChain).

## 官网

- 官网：https://doconda.com
- PyPI 项目页：https://pypi.org/project/doconda/
