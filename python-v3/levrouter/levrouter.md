# levrouter

> 标签: Python

## 简介

Per-request model routing for LangChain chat models (Anthropic, OpenAI, Gemini, Groq, DeepSeek, Mistral, xAI, Hugging Face), powered by lev from InterfazeAI

## 官网

- 官网：https://github.com/sathyalog/levrouter
- PyPI 项目页：https://pypi.org/project/levrouter/
