# spiflash

> 标签: Python

## 简介

A database of SPI flash chips (JEDEC ids, sizes, erase geometry, features, SFDP tables), merged from flashrom, flashprog, Linux, U-Boot, Dediprog, Rockchip, MediaTek, OpenOCD, openFPGALoader, IMSProg, QEMU and Zephyr.
