# google-ecommerce-mcp

> 标签: Python

## 简介

Multi-client MCP server for online shops: read GA4, Search Console, Merchant Center, Tag Manager, PageSpeed, Google Ads, Meta Ads and ChatGPT Ads, and prepare controlled, human-approved changes (off by default, plan then approve then apply, never tested on a real account).
