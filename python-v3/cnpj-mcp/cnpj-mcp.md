# cnpj-mcp

> 标签: Python

## 简介

MCP server for analytical queries over Brazil's open CNPJ company registry (Receita Federal), DuckDB + Parquet.

## 官网

- 官网：https://pypi.org/project/cnpj-mcp/
- PyPI 项目页：https://pypi.org/project/cnpj-mcp/

## 历史版本号

- 0.1.0

## 获取地址

- pip 安装：`pip install cnpj-mcp`
- 下载页面：https://pypi.org/project/cnpj-mcp/#files
- 运行要求：Python >=3.10
