# adona-market-data

> 标签: Python

## 简介

Client for the adona-robot market-data API: FX and metals OHLC candles from one second to one day, and the live bid and ask over WebSocket.

## 官网

- 官网：https://adona-robot.com/en
- 源码仓库：https://github.com/Adona-Robot/market-data-python
- PyPI 项目页：https://pypi.org/project/adona-market-data/
