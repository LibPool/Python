# inverge-nexus

> 标签: Python

## 简介

Nexus — one Python SDK for all Inverge Nexus services (analytics, logs, errors, feature flags, remote config, realtime, push, surveys, voice). Works in Django, Flask, FastAPI, Celery and plain scripts.
