# senswear-heartrate

> 标签: Python

## 简介

Real-time heart rate, SpO2, pulse waveform and body temperature monitor for SensWear devices.

- PyPI 项目页：https://pypi.org/project/senswear-heartrate/

- 下载页面：https://pypi.org/project/senswear-heartrate/#files
