# scigantic-ucsc

> 标签: Python

## 简介

Read UCSC Genome Browser conservation scores, multiz alignments, TOGA gene annotations and assembly lists straight from UCSC's public S3 bucket, without downloading the files.

## 官网

- 官网：https://scigantic.com
- 源码仓库：https://github.com/Scigantic/scigantic-ucsc
- PyPI 项目页：https://pypi.org/project/scigantic-ucsc/
