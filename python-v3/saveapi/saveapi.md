# saveapi

> 标签: Python

## 简介

Official Python client for saveapi.org — download media from Instagram, TikTok, YouTube, Facebook, X, Pinterest and 7 more platforms with one API.

## 官网

- 官网：https://saveapi.org/
- 源码仓库：https://github.com/akhroruz/saveapi-sdk
- PyPI 项目页：https://pypi.org/project/saveapi/
