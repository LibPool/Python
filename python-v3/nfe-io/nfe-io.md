# nfe-io

> 标签: Python

## 简介

SDK oficial da NFE.io para Python: NFS-e, empresas, certificados, webhooks e consultas de CNPJ, CPF e CEP.

## 官网

- 官网：https://nfe.io
- 源码仓库：https://github.com/nfe/client-python
- PyPI 项目页：https://pypi.org/project/nfe-io/

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- pip 安装：`pip install nfe-io`
- 下载页面：https://pypi.org/project/nfe-io/#files
- 运行要求：Python >=3.10
