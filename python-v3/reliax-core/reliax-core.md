# reliax-core

> 标签: Python

## 简介

Method components of the Reliax reliability envelope: split and Mondrian conformal sets, Venn-Abers brackets, a conformal test martingale, the credibility p-value, the fast-loop evaluator with route trace and certificate reasons, kNN distance, PSI, an error auditor, subjective-logic fusion and calibration opinions. Pure functions, no I/O.
