# anthropic-tokenizer

> 标签: Python

## 简介

Fast local Claude tokenizer (Rust + PyO3). Falls back from Anthropic count_tokens API to embedded BPE tokenizer.

## 官网

- 官网：https://pypi.org/project/anthropic-tokenizer/
- PyPI 项目页：https://pypi.org/project/anthropic-tokenizer/
