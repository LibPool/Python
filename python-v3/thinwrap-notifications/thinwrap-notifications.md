# thinwrap-notifications

> 标签: Python

## 简介

Lightweight, SDK-free, zero-dependency Python wrapper for sending email, SMS, push, and chat across 35 providers behind one normalized surface.

- 官网：https://thinwrap.dev
- 源码仓库：https://github.com/thinwrap/notifications-py
- PyPI 项目页：https://pypi.org/project/thinwrap-notifications/
