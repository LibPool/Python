# openjev-ai

> 标签: Python

## 简介

OpenJev: open-source, local alternative to Jev. Installs wev-ai, the OpenJev decision-model package (import wev).

- 官网：https://github.com/alanhuangyoo/OpenJev
- PyPI 项目页：https://pypi.org/project/openjev-ai/
