# akai-fire-handler

> 标签: Python

## 简介

Control the Akai Fire controller from Python: RGB pads, 128x64 OLED, and all input over MIDI.

- 官网：https://github.com/jamisonx-dev/akai-fire-handler
- PyPI 项目页：https://pypi.org/project/akai-fire-handler/
