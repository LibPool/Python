# ausdataio

> 标签: Python

## 简介

Python SDK + CLI for ausdata.io — the unified API for Australian public data (ABS, RBA, ATO, APRA, AIHW, ASIC, AEMO, WGEA, BOM).

## 官网

- 官网：https://ausdata.io
- 源码仓库：https://github.com/Bigred97/ausdata-py
- PyPI 项目页：https://pypi.org/project/ausdataio/
