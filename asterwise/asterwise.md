# asterwise

> 标签: Python

## 简介

Official Python SDK for the Asterwise API: Vedic and Western astrology, numerology, tarot. 118 endpoints, generated from the OpenAPI document; positions checked against NASA JPL Horizons; MCP server for Claude and Cursor.
