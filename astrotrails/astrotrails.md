# astrotrails

> 标签: Python

## 简介

Tool to generate startrails images by stacking consecutive images of nightsky in jpeg format. Also, astrotrails can create a timelapse video.

## 官网

- 官网：https://pypi.org/project/astrotrails/
- PyPI 项目页：https://pypi.org/project/astrotrails/
