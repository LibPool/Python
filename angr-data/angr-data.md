# angr-data

> 标签: Python

## 简介

Data files (function and type prototype definitions) for angr, released as a separate package so they do not bloat every angr release

## 官网

- 官网：https://angr.io/
- 源码仓库：https://github.com/angr/angr-data
- PyPI 项目页：https://pypi.org/project/angr-data/

## 历史版本号

- 0.1.1

## 获取地址

- pip 安装：`pip install angr-data`
- 下载页面：https://pypi.org/project/angr-data/#files
- 运行要求：Python >=3.12
