# acrcasppi-ml

> 标签: Python

## 简介

A package for predicting protein-protein interaction between CRISPR-associated protein (Cas) and Anti-CRISPR protein (Acr).

## 官网

- 官网：https://github.com/snehaiasri/acrcasppi
- PyPI 项目页：https://pypi.org/project/acrcasppi-ml/

- 下载页面：https://pypi.org/project/acrcasppi-ml/#files
