# 3dRenderPy

> 标签: Python

## 简介

This is an implementation of a ray tracer based on Jamis Buck's The Ray Tracer Challenge. It supports several primitives.

## 官网

- 官网：https://github.com/woes-lynne/3DRenderPy
- PyPI 项目页：https://pypi.org/project/3dRenderPy/

- 下载页面：https://pypi.org/project/3dRenderPy/#files
