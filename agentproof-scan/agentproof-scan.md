# agentproof-scan

> 标签: Python

## 简介

CLI security scanner for AI agents: probes your HTTP endpoint (or scans traces you already have) for leaked secrets and system prompts, including the reasoning channel. Runs keyless with --demo; CI-gating exit codes.
