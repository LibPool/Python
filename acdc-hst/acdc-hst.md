# acdc-hst

> 标签: Python

## 简介

Software to perform an optimized FUV (Far Ultraviolet) dark correction to HST COS data (Hubble Space Telescope Cosmic Origins Spectrograph).

## 官网

- 官网：https://github.com/jotaylor/cos_dark
- PyPI 项目页：https://pypi.org/project/acdc-hst/

## 历史版本号

- 当前版本：1.1

- 1.1

## 获取地址

- pip 安装：`pip install acdc-hst`
- 下载页面：https://pypi.org/project/acdc-hst/#files
- 运行要求：Python >=3.9
