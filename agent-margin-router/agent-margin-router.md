# agent-margin-router

> 标签: Python

## 简介

Official Python SDK for the Agent Margin Router API – one pay-per-call endpoint for web, market, on-chain, DeFi and developer data. Pay with USDC on Base via x402, or use an API key. 3 free calls per wallet.
