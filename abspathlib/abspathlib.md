# abspathlib

> 标签: Python

## 简介

AbsPathLib is a library to manage absolute paths replicating pathlib interface

- 官网：https://github.com/josemvas/abspathlib
- PyPI 项目页：https://pypi.org/project/abspathlib/

- 下载页面：https://pypi.org/project/abspathlib/#files
