# Adafruit_AS726x

> 标签: Python

## 简介

Python library to use the AS726x family of spectral ID sensors with raspberry pi or other linux boards.

## 官网

- 官网：https://github.com/adafruit/Adafruit_AS726x_python/
- PyPI 项目页：https://pypi.org/project/Adafruit_AS726x/
