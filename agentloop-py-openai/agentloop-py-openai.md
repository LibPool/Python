# agentloop-py-openai

> 标签: Python

## 简介

Drop-in OpenAI SDK wrapper for AgentLoop — adds memory retrieval and turn logging to chat.completions.create calls. Supports streaming.

- 官网：https://github.com/martinembon/agentloop-py
