# am1-rs-python

> 标签: Python

## 简介

AM1-family semiempirical methods (AM1, RM1) with a Python-native API and an ASE calculator: energies, analytic gradients, CPHF Hessians, AM1-BCC charges, and periodic boundary conditions with k-points, analytic stress and phonons
