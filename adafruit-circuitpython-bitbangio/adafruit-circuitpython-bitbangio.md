# adafruit-circuitpython-bitbangio

> 标签: Python

## 简介

A library for adding bitbang I2C and SPI to CircuitPython without the built-in bitbangio module

## 官网

- 官网：https://github.com/adafruit/Adafruit_CircuitPython_BitbangIO
- PyPI 项目页：https://pypi.org/project/adafruit-circuitpython-bitbangio/
