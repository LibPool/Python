# ak-apkverify

> 标签: Python

## 简介

Appknox Fork - Jar Signature / APK Signature v2 verify with pure python (support rsa dsa ecdsa).

- 官网：https://github.com/shuxin/apk-signature-verify
- PyPI 项目页：https://pypi.org/project/ak-apkverify/

- 下载页面：https://pypi.org/project/ak-apkverify/#files
