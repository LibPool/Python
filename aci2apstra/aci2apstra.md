# aci2apstra

> 标签: Python

## 简介

A tool for converting an ACI APIC configuration to an Apstra configuration, outputted as a Terraform configuration.

## 官网

- 官网：https://github.com/iamjarvs/Conversion_ACItoAPSTRA
- PyPI 项目页：https://pypi.org/project/aci2apstra/

- 当前版本：0.1.0

- 0.1.0

- pip 安装：`pip install aci2apstra`
- 下载页面：https://pypi.org/project/aci2apstra/#files
- 运行要求：Python >=3.6
