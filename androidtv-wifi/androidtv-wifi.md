# androidtv-wifi

> 标签: Python

## 简介

Fork of androidtv (python-androidtv) that uses adb-shell-wifi to add modern ADB Wi-Fi (TLS) pairing support.

## 官网

- 官网：https://github.com/jasonanovak/python-androidtv
- PyPI 项目页：https://pypi.org/project/androidtv-wifi/
