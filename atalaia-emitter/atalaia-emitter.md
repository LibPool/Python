# atalaia-emitter

> 标签: Python

## 简介

Report your AI agent's runs to a Dypsis Atalaia deployment - one function, one HTTP POST, fire-and-forget. Never raises, never blocks, zero dependencies.

- 官网：https://github.com/dypsis-ai-labs/dypsis-atalaia
